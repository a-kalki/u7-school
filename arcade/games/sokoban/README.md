# Техническое задание: Игра «Сокобан» (Sokoban)

## 1. Описание игры
«Сокобан» — классическая японская головоломка про кладовщика на складе. Игрок перемещается по лабиринту и толкает ящики к целевым клеткам. Тянуть ящики назад нельзя. Если за ящиком находится препятствие (стена или другой ящик), толкать его нельзя (двойная коллизия). Уровень считается пройденным, когда каждый ящик доставлен на целевую точку.

---

## 2. Символы игрового поля
- `#` — стена (непроходимое препятствие);
- ` ` — свободный пол;
- `.` — целевая точка для ящика;
- `$` — ящик на обычном полу;
- `*` — ящик, доставленный на целевую точку;
- `@` — игрок (кладовщик) на обычном полу;
- `+` — игрок, стоящий на целевой точке.

---

## 3. Структура состояния (`State`)

```javascript
{
  level: 1,                 // номер уровня
  width: 8,                 // ширина карты
  height: 7,                // высота карты
  player: { x: 2, y: 2 },   // координаты игрока
  grid: [                   // двумерный массив символов
    ['#', '#', '#', '#', '#'],
    ['#', '@', '$', '.', '#'],
    ['#', '#', '#', '#', '#']
  ],
  movesCount: 0,            // количество сделанных ходов
  pushesCount: 0,           // количество толчков ящиков
  status: 'PLAYING'         // 'PLAYING' | 'WON'
}
```

---

## 4. Контракт функций (`games/sokoban/sokoban.js`)

### `createState(options = {})`
Инициализирует карту уровня из текстовой матрицы по умолчанию или переданного шаблона `map`. Определяет стартовые координаты игрока `@` или `+`.

### `update(state, action)`
Обрабатывает действие `{ type: 'MOVE', direction: 'UP' | 'DOWN' | 'LEFT' | 'RIGHT' }`:
1. Вычисляет целевую клетку игрока: `toX = player.x + dx`, `toY = player.y + dy`.
2. Если `(toX, toY)` — стена (`#`), шаг блокируется.
3. Если `(toX, toY)` — пол (` `) или пустая цель (`.`): игрок перемещается.
4. Если `(toX, toY)` — ящик (`$` или `*`):
   - Вычисляется клетка за ящиком: `boxToX = toX + dx`, `boxToY = toY + dy`.
   - Если за ящиком стена или другой ящик — перемещение запрещено!
   - Если свободно (` ` или `.`) — ящик сдвигается, игрок шагает на освободившееся место, увеличивается счётчик `pushesCount`.
5. Проверяется условие победы: если на поле не осталось незанятых целей и обычных ящиков `$`, статус становится `'WON'`.

### `getView(state)`
Возвращает объект для рендерера `renderGrid`:
```javascript
{
  title: 'Сокобан',
  grid: state.grid,
  score: state.movesCount,
  status: state.status,
  extraInfo: [
    `Толчков ящиков: ${state.pushesCount}`
  ]
}
```
