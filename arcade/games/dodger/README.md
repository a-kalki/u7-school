# Техническое задание: Игра «Космический уворачивальщик» (Space Dodger)

## 1. Описание игры
«Космический уворачивальщик» — динамичная аркадная игра на выживание. Корабль игрока находится в нижней строке экрана и может перемещаться влево и вправо. Сверху непрерывным потоком падают метеориты/астероиды (`●`).

Цель — продержаться как можно дольше, уворачиваясь от падающих космических тел.
Каждый тик времени увеличивает счёт игрока.
При столкновении любого метеорита с кораблём наступает мгновенное поражение (`GAME_OVER`).

---

## 2. Структура состояния (`State`)

```javascript
{
  width: 15,                          // ширина космоса
  height: 12,                         // высота космоса
  playerX: 7,                         // горизонтальная позиция корабля в нижней строке
  asteroids: [                        // массив падающих астероидов
    { x: 3, y: 4 },
    { x: 8, y: 1 }
  ],
  score: 42,                          // количество пережитых тиков / очков выживания
  spawnRate: 0.35,                    // вероятность появления астероида на каждом тике
  status: 'PLAYING'                   // 'PLAYING' | 'GAME_OVER'
}
```

## 3. Контракт функций (`games/dodger/dodger.js`)

### `createState(options = {})`
Инициализирует пустое поле заданного размера (по умолчанию 15×12), корабль по центру нижней строки (`Math.floor(width / 2)`), пустой список астероидов и нулевой счёт.

### `update(state, action)`
- `{ type: 'MOVE', direction: 'LEFT' }` (или `MOVE_LEFT`):
  - Смещает корабль влево `playerX = Math.max(0, playerX - 1)`;
  - Проверяет коллизию с астероидами на новой позиции.
- `{ type: 'MOVE', direction: 'RIGHT' }` (или `MOVE_RIGHT`):
  - Смещает корабль вправо `playerX = Math.min(width - 1, playerX + 1)`;
  - Проверяет коллизию с астероидами на новой позиции.
- `{ type: 'TICK' }`:
  - Если `status !== 'PLAYING'` — состояние не меняется;
  - Сдвигает все астероиды вниз на одну клетку: `y + 1`;
  - Фильтрует астероиды, улетевшие за нижний край (`y < height`);
  - Проверяет коллизию любого астероида с позицией игрока `(playerX, height - 1)`. При совпадении координат возвращает `{ ...state, status: 'GAME_OVER' }`;
  - С вероятностью `spawnRate` добавляет новый астероид в верхней строке `y = 0` на случайном `x`;
  - Увеличивает счёт выживания (`score + 1`).

### `getView(state)`
Формирует матрицу символов для рендерера `renderGrid`:
- Корабль игрока: `'▲'`;
- Астероиды: `'●'`;
- Пустые клетки: `' '`.
В `extraInfo` выводится текущий счёт очков, плотность потока и подсказка по управлению.

## 4. Конфигурация запуска (`games/dodger/run.js`)
- Частота тиков: `tickRateMs: 100` (динамичная скорость 10 кадров/сек);
- Адаптер: `createDirectionAdapter()` (обрабатывает стрелки влево/вправо и клавиши A/D).
