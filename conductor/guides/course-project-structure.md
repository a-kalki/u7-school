# Учебный проект курса fullstack-js — структура

**Назначение:** единое дерево папок, которое **студент** строит у себя по мере прохождения
курса. Это стандарт учебного материала, а не структура этого репозитория: в репозитории меняются
только `*.md` уроков и `*.json` контента.

---

## 1. Принцип

Весь курс — **один растущий проект** в папке `fullstack-js/`. Студент не заводит новую
песочницу на каждый модуль, а дополняет существующую. Дерево растёт от модуля к модулю.

Уровни:

- **корень** `fullstack-js/` — весь проект, портфолио студента;
- **модуль** — `m1-syntax`, `m2-m3-algorithms`, `m4-html-css`, `m5-dom`;
- **тема или проект внутри модуля** — сюда студент кладёт свои материалы и файлы:
  `p1/…p4/` или тематические папки (`big-o/`, `utils/`, `m3-p2-http/`).

Подробности архитектуры конкретного проекта (слои, зависимости, поток вызова) — в материале
соответствующего трека/уроков, а не здесь. Здесь только высокоуровневое описание, какие модули что добавляют и какая общая картина будет.

---

## 2. Как растёт проект по модулям

### Модуль 1. Синтаксис

Студент только начинает: новые инструменты (редактор, `bun`), 4 учебных проекта.
Заводим простейшую раскладку — по папке на проект.

```
fullstack-js/
  m1-syntax/
    p1/  p2/  p3/  p4/
```

### Модуль 2. Алгоритмика: ядро

Студент уже выбрал развитие в программировании — учим «делать правильно».
В корне `fullstack-js/` создаётся git-репозиторий и связывается с удалённым;
в `README.md` студент пишет, что лежит в папках (портфолио). Появляются тематические папки.

```
fullstack-js/
  README.md
  m1-syntax/
  m2-m3-algorithms/
    big-o/
    utils/
      string/
      array/
      object/
```

### Модуль 3. Алгоритмика: прикладное

Первые настоящие проекты — здесь учим слоям и архитектуре. Добавляются бизнес-утилиты,
проект HTTP-сервиса и будущая Аркада.

```
fullstack-js/
  m2-m3-algorithms/
    big-o/
    utils/
      string/  array/  object/
      business/
    m3-p2-http/
    m3-arcade/
```

### Модуль 4. HTML & CSS

Возвращаемся к формату «по папке на проект».

```
fullstack-js/
  m4-html-css/
    p1/  p2/  p3/  p4/
```

### Модуль 5. DOM

```
fullstack-js/
  m5-dom/
```

---

## 3. Сквозные правила

- Корень `fullstack-js/` — один git-репозиторий (с модуля 2), связан с удалённым.
- `README.md` в корне ведётся студентом: что лежит в папках — это портфолио.
- Имена папок — kebab-case; внутри модуля папка = тема или проект.
