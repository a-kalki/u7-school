# План перехода

**Назначение:** порядок треков и правила сосуществования старого и нового кода. Каждый пункт — отдельный трек conductor (создаётся при старте).

---

## 1. Принципы

- **Strangler:** старое и новое работают параллельно; модуль за модулем, `bun run check` зелёный после каждого шага.
- **Переносить и перепроектировать — отдельно.** Сначала механический перенос (поведение не меняется), затем перевод на манифесты. Два риска не смешиваются.
- **Данные в `data/` трогаются только отдельным треком** (D-10), с `bun run backup` и подтверждением Нурболата.

## 2. Порядок треков

| # | Трек | Суть | Исполнитель |
|---|---|---|---|
| 0 | **agents-setup** | промпты `.pi/agents/*`, установка subagent-расширения | orchestrator |
| 1 | **core-dmg** | `Result`, `define*`, `F.*`, `Timestamp`, `*FromManifest`, Aggregate v2 (`Result`, restore/snapshot), `appApi.run`, граф-движок, каркас контрактных тестов, линт-правила ARC/DOM | orchestrator + Нурболат |
| 2 | **domain-package** | создать `@u7-scl/domain`, механически перенести domain-слои контекстов снизу вверх: user (+ `User` из app) → course → questionnaire → stream → wish → peer-review → dossier. Старые пути `@u7-scl/<m>/domain` временно реэкспортируют | migrator (механика) |
| 3 | **golden-wish** | перевести `wish` (1 Ar, 4 UC, 4 ER) на манифесты, `Result`, Policy, entity-правило, Timestamp. Результат — эталон; по нему переписываются скиллы | orchestrator + Нурболат |
| 4 | **stream-student** | первый срез конвейером агентов на сложном агрегате — проверка процесса | агенты |
| 5 | остальные контексты | stream/stream, course, user, questionnaire, peer-review, ... в порядке зависимостей | агенты |
| 6 | **timestamp-data** | пакетная миграция живых данных со строк на числа, удаление «чтения строки» из схем | orchestrator, с подтверждением |
| 7+ | потребители графа | CLI `domain`, doc-gen (Mermaid), http + OPTIONS, mcp | по roadmap |

Треки 1 и 2 независимы и могут идти параллельно.

## 3. Сосуществование

- Старые `UseCase`/`EventReaction`/`Job` и `throw*` работают до миграции своего модуля.
- `appApi.execute` (бросает) и `appApi.run` (`Result`) живут вместе; story переходит на `run` вместе с UC (см. [errors-result.md](./errors-result.md)).
- Схемы с `F.timestamp` читают и ISO-строку, и число, пишут число — данные мигрируют лениво при сохранении до трека 6.
- Старые styleguide-ы (`code_styleguides/`, ddd-скиллы, `arch-boundary-design`) действуют для немигрированного кода; после трека 3 новые скиллы ссылаются на эталон, после трека 5 старые удаляются.

## 4. Критерий завершения перехода

Все контексты в `@u7-scl/domain`, нет реэкспортов в старых пакетах, нет `throw*` для штатных отказов, нет строковых дат, все линт-правила и контрактные тесты из [rules.md](./rules.md) включены как блокирующие.
