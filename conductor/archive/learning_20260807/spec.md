# Трек 5: Контроллер `learning` — «Моя учёба»

**Контекст:** [bot-ui-refactoring.md](../../bot-ui-refactoring.md#трек-5-контроллер-learning--моя-учёба)

## 1. Обзор

Разделить `learning.story.ts` (670 строк, `packages/stream/src/ui/bot/stories/`) на 6 независимых файлов и перенести в новый контроллер `apps/u7-bot/src/controllers/learning/`.

Контроллер доступен **только роли STUDENT** (кнопка «🎓 Моя учёба»).

**Важно:** стори `enroll.ts` находится в контроллере `learning`, но её публичное действие «📝 Записаться» вызывается из `view-stream` (контроллер `streams`) и доступно всем, у кого **нет** роли `STUDENT`. Гость, кандидат, ментор, автор, админ — могут записаться. Студент — нет (пока можно проходить только один курс).

## 2. Функциональные требования

### 2.1. Правило доступа к записи (enroll)

- Кнопка «📝 Записаться» видна в `view-stream` всем, у кого **нет** роли `STUDENT`
- Гость, кандидат, ментор, автор, админ — могут записаться на поток
- Студент — не может (ограничение: один курс за раз)
- Реализуется через `StreamPolicy.canEnroll(actor)` → `!UserPolicy.isStudent(actor)`
- **Нужно исправить** текущую реализацию в `packages/stream/src/domain/stream/policy.ts` (сейчас только `isGuest || isCandidate`)

### 2.2. Разделение на 6 стори

| Файл | Назначение | Строк (оценка) |
|------|-----------|----------------|
| `hub.ts` | Хаб: главное меню обучения, список потоков студента | ~120 |
| `step-view.ts` | Просмотр/прохождение шага (S05a) | ~150 |
| `nav-tree.ts` | Дерево уроков с ✅/▶️/🔒 (S05b) | ~130 |
| `transition.ts` | Завершение урока/проекта/потока (S05c) | ~100 |
| `progress.ts` | Прогресс студента (S06) | ~100 |
| `enroll.ts` | Запись с кодовым словом (S10) | ~70 |

### 2.3. `nav-tree.ts` и `tree-renderer`

- Формирует `TreeNode[]` из `contentSnapshot` + `student.steps`
- Добавляет статусы: ✅ (пройдено), ▶️ (текущее), 🔒 (заблокировано)
- Рендеринг через общий `shared/tree-renderer.ts` (уже создан в Треке 3)

### 2.4. `getAction<T>()` вместо `cbFor()`

- Все кросс-ссылки (`monitor`, `enroll`, `view-stream`) перевести на `uiApp.getAction<T>(name)`
- Кнопка «📝 Записаться» в `view-stream` восстанавливается через `getAction<EnrollActions>('enroll')(streamId)` (сейчас TODO)
