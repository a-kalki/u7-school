# Итоги трека: Программа модуля — drill-down навигация (module-program-nav_20260928)

## 1. Обзор проделанной работы

Трек полностью реализован. В проекте внедрено единое переиспользуемое ядро карточной drill-down навигации по образовательному контенту (`модуль → проект → урок → шаг`) с листанием в пределах текущего уровня (`◀️ / ▶️`), иерархическими заголовками с хлебными крошками (` › `), автонумерацией и строгим контролем лимитов callback_data Telegram (до 64 байт с учётом суффиксов BotTransport).

На единое ядро успешно переведены:
- Студент: экран `📂 Уроки` (S05b) с отображением статусов шагов (`✅`, `▶️`, `🔒`) и доступом к телам только открытых шагов (пройденные + текущий).
- Ментор: экран `📖 Программа модуля` (S03) с полным доступом ко всем телам шагов для чтения (`readOnly`) и скрытием студенческих метрик.
- Зритель / гость: публичный экран `📖 Программа модуля` (S02/S03) со структурой до уроков и заголовков шагов, без кнопок входа в тела шагов.
- Сохранён неизменным флоу активного прохождения `▶️ Продолжить учёбу` (S05a).
- Удалено устаревшее наследие: плоский рендерер дерева уроков (`#formatTreeBody`), длинные простыни и старая строковая пагинация `p2`.

## 2. Реализованные компоненты

### 2.1. Переиспользуемое ядро (`packages/core/src/ui/content-nav/`)
- **`types.ts`**: Типы `NavLevel`, `NavSubItem`, `NavSibling`, `NavContext`, `NavAddress` и парсер/форматер `formatNavAddress`, `parseNavAddress`. Поддержка компактных адресов уровня `<level>:<id>`.
- **`presenter.ts`**: Чистая функция `presentNavLevel` для рендеринга `DialogResponse` (заголовок, хлебные крошки через ` › `, нумерованный список подуровней, кнопки соседства `◀️ Пред.` / `След. ▶️` и кнопка возврата `⬅️ Назад`).
- **`step-render.ts`**: Чистая функция `formatStepBody` с изоляцией pre-блоков MarkdownV2 и поддержкой режимов `'student'`, `'readOnly'` и `'study'`.

### 2.2. Резолверы навигации
- **`student-nav-resolver.ts`** (`apps/u7-bot/src/controllers/learning/`): резолвер `resolveStudentNavLevel` на основе `StreamSnapshot` и `StudentProgress`, вычисляющий доступность шагов и статусы.
- **`stream-nav-resolver.ts`** (`apps/u7-bot/src/controllers/streams/`): резолвер `resolveStreamNavLevel` для ментора и гостя без студенческих статусов.

### 2.3. Контроллеры и Story
- **`nav-tree.ts`**: полная миграция на ядро drill-down, удаление 337 строк legacy-кода.
- **`view-stream.story.ts`** и **`view-stream-mentor.ts`**: интеграция `presentNavLevel` + `resolveStreamNavLevel` в обработчик `handleProgramView`. Проверка прав доступа через `StreamPolicy.canEdit`.
