# Руководство по продукту

## Целевая аудитория
- **Гости (GUEST):** Пользователи, только что начавшие взаимодействие с ботом (например, нажали /start). Имеют минимальный доступ и могут стать подписчиками или выразить желание пройти курс.
- **Подписчики (SUBSCRIBER):** Пользователи, подписанные на Telegram-канал школы. Получают анонсы и могут перейти к подаче заявки.
- **Кандидаты (CANDIDATE):** Пользователи, выразившие желание пройти курс (wish) и подтвердившие его анкетой. Ожидают зачисления в поток.
- **Студенты курса (STUDENT):** Ученики, проходящие обучение, которым требуется доступ к материалам, проверка заданий и прямая связь с менторами.
- **Авторы (AUTHOR):** Создают программу обучения — модули, курсы, уроки, шаги. Не ведут потоки (для преподавания нужна роль MENTOR). Создание контента — прерогатива автора; редактировать может ADMIN или автор.
- **Менторы (MENTOR):** Преподают — создают и ведут потоки (Stream), активируют/завершают обучение, мониторят прогресс студентов. Не авторят программу (для создания контента нужна роль AUTHOR).
- **Администраторы (ADMIN):** Управляют пользователями, заявками и редактируют контент. Не создают модули/курсы/потоки — только редактируют.

## Ключевые функции
- **Желание пройти курс или модуль (wish):** Пользователь выражает желание пройти курс (или конкретный модуль — следующий/повтор после завершения). Курс без анкеты — желание фиксируется мгновенно; курс с анкетой об ожиданиях — желание подтверждается после её заполнения (брошенная анкета отменяет желание); желание на модуль фиксируется мгновенно без анкеты. Желание можно отменить; при зачислении в поток оно реализуется. Бот уведомляет о зачислении и завершении модуля с предложением записи на следующий. Анкеты ведёт модуль questionnaire.
- **Функционал для создания курсов:** Универсальные инструменты и API для авторов и менторов, позволяющие создавать, редактировать и управлять образовательным контентом, основанным на различных источниках.
- **Умный Telegram-помощник (Grammy):** Бот, сопровождающий студентов в процессе обучения на платформе **u7-school**.
- **REST API (Elysia):** Веб-интерфейс / API для взаимодействия базы данных и других сервисов (например, полноценного веб-приложения) с ядром платформы.
- **Консольный интерфейс (CLI):** Быстрый интерактивный интерфейс для управления системой, автоматически строящийся на основе метаданных модулей.
- **Валидация данных (Valibot):** Строгая проверка данных при создании курсов, ответах пользователей и анкетах для обеспечения стабильности платформы.

## Стиль общения
Дружелюбный: бот общается в легкой, располагающей манере, поддерживает диалог и использует эмодзи, создавая комфортную и мотивирующую среду для обучения.
