# Спецификация: Унификация drill-down навигации и хлебных крошек (Курсы, Ментор, Студент)

**Тип:** feature / refactor
**Трек:** `unified-drilldown-nav_20261015`
**Релиз:** `0.3.1` (группа «Drill-down»)
**Зависимости:** `module-program-nav_20260928`, `course-catalog-nav_20260928`

## Обзор

Привести отображение карточек drill-down навигации, хлебных крошек и клавиатур во всех трёх хабах (`Курсы`, `Ментор: Программа модуля`, `Студент: Уроки`) к единому стандарту на базе ядра `presentNavLevel` из `@u7-scl/core/ui`. За основу берётся самый удачный формат из хаба «Курсы» с устранением шероховатостей.

---

## Функциональные требования

### FR-1. Хлебные крошки и активный уровень
- На всех карточках multiline-хлебные крошки строятся по единому правилу.
- **Текущий (последний) сегмент пути всегда выделяется жирным шрифтом:**
  `\n› *Модуль: Базовые алгоритмы и поиск*` или `\n› *Урок: Синтаксис*`.
- На последнем уровне (шаги) вместо безликого «Шаг 1» выводится реальное название шага:
  `\n› *Шаг: Инициализация переменных*`.

### FR-2. Единообразие списков и подсписков в карточке
- В тексте карточки **всегда явно пишется тип уровня и соответствующий эмодзи:**
  - `1. 🏛 *Этап: Синтаксис*`
    `    📦 Модуль: JavaScript Основы`
  - `1. 📁 *Проект: Введение*`
    `    📝 Урок: Переменные и типы`
  - `1. 📄 *Шаг: Инициализация переменных*` (у студента с индикатором статуса: `1. ✅ Шаг: ...` / `1. ▶️ Шаг: ...` / `1. 🔒 Шаг: ...`).
- Исключены разночтения между уровнями (формат `Уровень: Название` строго соблюдается во всех карточках).

### FR-3. Упрощенные кнопки подуровней (без эмодзи и префиксов)
- В inline-кнопках перехода на следующий уровень **убираются эмодзи и служебные префиксы уровня:**
  - Вместо `1. 🏛 Этап: Синтаксис` → `1. Синтаксис`.
  - Вместо `1. 📁 Проект: Введение` → `1. Введение`.
  - Вместо `1. 📝 Урок: Переменные` → `1. Переменные`.
- Номер кнопки строго совпадает с номером в списке карточки.

### FR-4. Стандартизация эмодзи сущностей
Единый словарь эмодзи во всех хабах:
- 📚 **Курс**
- 🏛 **Этап**
- 📦 **Модуль**
- 📁 **Проект**
- 📝 **Урок**
- 📄 **Шаг** (у студента: ✅ / ▶️ / 🔒)

### FR-5. Унификация хаба Ментора («Программа модуля»)
- Перевести программу модуля у ментора в потоке на единый карточный drill-down формат из хаба «Курсы»:
  - multiline-хлебные крошки с жирным активным уровнем;
  - пояснения («Модуль состоит из N проектов», «Проект состоит из N уроков»);
  - идентичный стиль списков и отступов.

### FR-6. Унификация хаба Студента («Уроки»)
- Привести карточки студента к тому же формату представления, с сохранением студенческой специфики:
  - статусы доступности (✅ пройден, ▶️ текущий, 🔒 заблокирован);
  - показ тела пройденных и текущего шагов.

### FR-7. Единый Presentation Layer
- Централизовать всю логику рендеринга текста карточек, хлебных крошек и клавиатур в `@u7-scl/core/ui` (`presentNavLevel` / `presenter.ts`).
- Резолверы (`course-nav-resolver`, `stream-nav-resolver`, `student-nav-resolver`) возвращают строго нормализованный `NavLevel`.

---

## Критерии приёмки
- Все три хаба («Курсы», Ментор, Студент) имеют одинаковый визуальный язык карточек и хлебных крошек.
- Последний уровень в крошках всегда жирный.
- Шаг именуется настоящим названием (`› *Шаг: ...*`).
- Кнопки компактные (`1. Название`), карточки подробные (`1. 📁 *Проект: Название*`).
- Тесты на Presenter и e2e-тесты всех трех хабов зелёные (`bun run check` успешен).
