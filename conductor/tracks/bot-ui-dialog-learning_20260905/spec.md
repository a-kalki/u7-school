# Спецификация — Трек: Learning-стори (bot-ui-dialog-learning_20260905)

> **Материнский документ:** [bot-ui-session-architecture.md](../../bot-ui-session-architecture.md) — утверждённая целевая архитектура bot-ui v3 (инварианты §3, контракты §4, политика рендера §5). Трек 3 декомпозиции §9.

## Обзор

Edit-интенсивная навигация обучения: hub, step-view, nav-tree, progress — перевод на контракт «Диалог и Экран».

## Функциональные требования

- Перевод hub, step-view, nav-tree, progress на `DialogResponse`.
- «Владеешь экраном — обновляешь (edit)» вместо `editOrSend`; ретир чужих экранов с маркером выбора.
- Кнопки навигации — мосты (валидный штамп, §3 И1–И2).

## Нефункциональные требования

- Правило «трек уменьшает» (§9): никаких адаптеров совместимости.

## Критерии приёмки

- Скоуп трека целиком на новом контракте, тесты/линт/tsc скоупа зелёные; вне скоупа допустим красный tsc.
- Grep по скоупу: не осталось `BotResponse`/`editOrSend` (learning/shared.ts удалён или очищен).

## За рамками

- app/user/courses/streams (трек 2), questionnaire (трек 4), mentor (трек 5).
- Удаление старых типов (трек 5); персистентность (трек 6).
