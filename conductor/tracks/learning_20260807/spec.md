# Трек 5: Контроллер `learning` — «Моя учёба»

## 1. Обзор

Разделить `learning.story.ts` (670 строк, `packages/stream/src/ui/bot/stories/`) на 6 независимых файлов и перенести в новый контроллер `apps/u7-bot/src/learning/`.

Контроллер доступен **только роли STUDENT**, кнопка главного меню: `🎓 Моя учёба`.

## 2. Функциональные требования

### 2.1. Разделение на 6 стори

| Файл | Назначение | Строк (оценка) |
|------|-----------|----------------|
| `hub.ts` | Хаб: главное меню обучения, список потоков студента | ~120 |
| `step-view.ts` | Просмотр/прохождение шага (S05a) | ~150 |
| `nav-tree.ts` | Дерево уроков с ✅/▶️/🔒 (S05b) | ~130 |
| `transition.ts` | Завершение урока/проекта/потока (S05c) | ~100 |
| `progress.ts` | Прогресс студента (S06) | ~100 |
| `enroll.ts` | Запись с кодовым словом (S10) | ~70 |

### 2.2. `nav-tree.ts` и `tree-renderer`

- Формирует `TreeNode[]` из `contentSnapshot` + `student.steps`
- Добавляет статусы: ✅ (пройдено), ▶️ (текущее), 🔒 (заблокировано)
- Рендеринг через общий `shared/tree-renderer.ts` (уже создан в Треке 3)

### 2.3. `getAction<T>()` вместо `cbFor()`

- Все кросс-ссылки (`monitor`, `enroll`, `view-stream`) перевести на `uiApp.getAction<T>(name)`
- Кнопка «📝 Записаться» в `view-stream` восстанавливается через `getAction<EnrollActions>('enroll')(streamId)` (сейчас TODO)

### 2.4. Общие хелперы

- Вынести в `learning/shared.ts` или оставить protected-методами в базовом классе
- Проанализировать и принять решение при реализации
