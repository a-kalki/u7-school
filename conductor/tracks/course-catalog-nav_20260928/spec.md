# Спецификация: Каталог курсов — drill-down навигация

**Тип:** feature
**Трек:** `course-catalog-nav_20260928`
**Зависимости:** `module-program-nav_20260928` (переиспользует ядро навигации).

## Обзор

Перевести «Программы курсов» (`CourseCatalogStory`, S00) на ту же карточную drill-down
навигацию, что введена треком `module-program-nav`. Сейчас это 5 уровней с inline-поддеревьями
и пагинацией длинного текста. Станет: курс → этап → модуль → проект → урок.

## Функциональные требования

**FR-1. Уровни.** Drill-down: `курс → этап → модуль → проект → урок`.

**FR-2. Карточка уровня.** Тот же формат, что в треке ядра:
- **Карточка курса:** этапы (жирным, нумерованные кнопки), под каждым — его модули списком.
- **Карточка этапа:** модули (жирным, кнопки), под каждым — его проекты списком.
- **Карточка модуля:** проекты (жирным, кнопки), под каждым — его уроки списком.
- **Карточка проекта:** уроки (жирным, кнопки), под каждым — заголовки шагов.
- **Карточка урока:** одноуровневый список шагов; внутрь (тело шага) заходить нельзя.

**FR-3. Пояснения.** На каждом уровне типовая подпись «где я / из чего состоит», например
«Курс состоит из N этапов», «Этап состоит из N модулей».

**FR-4. Навигация.** `◀️/▶️` по соседям в пределах родителя, `⬅️ Назад` на уровень выше;
номера в кнопках соответствуют списку.

**FR-5. Отсутствие прогресса.** Статусов, иконок и счётчиков нет — навигация нейтральна
для любого зрителя (в т.ч. любопытного).

**FR-6. Шаги только заголовками.** На уровне урока шаги показываются заголовками, тела
недоступны (на существующую `StepPolicy` это не влияет — тела просто не запрашиваются/не
показываются).

**FR-7. Wish-кнопки.** Существующие кнопки желаний (`🎓 Хочу пройти курс`, `📝 Продолжить
анкету`, `🗑️ Отменить желание`) и их сценарии сохраняются на карточке курса.

**FR-8. Выпиливание старого.** Убрать inline-поддеревья и `pagedScreen` из `course-catalog`;
`renderTreeBlocks`/`tree-renderer` — удалить, если не останется потребителей; убрать хрупкие
индексы `phaseIdx`/`projectIdx` в пользу id.

## Нефункциональные требования

- Тексты — `md` (MarkdownV2).
- Навигация — на общем ядре из трека `module-program-nav` (новых дублей нет).
- Ноль новых UC (используются существующие `list-courses`, `get-course`, `get-module`,
  `get-module-snapshot`, `get-steps-by-lessons`).

## Критерии приёмки

- «Программы курсов»: drill-down курс → этап → модуль → проект → урок, листание, пояснения;
  шаги только заголовками, внутрь нельзя.
- Wish-сценарии курса не сломаны.
- `bun run lint`, `bun run tslint`, `bun test` — зелёные.

## За рамками

- Программа модуля (студент/ментор) — трек `module-program-nav_20260928`.
- Тела шагов в каталоге — недоступны по решению владельца.
