# Трек 6: Контроллер `mentor` — «Инструменты ментора»

## 1. Обзор

Перенести 6 оставшихся стори из `packages/stream/src/ui/bot/stories/` в новый контроллер `apps/u7-bot/src/mentor/`.

Контроллер доступен **ролям MENTOR и ADMIN**, кнопка главного меню: `🛠️ Инструменты ментора`.

## 2. Функциональные требования

### 2.1. Переносимые стори

| Файл | Назначение |
|------|-----------|
| `submenu.ts` | Подменю инструментов ментора |
| `my-streams.ts` | Список потоков, где пользователь — ментор |
| `view-stream-mentor.ts` | Карточка потока с lifecycle-кнопками (наследует `view-stream`) |
| `create-stream.ts` | Wizard создания потока (S09) |
| `activate-stream.ts` | Запуск потока |
| `monitor.ts` | Мониторинг группы (S07/S08) |

### 2.2. Исправление бага с кнопкой «Назад»

В `activate-stream.ts` кнопка «Назад к потоку» жёстко ссылается на `view-stream:view:{streamId}`, из-за чего ментор попадает в curious-режим без lifecycle-кнопок.

**Решение:** заменить на `getAction<ViewStreamMentorActions>('view')(streamId)`.

### 2.3. `view-stream-mentor` — наследование vs композиция

- `view-stream-mentor.ts` наследует `view-stream.ts` из `streams/` контроллера
- Проанализировать, можно ли избежать наследования через композицию
- Принять решение при реализации

### 2.4. `getAction<T>()` вместо `cbFor()`

- Все кросс-ссылки перевести на `uiApp.getAction<T>(name)`
- Кнопка «👥 Студенты» в `view-stream` восстанавливается через `getAction<MonitorActions>('students')(streamId)` (сейчас TODO)
