## Архитектурные решения

1. **Стори — только через `appApi`.** Все доменные чтения (9 UC:
   get-campaign-recipients, get-my-campaigns, create-review, get-my-review,
   list-scope-reviews, get-stream, get-user, get-users-by-ids,
   list-scope-facts) идут через `appApi.execute`; фасад модуля удалён за
   ненадобностью (ревью 2026-09-21).
2. **Приглашения — `ProactiveSender.invite`** с ПОЛНЫМИ кодами кнопок
   (транспорт проактивы не префиксует контроллером). Пропуск при отсутствии
   `telegramId`/профиля — молчаливый.
3. **Пагинация S07 — готовый пагинатор** (`pagedScreen` → `BotPaginator` +
   `DialogCache`): блок = отзыв, кеш эпохи диалога, build только при промахе.
4. **Исход автора — скрытый:** `myOutcome`/`subjectOutcome` никогда не
   рендерятся, только выбирают текст (S01, S05); в просмотре лейбл — только
   у автора-студента из снапшота `authorOutcome`.
