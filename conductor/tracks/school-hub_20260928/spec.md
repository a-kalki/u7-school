# Трек: Хаб «Школа» (school-hub)

## Обзор

Ввести в Telegram-боте хаб **«🏫 Школа»** — точку входа «места»: информация о школе,
её менторы, потоки, отзывы и сообщество. Разделить две оси продукта: **«🏫 Школа»**
(место) и **«📖 Курсы»** (материалы авторов).

Трек создаёт контроллер `school` и переносит в него то, что сейчас разбросано по
главному меню: «📚 Потоки курсов» и «💬 Сообщество школы». Добавляет кнопки
«💬 Отзывы» (отзывы студентов о менторах школы) и «ℹ️ Инфо». Каталог курсов
переименовывается «📖 Программы курсов» → «📖 Курсы».

Опирается на трек [school-config](../school-config_20260928/spec.md) — считаем
реализованным: есть тип `School`, `appResolver.school`, `U7BotUiAppResolve.school`.
Общая концепция множественных школ — [schools-system](../../roadmap/schools-system.md).

## Функциональные требования

**FR-1. Контроллер `school`.**
В `apps/u7-bot/src/controllers/school/` создаётся `SchoolController` (+ `ui-spec.md`),
делегирующий действия в стори `SchoolHubStory`. Пакет `packages/school` **не
создаётся** — модуль школ в будущем.

**FR-2. Главное меню.**
- Новая кнопка `🏫 Школа` (priority 10) → хаб.
- `📖 Программы курсов` → переименовать в `📖 Курсы` (priority 12).
- `📚 Потоки курсов` (15) — убрать из главного меню (внутрь хаба).
- `💬 Сообщество школы` (90) — убрать из главного меню (в хабе — как `💬 Сообщество`).
- `💬 Отзывы` (25) — **оставить**: личный процесс отзывов не смешиваем с хабом.

**FR-3. Экран хаба (SH01).**
Заголовок `🏫 {School.name}`, краткое описание, строка `Наши менторы: {имена}`
(имена резолвятся по uuid из `school.mentors`; при пустом списке строка не
выводится). Кнопки в порядке:
`📚 Потоки` → `💬 Отзывы` → `ℹ️ Инфо` → `💬 Сообщество` → `↩️ Главное меню`.

**FR-4. SH02 «Инфо».**
Полная информация о школе: имя, описание, адрес, контакты (телефон; сайт — если
задан, иначе «сайта пока нет, но скоро будет»). Кнопка возврата в хаб.

**FR-5. «📚 Потоки» — перенос каталога потоков.**
Кнопка хаба ведёт в существующий каталог потоков (`CatalogStory`), без
переписывания сценариев (статусы/фильтры/карточка/запись). Из главного меню вход
убирается; возврат — «⬅️ Назад в школу».

**FR-6. «💬 Отзывы» — простой срез.**
Отзывы **студентов о менторах** для потоков, проведённых в этой школе
(направление student→mentor). Постраничный просмотр. Источник — peer-review
(`list-scope-reviews` по потокам школы). Простая реализация (MVP), без рейтингов
и агрегатов.

**FR-7. «💬 Сообщество».**
Кнопка-ссылка на `school.communityGroup.url`; `CommunityStory` переезжает из
`AppController` в `SchoolController`.

**FR-8. Данные — из резолвера.**
Все данные школы берутся из `school` (резолвер), как закреплено в `school-config`;
UI не читает `config`.

## Нефункциональные требования

- TDD; гейт `bun run lint` + `bun run tslint` + `bun test`.
- Не ломать существующий каталог потоков и личный процесс отзывов.
- Инвариант `school-config`: UI-слой не зависит от `BotConfig`.

## Критерии приёмки

- В главном меню есть `🏫 Школа` и `📖 Курсы`; отсутствуют `📚 Потоки курсов` и
  `💬 Сообщество школы`; `💬 Отзывы` остаётся.
- Хаб показывает имя, описание, менторов и кнопки `Потоки · Отзывы · Инфо ·
  Сообщество · Меню`.
- «Инфо» выводит адрес и контакты (с заглушкой сайта), «Сообщество» ведёт по URL.
- «Потоки» открывают существующий каталог; возврат — в хаб.
- «Отзывы» показывают отзывы студентов о менторах школы с пагинацией.
- `bun run lint`, `bun run tslint`, `bun test` — зелёные.

## За рамками (техдолг)

- Статистика ментора (потоки, пришло/выпустилось) и отдельная кнопка «Менторы».
- Карточка ментора.
- Хаб «Школы» и выбор активной школы.
- Модуль `schools` (`SchoolAr`/`SchoolRepo`), множественность школ.
- Регистрация менторов в школе.
- Рейтинг/агрегация отзывов о менторе.
- География, онбординг активной школы.
