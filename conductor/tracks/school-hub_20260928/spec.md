# Трек: Хаб «Школа» (school-hub)

**Релиз:** `0.2.0` (группа «Школа»); окно включает миграцию `streams.schoolId`.

## Обзор

Ввести в Telegram-боте хаб **«🏫 Школа»** — точку входа «места»: информация о школе,
её менторы, потоки, отзывы и сообщество. Разделить две оси продукта: **«🏫 Школа»**
(место) и **«📖 Курсы»** (материалы авторов).

Трек создаёт контроллер `school` и переносит в него то, что сейчас разбросано по
главному меню: «📚 Потоки курсов» и «💬 Сообщество школы». Добавляет кнопки
«💬 Отзывы» и «ℹ️ Инфо». Каталог курсов
переименовывается «📖 Программы курсов» → «📖 Курсы».

Опирается на трек [school-config](../school-config_20260928/spec.md) — считаем
реализованным: есть тип `School`, `appResolver.school`, `U7BotUiAppResolve.school`.
Общая концепция множественных школ — [schools-system](../../roadmap/schools-system.md).

## Функциональные требования

**FR-1. Контроллер `school`.**
В `apps/u7-bot/src/controllers/school/` создаётся `SchoolController` (+ `ui-spec.md`),
делегирующий действия в стори `SchoolHubStory`. Пакет `packages/school` **не
создаётся** — модуль школ в будущем.

**FR-2. Главное меню.**
- Новая кнопка `🏫 Школа` (priority 10) → хаб.
- `📖 Программы курсов` → `📖 Курсы`; priority меняется `10 → 12` (иначе коллизия
  с `🏫 Школа`).
- `📚 Потоки курсов` (15) — убрать из главного меню (внутрь хаба).
- `💬 Сообщество школы` (90) — убрать из главного меню (в хабе — как `💬 Сообщество`).
- `💬 Отзывы` (25, личные кампании peer-review) — **не трогать**; школьный экран
  отзывов называется иначе (FR-6).
- Все тексты путей в каталог потоков обновляются на `🏫 Школа → 📚 Потоки`
  (`wish-invite.story.ts`, `streams/ui-spec.md` S11).

**FR-3. Экран хаба (SH01).**
Заголовок `🏫 {School.name}`, краткое описание, строка `Наши менторы: {имена}`
(имена резолвятся по uuid из `school.mentors`; при пустом списке строка не
выводится). Кнопки в порядке:
`📚 Потоки` → `💬 Отзывы` → `ℹ️ Инфо` → `💬 Сообщество` → `↩️ Главное меню`.

**FR-4. SH02 «Инфо».**
Полная информация о школе: имя, описание, адрес, контакты (телефон; сайт — если
задан, иначе «сайта пока нет, но скоро будет»). Кнопка возврата в хаб.

**FR-5. «📚 Потоки» — перенос каталога потоков.**
Кнопка хаба ведёт в существующий каталог потоков (`CatalogStory`), без
переписывания сценариев (статусы/фильтры/карточка/запись). Из главного меню вход
убирается; возврат — «⬅️ Назад в школу»; тексты путей записи обновляются (FR-2).

**FR-6. «💬 Отзывы» — отзывы менторам школы (только чтение).**
Все отзывы, адресованные менторам, по потокам школы: потоки отбираются по
`Stream.schoolId` (FR-8), отзывы — направление student→mentor. Только чтение,
с пагинацией; рейтингов и агрегатов нет, строка «Наши менторы» в хабе — просто имена.
Личное `💬 Отзывы` главного меню (задачи peer-review) не меняется — контексты разные.
Механика (гибкий батч вместо одного скоупа): `list-scope-reviews` расширяется
с `scopeId` на `scopeIds: string[]` (+ фильтр `direction`), в DTO отзыва добавляется
`scopeId`; существующий потребитель (панель отзывов потока) передаёт `[scopeId]`.
Срез школы: `list-streams({ schoolId })` → `scopeIds` → `list-scope-reviews`.
Контракт переиспользуется для будущих срезов (ментор, курс, автор).

**FR-7. «💬 Сообщество».**
Кнопка-ссылка на `school.communityGroup.url`; `CommunityStory` переезжает из
`AppController` в `SchoolController`.

**FR-8. `Stream.schoolId` — поток принадлежит школе.**
В домен потока добавляется обязательное `schoolId` (uuid школы из FR-1 трека
`school-config`); при создании потока значение берётся из `appResolver.school.id`
(пока школа одна); `list-streams` получает фильтр `schoolId`.
Миграция — `scripts/migrate-streams-school-id.ts` (идемпотентный): проставляет
`schoolId` существующим потокам. Порядок обязателен: **бот остановлен** →
`bun run backup before-migration` (`data/streams/` — незащищённые данные) → миграция →
старт. На работающем старом коде мигрировать нельзя: valibot при parse отбрасывает
неизвестные поля и затрёт `schoolId` при следующей записи.

**FR-9. Данные — из резолвера.**
Все данные школы берутся из `school` (резолвер), как закреплено в `school-config`;
UI не читает `config`.

## Нефункциональные требования

- TDD; гейт `bun run lint` + `bun run tslint` + `bun test`.
- Не ломать существующий каталог потоков и личный процесс отзывов.
- Инвариант `school-config`: UI-слой не зависит от `BotConfig`.

## Критерии приёмки

- В главном меню есть `🏫 Школа` (10) и `📖 Курсы` (12); нет `📚 Потоки курсов` и
  `💬 Сообщество школы`; личные `💬 Отзывы` (25) остаются.
- Хаб показывает имя, описание, менторов и кнопки `Потоки · Отзывы ·
  Инфо · Сообщество · Меню`.
- «Инфо» выводит адрес и контакты (с заглушкой сайта), «Сообщество» ведёт по URL.
- «Потоки» открывают существующий каталог; возврат — в хаб; тексты путей записи
  указывают новый маршрут.
- «Отзывы» показывают отзывы student→mentor по потокам школы с пагинацией;
  `list-scope-reviews` принимает `scopeIds`, старый потребитель не сломан.
- У всех потоков есть `schoolId`; `list-streams` фильтрует по нему.
- `bun run lint`, `bun run tslint`, `bun test` — зелёные.

## За рамками (техдолг)

- Статистика ментора (потоки, пришло/выпустилось) и отдельная кнопка «Менторы».
- Карточка ментора.
- Хаб «Школы» и выбор активной школы.
- Модуль `schools` (`SchoolAr`/`SchoolRepo`), множественность школ.
- Регистрация менторов в школе.
- Рейтинг/агрегация отзывов о менторе; школьный срез отзывов не смешивается
  с личными `💬 Отзывы`.
- География, онбординг активной школы.
