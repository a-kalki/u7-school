# Summary: Хаб «Школа» (school-hub)

> Трек завершён 2026-10-14.
> Релиз: `0.2.0` (группа «Школа»).
> Следующий шаг — трек [module-program-nav](../module-program-nav_20260928/plan.md).

## Цель трека

Разделить в боте две основные оси продукта:
1. **«Школа» (место):** кто учит, где учит, отзывы о менторах, сообщество, визитка и потоки школы.
2. **«Курсы» (материалы авторов):** каталог учебных программ (курсы, модули, уроки).

Реализовать единый хаб «Школа» (SH01), экраны «Инфо» (SH02), «Отзывы» (SH03), перенести экран «Сообщество» (SH04) и каталог потоков (S01) внутрь школы. Привязать сущность потока к школе через обязательное поле `Stream.schoolId`, предоставить безопасный идемпотентный скрипт миграции существующих данных и реорганизовать главное меню бота.

## Выполнено по фазам

- **Фаза 1: Хаб «Школа» (SH01)** — создан контроллер `SchoolController` и стори `SchoolHubStory` (`school:hub:open`). Отображается визитная карточка школы (название, описание, адрес, список менторов школы с резолвом UUID в имена через `get-users-by-ids`), инлайн-кнопки переходов: `📚 Потоки`, `💬 Отзывы`, `ℹ️ Инфо`, `💬 Сообщество` (URL) и `↩️ Главное меню`. Документирован `apps/u7-bot/src/controllers/school/ui-spec.md`.
- **Фаза 2: Экран «Инфо» (SH02)** — реализована `SchoolInfoStory` (`school:info:view`). Выводит подробное описание школы, адрес, контакты, условный сайт (или заглушку) и кнопку «⬅️ Назад в школу» (`school:hub:open`).
- **Фаза 3: «Сообщество» (перенос)** — стори `CommunityStory` перенесена из `AppController` в `SchoolController` (SH04). Кнопка «💬 Сообщество школы» убрана из главного меню бота, ссылка на сообщество доступна через прямую URL-кнопку карточки хаба школы.
- **Фаза 4: «Потоки» (перенос каталога)** — кнопка «📚 Потоки» в хабе школы делегирует переход в `CatalogStory` (`stream:catalog:list`). Кнопка каталога потоков убрана из главного меню. Кнопка возврата из каталога изменена на «⬅️ Назад в школу» (`buttons.backToSchool()`). Вспомогательные тексты навигации при записи (`WishInviteStory`, UI-спецификации) обновлены на путь `🏫 Школа → 📚 Потоки → «...» → 📝 Записаться`.
- **Фаза 5: Потоки школы и «Отзывы»** —
  - В доменную сущность `Stream` добавлено обязательное поле `schoolId` (UUID). `StreamAr.create` и `CreateStreamUc` проставляют `schoolId` (по умолчанию `U7_SCHOOL_ID` / `appResolver.school.id`).
  - Добавлена фильтрация по `schoolId` в `ListStreamsCmdSchema`, `StreamRepo` и `StreamJsonRepo`.
  - Разработан и протестирован скрипт холодной миграции `scripts/migrate-streams-school-id.ts` (`bun run migrate:streams-school-id`). В `CHANGELOG.md` добавлена секция Migration с детальным регламентом выката на проде.
  - Команда `list-scope-reviews` расширена: принимает `scopeIds: string[]` и опциональный `direction?: ReviewDirection`. В `ReviewSnapshot` добавлен `scopeId`. Репозиторий `ReviewRepo` дополнен методом `findByScopes(scopeIds)`.
  - Реализован экран «Отзывы» (SH03, `SchoolReviewsStory`): агрегирует потоки школы по `schoolId`, запрашивает отзывы студентов о менторах (`direction: student_mentor`) по их `scopeIds`, резолвит имена через `get-users-by-ids` и рендерит страницы через `pagedScreen` с кнопкой «⬅️ Назад в школу».

  - Удалены старые кнопки `📚 Потоки курсов` и `💬 Сообщество школы`. Личные отзывы `💬 Отзывы` (`priority: 25`) сохранены.
  - Обновлены `courses/ui-spec.md`, `courses/content-nav.md` и все сквозные e2e-тесты бота.

## Ключевые архитектурные решения

1. **Разделение осей Школа / Курсы:** Чётко разграничена зона ответственности: школа агрегирует менторов, потоки, отзывы и каналы общения; каталог курсов отвечает только за программы обучения.
2. **Связь Stream ↔ School:** Добавлена строгая типизация и валидация `schoolId` в сущности потока, что позволило отбирать отзывы о менторах именно в контексте потоков конкретной школы.
3. **Безопасная миграция данных:** Создан идемпотентный скрипт миграции данных потоков, протестированный на временных файлах и изолированный от живой БД.
4. **Бесшовная навигация бота:** Каталог потоков и экраны школы объединены единым контекстом возврата в школу (`⬅️ Назад в школу`), разгрузив верхнеуровневое меню бота.
