## Цель

`apps/u7-bot/src/infra/bot-transport.ts`): устранение системной причины рассинхрона

## Ключевые архитектурные решения (обоснование — §10 архитектуры)

1. **Вариант A** (проактив): диалог открывается только действием пользователя;
   `send` не возвращается; легаси-приглашения — временный `invite` с якорем
   `app/invite` (штамп легальной эпохи, приглашение не умирает).
2. **Валидация без исключений**: невалидные кнопки гасятся alert'ами транспорта
   до uiApp; класс stale-багов (инцидент анкеты) закрыт по построению.
3. **Трёхуровневый pipe команд**: ядро не знает имён команд; реакция
   `pass`/`continue`/`stop`; `/start` и `/help` — прямые пути uiApp мимо pipe
   (неактивная стори на `/help` не отвечает никогда); меню — декларативные
   `menuButtons`, не обработчики.
4. **Kind-уведомления**: один словарь 🔔/ℹ️/⚠️ для проактива и реплик;
   `errorNotify` отделяет валидацию (переспрос) от ошибок (экран).
5. **Ввод без ожидания** — реплика-подсказка транспорта (контракт без `next`);
   дефолт `handleMessage` стори — страховка от `awaitInput` без обработчика.
