# Спецификация — Трек 1.2: Вопросы и шкалы

## Обзор

Создать конкретные утверждения (2–4 на подкатегорию) для каждой из 10 подкатегорий, сгруппированные по контекстам анкет. Утверждения обезличены (без «Студент») и могут применяться для всех ролей. Шкала Лайкерта 1–5. Структура позволяет легко добавлять/редактировать утверждения и тасовать их при формировании анкеты.

## FR3 — Структура вопроса

```typescript
interface MetricQuestion {
  code: string;                    // "mc_work_quality_1"
  context: string;                 // "module_completed" | "pair_programming" | "code_review"
  roles: string[];                 // ["student_student", "mentor_student", "student_mentor"]
  subcategory: string;             // "work_quality"
  text: string;                    // текст утверждения (без «Студент»)
  weight: number;                  // 1.0 (по умолчанию)
}
```

- `code` — уникальный код для идентификации при тасовании
- `context` — в каком контексте анкеты используется
- `roles` — для каких ролей оценивающего применим
- Тасование: при формировании анкеты фильтруются вопросы по `context` + `roles`, затем перемешиваются
