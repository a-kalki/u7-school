# Техническое задание: Игра «Крестики-нолики» (Tic-Tac-Toe)

## 1. Описание игры
«Крестики-нолики 3×3» — классическая дуэльная стратегическая игра для двух игроков на одном терминале. Игроки по очереди ставят свои знаки (`X` и `O`) на свободные клетки поля 3×3 с помощью перемещения курсора и клавиши выбора (Пробел или Enter).

Игра завершается:
- **Победой (`WON`):** один из игроков собрал непрерывную линию из 3 своих символов (по горизонтали, вертикали или диагонали);
- **Ничьей (`DRAW`):** все 9 клеток заполнены, но ни один игрок не собрал линию победы.

---

## 2. Структура состояния (`State`)

```javascript
{
  size: 3,                  // размер поля 3x3
  cursor: { x: 1, y: 1 },   // координаты курсора
  grid: [                   // матрица 3x3 символов
    [' ', ' ', ' '],
    [' ', 'X', ' '],
    [' ', ' ', 'O']
  ],
  currentPlayer: 'X',       // 'X' | 'O'
  winner: null,             // null | 'X' | 'O'
  movesCount: 2,            // количество сделанных ходов
  status: 'PLAYING'         // 'PLAYING' | 'WON' | 'DRAW'
}
```

---

## 3. Контракт функций (`games/tictactoe/tictactoe.js`)

### `createState(options = {})`
Инициализирует пустое поле 3×3, устанавливает курсор в центр `(1, 1)`, начинает игрок `'X'`.

### `update(state, action)`
- `{ type: 'MOVE_CURSOR', dx, dy }`: смещает курсор с ограничением по границам поля `[0, size - 1]`.
- `{ type: 'ACTION_PLACE' }`:
  - если игра уже окончена (`status !== 'PLAYING'`) — ничего не делает;
  - если клетка под курсором уже занята — действие игнорируется;
  - если клетка свободна:
    - ставит символ `state.currentPlayer`;
    - проверяет линии на победу: если есть 3 одинаковых символа в ряд, статус становится `'WON'`, а `winner = state.currentPlayer`;
    - если победы нет и ходы исчерпаны (9 ходов) — статус становится `'DRAW'`;
    - если игра продолжается — меняет текущего игрока `'X' -> 'O' -> 'X'`.

### `getView(state)`
Формирует матрицу символов для рендерера `renderGrid`:
- Ячейка под курсором подсвечивается квадратными скобками `[·]`, `[X]`, `[O]`;
- Обычные клетки: ` · `, ` X `, ` O `;
- В `extraInfo` выводится чей сейчас ход или кто победил.
