# Техническое задание: Игра «Сапёр» (Minesweeper)

## 1. Описание игры
«Сапёр» — классическая логическая игра. На минном поле спрятано фиксированное количество мин. Игрок управляет курсором с помощью стрелок или WASD:
- Клавиша **Пробел** или **Enter** — открыть ячейку под курсором;
- Клавиша **f** — поставить или снять флажок мины.

Если игрок открывает клетку с миной — происходит взрыв и игра завершается поражением (`LOST`). Если в клетке нет мины, отображается число мин в 8 соседних ячейках (от 1 до 8). Если мин по соседству нет (число 0), игра автоматически каскадно раскрывает все соседние безопасные клетки с помощью алгоритма поиска в ширину (BFS).

Победа (`WON`) наступает, когда открыты абсолютно все безопасные ячейки поля.

---

## 2. Структура состояния (`State`)

```javascript
{
  width: 9,                 // ширина поля (колонок)
  height: 9,                // высота поля (строк)
  minesCount: 10,           // общее количество мин
  cursor: { x: 4, y: 4 },   // текущее положение курсора
  cells: [                  // двумерный массив объектов ячеек
    [
      { hasMine: false, state: 'CLOSED', adjacentMines: 0 },
      ...
    ]
  ],
  flagsCount: 0,            // количество установленных флагов
  status: 'PLAYING'         // 'PLAYING' | 'WON' | 'LOST'
}
```

Состояния ячейки (`cell.state`):
- `'CLOSED'` — скрыта;
- `'OPEN'` — открыта;
- `'FLAG'` — помечена флагом.

## 3. Контракт функций (`games/minesweeper/minesweeper.js`)

### `createState(options = {})`
Инициализирует поле размером `width` на `height` (по умолчанию 9×9) с `minesCount` случайными минами (по умолчанию 10), рассчитывает количество соседних мин для каждой клетки. Курсор устанавливается по центру.

### `update(state, action)`
Принимает действие и возвращает обновлённое состояние:
- `{ type: 'MOVE_CURSOR', dx, dy }`: смещает курсор с ограничением по границам поля.
- `{ type: 'ACTION_FLAG' }`:
  - если ячейка закрыта (`'CLOSED'`) — ставит флаг (`'FLAG'`);
  - если стоял флаг — снимает его обратно в `'CLOSED'`;
  - если ячейка уже открыта — ничего не делает.
- `{ type: 'ACTION_OPEN' }`:
  - если ячейка помечена флагом или уже открыта — действие игнорируется;
  - если ячейка содержит мину — статус становится `'LOST'`, все мины открываются;
  - если мины нет — клетка открывается. Если `adjacentMines === 0`, запускается каскадный обход BFS для открытия прилегающих пустых зон.
  - после открытия проверяется условие победы: число оставшихся закрытых ячеек равно `minesCount`.

### `getView(state)`
Формирует матрицу символов для рендерера `renderGrid`:
- Ячейка под курсором выделяется скобками `[·]`, `[F]`, `[1]`, `[ ]`;
- Обычные закрытые ячейки: ` · `;
- Флаги: ` F `;
- Пустые открытые ячейки: `   `;
- Числа соседей: ` 1 `, ` 2 ` ...
- Мины при поражении: ` * `.
