# Техническое задание: Игра «Черепашка на сетке» (Turtle Graphics)

## 1. Описание игры
«Черепашка на сетке» — классический интерактивный робот-исполнитель (вдохновлённый Черепашьей графикой Сеймура Пейперта из языка Logo).

Игрок управляет виртуальной Черепашкой на клетчатом холсте в терминале:
- Черепашка находится в определённой клетке поля `(x, y)` и смотрит в одну из 4 сторон света: Север (`N`), Восток (`E`), Юг (`S`) или Запад (`W`).
- Игрок командует Черепашке шагать вперёд или назад, а также поворачиваться на 90° налево или направо.
- У Черепашки есть **перо для рисования**:
  - Когда перо **опущено** (`penDown: true`), каждый шаг оставляет за собой след — клетка закрашивается точкой `·`.
  - Когда перо **поднято** (`penDown: false`), Черепашка свободно гуляет по полю, не оставляя меток.
- По нажатию клавиши **C** игрок может начисто стереть все нарисованные следы и начать рисунок заново.
- Черепашка никогда не может выйти за пределы холста: при попытке шагнуть в край экрана она мягко упирается в границу.

**Суть игрового процесса:** рисовать на терминальном холсте геометрические фигуры, лабиринты и узоры, управляя траекторией исполнителя.

## 2. Символы на экране и обозначения
- `+-----+` — рамка игрового поля;
- ` ` (пробел) — чистый холст (непосещённая клетка);
- `·` — след опущенного пера Черепашки;
- `▲` — Черепашка, смотрящая на Север (вверх, уменьшение Y);
- `►` — Черепашка, смотрящая на Восток (вправо, увеличение X);
- `▼` — Черепашка, смотрящая на Юг (вниз, увеличение Y);
- `◄` — Черепашка, смотрящая на Запад (влево, уменьшение X).

Внизу экрана отображается панель статуса:
```text
Позиция: (x=3, y=4) | Направление: Восток (вправо) | Перо: ОПУЩЕНО | Шагов: 12
Управление: Стрелки / WASD — движение и поворот | Пробел — перо | C — стереть | r — сброс | q — выход
```

## 3. Структура состояния (`State`)

```javascript
{
  width: 10,                 // ширина поля (по умолчанию 10)
  height: 10,                // высота поля (по умолчанию 10)
  x: 0,                      // текущая координата X (0 .. width - 1)
  y: 0,                      // текущая координата Y (0 .. height - 1)
  direction: 'E',            // направление: 'N' | 'E' | 'S' | 'W'
  penDown: false,            // флаг пера: поднято (false) или опущено (true)
  trail: [],                 // массив координат со следами вида 'x,y'
  stepsCount: 0,             // количество сделанных шагов
  status: 'PLAYING'          // статус игры
}
```

## 4. Контракт функций (`games/turtle/turtle.js`)

### `createState(options = {})`
Создаёт начальное состояние поля размером `width × height` (по умолчанию 10×10).
- Черепашка стартует в верхнем левом углу `(0, 0)`.
- Начальное направление — Восток (`'E'`).
- Перо поднято (`penDown: false`).
- Если перо поднято, след изначально пуст (`trail: []`).
- Счётчик шагов равен `0`.

### `update(state, event)`
Принимает текущее состояние и доменное событие, возвращает **новый объект состояния**:
- **`{ type: 'FORWARD' }`** — шаг на 1 клетку вперёд по направлению взгляда с учётом границ поля;
- **`{ type: 'BACKWARD' }`** — шаг на 1 клетку назад вдоль направления взгляда;
- **`{ type: 'TURN_RIGHT' }`** — поворот на 90° по часовой стрелке (`N → E → S → W → N`);
- **`{ type: 'TURN_LEFT' }`** — поворот на 90° против часовой стрелки (`N → W → S → E → N`);
- **`{ type: 'TOGGLE_PEN' }`** — переключение состояния пера (`penDown`). Если перо опускается, текущая координата добавляется в `trail`;
- **`{ type: 'CLEAR_TRAIL' }`** — очистка нарисованного пути (`trail: []`).

### `getView(state)`
Формирует модель кадра для рендерера:
- `grid` — двумерная матрица символов (матрица `height` строк на `width` колонок);
- `x`, `y`, `direction`, `penDown`, `stepsCount` — как в `state`.

## 5. Управление клавишами
- **Стрелка вверх / W / Ц** — шаг вперёд (`FORWARD`);
- **Стрелка вниз / S / Ы** — шаг назад (`BACKWARD`);
- **Стрелка влево / A / Ф** — поворот налево (`TURN_LEFT`);
- **Стрелка вправо / D / В** — поворот направо (`TURN_RIGHT`);
- **Пробел** — поднять / опустить перо (`TOGGLE_PEN`);
- **C / С** — стереть нарисованный след (`CLEAR_TRAIL`);
- **r / к** — перезапуск игры с чистого листа;
- **q / й / Ctrl+C** — выход из игры в консоль.
