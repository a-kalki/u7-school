# Техническое задание: Игра «Виселица: Термины курса» (Hangman)

## 1. Описание игры
«Виселица» — классическая игра на угадывание слов по буквам. В нашей Аркаде игра тематическая: она загадывает ключевые термины веб-разработки и программирования (на русском или английском языке).

Игрок видит перед собой замаскированное слово (например, `_ _ _ _ _ _`) и пустую виселицу.
- Нажимая буквы на клавиатуре, игрок пытается угадать слово.
- Если буква есть в слове — она открывается на всех соответствующих позициях (например, `М А _ С И _`).
- Если буквы в слове нет — она заносится в список ошибок, а на виселице дорисовывается часть человечка (голова, туловище, руки, ноги).
- **Лимит ошибок — 6.**
- **Победа (`WON`):** игрок успел отгадать все буквы слова до того, как человечек повешен.
- **Поражение (`LOST`):** допущено 6 ошибок — игра показывает загаданное слово целиком.

Игрок может в любой момент нажать **Tab**, чтобы переключить словарь между русскими и английскими терминами, а после победы или поражения нажать **Enter** или **Пробел**, чтобы начать новый раунд с новым словом.

## 2. Символы на экране и стадии виселицы
На экране последовательно отображается одна из 7 стадий (от 0 до 6 ошибок):
```text
  +---+         +---+         +---+
  |   |         |   |         |   |
      |   -->   O   |   -->   O   |
      |             |        /|\  |
      |             |        / \  |
      |             |             |
=========     =========     =========
0 ошибок      1 ошибка      6 ошибок (поражение)
```

Внизу отображается:
- Язык словаря: `[ Язык: RU ] (Tab — сменить язык)`;
- Замаскированное слово: `Слово: А Л Г О Р _ Т М`;
- Ошибочные буквы: `Ошибки (2/6): Б, Ю`;
- Подсказки управления.

## 3. Структура состояния (`State`)

```javascript
{
  word: 'АЛГОРИТМ',          // загаданное слово в верхнем регистре
  lang: 'ru',                // текущий язык: 'ru' | 'en'
  guessedLetters: ['А', 'Л'],// список правильно угаданных букв
  wrongLetters: ['Б', 'Ю'],  // список названных ошибочных букв
  maxErrors: 6,              // максимальное количество ошибок
  status: 'PLAYING'          // 'PLAYING' | 'WON' | 'LOST'
}
```

## 4. Контракт функций (`games/hangman/hangman.js`)

### `createState(options = {})`
Инициализирует игру. Выбирает случайное слово из встроенного словаря `words.js` (Base64) на указанном языке `options.lang` ('ru' по умолчанию) либо использует переданное слово `options.word`. Списки букв пустые, статус `'PLAYING'`.

### `update(state, event)`
Чистая функция обновления состояния:
- **`{ type: 'GUESS', char: 'А' }`**:
  - Игнорируется, если игра уже завершена (`WON` или `LOST`);
  - Игнорируется, если буква уже называлась ранее;
  - Если буква есть в `word` — добавляется в `guessedLetters`. Если отгаданы все уникальные буквы слова — статус становится `'WON'`;
  - Если буквы нет в `word` — добавляется в `wrongLetters`. Если `wrongLetters.length >= maxErrors` — статус становится `'LOST'`.
- **`{ type: 'TOGGLE_LANG' }`**: переключает язык ('ru' ↔ 'en') и перезапускает игру с новым словом.
- **`{ type: 'ACTION_CONFIRM' }`** (Enter / Space): начинает новый раунд, если текущий раунд завершён.
- **`{ type: 'RESTART' }`**: принудительный сброс раунда.

### `getView(state)`
Формирует модель экрана для рендерера `renderHangman`:
```javascript
{
  word: state.word,
  maskedWord: 'А Л Г О Р _ Т М', // неразгаданные буквы скрыты подчеркиванием '_'
  errorsCount: state.wrongLetters.length,
  maxErrors: state.maxErrors,
  wrongLetters: state.wrongLetters,
  status: state.status,
  lang: state.lang.toUpperCase(),
}
```

---

## 5. Управление клавишами
- **Буквы А-Я / A-Z** — попытка угадать букву (`GUESS`);
- **Tab** — переключение языка словаря RU/EN (`TOGGLE_LANG`);
- **Enter / Пробел** — новая игра после победы или поражения;
- **Ctrl+R** — принудительный рестарт раунда;
- **Esc / Ctrl+C** — выход в терминал.
