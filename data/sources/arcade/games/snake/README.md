# Техническое задание: Игра «Змейка» (Snake)

## 1. Описание игры
«Змейка» — аркадная игра реального времени. Игрок управляет змейкой на дискретном поле. Движение происходит непрерывно по тикам таймера (`TICK`). Игрок задает направление клавишами со стрелками или WASD.

Цель — набрать как можно больше очков, собирая еду (`★`), которая увеличивает длину змейки.
Игра завершается поражением (`GAME_OVER`):
- при столкновении с границей поля;
- при столкновении головы змейки с собственным хвостом.

---

## 2. Структура состояния (`State`)

```javascript
{
  width: 20,                          // ширина поля
  height: 12,                         // высота поля
  body: [                             // массив координат сегментов тела (body[0] — голова)
    { x: 5, y: 5 },
    { x: 4, y: 5 },
    { x: 3, y: 5 }
  ],
  direction: 'RIGHT',                 // текущее фактическое направление: 'UP' | 'DOWN' | 'LEFT' | 'RIGHT'
  nextDirection: 'RIGHT',             // буфер направления для следующего тика
  food: { x: 12, y: 5 },              // координаты текущей еды
  score: 0,                           // набранные очки (10 за каждую еду)
  status: 'PLAYING'                   // 'PLAYING' | 'GAME_OVER'
}
```

---

## 3. Контракт функций (`games/snake/snake.js`)

### `createState(options = {})`
Инициализирует поле заданного размера (по умолчанию 20×12), стартовую змейку из 3 сегментов по центру, направленную вправо, и случайную позицию еды, не пересекающуюся со змейкой.

### `update(state, action)`
- `{ type: 'CHANGE_DIRECTION', direction }` или `{ type: 'MOVE', direction }`:
  - Игнорирует команду, если новое направление противоположно текущему (например, движение вправо при попытке повернуть влево), чтобы предотвратить мгновенное самопоедание;
  - Сохраняет валидное направление в `nextDirection`.
- `{ type: 'TICK' }`:
  - Если `status !== 'PLAYING'` — состояние не меняется;
  - Применяет `direction = nextDirection`;
  - Вычисляет новые координаты головы `newHead = { x: head.x + dx, y: head.y + dy }`;
  - Проверяет выход за границы поля `[0, width - 1]`, `[0, height - 1]`: при выходе возвращает `{ ...state, status: 'GAME_OVER' }`;
  - Проверяет самопересечение (содержится ли `newHead` среди сегментов тела змейки): при коллизии возвращает `{ ...state, status: 'GAME_OVER' }`;
  - Если на клетке `newHead` находится еда:
    - голова добавляется к телу без удаления хвоста (змейка растёт);
    - начисляются очки (`score + 10`);
    - спавнится новая еда на свободной клетке;
  - Если еды нет:
    - голова добавляется в начало, а последний сегмент хвоста удаляется (сдвиг).

### `getView(state)`
Формирует матрицу символов для рендерера `renderGrid`:
- Голова: `'▲'`, `'▼'`, `'◄'`, `'►'` (в зависимости от текущего направления);
- Сегменты тела: `'o'`;
- Еда: `'★'`;
- Пустые клетки: `' '`.
В `extraInfo` выводится текущий счёт, длина змейки и подсказки по управлению.

## 4. Конфигурация запуска (`games/snake/run.js`)
- Частота тиков: `tickRateMs: 150` (плавная аркадная скорость);
- Адаптер: `createDirectionAdapter({ eventType: 'CHANGE_DIRECTION' })`.
