# Техническое задание: Игра «2048»

## 1. Описание игры
«2048» — популярная числовая головоломка на поле 4×4. Игрок сдвигает плитки стрелками или WASD во все четыре стороны. При столкновении две плитки с одинаковым номиналом схлопываются в одну с удвоенным значением (`2 + 2 = 4`, `4 + 4 = 8`), а игроку начисляются очки. После каждого результативного хода на свободной клетке появляется новая плитка (с вероятностью 90% — `2`, с вероятностью 10% — `4`).

Игра завершается:
- **Победой (`WON`):** на поле появилась плитка со значением `2048`.
- **Поражением (`LOST`):** на поле нет свободных клеток и ни в одной строке или столбце нет двух соседних равных плиток (ходы исчерпаны).

---

## 2. Структура состояния (`State`)

```javascript
{
  size: 4,                  // размерность поля 4x4
  matrix: [                 // двумерный массив чисел
    [0, 2, 0, 0],
    [0, 0, 4, 0],
    [0, 0, 0, 0],
    [0, 0, 0, 0]
  ],
  score: 6,                 // текущий счёт очков
  status: 'PLAYING'         // 'PLAYING' | 'WON' | 'LOST'
}
```

## 3. Контракт функций (`games/2048/game-2048.js`)

### `createState(options = {})`
Создаёт начальное состояние поля 4×4, заполненное нулями, и спавнит 2 случайные плитки. Счёт равен 0, статус `'PLAYING'`.

### `update(state, action)`
Принимает текущее состояние и объект действия.
- Поддерживает событие `{ type: 'MOVE', direction: 'UP' | 'DOWN' | 'LEFT' | 'RIGHT' }`.
- Если игра уже закончена (`status !== 'PLAYING'`), состояние не меняется.
- Если сдвиг в указанном направлении ничего не изменил на поле, новое число не появляется, состояние возвращается прежним.
- Если сдвиг изменил поле, к очкам добавляется сумма всех схлопываний, на пустом месте появляется новое число (2 или 4), после чего проверяется достижение 2048 или отсутствие ходов.

### `getView(state)`
Возвращает объект для рендерера `renderNumberGrid`:
```javascript
{
  title: '2048',
  matrix: state.matrix,
  score: state.score,
  status: state.status
}
```

## 4. Алгоритм сдвига и слияния

Рекомендуется декомпозировать движение матрицы на сдвиг одной одномерной строки:
1. `slideRow(row)`:
   - Удалить все нули: `[2, 0, 2, 4]` -> `[2, 2, 4]`.
   - Пройтись слева направо: если `row[i] === row[i + 1]`, объединить `merged = row[i] * 2`, начислить очки, пропустить следующий индекс: `[2, 2, 4]` -> `[4, 4]`.
   - Дополнить нулями справа до длины 4: `[4, 4, 0, 0]`.
2. Движение влево: применить `slideRow` к каждой строке матрицы.
3. Движение вправо, вверх и вниз реализуется через поворот или транспонирование матрицы, вызов сдвига влево и обратный поворот/транспонирование.
