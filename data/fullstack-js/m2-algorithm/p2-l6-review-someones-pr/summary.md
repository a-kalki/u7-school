# Ревьюим чужой homework-PR — краткая выжимка

- Выбор PR: не свой; из разобранных — тот, где меньше всего ревью
- Смотреть на вкладке Files changed: видно, что именно изменилось
- Чек-лист текстового PR: полнота → структура → markdown → читаемость
- Минимум одно содержательное предложение: «Предлагаю X, потому что Y» (про конкретное место)
- Комментарий: наведение на строку в diff → +, или Review changes
- Вердикт: предложения → Approve; проблема → Request changes; нечего сказать → Comment
- Студент спокойно может ставить апрув — так задумано
