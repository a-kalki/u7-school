# Ревьюим чужой homework-PR

**Краткое содержание:**
Первое настоящее ревью: находим PR одногруппника в общем чате, проверяем по памятке, оставляем минимум одно содержательное предложение и завершаем ревью вердиктом.

**Время:** ~25 мин

**Основные темы:**
1. Выбор PR для ревью
2. Проверка по чек-листу текстового PR
3. Вердикт: Comment / Approve / Request changes

**Термины:**
Files changed — вкладка PR с diff: какие строки изменены;
построчный комментарий — комментарий, привязанный к конкретной строке diff
