# shift(arr) — краткая выжимка

- Удаляет **первый** элемент и возвращает его
- Для пустого массива возвращает `undefined`
- **Мутабельная**
- Сдвиг влево: `for (let i = 0; i < length - 1; i++) arr[i] = arr[i + 1];` затем `delete arr[length-1]`
- Здесь идём **с начала** (в отличие от unshift) — подумай почему
- JSDoc обязателен
