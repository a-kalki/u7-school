# Шаги урока: Функция shift(arr) — удаление с начала

---

### Реализация shift()

**kind:** `text`

Реализуй функцию `shift(arr)` — удаление первого элемента со сдвигом. Создай файлы `arrays/shift.js` и `arrays/shift.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)

**Функция возвращает:** удалённый первый элемент, либо `undefined` для пустого массива.

Тестовые случаи:
- Должна удалить первый элемент и вернуть его: `shift([1, 2, 3])` → `1`, массив `[2, 3]`
- Должна вернуть `undefined` для пустого массива: `shift([])` → `undefined`
- Должна удалить единственный элемент: `shift([42])` → `42`, массив стал пустым
- Должна сохранить порядок остальных элементов: `shift(['a', 'b', 'c'])` → `'a'`, массив `['b', 'c']`
- Должна корректно удалить `falsy` значение (не спутать с `undefined`): `shift([0, 1])` → `0`
- Два `shift` подряд уменьшают длину на 2
- Должна выбросить `TypeError` если `arr` не массив

**Проверка сдвига:**
```javascript
const arr = [1, 2, 3, 4];
const removed = shift(arr);
expect(removed).toBe(1);
expect(len(arr)).toBe(3);
expect(arr[0]).toBe(2);
expect(arr[1]).toBe(3);
expect(arr[2]).toBe(4);
```
