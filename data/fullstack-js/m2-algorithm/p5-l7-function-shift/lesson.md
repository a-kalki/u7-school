# Функция shift(arr) — удаление с начала

**Краткое содержание:**
`shift(arr)` удаляет первый элемент массива, сдвигая все остальные на одну позицию влево. Возвращает удалённый элемент. Мутабельная. Для пустого массива — `undefined`.

### Алгоритм

1. Проверить, что `arr` — массив. Иначе `throw new TypeError`
2. `const length = len(arr)`
3. Если `length === 0` — вернуть `undefined`
4. `const item = arr[0]`
5. Сдвинуть все элементы **на одну позицию влево**, идя **с начала**:
   `for (let i = 0; i < length - 1; i++) arr[i] = arr[i + 1];`
6. `delete arr[length - 1]` — убрать ставший лишним последний индекс
7. Вернуть `item`

### Почему здесь идём с начала

В `unshift` мы сдвигали вправо и шли с конца, чтобы не затереть. В `shift` мы сдвигаем влево: `arr[i] = arr[i + 1]`. Здесь каждый элемент берёт значение следующего. Идём с начала: сначала `arr[0] = arr[1]` (старый `arr[0]` нам уже не нужен — мы его сохранили в `item`), потом `arr[1] = arr[2]`, и так до предпоследнего. Ни одно нужное значение не теряется.

```javascript
function shift(arr) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');
  const length = len(arr);
  if (length === 0) return undefined;
  const item = arr[0];
  for (let i = 0; i < length - 1; i++) arr[i] = arr[i + 1];
  delete arr[length - 1];
  return item;
}
```


### Оператор delete

Оператор `delete` подробно разобран в уроке 5.5 (pop): он убирает элемент массива по индексу, не сдвигая остальные, оставляя «дырку». Здесь `shift` использует `delete arr[length - 1]`, чтобы убрать ставший лишним последний индекс после сдвига.
