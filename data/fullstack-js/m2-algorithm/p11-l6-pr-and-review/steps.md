### Создание PR по шаблону

**kind:** `text`

Создай PR: base `main` ← compare `feat/object-methods`.

**Заголовок:**
```
Проект 11: Объекты — методы и глубокая обработка
```

**Описание — заполни по шаблону:**

```markdown
## Что сделано

Реализованы 5 функций для работы с объектами (папка object-utils/):

- keys(obj) — массив собственных ключей, аналог Object.keys()
- values(obj) — массив значений, аналог Object.values()
- entries(obj) — массив пар [ключ, значение], аналог Object.entries()
- cloneDeep(value) — глубокое копирование с рекурсией
- isEqualDeep(a, b) — глубокое структурное сравнение

## Особенности реализации

- Все функции иммутабельные — исходные объекты не меняются
- values и entries построены через композицию с keys — без дублирования for...in
- cloneDeep и isEqualDeep используют рекурсию, работают с любой вложенностью
- hasOwnProperty отличает собственные свойства от унаследованных
- isEqualDeep различает { x: undefined } и {} через hasOwnProperty

## Как запустить тесты

bun test
```

Что важно для ревьюеров, может быть не очевидно — обязательно указывай. Если считаешь, что команда «в теме», часть разделов можно сократить.

### Ревью-цикл, мерж и ретро: напоминания

**kind:** `text`

Полная методика — в проекте 4. Короткий ориентир:

1. **Пришли комментарии** → разбери на 🐛 баги / 🎨 стиль / 📝 документацию / 💡 предложения
2. **Правки** → в той же ветке, одно исправление = один коммит, затем `git push`
3. **Ответы** → на каждый комментарий + Resolve conversation
4. **Re-request review** → 2 апрува + все resolved → мерж
5. **Мерж** → `git switch main && git pull && git branch -d feat/object-methods && git fetch --prune`
