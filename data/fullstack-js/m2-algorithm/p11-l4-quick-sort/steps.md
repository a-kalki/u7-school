### Реализация quickSort()

**kind:** `text`

**Аналогия алгоритма "Быстрая".** У тебя стопка карточек. Выбери одну — опорную. Разложи остальные в две стопки: меньше опорной и больше (или равные). Теперь отсортируй каждую стопку **тем же способом**. Когда обе стопки готовы — склей: отсортированные «меньше» + опорная + отсортированные «больше». Это стратегия «разделяй и властвуй»: задача делится на меньшие подзадачи, которые решаются так же.

Реализуй функцию `quickSort(arr)`. Создай файлы `sorting/quick-sort.js` и `sorting/quick-sort.test.js`, следуй TDD.

**Функция принимает:** `arr`: `array` — массив чисел для сортировки.

**Функция возвращает:** `array` — новый отсортированный по возрастанию массив.

**Важно:** функция **иммутабельная** и **рекурсивная**.

**Человеческий псевдокод:**
1. Если в массиве 0 или 1 элемент — он уже отсортирован, верни его копию.
2. Выбери опорный элемент (например, первый).
3. Разложи остальные элементы в две стопки: меньше опорного и больше/равные.
4. Отсортируй каждую стопку этим же способом (рекурсивно).
5. Склей: отсортированные «меньше» + опорный + отсортированные «больше». Верни результат.

**Технический алгоритм (подсказка):**
- закэшируй длину: `const n = len(arr)` в начале функции (иначе `len` будет пересчитываться в цикле);
- если `n <= 1` — верни копию (`slice`);
- выбери `pivot = arr[0]`;
- пройди по элементам с индекса 1 до `n - 1`: меньшие `pivot` клади в `less`, остальные — в `greater` (через свой `push`);
- верни `concat(concat(quickSort(less), [pivot]), quickSort(greater))`.

**Тестовые случаи** (каждый — отдельный `test(...)`):
- Пустой массив: `quickSort([])` → `[]`
- Один элемент: `quickSort([7])` → `[7]`
- Уже отсортированный: `quickSort([1, 2, 3])` → `[1, 2, 3]`
- Обратный порядок: `quickSort([3, 2, 1])` → `[1, 2, 3]`
- С дубликатами: `quickSort([4, 2, 4, 1])` → `[1, 2, 4, 4]`
- Иммутабельность: исходный массив не изменился
- `quickSort('abc')` → `TypeError`
