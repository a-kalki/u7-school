# Шаги урока: Функции lastIndexOf() и includes()

---

### Реализация lastIndexOf()

**kind:** `text`

Реализуй функцию `lastIndexOf(arr, item)` — поиск последнего вхождения. Создай файлы `arrays/last-index-of.js` и `arrays/last-index-of.test.js`.

**Функция принимает:**
- `arr`: `array` — массив для поиска
- `item`: `any` — искомый элемент

**Функция возвращает:** `number` — индекс последнего вхождения, либо `-1` если не найден.

Тестовые случаи:
- Должна вернуть индекс **последнего** вхождения при дубликатах: `lastIndexOf([1, 2, 1, 3], 1)` → `2`
- Должна вернуть `-1` если элемента нет: `lastIndexOf([1, 2, 3], 9)` → `-1`
- Должна вернуть `0` для единственного вхождения в начале: `lastIndexOf([5, 6, 7], 5)` → `0`
- Должна вернуть последний индекс для элемента в конце: `lastIndexOf([5, 6, 7], 7)` → `2`
- Должна вернуть `-1` для пустого массива: `lastIndexOf([], 1)` → `-1`
- Должна найти символ: `lastIndexOf(['a', 'b', 'a'], 'a')` → `2`
- Должна найти строку: `lastIndexOf(['ab', 'cd', 'ab'], 'ab')` → `2`
- Должна не мутировать исходный массив
- Должна выбросить `TypeError` если `arr` не массив

### Реализация includes()

**kind:** `text`

Реализуй функцию `includes(arr, item)` — проверка наличия элемента. Создай файлы `arrays/includes.js` и `arrays/includes.test.js`.

Импортируй свой `indexOf` из `./index-of.js` — реализуй `includes` через него.

**Функция принимает:**
- `arr`: `array` — массив для поиска
- `item`: `any` — искомый элемент

**Функция возвращает:** `boolean` — `true` если элемент найден, `false` если нет.

**Алгоритм:**
1. Если `arr` не массив — `throw new TypeError`
2. `return indexOf(arr, item) !== -1`

**Принцип:** не дублируй логику поиска. `indexOf` уже умеет искать — используй его. Это композиция функций.

Тестовые случаи:
- Должна вернуть `true` если элемент есть: `includes([1, 2, 3], 2)` → `true`
- Должна вернуть `false` если элемента нет: `includes([1, 2, 3], 9)` → `false`
- Должна вернуть `false` для пустого массива: `includes([], 1)` → `false`
- Должна вернуть `true` для первого элемента: `includes([1, 2, 3], 1)` → `true`
- Должна вернуть `true` для последнего элемента: `includes([1, 2, 3], 3)` → `true`
- Должна найти строку: `includes(['a', 'b'], 'b')` → `true`
- Должна различать `0` и `false`: `includes([0], false)` → `false`, `includes([0], 0)` → `true`
- Должна не мутировать исходный массив
- Должна выбросить `TypeError` если `arr` не массив
