# lastIndexOf и includes — краткая выжимка

- `lastIndexOf(arr, item)` — индекс **последнего** вхождения, идём с конца
- Не найден → `-1`
- `includes(arr, item)` — `true`/`false`, реализуется через `indexOf(...) !== -1`
- Обе не мутируют массив
- `includes` — пример переиспования: не дублируем логику поиска, делегируем `indexOf`
- JSDoc обязателен
