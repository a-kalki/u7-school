# Практика: ревью кодового PR одногруппника — краткая выжимка

- Все делают проект 3 — можно сравнивать подходы к одной задаче
- Выбор: не свой, с наименьшим числом ревью
- Методика: сигнатура → тесты → реализация; чек-лист: корректность, граничные, правила, читаемость, тесты
- Минимум: 1–2 содержательных замечания «Предлагаю/Нужно X, потому что Y» про конкретное место
- Комментарии построчно в Files changed
- Вердикт: предложения → Approve; баг/нарушение → Request changes; нечего сказать → Comment
