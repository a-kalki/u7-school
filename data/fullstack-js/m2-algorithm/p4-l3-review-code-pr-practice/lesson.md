# Практика: ревью кодового PR одногруппника

**Краткое содержание:**
Первое настоящее кодовое ревью: находим в чате PR одногруппника из проекта 3, читаем по методике, оставляем минимум 1–2 содержательных замечания, ставим вердикт.

**Время:** ~30 мин

**Основные темы:**
1. Выбор PR
2. Проведение ревью
3. Вердикт и рефлексия

**Термины:**
мысленный прогон — выполнение кода в голове по шагам на конкретных данных
