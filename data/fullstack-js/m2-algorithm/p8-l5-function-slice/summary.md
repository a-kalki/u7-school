# Функция slice(arr, start, end) — краткая выжимка

- slice(arr, start, end) — новый массив из копии части исходного; ИММУТАБЕЛЬНАЯ
- Отрицательные индексы: отсчёт с конца (len + индекс); end «не включая», необязателен
- Правила те же, что у строкового slice из проекта 6 — разница только в типе результата
- start >= end или пустой исходный → []
- Исходный массив нетронут — обязательная проверка
