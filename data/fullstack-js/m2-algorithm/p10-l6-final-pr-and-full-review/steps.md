### Создание финального PR

**kind:** `text`

Создай Pull Request:

1. На GitHub нажми **Compare & pull request**
2. Выбери base: `main`, compare: `feat/business-utils`

Заполни заголовок и описание:

**Заголовок:** `Проект 10: Бизнес-утилиты — query, URL, CSV, группировка`

**Описание:** перечисли все 5 функций с краткими пояснениями:

- `getQueryParams(url)` — разбор query-строки URL в объект. Поддерживает URL-кодирование (через `decodeURIComponent`).
- `parseUrl(url)` — разбор URL на 6 компонентов: protocol, host, port, path, query, hash. Важен порядок разбора от внешних разделителей к внутренним.
- `toCSV(data)` — массив объектов → CSV-строка. Первая строка — заголовки. Экранирует запятые, кавычки, переносы строк.
- `fromCSV(csvString)` — CSV-строка → массив объектов. Реализован как конечный автомат с посимвольным обходом и флагом `inQuotes`. Обратен к `toCSV` (round-trip).
- `groupBy(array, key)` — группировка массива объектов по значению ключа. Объекты в группах — те же ссылки.

Все функции используют только собственные реализации (`indexOf`, `slice`, `len`, `push`, `keys`) и разрешённые глобальные функции (`decodeURIComponent`).

Это финальный PR модуля 2. Всего реализовано ~55 функций.
