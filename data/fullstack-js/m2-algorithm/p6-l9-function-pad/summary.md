# Функция pad(str, length, char, side) — краткая выжимка

- pad(str, length, char, side) — дополняет строку до длины length: слева, справа или с обеих сторон
- padding = length - len(str); строка уже достаточной длины → без изменений
- 'both': слева Math.floor(padding / 2), остаток справа — лишний символ при нечётном padding идёт вправо
- char может быть многосимвольным: повторяется циклично и обрезается до нужной длины
- Неверный side (не 'left'/'right'/'both') — ошибка
