### Создание PR по шаблону

**kind:** `text`

Создай PR: base `main` ← compare `feat/array-basics`.

**Заголовок:**
```
Проект 7: Массивы — структура и базовые операции
```

**Описание — заполни по шаблону:**

```markdown
## Что сделано

Реализованы 9 функций для работы с массивами (папка array-utils/):

- len(arr) — количество элементов
- at(arr, index) — доступ по индексу, с отрицательными
- push(arr, item) — добавление в конец (мутирует)
- pop(arr) — удаление с конца (мутирует)
- unshift(arr, item) — добавление в начало (мутирует)
- shift(arr) — удаление с начала (мутирует)
- indexOf(arr, item) — индекс первого вхождения
- lastIndexOf(arr, item) — индекс последнего вхождения
- includes(arr, item) — проверка наличия (через indexOf)

## Особенности реализации

- Папка array-utils/ — чтобы не конфликтовать со строковыми функциями
  того же имени (len, indexOf, includes)
- Мутабельные функции отмечены в JSDoc; в тестах проверяются
  и возвращаемое значение, и состояние массива после вызова
- Своя len считает до первого undefined (без .length)
- includes построен на indexOf

## Как запустить тесты

bun test
```

Что важно для ревьюеров, может быть не очевидно — обязательно указывай. Если считаешь, что команда «в теме», часть разделов можно сократить.
