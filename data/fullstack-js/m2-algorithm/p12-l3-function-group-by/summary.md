# groupBy(array, key) — краткая выжимка

- Группирует массив объектов по значению указанного ключа
- Результат — объект: ключи = значения группировки, значения = массивы объектов
- Использует `hasOwnProperty` для проверки существования группы
- Объекты в группах — те же ссылки (не копии)
- Ключи результата всегда строки (даже для числовых значений группировки)
- Пустой массив → `{}`
- Использует свои: `len`, `push`, `hasOwnProperty`
- **Иммутабельная** — не меняет исходный массив
- JSDoc обязателен, отметь что объекты в группах не клонируются
