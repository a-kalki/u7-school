# Правила ревью — краткая выжимка

- Два типа комментариев: 🟢 предложение («Предлагаю/Можно...», автор решает сам) и 🔴 критическое («Нужно...», обязательно исправить)
- Формула комментария: действие + потому что
- Итог ревью: только предложения → Approve ✅; есть критические → Request changes ❌; Comment — без вердикта
- Request changes ≠ «код плохой», это «найдена проблема, исправь — и получишь апрув»
- Чек-лист кода: корректность, граничные случаи, правила модуля, читаемость, тесты
- Чек-лист текстового PR: полнота, структура, markdown, читаемость
- Правило курса: 2 апрува для мержа
