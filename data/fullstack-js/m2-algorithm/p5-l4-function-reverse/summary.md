# Функция reverse(str) — краткая выжимка

- `reverse(str)` → `string`: новая строка с символами в обратном порядке
- Подход: `result = ''`, цикл от конца к началу, `result += str[i]`
- Классические случаи: `''` → `''`, один символ → тот же, палиндром → тот же (`'racecar'`)
- Пробелы и кириллица переворачиваются как обычные символы
- `TypeError` для `123` и `null`
- Коммит: «Реализована reverse — переворот строки»
