# Шаги урока: Пуш ветки и Pull Request для проекта 5

---

### Финальная проверка

**kind:** `text`

Перед отправкой кода на GitHub убедись, что всё в порядке:

1. Все 9 функций готовы в папке `arrays/` и протестированы: `len`, `at`, `push`, `pop`, `unshift`, `shift`, `indexOf`, `lastIndexOf`, `includes`
2. JSDoc добавлен ко всем функциям (мутабельные — `push`, `pop`, `unshift`, `shift` — отмечены явно в описании)
3. `bun test` — все тесты зелёные
4. `git status` — working tree clean, ты в ветке `feat/array-basics`
5. `git log --oneline` — осмысленная история коммитов (один коммит на функцию или группу)

Если есть незакоммиченные изменения — закоммить их.

---

### Пуш ветки

**kind:** `text`

Отправь ветку на GitHub:

```
git push -u origin feat/array-basics
```

Проверь, что ветка появилась на GitHub — открой репозиторий, посмотри выпадающий список веток.

---

### Создание PR

**kind:** `text`

Создай Pull Request:

1. На GitHub нажми **Compare & pull request**
2. Выбери base: `main`, compare: `feat/array-basics`

Заполни заголовок и описание:

**Заголовок:** `Проект 5: Массивы — структура и базовые операции`

**Описание:** перечисли все 9 функций с краткими пояснениями. Отметь, какие из них мутабельные (`push`, `pop`, `unshift`, `shift`), а какие только читают массив (`len`, `at`, `indexOf`, `lastIndexOf`, `includes`). Укажи как запустить тесты (`bun test`), отметь особенности реализации (папка `arrays/` для избежания конфликта имён со строковым `len`, собственная `len` считает до `undefined`, `includes` построен на `indexOf`).

**Примечание:** в разделе "Описание PR" даны расширенные коментарии. Если считаешь что участники в команде "в теме", то можешь опустить некоторые разделы. Но обязательно укажи то что важно для ревьюеров, что может быть не очевидно.

### Приглашение ревьюеров и pin

**kind:** `text`
