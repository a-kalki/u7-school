# toCSV(data) — краткая выжимка

- Преобразует массив объектов в CSV-строку
- Первая строка — заголовки (ключи первого объекта через `keys`)
- Экранирование: запятая/кавычка/перенос строки → обернуть в `"`, кавычки внутри удвоить
- Числа и булевы → строка, `null`/`undefined` → пустая строка
- Пустой массив → `''`
- Использует свои: `keys`, `len`
- Строки собираются через `+=` (ручная конкатенация, аналог `join`)
- **Иммутабельная** — не меняет исходный массив
- JSDoc обязателен, отметь правила экранирования
