# Шаги урока: Функция toCSV(data)

---

### Разбор алгоритма toCSV

**kind:** `text`

Прежде чем писать код, разберись в алгоритме. Функция `toCSV` работает в два этапа: сначала собирает заголовки, затем строки данных. Но главная хитрость — в экранировании значений.

**Этап 1 — заголовки.** Берёшь первый объект `data[0]`, получаешь его ключи через `keys()`. Это будет первая строка CSV. Например, для `[{ name: 'Анна', age: 25 }]` заголовки: `['name', 'age']`.

**Этап 2 — строки данных.** Для каждого объекта в массиве проходишь по тем же ключам и собираешь значения. Значения склеиваешь через запятую. Каждую строку заканчиваешь символом `\n`.

**Этап 3 — экранирование.** Не каждое значение можно просто вставить в CSV. Три символа ломают формат:
- `,` — разделитель полей. Если запятая внутри значения, CSV-читатель подумает что это новое поле
- `"` — символ кавычки. Используется для обрамления экранированных значений
- `\n` — разделитель строк. Если перенос строки внутри значения, читатель подумает что это новая строка

Поэтому для каждого значения нужно принять решение:
1. **Проверить, есть ли спецсимволы.** Пройти по значению и поискать `,`, `"`, `\n`.
2. **Если нет** — вернуть значение как есть.
3. **Если есть** — обернуть в двойные кавычки. Но перед этим нужно обезвредить кавычки внутри: заменить `"` на `""` (удвоение).

Пример: значение `say "hi"` → содержит `"` → нужно экранирование → удваиваем: `say ""hi""` → оборачиваем: `"say ""hi"""`.

Почему удвоение? Потому что в CSV двойная кавычка внутри экранированного поля — это способ сказать «это не конец поля, это символ кавычки». Одинарная кавычка внутри `"..."` означала бы закрытие поля.

**Преобразование типов.** Числа и булевы значения нужно превратить в строку. Используй глобальную функцию `String()` — она разрешена (не метод строки/массива/объекта). `null` и `undefined` должны становиться пустой строкой.

### Реализация toCSV()

**kind:** `text`

> Убедись, что ты в ветке `feat/business-utils`.

Реализуй функцию `toCSV(data)` — преобразование массива объектов в CSV-строку. Создай файлы `utils/to-csv.js` и `utils/to-csv.test.js`, следуй TDD.

**Функция принимает:**
- `data`: `array` — массив объектов с одинаковой структурой

**Функция возвращает:** `string` — CSV-строка. Первая строка — заголовки (ключи первого объекта), затем строки данных.

**Важно:** функция **иммутабельная**. Используй свои `keys`, `len`. Для экранирования значений напиши вспомогательную функцию `escapeCSV`.

Правила экранирования CSV:
- Если значение содержит запятую, двойную кавычку или перенос строки — обернуть в двойные кавычки
- Кавычки внутри значения удваиваются: `"` → `""`
- Числа и булевы значения преобразуются в строку через `String()`
- `null` и `undefined` → пустая строка

Краткий алгоритм:
1. Проверить что `data` — массив. Пустой массив → `''`.
2. Получить заголовки через `keys(data[0])`.
3. Собрать строку заголовков, разделяя запятыми, с экранированием.
4. Для каждого объекта собрать строку значений, разделяя запятыми, с экранированием.
5. Строки разделять символом `\n`.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть пустую строку для пустого массива: `toCSV([])` → `''`
- Должна преобразовать один объект: `toCSV([{ name: 'Анна', age: 25 }])` → `'name,age\nАнна,25\n'`
- Должна преобразовать несколько объектов: `toCSV([{ a: 1 }, { a: 2 }, { a: 3 }])` → `'a\n1\n2\n3\n'`
- Должна экранировать значение с запятой: `toCSV([{ name: 'Анна, Борис', age: 25 }])` → `'name,age\n"Анна, Борис",25\n'`
- Должна экранировать значение с кавычками: `toCSV([{ text: 'say "hi"' }])` → `'text\n"say ""hi"""\n'`
- Должна экранировать значение с переносом строки: `toCSV([{ desc: 'line1\nline2' }])` → `'desc\n"line1\nline2"\n'`
- Должна преобразовывать числа в строку: `toCSV([{ x: 42 }, { x: -7 }])` → `'x\n42\n-7\n'`
- Должна преобразовывать булевы значения в строку: `toCSV([{ a: true }, { a: false }])` → `'a\ntrue\nfalse\n'`
- Должна превращать `null` в пустую строку: `toCSV([{ x: 1 }, { x: null }])` → `'x\n1\n\n'` (между `\n` и `\n` — пусто)
- Должна превращать `undefined` в пустую строку: `toCSV([{ x: 'a' }, {}])` → `'x\na\n\n'` (отсутствующий ключ → пусто)
- Должна выбросить `TypeError` если аргумент не массив

### Вопросы на понимание

**kind:** `text`

Ответь на вопросы. Если не знаешь — проверь гипотезу кодом через `bun`.
