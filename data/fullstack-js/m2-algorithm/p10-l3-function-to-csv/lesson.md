# Функция toCSV(data)

**Краткое содержание:**
Третья бизнес-утилита — преобразование массива объектов в CSV-строку. Студент применяет `keys`, `join`, `len`, `push` и ручную обработку экранирования для создания строки, совместимой с табличными процессорами.

### 1. Что такое CSV

CSV (Comma-Separated Values) — текстовый формат табличных данных:

```
name,age,city
Анна,25,Москва
Борис,30,Питер
```

- Первая строка — заголовки (ключи объектов)
- Последующие строки — значения
- Значения разделены запятыми
- Значения, содержащие запятую или кавычку, оборачиваются в двойные кавычки
- Кавычки внутри значений удваиваются

### 2. Алгоритм toCSV

Функция работает в три этапа:

**Этап 1 — получить заголовки.** Берём первый объект массива `data[0]` и получаем его ключи через `keys()`. Это будет первая строка CSV.

**Этап 2 — собрать строку.** Для заголовков и для каждой строки данных:
1. Пройти по всем ключам
2. Для каждого значения вызвать `escapeCSV()` — она решит, нужно ли экранирование
3. Склеить значения через запятую
4. Добавить `\n` в конце строки

**Этап 3 — экранировать значение (escapeCSV).** Для каждого значения нужно принять решение:
1. **Проверить, нужно ли экранирование.** Если в строке есть запятая, кавычка или перенос строки — значение НЕЛЬЗЯ вставить как есть, потому что эти символы имеют специальное значение в CSV (запятая разделяет поля, кавычка открывает/закрывает экранирование, `\n` разделяет строки).
2. **Если спецсимволов нет** — вернуть значение как есть.
3. **Если спецсимволы есть** — обернуть значение в двойные кавычки. Но перед этим нужно обезвредить кавычки ВНУТРИ значения: каждую `"` заменить на `""` (удвоение). Потому что в CSV двойная кавычка внутри экранированного поля — это способ сказать «здесь не конец поля, а символ кавычки».

Пример трансформации значения `say "hi"`:
```
исходное:  say "hi"
шаг 1:     находим " — это спецсимвол → нужно экранирование
шаг 2:     удваиваем кавычки: say ""hi""
шаг 3:     оборачиваем:       "say ""hi"""
результат: "say ""hi"""
```

**Почему разрешён `String(value)`.** `String` — это глобальная функция, а не метод строки/массива/объекта. Она преобразует любое значение в строку: `String(42)` → `'42'`, `String(true)` → `'true'`, `String(null)` → `'null'`. Однако для `null` и `undefined` мы хотим пустую строку, поэтому проверяем `value !== undefined` до вызова.

```javascript
function toCSV(data) {
  if (!Array.isArray(data)) throw new TypeError('Ожидается массив');
  if (len(data) === 0) return '';

  // 1. Заголовки — ключи первого объекта
  const headers = keys(data[0]);

  // 2. Строим строку заголовков
  let result = '';
  for (let i = 0; i < len(headers); i++) {
    if (i > 0) result += ',';
    result += escapeCSV(headers[i]);
  }
  result += '\n';

  // 3. Строим строки данных
  for (let i = 0; i < len(data); i++) {
    for (let j = 0; j < len(headers); j++) {
      if (j > 0) result += ',';
      const value = data[i][headers[j]];
      result += escapeCSV(value !== undefined ? String(value) : '');
    }
    result += '\n';
  }

  return result;
}

// Вспомогательная функция экранирования
function escapeCSV(value) {
  // Если значение содержит запятую, кавычку или перенос строки — оборачиваем в кавычки
  let needsQuotes = false;
  for (let i = 0; i < len(value); i++) {
    if (value[i] === ',' || value[i] === '"' || value[i] === '\n') {
      needsQuotes = true;
      break;
    }
  }

  if (!needsQuotes) return value;

  // Экранируем: удваиваем кавычки внутри
  let escaped = '"';
  for (let i = 0; i < len(value); i++) {
    if (value[i] === '"') {
      escaped += '""';
    } else {
      escaped += value[i];
    }
  }
  escaped += '"';
  return escaped;
}
```

### 3. Правила экранирования CSV

| Значение | CSV-представление | Причина |
|----------|-------------------|---------|
| `hello` | `hello` | Простое значение |
| `hello, world` | `"hello, world"` | Содержит запятую |
| `say "hi"` | `"say ""hi"""` | Содержит кавычки (удваиваются) |
| `line1\nline2` | `"line1\nline2"` | Содержит перенос строки |
| `42` | `42` | Число → строка |
| `true` | `true` | Булево → строка |
| `null` | (пусто) | null → пустая строка |
| `undefined` | (пусто) | undefined → пустая строка |

### 4. Граничные случаи

- `toCSV([])` → `''` (пустой массив)
- `toCSV([{ a: 1 }])` → `"a\n1\n"`
- `toCSV([{ name: 'Анна', age: 25 }])` → `"name,age\nАнна,25\n"`
- `toCSV([{ name: 'Анна, Борис', age: 25 }])` → `"name,age\n\"Анна, Борис\",25\n"` (запятая экранирована)
- `toCSV([{ text: 'say "hi"' }])` → `"text\n\"say \"\"hi\"\"\"\n"` (кавычки удвоены)
- `toCSV([{ desc: 'line1\nline2' }])` → `"desc\n\"line1\nline2\"\n"` (перенос строки внутри кавычек)
- `toCSV([{ x: 42 }, { x: -7 }])` → `"x\n42\n-7\n"` (числа → строки)
- `toCSV([{ a: true }, { a: false }])` → `"a\ntrue\nfalse\n"` (булевы → строки)
- `toCSV([{ x: 1 }, { x: null }])` → `"x\n1\n\n"` (null → пусто — между `\n` и `\n` ничего нет)
- `toCSV([{ x: 'a' }, {}])` → `"x\na\n\n"` (отсутствующий ключ → пусто)
- `toCSV('не массив')` → `TypeError`

### 5. Какие свои функции используем

- `keys` — получить заголовки из первого объекта
- `len` — длина массива/строки
- Сборка строки через `+=` (ручная конкатенация, аналог `join`)
