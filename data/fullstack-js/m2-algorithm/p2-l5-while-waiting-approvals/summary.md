# Пока ждёшь апрувы — краткая выжимка

- Следить в двух местах: общий чат + GitHub (вкладка Pull requests, Notifications, почта)
- Проверить Settings → Notifications: «Participating and @mentions» включены
- За свой PR отвечаешь ты — никто не будет звать персонально
- Эскалация: 1–2 дня — вежливое напоминание в личку → ещё день — пинг в чате → другой ревьюер (2 апрува ≠ от тех же людей) → крайний случай — ментор
- Не молчать неделю: напоминать — нормально
- И наоборот: тебя попросили ревью — не тяни
