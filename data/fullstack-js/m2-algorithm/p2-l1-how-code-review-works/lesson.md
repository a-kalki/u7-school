# Как работает код-ревью

**Краткое содержание:**
Зачем нужно ревью, если код и так работает; кто такие ревьюеры в нашем курсе; механика ревью на GitHub (Comment / Approve / Request changes).

**Время:** ~15 мин

**Основные темы:**
1. Ценность код-ревью
2. Ревьюеры в нашей команде
3. Три исхода ревью на GitHub

**Термины:**
код-ревью — по англ. `code review`: проверка изменений другими людьми до слияния;
ревьюер — по англ. `reviewer`: тот, кто проверяет чужие изменения;
автор — создатель PR, тот, кто вносил изменения;
уведомление — по англ. `notification`: сигнал о событии (комментарий, ревью) на GitHub или в почте
