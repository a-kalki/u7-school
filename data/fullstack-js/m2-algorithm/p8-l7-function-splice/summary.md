# Функция splice(arr, start, deleteCount, ...items) — краткая выжимка

- splice — удаление и вставка за один вызов; МУТАБЕЛЬНАЯ; возвращает массив удалённых
- Двухчастная реализация: сначала удаление, потом вставка (промежуточный коммит)
- rest-параметр `...items` собирает аргументы после deleteCount в массив; функция вариадическая
- deleteCount не передан → удалить всё до конца; deleteCount = 0 → только вставка
- Отрицательный start — отсчёт с конца; за границами → пустой результат
- Самая сложная функция проекта — не торопись, TDD по одному тесту
