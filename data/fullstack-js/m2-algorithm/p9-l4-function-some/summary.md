# some(arr, callback) — краткая выжимка

- Проверяет, удовлетворяет ли **хотя бы один** элемент условию callback
- **Ранний выход** — обход останавливается при первом `true`
- Возвращает `true` при совпадении, `false` если ни один не подошёл
- Для пустого массива возвращает `false`
- Callback получает (элемент, индекс, массив)
- JSDoc обязателен, отметь ранний выход
