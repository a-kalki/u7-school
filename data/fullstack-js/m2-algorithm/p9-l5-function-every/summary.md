# every(arr, callback) — краткая выжимка

- Проверяет, удовлетворяют ли **все** элементы условию callback
- **Ранний выход** — обход останавливается при первом `false`
- Возвращает `true` если все подошли, `false` при первом несовпадении
- Для пустого массива возвращает `true` (вакуумная истина)
- Callback получает (элемент, индекс, массив)
- Логическая симметрия с `some`: `every` = ∀, `some` = ∃
- JSDoc обязателен, отметь ранний выход
