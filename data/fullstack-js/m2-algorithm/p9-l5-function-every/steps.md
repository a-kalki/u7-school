# Шаги урока: Функция every(arr, callback) — проверка «все»

---

### Реализация every()

**kind:** `text`

Реализуй функцию `every(arr, callback)` — проверка, удовлетворяют ли все элементы условию. Создай файлы `array-utils/every.js` и `array-utils/every.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для проверки
- `callback`: `function` — функция-предикат, возвращает `true`/`false`

**Функция возвращает:** `boolean` — `true` если все элементы удовлетворяют условию, иначе `false`.

**Важно:** функция должна делать **ранний выход** — остановить обход при первом `false`.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть `true` если все подходят: `every([2, 4, 6], x => x % 2 === 0)` → `true`
- Должна вернуть `false` если хотя бы один не подходит: `every([2, 3, 4], x => x % 2 === 0)` → `false`
- Должна вернуть `true` для пустого массива: `every([], fn)` → `true`
- Должна остановиться при первом `false` (ранний выход): создай callback-счётчик
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция
