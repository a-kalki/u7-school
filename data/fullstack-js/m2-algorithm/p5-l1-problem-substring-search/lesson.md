# Проблема: поиск подстроки

**Краткое содержание:**
Вторая реализация: где встречается поиск подстроки, как формально выглядит задача, идея наивного алгоритма. Состав API проекта и ветка `feat/substring-search`.

**Время:** ~20 мин

**Основные темы:**
1. Где встречается поиск подстроки
2. Формальная постановка и наивный алгоритм
3. Ветка проекта

**Термины:**
подстрока — непрерывная последовательность символов внутри строки;
вхождение — позиция, с которой подстрока начинается в строке;
индекс — номер позиции символа (счёт с нуля);
наивный алгоритм — прямолинейное решение «в лоб», без хитростей
