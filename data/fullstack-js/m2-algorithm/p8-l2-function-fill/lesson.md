# Функция fill(arr, value, start, end)

**Краткое содержание:**
Заполнение массива (или его части) указанным значением — мутабельная, возвращает тот же массив. Нормализация отрицательных индексов — как в slice из проекта 6.

**Время:** ~15 мин

**Основные темы:**
1. Реализация fill() через TDD

**Термины:**
параметр по умолчанию — значение, которое используется, когда аргумент не передан;
нормализация — приведение индекса к допустимому диапазону `[0, len(arr)]`: отрицательный отсчитывается с конца (`len + индекс`), выход за границу обрезается
