# Шаги урока: Функция fill(arr, value, start, end)

---

### Реализация fill() через TDD

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

Реализуй функцию `fill(arr, value, start, end)` — заполнение массива (или его части) указанным значением. Создай файлы `array-utils/fill.js` и `array-utils/fill.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)
- `value`: `any` — значение для заполнения
- `start`: `number` (необязательный, по умолчанию `0`) — начальный индекс
- `end`: `number` (необязательный, по умолчанию `len(arr)`) — конечный индекс (не включая)

**Функция возвращает:** `array` — тот же массив `arr` (изменённый).

**Важно:** функция **мутабельная** — меняет массив на месте. В JSDoc отметь это. В тестах проверяй и содержимое массива после вызова, и что возвращается тот же самый массив.

**Напоминание по нормализации индексов:**
- Отрицательный индекс → `len(arr) + индекс` (отсчёт с конца)
- После приведения отрицательный может остаться отрицательным → обнулить
- Индекс больше `len(arr)` → обрезать до `len(arr)`

**Термины:**
параметр по умолчанию — значение, которое используется, когда аргумент не передан;
нормализация — приведение индекса к допустимому диапазону `[0, len(arr)]`: отрицательный отсчитывается с конца (`len + индекс`), выход за границу обрезается

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна заполнить весь массив: `fill([1, 2, 3], 0)` → массив `[0, 0, 0]`
- Должна заполнить от начального индекса и до конца: `fill([1, 2, 3], 0, 1)` → массив `[1, 0, 0]`
- Должна заполнить часть от start до end: `fill([1, 2, 3, 4], '*', 1, 3)` → `[1, '*', '*', 4]`
- Должна обработать end больше длины: `fill([1, 2, 3, 4], '*', 1, 7)` → `[1, '*', '*', '*']`
- Должна вернуть тот же массив (проверь `===` между переданным массивом и возвращённым)
- Должна работать с пустым массивом: `fill([], 5)` → `[]`
- Должна ничего не менять если start >= end: `fill([1, 2, 3], 0, 2, 1)` → `[1, 2, 3]`
- Должна поддерживать отрицательный start: `fill([1, 2, 3, 4], '*', -2)` → `[1, 2, '*', '*']`
- Должна поддерживать отрицательный end: `fill([1, 2, 3, 4], '*', 0, -1)` → `['*', '*', '*', 4]`
- Должна обрабатывать отрицательный start больше `len`: `fill([1, 2, 3, 4], '*', -5)` → `['*', '*', '*', '*']`
- Должна работать с start и end по умолчанию: `fill([1, 2, 3], 'a')` → `['a', 'a', 'a']`
- Должна нормализовать start > len: `fill([1, 2], 5, 5)` → `[1, 2]` (без изменений)
- Должна нормализовать отрицательный start, уходящий за границу: `fill([1, 2, 3], '*', -10, 2)` → `['*', '*', 3]`
- Должна нормализовать отрицательный end, уходящий за границу: `fill([1, 2, 3, 4], '*', 0, -5)` → `[1, 2, 3, 4]` (без изменений)
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `start`, `end` не числа
