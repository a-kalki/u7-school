# Функция fill(arr, value, start, end) — краткая выжимка

- fill(arr, value, start, end) — заполняет массив или его часть значением; МУТАБЕЛЬНАЯ
- Возвращает тот же самый массив (=== с аргументом) — проверяем в тестах
- start по умолчанию 0, end по умолчанию len(arr); end «не включая»
- Нормализация как в slice: отрицательный → len + индекс; за границей → обрезать
- start >= end после нормализации → без изменений
