# Функция repeat(str, count) — краткая выжимка

- `repeat(str, count)` → `string`: `result += str` в цикле `count` раз
- Дробный count: `2.7` → 2 повторения; `0.5` → `''`; пропущенный count → `''`
- `count = 0` → `''`; пустая строка → `''` всегда
- Ошибки: `RangeError` для отрицательного count, `TypeError` для не-строки / не-числа
- Тонкие случаи сначала определи для себя, потом зафиксируй тестами
- Коммит: «Реализована repeat — повторение строки»
