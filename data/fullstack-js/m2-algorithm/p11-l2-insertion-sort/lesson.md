# Сортировка вставками (insertion sort)

**Краткое содержание:**
Второй алгоритм сортировки. Сортировка вставками работает как сортировка карт в руке: берём очередной элемент и вставляем его в нужное место уже отсортированной части массива.

### 1. Идея: сортировка карт в руке

Представь, что тебе раздают карты, и ты раскладываешь их по возрастанию в руке. Ты берёшь новую карту и вставляешь её между теми, что уже лежат в порядке. Ты не перебираешь всю руку заново — только ищешь место для одной карты.

Сортировка вставками делает то же самое с массивом:
- слева от текущей позиции — уже отсортированная часть;
- берём очередной элемент и «вдвигаем» его в правильное место, сдвигая большие элементы вправо.

### 2. Алгоритм по шагам

1. Проверить тип и скопировать массив (как в `bubbleSort`).
2. Внешний цикл `i` от 1 до `len - 1` — элемент `result[i]` это «карта» для вставки.
3. Запомнить `current = result[i]`.
4. Внутренний цикл: сдвигать элементы вправо, пока `j >= 0` и `result[j] > current`.
5. Поставить `current` на освободившееся место `result[j + 1]`.
6. Вернуть `result`.

### 3. Реализация

```javascript
function insertionSort(arr) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');

  const result = slice(arr, 0, len(arr));
  const n = len(result);

  for (let i = 1; i < n; i++) {
    const current = result[i];
    let j = i - 1;
    while (j >= 0 && result[j] > current) {
      result[j + 1] = result[j];
      j--;
    }
    result[j + 1] = current;
  }

  return result;
}
```

Обрати внимание: `while` сдвигает элементы вправо, а `current` хранится в отдельной переменной — поэтому его значение не затирается при сдвигах.

### 4. Ключевое свойство: быстрая на почти отсортированных данных

В отличие от пузырька, вставки сдвигают элементы только пока встречают значения больше `current`. Если массив **уже отсортирован**, внутренний цикл не выполнится ни разу — каждая вставка происходит мгновенно. Итого на отсортированном массиве вставки делают ~n операций, а пузырёк — всё те же ~n²/2 сравнений.

Это важная идея: **скорость алгоритма может зависеть от того, какие данные пришли на вход**. К этому мы вернёмся при измерении скорости в уроке 5.

### 5. Граничные случаи

- `insertionSort([])` → `[]`
- `insertionSort([7])` → `[7]`
- `insertionSort([1, 2, 3])` → `[1, 2, 3]` (быстро, почти без сдвигов)
- `insertionSort([3, 2, 1])` → `[1, 2, 3]`
- `insertionSort([4, 2, 4, 1])` → `[1, 2, 4, 4]`
- `insertionSort('abc')` → `TypeError`
