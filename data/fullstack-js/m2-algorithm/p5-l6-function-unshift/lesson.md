# Функция unshift(arr, item) — добавление в начало

**Краткое содержание:**
`unshift(arr, item)` добавляет элемент в начало массива, сдвигая все существующие элементы на одну позицию вправо. Возвращает новую длину. Мутабельная.

### Алгоритм

1. Проверить, что `arr` — массив. Иначе `throw new TypeError`
2. `const length = len(arr)`
3. Сдвинуть все элементы **на одну позицию вправо**, идя **с конца**:
   `for (let i = length; i > 0; i--) arr[i] = arr[i - 1];`
4. `arr[0] = item`
5. Вернуть `length + 1`

### Почему идём с конца

Если сдвигать слева направо, каждый следующий элемент затрёт предыдущий:
```
шаг 1: arr[1] = arr[0]  ← затёрли старый arr[1]!
шаг 2: arr[2] = arr[1]  ← но arr[1] уже равен arr[0]... все стали одинаковыми
```

Идя с конца, мы сначала переносим последний элемент в новую позицию, освобождая место, и так до самого начала. Ни один элемент не теряется.

```javascript
function unshift(arr, item) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');
  const length = len(arr);
  for (let i = length; i > 0; i--) arr[i] = arr[i - 1];
  arr[0] = item;
  return length + 1;
}
```
