# Шаги урока: Функция unshift(arr, item) — добавление в начало

---

### Реализация unshift()

**kind:** `text`

Реализуй функцию `unshift(arr, item)` — добавление элемента в начало со сдвигом. Создай файлы `arrays/unshift.js` и `arrays/unshift.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)
- `item`: `any` — элемент для добавления

**Функция возвращает:** `number` — новая длина массива.

Тестовые случаи:
- Должна добавить элемент в начало и вернуть новую длину: `unshift([2, 3], 1)` → `3`, массив `[1, 2, 3]`
- Должна работать с пустым массивом: `unshift([], 'a')` → `1`, массив `['a']`
- Должна добавить в массив из одного элемента: `unshift([20], 10)` → `2`, массив `[10, 20]`
- Должна сохранить порядок остальных элементов (ничего не затерлось): `unshift(['b', 'c', 'd'], 'a')` → `['a', 'b', 'c', 'd']`
- Два `unshift` подряд: первый элемент становится вторым
- Должна выбросить `TypeError` если `arr` не массив
