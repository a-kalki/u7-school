# unshift(arr, item) — краткая выжимка

- Добавляет элемент в **начало**, сдвигая остальные вправо
- Возвращает **новую длину**
- **Мутабельная**
- Сдвиг: цикл от конца к началу `arr[i] = arr[i-1]`, затем `arr[0] = item`
- Идти нужно **с конца**, чтобы не затереть элементы
- JSDoc обязателен
