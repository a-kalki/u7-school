# Функция pop(arr) — удаление с конца

**Краткое содержание:**
`pop(arr)` удаляет последний элемент массива и возвращает его. Мутабельная операция. Для пустого массива возвращает `undefined`. В этом уроке впервые вводится оператор `delete`.

### Алгоритм

1. Проверить, что `arr` — массив. Иначе `throw new TypeError`
2. `const length = len(arr)`
3. Если `length === 0` — вернуть `undefined`
4. `const item = arr[length - 1]`
5. `delete arr[length - 1]` — создаёт «дырку»: `arr[last] === undefined`, и `len` в следующий раз остановится раньше
6. Вернуть `item`

### Оператор delete

`delete` удаляет свойство из объекта или элемент массива по индексу.

- **С объектами:** `delete obj.key` убирает свойство целиком (`'key' in obj → false`).
- **С массивами:** `delete arr[i]` убирает элемент по индексу, но **не сдвигает** остальные — на месте остаётся «дырка» (hole), `arr[i]` возвращает `undefined`, сам индекс исчезает.

**delete vs `arr[i] = undefined`.** Присваивание оставляет элемент со значением `undefined` (`'i' in arr → true`), а `delete` именно убирает индекс (`'i' in arr → false`). Для нашего `len` (считает до первого `undefined`) оба варианта дают остановку, но `delete` семантически честнее.

**Что помнить:** `delete` не меняет `.length` и не работает с переменными — только со свойствами и индексами.

### Граничный случай: пустой массив

`pop([])` не должен падать. Проверяем `length === 0` и возвращаем `undefined`.
