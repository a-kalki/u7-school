# pop(arr) — краткая выжимка

- Удаляет **последний** элемент и возвращает его
- Для пустого массива возвращает `undefined`
- **Мутабельная** — `delete arr[len-1]` создаёт «дырку», `len` остановится на ней
- В этом уроке впервые вводится оператор `delete` (объекты, массивы, дырки, отличие от `= undefined`)
- Использует собственную `len`
- В тесте проверяй возвращаемое значение и длину массива после
- JSDoc обязателен
