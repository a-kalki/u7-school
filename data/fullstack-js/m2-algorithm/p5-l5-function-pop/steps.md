# Шаги урока: Функция pop(arr) — удаление с конца

---

### Оператор delete

**kind:** `text`

В этом уроке нам впервые понадобится оператор `delete` — он удаляет свойство из объекта или элемент массива по индексу. Разберёмся, как именно он работает.

**С объектами.** `delete obj.key` убирает свойство целиком — его больше нет в объекте:
```javascript
const user = { name: 'Анна', age: 30 };
delete user.age;
// user → { name: 'Анна' }
// 'age' in user → false
```

**С массивами.** `delete arr[i]` убирает элемент по индексу, но **не сдвигает** остальные элементы. На месте удалённого элемента остаётся «дырка» (hole): обращение `arr[i]` возвращает `undefined`, а сам индекс исчезает из массива.
```javascript
const arr = [10, 20, 30];
delete arr[1];
// arr → [10, empty, 30]
// arr[0] → 10
// arr[1] → undefined   ← дырка
// arr[2] → 30
```

**delete vs присваивание undefined.** Это разные вещи:
```javascript
const a = [1, 2, 3];
a[1] = undefined;     // элемент остался, просто со значением undefined
// '1' in a → true

const b = [1, 2, 3];
delete b[1];          // индекс убран — дырка
// '1' in b → false
```
Оба варианта дают `arr[1] === undefined`, поэтому для нашего `len` (который считает до первого `undefined`) результат одинаковый — он остановится. Но семантически `delete` честнее: он именно убирает элемент, а не кладёт `undefined` на его место.

**Что важно помнить:**
- `delete` не меняет внутренний `.length` массива и не сдвигает элементы — только убирает один индекс, оставляя дырку.
- `delete` работает только со свойствами и индексами, **не с переменными**: `delete x` (где `x` — переменная) не сработает как надо.
- В этом уроке `pop` использует `delete`, чтобы убрать последний индекс — тогда `len` в следующий раз корректно остановится раньше. Позже `shift` поступит так же.

### Реализация pop()

**kind:** `text`

Реализуй функцию `pop(arr)` — удаление последнего элемента. Создай файлы `arrays/pop.js` и `arrays/pop.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)

**Функция возвращает:** удалённый элемент, либо `undefined` для пустого массива.

Тестовые случаи:
- Должна удалить последний элемент и вернуть его: `pop([1, 2, 3])` → `3`, массив стал `[1, 2]`
- Должна вернуть `undefined` для пустого массива: `pop([])` → `undefined`
- Должна удалить единственный элемент: `pop([42])` → `42`, массив стал пустым (`len === 0`)
- Должна работать с массивом строк: `pop(['a', 'b'])` → `'b'`
- Должна корректно удалить `0` или `false` (не спутать с `undefined`): `pop([0])` → `0`
- После двух `pop` подряд длина уменьшается на 2
- Должна выбросить `TypeError` если `arr` не массив
