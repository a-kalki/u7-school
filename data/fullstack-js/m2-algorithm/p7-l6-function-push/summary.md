# Функция push(arr, item) — краткая выжимка

- push(arr, item) — добавляет элемент в конец, возвращает новую длину; МУТАБЕЛЬНАЯ
- Первая мутабельная функция проекта: в тесте проверяем и возврат, и состояние массива
- Шпаргалка bun:test: примитив → toBe (===), массив/объект → toEqual (содержимое)
- toBe для массивов всегда падает: два массива с одинаковым содержимым — разные объекты в памяти
- 0, false, null — полноценные элементы; len их должен учитывать
- JSDoc: явная отметка «функция мутирует массив»
