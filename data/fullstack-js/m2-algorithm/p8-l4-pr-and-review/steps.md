### Создание PR

**kind:** `text`

Создай Pull Request:

1. На GitHub нажми **Compare & pull request**
2. Выбери base: `main`, compare: `feat/iterative-methods-2`

Заполни заголовок и описание:

**Заголовок:** `Проект 8: Массивы — find, reduce, flat`

**Описание:** перечисли все 4 функции с краткими пояснениями:

- `find` — поиск первого подходящего элемента, ранний выход при `true`, не найден → `undefined`
- `findIndex` — поиск индекса первого подходящего, ранний выход при `true`, не найден → `-1`
- `reduce` — свёртка массива в одно значение, два режима (с/без initialValue)
- `flat` — разглаживание вложенных массивов, рекурсия, поддержка `depth` и `Infinity`

Все функции иммутабельные — не меняют исходный массив. `find`/`findIndex` демонстрируют ранний выход. `flat` можно реализовать как через рекурсию, так и через `reduce`.

Укажи как запустить тесты (`bun test`).
