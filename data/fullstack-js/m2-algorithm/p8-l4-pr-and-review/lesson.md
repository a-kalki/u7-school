### Ветка и функции

- **Ветка:** `feat/iterative-methods-2`
- **4 функции** в папке `arrays/`:

| Функция | Описание | Особенность |
|---------|----------|------------|
| `find` | Поиск первого подходящего элемента | Ранний выход, не найден → `undefined` |
| `findIndex` | Поиск индекса первого подходящего | Ранний выход, не найден → `-1` |
| `reduce` | Свёртка массива в одно значение | Два режима: с/без initialValue |
| `flat` | Разглаживание вложенных массивов | Рекурсия + reduce, `depth`, `Infinity` |
