# parseUrl(url) — краткая выжимка

- Разбирает URL на 6 компонентов: protocol, host, port, path, query, hash
- Порядок разбора важен: protocol → hash → query → path → host:port
- Отсутствующие компоненты — пустые строки
- Path по умолчанию `/`
- Использует свои: `indexOf`, `slice`, `len`
- `://` — разделитель протокола, `#` — хэш, `?` — query, `/` — путь, `:` — порт
- **Иммутабельная** — не меняет исходную строку
- JSDoc обязателен, отметь все поля возвращаемого объекта
