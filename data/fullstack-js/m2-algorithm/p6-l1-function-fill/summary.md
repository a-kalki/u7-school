# fill(arr, value, start, end) — краткая выжимка

- Заполняет массив (или его часть) значением `value`
- **Мутабельная** — меняет массив на месте и возвращает его же
- `start` (по умолчанию `0`) и `end` (по умолчанию `len(arr)`) — индексы, `end` не включается
- Поддержка отрицательных индексов (отсчёт с конца)
- Выход за границы → нормализация (0 или `len(arr)`)
- `start >= end` → массив не меняется
- JSDoc обязателен, отметь мутабельность
