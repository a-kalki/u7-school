# Сортировка пузырьком (bubble sort)

**Краткое содержание:**
Первый алгоритм сортировки. Студент реализует сортировку пузырьком через TDD: сравнивает соседние элементы и «всплывает» максимум в конец массива за каждый проход.

### 1. Зачем сортировать

Сортировка — одна из самых частых операций в программировании. Отсортированные данные позволяют:
- искать элементы быстрее (бинарный поиск — с ним познакомимся в следующем проекте);
- выводить списки в понятном порядке (лента новостей, таблица результатов, товары по цене);
- сравнивать и объединять наборы данных.

Стандартный `Array.prototype.sort` мы использовать не будем — как и весь модуль, реализуем сортировку сами, чтобы понять, что происходит «под капотом».

### 2. Идея пузырька

Сортировка пузырьком сравнивает пары соседних элементов и меняет их местами, если они стоят в неправильном порядке. За один полный проход по массиву самый большой элемент гарантированно «всплывает» в конец — как пузырёк воздуха в воде.

Пример массива `[5, 3, 8, 1]`:

1. Сравниваем 5 и 3 → меняем: `[3, 5, 8, 1]`
2. Сравниваем 5 и 8 → оставляем: `[3, 5, 8, 1]`
3. Сравниваем 8 и 1 → меняем: `[3, 5, 1, 8]`

После первого прохода 8 — на своём месте (в конце). Повторяем проходы для оставшихся элементов, пока массив не отсортируется.

### 3. Алгоритм по шагам

1. Проверить тип: `arr` — массив. Иначе `throw new TypeError`.
2. Скопировать массив в `result` (иммутабельность).
3. Внешний цикл `i` от 0 до `len - 2` — каждый проход ставит максимум в конец.
4. Внутренний цикл `j` от 0 до `len - 2 - i` — не заходим в уже отсортированный «хвост».
5. Если `result[j] > result[j + 1]` — поменять их местами.
6. Вернуть `result`.

### 4. Реализация

```javascript
function bubbleSort(arr) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');

  const result = slice(arr, 0, len(arr));
  const n = len(result);

  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - 1 - i; j++) {
      if (result[j] > result[j + 1]) {
        const temp = result[j];
        result[j] = result[j + 1];
        result[j + 1] = temp;
      }
    }
  }

  return result;
}
```

Обмен местами (swap) — три строки через временную переменную `temp`. Без неё нельзя: если сразу записать `result[j] = result[j + 1]`, старое значение `result[j]` потеряется.

### 5. Иммутабельность

Все функции сортировки в этом проекте **иммутабельные**: исходный массив не меняется, функция возвращает новый отсортированный массив. Для этого первым делом копируем массив через `slice(arr, 0, len(arr))`.

Проверка в тесте:

```javascript
const input = [3, 1, 2];
const output = bubbleSort(input);
expect(input).toEqual([3, 1, 2]);  // исходный не изменился
expect(output).toEqual([1, 2, 3]); // результат отсортирован
```

### 6. Граничные случаи

- `bubbleSort([])` → `[]`
- `bubbleSort([7])` → `[7]`
- `bubbleSort([1, 2, 3])` → `[1, 2, 3]` (уже отсортирован)
- `bubbleSort([3, 2, 1])` → `[1, 2, 3]` (обратный порядок)
- `bubbleSort([4, 2, 4, 1])` → `[1, 2, 4, 4]` (дубликаты)
- `bubbleSort('abc')` → `TypeError`

### 7. Сколько операций делает пузырёк

Посчитай сравнения: на массиве из n элементов внешний цикл делает ~n проходов, внутренний — в среднем ~n/2 сравнений. Итого примерно n²/2 сравнений. Для n = 100 это ~5 000, для n = 10 000 — уже ~50 000 000.

Это ощущение «квадратичного» роста — ключевое для всего проекта. В уроке 5 мы измерим его вживую, а в следующем проекте научимся называть его языком O-нотации.
