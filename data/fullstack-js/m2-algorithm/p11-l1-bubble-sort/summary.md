# bubbleSort — краткая выжимка

- Сортировка пузырьком: сравниваем соседей, меняем местами, максимум «всплывает» в конец
- Внешний цикл — проходы, внутренний — сравнения соседей (не заходим в отсортированный «хвост»)
- Обмен через временную переменную `temp`
- **Иммутабельная** — сначала копия через `slice(arr, 0, len(arr))`
- ~n²/2 сравнений на n элементах — квадратичный рост
- `[]` → `[]`, `[7]` → `[7]`, обратный порядок → отсортированный, не массив → `TypeError`
