# JSDoc: документирование функций — краткая выжимка

- Код читают чаще, чем пишут — документация экономит время: тебе через месяц, ревьюеру сейчас
- JSDoc — комментарии `/** ... */` перед функцией: стандарт, который понимают VS Code, GitHub, генераторы документации
- Четыре основных тега: `@param` (параметры), `@returns` (возврат), `@throws` (ошибки), `@example` (примеры)
- Описание отвечает на вопрос «что делает», а не «как делает»
- Две звёздочки `/**` — обязательны: так JSDoc отличает документацию от обычного комментария
- Контракт функции: что принимает, что возвращает, какие ошибки возможны
