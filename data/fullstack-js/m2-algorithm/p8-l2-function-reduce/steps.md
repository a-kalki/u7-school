# Шаги урока: Функция reduce(arr, callback, initialValue) — свёртка массива

---

### Реализация reduce()

**kind:** `text`

> Убедись, что ты в ветке `feat/iterative-methods-2`.

Реализуй функцию `reduce(arr, callback, initialValue)` — свёртка массива в одно значение. Создай файлы `arrays/reduce.js` и `arrays/reduce.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для свёртки
- `callback`: `function` — функция-свёртка, получает `(аккумулятор, элемент, индекс, массив)`
- `initialValue`: `any` (необязательный) — начальное значение аккумулятора

**Функция возвращает:** `any` — итоговое значение аккумулятора.

**Два режима работы:**
1. **С initialValue:** аккумулятор = `initialValue`, обход с первого элемента (индекс 0)
2. **Без initialValue:** аккумулятор = `arr[0]`, обход со второго элемента (индекс 1)

**Важно:** функция **иммутабельная** — не меняет исходный массив.

**Подсказка по определению наличия initialValue:** используй `arguments.length >= 3`, а не сравнение с `undefined`. Студент может явно передать `undefined` как initialValue — это допустимо.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна посчитать сумму без initialValue: `reduce([1, 2, 3], (acc, x) => acc + x)` → `6`
- Должна посчитать сумму с initialValue: `reduce([1, 2, 3], (acc, x) => acc + x, 4)` → `10`
- Должна вернуть `initialValue` для пустого массива: `reduce([], (acc, x) => acc + x, 42)` → `42`
- Должна выбросить `TypeError` для пустого массива без initialValue: `reduce([], (acc, x) => acc + x)` — используй `toThrow()`
- Должна сконкатенировать строки: `reduce(['a', 'b', 'c'], (acc, s) => acc + s, '')` → `'abc'`
- Должна работать с массивом из одного элемента без initialValue: `reduce([42], (acc, x) => acc + x)` → `42`
- Должна передавать правильные аргументы в callback: собрать вызовы и проверить `acc`, `element`, `index`
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция
