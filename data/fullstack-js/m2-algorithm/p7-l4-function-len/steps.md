### Реализация len(arr) через TDD

**kind:** `text`

> Ты в ветке `feat/array-basics`, папка `array-utils/` создана. Если нет — вернись к уроку 1.

Реализуй функцию `len(arr)` — подсчёт элементов массива. Создай файлы `array-utils/len.js` и `array-utils/len.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив элементов

**Функция возвращает:** `number` — количество элементов.

Если `arr` не массив — `throw new TypeError`. Подсказка: используй `Array.isArray(...)`.

**Напоминание по TDD + JSDoc:**
- Создай `array-utils/len.js` с заглушкой: `export function len(arr) { return 0; }`
- Сразу добавь JSDoc (не забудь отметить, что функция **не мутирует** массив)
- Создай `array-utils/len.test.js` с первым тестом
- RED → GREEN → добавляй тесты по одному → REFACTOR

**Термины:**
примитив — минимальная базовая функция, на которой строятся остальные функции API

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть `3` для `[1, 2, 3]`
- Должна вернуть `0` для пустого массива `[]`
- Должна вернуть `1` для массива из одного элемента `[42]`
- Должна вернуть `4` для массива строк `['a', 'b', 'c', 'd']`
- Должна вернуть `5` для массива с разными типами `[1, 'two', true, null, 0]`
- Должна не мутировать исходный массив: после `len([1, 2, 3])` массив по-прежнему `[1, 2, 3]` (запомни длину и элементы до вызова)
- Должна выбросить `TypeError` если передать строку `len('hello')`
- Должна выбросить `TypeError` если передать число `len(123)`
- Должна выбросить `TypeError` если передать объект `len({0: 'a'})`
- Должна выбросить `TypeError` если аргумент не передан `len()`

> **Ограничение.** Свойство `.length` запрещено, поэтому `len` считает элементы циклом — до первого `undefined`. Из-за этого массив с «дыркой» посчитается неверно: `len([1, 2, undefined, 3])` вернёт `2`, хотя элементов четыре. Это осознанный компромисс: сейчас мы платим этим багом в учёбе, зато учимся собирать сложное из простых частей.
