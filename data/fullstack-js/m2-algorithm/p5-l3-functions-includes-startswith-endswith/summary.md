# Функции includes(), startsWith(), endsWith() — краткая выжимка

- `includes(str, search)` → `boolean`: «indexOf вернул не -1» — переиспользование готовой функции
- `startsWith(str, search)`: сравнение префикса, окно не нужно
- `endsWith(str, search)`: сравнение суффикса «от конца»
- Пустой `search` — всегда `true` для всех трёх
- Дублирование vs переиспользование: когда функция уже решает задачу — строй следующую на её основе
- Коммит: «Реализованы includes, startsWith, endsWith — проверки наличия подстроки»
