# Функции includes(), startsWith(), endsWith()

**Краткое содержание:**
Три функции-проверки наличия подстроки. Секрет эффективности: все три можно построить на базе уже готового `indexOf()` — переиспользование вместо дублирования.

**Время:** ~40 мин

**Основные темы:**
1. includes()
2. startsWith()
3. endsWith()

**Термины:**
префикс — начало строки (для startsWith);
суффикс — конец строки (для endsWith);
переиспользование — построение новой функции на базе уже готовой вместо дублирования
