# Шаги урока: Функции includes(), startsWith(), endsWith()

---

### includes()

**kind:** `text`

> Убедись, что ты в ветке `feat/substring-search`: `git branch --show-current`

Реализуй функцию `includes(str, search)` — проверка наличия подстроки. Создай файлы `string-utils/includes.js` и `string-utils/includes.test.js`.

**Функция принимает:**
- `str`: `string` — строка, в которой ищем
- `search`: `string` — подстрока, которую ищем

**Функция возвращает:** `boolean` — `true` если подстрока найдена, `false` если нет.

Тестовые случаи:
- Должна вернуть `true` для подстроки в начале (`'hello'`, `'he'`)
- Должна вернуть `true` для подстроки в середине (`'hello'`, `'ll'`)
- Должна вернуть `true` для подстроки в конце (`'hello'`, `'lo'`)
- Должна вернуть `false` если подстрока не найдена (`'hello'`, `'li'`)
- Должна вернуть `true` для пустой поисковой строки (`'hello'`, `''`)
- Должна вернуть `false` если поисковая строка длиннее исходной (`'hello'`, `'hello!'`)
- Должна вернуть `true` для одинаковых строк (`'abc'`, `'abc'`)
- Должна вернуть `true` при нескольких совпадениях (`'ababa'`, `'ba'`)
- Должна найти подстроку, которая начинается внутри предыдущего почти-совпадения (`'abababc'`, `'ababc'`) → `true`
- Должна вернуть `true` для поиска одного символа в начале (`'hello'`, `'h'`)
- Должна вернуть `true` для поиска символа в середине (`'hello'`, `'l'`)
- Должна вернуть `true` для поиска символа в конце (`'hello'`, `'o'`)
- Должна работать с кириллицей (`'привет'`, `'иве'`) → `true`
- Должна выбросить `TypeError` если первый аргумент не строка (`123`, `'hello'`)
- Должна выбросить `TypeError` если второй аргумент не строка (`'hello'`, `123`)

**Термины:**
префикс — начало строки (для startsWith);
суффикс — конец строки (для endsWith);
переиспользование — построение новой функции на базе уже готовой вместо дублирования

### startsWith()

**kind:** `text`

Реализуй функцию `startsWith(str, search)` — проверка, начинается ли строка с подстроки. Создай файлы `string-utils/starts-with.js` и `string-utils/starts-with.test.js`.

**Функция принимает:**
- `str`: `string` — исходная строка
- `search`: `string` — подстрока для проверки начала

**Функция возвращает:** `boolean` — `true` если `str` начинается с `search`.

Тестовые случаи:
- Должна вернуть `true` для одного символа (`'hello'`, `'h'`)
- Должна вернуть `true` для подстроки (`'hello'`, `'hel'`)
- Должна вернуть `false` для несовпадающего вхождения (`'hello'`, `'el'`)
- Должна вернуть `true` для пустой поисковой строки (`'hello'`, `''`)
- Должна вернуть `false` если поисковая строка длиннее (`'hell'`, `'hello'`)
- Должна вернуть `true` для точного совпадения (`'abc'`, `'abc'`)
- Должна выбросить `TypeError` если первый аргумент не строка

**Подсказка:** здесь скользящее окно не нужно — достаточно одного сравнения префикса. `indexOf` тоже сработает (поиск с начала), но подумай, что дешевле.

### endsWith()

**kind:** `text`

Реализуй функцию `endsWith(str, search)` — проверка, заканчивается ли строка подстрокой. Создай файлы `string-utils/ends-with.js` и `string-utils/ends-with.test.js`.

**Функция принимает:**
- `str`: `string` — исходная строка
- `search`: `string` — подстрока для проверки конца

**Функция возвращает:** `boolean` — `true` если `str` заканчивается на `search`.

Тестовые случаи:
- Должна вернуть `true` для одного символа (`'hello'`, `'o'`)
- Должна вернуть `true` для подстроки (`'hello'`, `'llo'`)
- Должна вернуть `false` для несовпадающего вхождения (`'hello'`, `'ell'`)
- Должна вернуть `true` для пустой поисковой строки
- Должна вернуть `false` если поисковая строка длиннее
- Должна вернуть `true` для точного совпадения (`'abc'`, `'abc'`)
- Должна выбросить `TypeError` если первый аргумент не строка
