### Алгоритм

1. Проверить тип: `typeof obj !== 'object' || obj === null` → `TypeError`
2. Пройти циклом `for...in` по объекту
3. Оставить только собственные свойства — `obj.hasOwnProperty(key)`
4. Собрать ключи в массив через `push`

```javascript
function keys(obj) {
  if (typeof obj !== 'object' || obj === null) {
    throw new TypeError('Ожидается объект');
  }

  const result = [];
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      push(result, key);
    }
  }
  return result;
}
```

### Собственные и унаследованные свойства

`for...in` перебирает не только собственные свойства объекта, но и унаследованные от прототипа (`Object.prototype`). `hasOwnProperty(key)` оставляет только собственные — правило: всегда проверяй его внутри `for...in`. Отдельная проверка `obj === null` нужна потому, что `typeof null === 'object'` — известная особенность JS.
