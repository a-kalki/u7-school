# Шаги урока: Функция map(arr, callback) — трансформация массива

---

### Реализация map()

**kind:** `text`

Реализуй функцию `map(arr, callback)` — трансформация массива. Создай файлы `array-utils/map.js` и `array-utils/map.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для трансформации
- `callback`: `function` — функция, которая преобразует каждый элемент

**Функция возвращает:** `array` — новый массив из результатов callback.

**Важно:** функция **иммутабельная** — не меняет исходный массив. Callback получает три аргумента: `(элемент, индекс, массив)`.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна удвоить числа: `map([1, 2, 3], x => x * 2)` → `[2, 4, 6]`
- Должна вернуть новый массив (исходный не изменился): проверить что исходный массив тот же, и `исходный !== результат`
- Должна вернуть пустой массив для пустого исходного: `map([], fn)` → `[]`
- Должна передать правильные аргументы в callback: `calls = []`, `map([10, 20], (el, i, arr) => { calls.push({ el, i }); return el; })` — проверить `calls`
- Должна работать с преобразованием типов: `map([1, 2], x => String(x))` → `['1', '2']`
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция
