# forEach(arr, callback) — краткая выжимка

- Перебирает массив, вызывает `callback` для каждого элемента
- Callback получает три аргумента: (элемент, индекс, массив)
- **Не меняет** исходный массив, возвращает `undefined`
- Для пустого массива callback не вызывается ни разу
- Проверка типов: `arr` — массив, `callback` — функция
- JSDoc обязателен, отметь иммутабельность
