# Сохранение и чтение файла — краткая выжимка

- Файл нужен, чтобы данные переживали перезапуск программы
- Цепочка: `массив → toCSV → строка → файл → строка → fromCSV → массив`
- Файловый API Bun:
  - `await Bun.write(path, text)` — записать строку (создаёт или перезаписывает), вернёт число байт
  - `await Bun.file(path).text()` — прочитать файл как строку
  - `await Bun.file(path).exists()` — проверить наличие файла
- Операции асинхронные, поэтому функции `async`, вызовы через `await`
- `saveToFile(path, data)` = `toCSV(data)` → `Bun.write`
- `loadFromFile(path)` = `Bun.file(path).text()` → `fromCSV`
- Кодировка UTF-8, переносы `\n` сохраняются как есть
- Несуществующий файл: `.text()` выбрасывает ошибку, `.exists()` → `false`
- Набор объектов для проб покрывает типы, falsy-значения и спецсимволы
- **Round-trip через файл** — `loadFromFile` после `saveToFile` возвращает те же данные
- Файл из Windows с CRLF (`\r\n`) читается так же, как LF
- Функции иммутабельные, JSDoc обязателен
