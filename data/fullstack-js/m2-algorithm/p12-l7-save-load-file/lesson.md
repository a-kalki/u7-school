# Сохранение и чтение файла (`node:fs`)

**Краткое содержание:**
Шестая бизнес-утилита — сохраняем массив объектов в настоящий текстовый файл на диске и читаем его обратно. Используем встроенные синхронные функции модуля `'node:fs'` (`writeFileSync`, `readFileSync`, `existsSync`), пишем синхронные функции `saveToFile(path, data)` и `loadFromFile(path)` поверх готовых `toCSV`/`fromCSV` и проверяем round-trip через реальный физический файл без моков.

**Время:** ~20 мин

**Основные темы:**
- Зачем файл
- Синхронные функции модуля `node:fs`
- Функция saveToFile(path, data)
- Функция loadFromFile(path)
- Комплект объектов для проб
- Round-trip через файл
- Вопросы на понимание
- Сохрани изменения
- Термины урока

**Термины:**
* **Файл** — именованное хранилище данных на диске, переживает перезапуск программы.
* **`writeFileSync(path, text, 'utf8')`** — синхронная запись строки в файл (создаёт или перезаписывает).
* **`readFileSync(path, 'utf8')`** — синхронное чтение файла в строку.
* **`existsSync(path)`** — проверка существования файла на диске (`true` / `false`).
* **Синхронный ввод-вывод** — пошаговое выполнение без промисов и асинхронности.
* **UTF-8** — кодировка текста, в которой файлы пишутся и читаются.
* **Персистентность** — свойство данных сохраняться между запусками программы.
* **Round-trip через файл** — `loadFromFile` после `saveToFile` возвращает исходные данные и типы.
* **LF / CRLF** — варианты переноса строки (`\n` и `\r\n`); `fromCSV` читает оба.

### Цепочка

`toCSV` и `fromCSV` работают со строками. Осталось научиться класть строку в файл и доставать её обратно. Полная цепочка выглядит так:

```
массив объектов → toCSV → строка → файл → строка → fromCSV → массив объектов
```

### Синхронный API модуля `node:fs`

1. `writeFileSync(path, text, 'utf8')` — записать строку в файл (создаёт или перезаписывает).
2. `readFileSync(path, 'utf8')` — прочитать файл как строку.
3. `existsSync(path)` — проверить, существует ли файл.

Все операции синхронные — выполняются последовательно, без `async/await` и `Promise`. Bun и Node.js нативно поддерживают этот модуль.

```javascript
import { writeFileSync, readFileSync } from 'node:fs';

function saveToFile(path, data) {
  const text = toCSV(data);
  writeFileSync(path, text, 'utf8');
}

function loadFromFile(path) {
  const text = readFileSync(path, 'utf8');
  return fromCSV(text);
}
```

### Что важно

- `loadFromFile` для несуществующего файла выбрасывает ошибку (ENOENT) — это нормально: значит, файл ещё не создавали.
- Round-trip через файл: `loadFromFile(path)` после `saveToFile(path, data)` возвращает те же данные и типы.
- На Windows файл, сохранённый вручную, может получить CRLF (`\r\n`) — `fromCSV` пропускает `\r` вне строки.
