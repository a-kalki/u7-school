# Мутабельность — краткая выжимка

- **Мутабельная операция** меняет исходный массив «на месте» (пример: `push`, `pop`)
- **Иммутабельная операция** создаёт новый массив, исходный не трогает (пример: `concat`)
- Мутабельность опасна: один массив могут использовать разные части программы — неожиданное изменение ломает логику
- В тестах мутабельной функции: сохраняй исходное состояние, вызови функцию, проверь и результат, и изменённый массив
- **Тесты всегда независимы**: каждый тест сам создаёт свои данные, не полагается на порядок выполнения и на побочные эффекты других тестов
- В этом проекте все функции (`push`, `pop`, `unshift`, `shift`, `fill`-подобные) — мутабельные, кроме поиска (`indexOf`, `includes`, `at`)
