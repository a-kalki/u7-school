# isEqualDeep(a, b) — краткая выжимка

- Глубокое структурное сравнение любых значений (не только строк, как `isEqual` из проекта 1)
- Примитивы: `a === b`
- Разные типы → `false`
- Массивы: сравнить `len`, затем рекурсивно каждый элемент
- Объекты: сравнить `keys`, затем рекурсивно каждое значение
- `hasOwnProperty` для проверки наличия ключа — различает `{ x: undefined }` и `{}`
- `Array.isArray(a) !== Array.isArray(b)` — массив vs объект → `false`
- **Иммутабельная** — не меняет аргументы
- **Рекурсивная** — глубина сравнения не ограничена
- JSDoc обязателен, отметь рекурсивность и отличие от `isEqual`
