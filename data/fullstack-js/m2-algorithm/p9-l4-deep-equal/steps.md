### Реализация isEqualDeep()

**kind:** `text`

> Убедись, что ты в ветке `feat/object-methods`.

Реализуй функцию `isEqualDeep(a, b)` — глубокое структурное сравнение двух значений. Создай файлы `objects/is-equal-deep.js` и `objects/is-equal-deep.test.js`, следуй TDD.

**Функция принимает:**
- `a`: `any` — первое значение для сравнения
- `b`: `any` — второе значение для сравнения

**Функция возвращает:** `boolean` — `true` если значения структурно идентичны, `false` иначе.

**Важно:** функция **иммутабельная** — не меняет аргументы. Использует **рекурсию**. В отличие от `isEqual` из проекта 1 (только строки), эта работает с любыми типами.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть `true` для одинаковых чисел: `isEqualDeep(1, 1)` → `true`
- Должна вернуть `false` для разных типов: `isEqualDeep(1, '1')` → `false`
- Должна вернуть `true` для двух `null`: `isEqualDeep(null, null)` → `true`
- Должна вернуть `false` для `null` и `undefined`: `isEqualDeep(null, undefined)` → `false`
- Должна вернуть `true` для одинаковых плоских объектов: `isEqualDeep({ a: 1, b: 2 }, { a: 1, b: 2 })` → `true`
- Должна вернуть `false` для объектов с разными значениями: `isEqualDeep({ a: 1 }, { a: 2 })` → `false`
- Должна вернуть `false` для объектов с разным количеством ключей: `isEqualDeep({ a: 1 }, { a: 1, b: 2 })` → `false`
- Должна вернуть `true` для глубоко вложенных одинаковых структур: `isEqualDeep({ a: { b: [1, 2] } }, { a: { b: [1, 2] } })` → `true`
- Должна вернуть `false` для глубоко вложенных разных структур: `isEqualDeep({ a: { b: [1, 2] } }, { a: { b: [1, 3] } })` → `false`
- Должна вернуть `true` для одинаковых массивов: `isEqualDeep([1, 2, 3], [1, 2, 3])` → `true`
- Должна вернуть `false` для массивов разной длины: `isEqualDeep([1, 2], [1, 2, 3])` → `false`
- Должна вернуть `false` для массива и объекта: `isEqualDeep([], {})` → `false`
- Должна вернуть `false` для `{ x: undefined }` и `{}` (проверка что свойство существует, а не просто `undefined`)
- Должна вернуть `true` для `{ x: undefined }` и `{ x: undefined }`

*Примечение:* расширьте тесты, если видите не покрытые тестовые случаи
