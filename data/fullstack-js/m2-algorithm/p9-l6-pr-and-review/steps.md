### Создание PR по шаблону

**kind:** `text`

Создай PR: base `main` ← compare `feat/iterative-methods`.

**Заголовок:**
```
Проект 9: Массивы — итеративные методы
```

**Описание — заполни по шаблону:**

```markdown
## Что сделано

Реализованы 5 итеративных методов массивов (папка array-utils/):

- forEach(arr, callback) — перебор, вызов callback для каждого элемента
- map(arr, callback) — трансформация, новый массив из результатов callback
- filter(arr, callback) — фильтрация по предикату, новый массив
- some(arr, callback) — «хотя бы один» с ранним выходом при true
- every(arr, callback) — «все» с ранним выходом при false

## Особенности реализации

- Все функции иммутабельные — исходный массив не меняется
- some и every используют ранний выход: обход останавливается,
  как только результат известен
- callback получает три аргумента (элемент, индекс, массив) —
  как в стандартных методах
- filter внутри использует свою push из проекта 7

## Как запустить тесты

bun test
```

Что важно для ревьюеров, может быть не очевидно — обязательно указывай. Если считаешь, что команда «в теме», часть разделов можно сократить.
