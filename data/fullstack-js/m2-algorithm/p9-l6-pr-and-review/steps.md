### Создание PR

**kind:** `text`

Создай Pull Request:

1. На GitHub нажми **Compare & pull request**
2. Выбери base: `main`, compare: `feat/object-methods`

Заполни заголовок и описание:

**Заголовок:** `Проект 9: Объекты — keys, values, entries, cloneDeep, isEqualDeep`

**Описание:** перечисли все 5 функций с краткими пояснениями:

- `keys(obj)` — аналог `Object.keys()`. Использует `for...in` с фильтрацией через `hasOwnProperty`. Возвращает массив собственных ключей.
- `values(obj)` — аналог `Object.values()`. Реализован через композицию с `keys` — не дублирует `for...in`.
- `entries(obj)` — аналог `Object.entries()`. Тоже через композицию с `keys`. Возвращает массив пар `[ключ, значение]`.
- `cloneDeep(value)` — глубокое рекурсивное копирование. Корректно обрабатывает `null`, примитивы, массивы, объекты. Изменение копии не затрагивает оригинал ни на каком уровне.
- `isEqualDeep(a, b)` — глубокое структурное сравнение. В отличие от `isEqual` из проекта 1 (только строки), работает с любыми типами и структурами. Использует `hasOwnProperty` чтобы различать `{ x: undefined }` и `{}`.

Все функции иммутабельные. `cloneDeep` и `isEqualDeep` используют рекурсию.

Укажи как запустить тесты (`bun test`).
