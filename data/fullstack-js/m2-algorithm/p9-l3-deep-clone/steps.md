### Поверхностное копирование — смотрим на проблему

**kind:** `text`

Создай тестовый файл и посмотри, чем опасно поверхностное копирование:

```javascript
// Запусти через bun
const original = {
  name: 'Анна',
  scores: [5, 4, 5],
  address: { city: 'Москва' },
};

// «Копируем» вручную
const shallow = {};
for (const key of Object.keys(original)) shallow[key] = original[key];

shallow.name = 'Борис';
shallow.scores[0] = 3;
shallow.address.city = 'Питер';

console.log('original.name:', original.name);       // ?
console.log('original.scores[0]:', original.scores[0]); // ?
console.log('original.address.city:', original.address.city); // ?
```

Запусти и посмотри, какие поля изменились в оригинале, а какие нет. Почему `name` не изменился, а `scores[0]` и `address.city` — изменились?

Проверь сохранится ли такой результат если делать копирование через деструктуризацию `shallow = {...original};`.

### Реализация cloneDeep()

**kind:** `text`

Реализуй функцию `cloneDeep(value)` — глубокое копирование значения. Создай файлы `objects/clone-deep.js` и `objects/clone-deep.test.js`, следуй TDD.

**Функция принимает:**
- `value`: `any` — значение для копирования (примитив, объект, массив, null)

**Функция возвращает:** `any` — глубокая копия. Изменение копии не затрагивает оригинал ни на каком уровне вложенности.

**Важно:** функция **иммутабельная** по отношению к исходному значению — создаёт полностью независимую копию. Использует **рекурсию**.

Порядок проверок в функции:
1. `null` — вернуть `null`
2. Примитив (`typeof !== 'object'`) — вернуть как есть
3. Массив (`Array.isArray`) — создать новый массив, рекурсивно склонировать каждый элемент
4. Объект — создать новый объект, рекурсивно склонировать каждое значение через `keys`

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть тот же примитив: `cloneDeep(42)` → `42`, `cloneDeep('hello')` → `'hello'`
- Должна вернуть `null` для `null`: `cloneDeep(null)` → `null`
- Должна вернуть новый массив (не ссылку): `const arr = [1, 2]; cloneDeep(arr) !== arr`
- Должна создать копию плоского объекта: `cloneDeep({ a: 1, b: 2 })` → `{ a: 1, b: 2 }`
- Должна создать глубокую копию вложенного объекта: изменение `copy.a.b.c` не меняет `original.a.b.c`
- Должна создать копию массива: `cloneDeep([1, 2, 3])` → `[1, 2, 3]`, изменение копии не меняет оригинал
- Должна создать копию вложенного массива: `cloneDeep([1, [2, [3]]])` — три уровня
- Должна создать копию смешанной структуры: объект с массивами
- Должна создать копию смешанной структуры: объект с массивами

*Примечение:* расширьте тесты, если видите не покрытые тестовые случаи

### Вопросы на понимание

**kind:** `text`

Ответь на вопросы. Если не знаешь — проверь гипотезу кодом через `bun`.

**1.** Почему `typeof null === 'object'` — это проблема для `cloneDeep`? Что будет, если не проверять `null` отдельно?

**2.** Почему `Array.isArray` должно идти до проверки на объект? Что будет, если поменять их местами?

**3.** Функция использует рекурсию. Что произойдёт, если передать объект с циклической ссылкой: `const obj = {}; obj.self = obj;`? Как можно было бы защититься от бесконечной рекурсии?

**4.** Достаточно ли в тесте глубокого копирования проверить только что `cloneDeep(original) !== original`? Почему нет?
