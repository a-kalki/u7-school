# Повторное ревью и апрувы — краткая выжимка

- Re-request: иконка 🔄 рядом с каждым ревьюером в панели Reviewers (+ сообщение в чат)
- Ревьюер смотрит исправленное; ок → Approve, нашёл новое → снова Request changes (2–3 круга — норма)
- Новые коммиты в ветку сами попадают в открытый PR
- Цель: **2 апрува + все conversations resolved** → мерж
- Ревьюер пропал: напоминание (1–2 дня) → пинг в чате → другой ревьюер → ментор
