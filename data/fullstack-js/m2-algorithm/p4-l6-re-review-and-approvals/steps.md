# Шаги урока: Повторное ревью и апрувы

---

### Запроси повторное ревью

**kind:** `text`

Когда все правки внесены и на все комментарии отвечено:

1. В правой панели PR найди ревьюеров
2. Рядом с именем каждого — иконка «повторного запроса» (две стрелки по кругу)
3. Нажми её для каждого ревьюера, кто оставлял замечания

Также можешь написать в чате:

```
Правки по ревью внесены, жду повторной проверки 🙏
```

**Термины:**
круг ревью — один проход «замечания → правки → повторная проверка»;
re-request review — запрос повторного ревью (иконка 🔄)

---

### Жди повторного прохода: 2 апрува — зелёный свет

**kind:** `text`

Как это работает:

- Ревьюер открывает PR снова и смотрит **исправленные места** (diff с прошлого ревью)
- Если всё ок — ставит **Approve**. Если нашёл новое — снова Request changes, и цикл повторяется (это нормально, 2–3 круга — обычное дело)
- Новые коммиты в ветку автоматически попадают в открытый PR — новый PR создавать не нужно

**Цель: 2 апрува и все conversations resolved.** Как только это есть — переходи к следующему уроку и делай мерж.

Если ревьюер пропал — алгоритм эскалации из урока 5 проекта 2: вежливое напоминание через 1–2 дня → пинг в чате → другой ревьюер (2 апрува не обязательно от одних и тех же людей) → крайний случай ментор.
