# Ревью-цикл, финальный мерж и ретро — краткая выжимка

- Ревью-цикл по накатанной: раздели замечания → fix-коммиты → ответы + Resolve → re-request 🔄 → 2 апрува → мерж
- Особое внимание: отметки мутабельности в JSDoc, два результата в тестах, независимость тестов
- Мерж: GitHub Merge commit → Delete branch; локально: switch main → pull → branch -d → fetch --prune
- Ретро: что изменилось со строками, какое правило тестирования самое важное, польза композиции
- Дальше: трансформация массивов — мутабельность vs иммутабельность как разметка API
