### Создание PR по шаблону

**kind:** `text`

Создай PR: base `main` ← compare `feat/iterative-methods-2`.

**Заголовок:**
```
Проект 10: Массивы — find, reduce, flat
```

**Описание — заполни по шаблону:**

```markdown
## Что сделано

Реализованы 4 функции (папка array-utils/):

- find(arr, callback) — первый подходящий элемент, не найден → undefined
- findIndex(arr, callback) — индекс первого подходящего, не найден → -1
- reduce(arr, callback, initialValue) — свёртка в одно значение, два режима
- flat(arr, depth) — разглаживание вложенных массивов, рекурсия и depth

## Особенности реализации

- Все функции иммутабельные — исходный массив не меняется
- find и findIndex используют ранний выход при true
- reduce работает в двух режимах: с initialValue и без него
  (тогда аккумулятором становится первый элемент)
- flat поддерживает depth (по умолчанию 1) и Infinity

## Как запустить тесты

bun test
```

Что важно для ревьюеров, может быть не очевидно — обязательно указывай. Если считаешь, что команда «в теме», часть разделов можно сократить.
