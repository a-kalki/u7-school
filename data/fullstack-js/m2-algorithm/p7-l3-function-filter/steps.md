# Шаги урока: Функция filter(arr, callback) — фильтрация массива

---

### Реализация filter()

**kind:** `text`

> Убедись, что ты в ветке `feat/iterative-methods`.

Реализуй функцию `filter(arr, callback)` — фильтрация массива. Создай файлы `arrays/filter.js` и `arrays/filter.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для фильтрации
- `callback`: `function` — функция-предикат, возвращает `true`/`false` для каждого элемента

**Функция возвращает:** `array` — новый массив из элементов, для которых callback вернул `true`.

**Важно:** функция **иммутабельная** — не меняет исходный массив. Используй свою `push` (`arrays/push.js`) для добавления в результат.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна отфильтровать чётные: `filter([1, 2, 3, 4], x => x % 2 === 0)` → `[2, 4]`
- Должна вернуть пустой массив если ни один не прошёл: `filter([1, 3, 5], x => x > 10)` → `[]`
- Должна вернуть все элементы если все прошли: `filter([2, 4, 6], x => x > 0)` → `[2, 4, 6]`
- Должна вернуть новый массив (исходный не изменился): проверить исходный массив после вызова
- Должна вернуть пустой массив для пустого исходного: `filter([], fn)` → `[]`
- Должна передать правильные аргументы в callback: (элемент, индекс, массив)
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция
