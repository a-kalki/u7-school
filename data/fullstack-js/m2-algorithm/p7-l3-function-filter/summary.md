# filter(arr, callback) — краткая выжимка

- Вызывает `callback` для каждого элемента, оставляет только те, для которых callback вернул `true`
- Callback получает (элемент, индекс, массив)
- **Иммутабельная** — возвращает новый массив, исходный не меняется
- Длина результата может быть меньше исходной (или 0)
- Пустой массив → пустой массив
- Внутри использует `push` (из проекта 5) для добавления в результат
- JSDoc обязателен, отметь иммутабельность
