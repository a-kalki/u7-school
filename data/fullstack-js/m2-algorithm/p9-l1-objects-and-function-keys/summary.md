# keys(obj) — краткая выжимка

- Объект — коллекция пар «ключ-значение», доступ по имени (строковому ключу)
- `for...in` перебирает все свойства, включая унаследованные от прототипа
- `hasOwnProperty(key)` — фильтр: `true` только для собственных свойств
- `keys(obj)` — пройти `for...in`, проверить `hasOwnProperty`, собрать ключи через `push`
- Проверка типа: `typeof obj !== 'object' || obj === null` → `TypeError`
- `null` проверяется отдельно: `typeof null === 'object'` — особенность JS
- Иммутабельная — исходный объект не меняется
- Пустой объект → `[]`
- JSDoc обязателен
