# Объекты и функция keys(obj)

**Краткое содержание:**
Урок вводит объект как структуру данных — набор пар «ключ-значение». Студент осваивает перебор свойств через `for...in`, понимает проблему унаследованных свойств и роль `hasOwnProperty`. Главная задача — реализовать функцию `keys(obj)`, возвращающую массив собственных ключей объекта.

### 1. Объект как структура данных

Объект в JavaScript — это коллекция пар «ключ-значение». В отличие от массива, где элементы нумеруются по порядку (0, 1, 2...), в объекте доступ идёт по имени (строковому ключу):

```javascript
const user = {
  name: 'Анна',
  age: 25,
  city: 'Москва',
};
```

Ты уже работал с объектами в модуле 1. Теперь мы посмотрим на них глубже и реализуем собственные аналоги методов `Object.keys`, `Object.values` и `Object.entries`.

### 2. Цикл for...in — перебор свойств

Для перебора всех свойств объекта используется цикл `for...in`:

```javascript
const user = { name: 'Анна', age: 25 };

for (const key in user) {
  console.log(key, '=', user[key]);
}
// Выведет:
// name = Анна
// age = 25
```

Выглядит просто, но есть нюанс: `for...in` перебирает **не только собственные** свойства объекта, но и **унаследованные** от прототипа.

### 3. Проблема унаследованных свойств и hasOwnProperty

Каждый объект в JS имеет скрытую ссылку на свой прототип (`Object.prototype`). В прототипе уже есть методы вроде `toString`, `hasOwnProperty` и другие. Цикл `for...in` видит и их:

```javascript
const obj = { a: 1 };

// Добавим свойство в прототип (никогда не делай так в реальном коде!)
Object.prototype.custom = 'унаследованное';

for (const key in obj) {
  console.log(key); // 'a', потом 'custom'!
}
```

Чтобы отфильтровать только «свои» свойства, используют метод `hasOwnProperty`:

```javascript
for (const key in obj) {
  if (obj.hasOwnProperty(key)) {
    console.log(key); // только 'a'
  }
}
```

**Правило:** всегда используй `hasOwnProperty` внутри `for...in`, если не хочешь захватить унаследованные свойства. Это критически важно для правильной реализации `keys`.

### 4. Устройство keys(obj) — наш аналог Object.keys()

Задача: пройти `for...in`, проверить `hasOwnProperty`, собрать ключи в массив через `push`:

```javascript
function keys(obj) {
  if (typeof obj !== 'object' || obj === null) {
    throw new TypeError('Ожидается объект');
  }

  const result = [];
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      push(result, key);
    }
  }
  return result;
}
```

Ключевые моменты:
1. **Проверка типа:** `typeof obj !== 'object' || obj === null`. Отдельная проверка на `null` нужна потому, что `typeof null === 'object'` — известная особенность JS.
2. **hasOwnProperty:** фильтрует унаследованные свойства, оставляя только собственные.
3. **push для накопления:** используем нашу реализацию `push` из проекта 5.
4. **Иммутабельность:** исходный объект не меняется.

### 6. Возвращаемые значения и граничные случаи

- `keys({})` → `[]` (пустой объект — пустой массив ключей)
- `keys({ a: 1, b: 2 })` → `['a', 'b']`
- Унаследованные свойства не попадают в результат
- Порядок ключей соответствует порядку `for...in` (строковые ключи — в порядке добавления)
- `keys(null)` → `TypeError`
- `keys(42)` → `TypeError`
- `keys('строка')` → `TypeError` (строка — не объект для нашей функции)
- `keys([])` — на усмотрение реализации; массивы в JS — тоже объекты, но в рамках этого проекта мы работаем с plain-объектами
