### Объекты и for...in

**kind:** `text`

Объект — это коллекция пар «ключ-значение». Для перебора свойств объекта в JS есть цикл `for...in`:

```javascript
const user = { name: 'Анна', age: 25, city: 'Москва' };

for (const key in user) {
  console.log(key, '=', user[key]);
}
```

Но у `for...in` есть подвох: он перебирает не только собственные свойства объекта, но и унаследованные от прототипа. Проверь это сам:

```javascript
const obj = { a: 1 };

// Встроенные свойства прототипа, которые есть у любого объекта:
for (const key in obj) {
  console.log(key); // только 'a'? или ещё что-то?
}
```

Чтобы увидеть унаследованные свойства, добавь своё в прототип:

```javascript
Object.prototype.custom = 'я унаследованное';
const obj = { a: 1 };

for (const key in obj) {
  console.log(key); // теперь точно видно и 'a', и 'custom'
}

// Убери за собой:
delete Object.prototype.custom;
```

Запомни: чтобы отфильтровать только собственные свойства, используй `obj.hasOwnProperty(key)`.

### Реализация keys(obj)

**kind:** `text`

Реализуй функцию `keys(obj)` — аналог `Object.keys()`. Создай файлы `objects/keys.js` и `objects/keys.test.js`, следуй TDD.

**Функция принимает:**
- `obj`: `object` — объект, ключи которого нужно получить

**Функция возвращает:** `array` — массив строк (ключей объекта)

**Важно:** функция **иммутабельная** — не меняет исходный объект.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть массив ключей: `keys({ a: 1, b: 2, c: 3 })` → `['a', 'b', 'c']`
- Должна вернуть пустой массив для пустого объекта: `keys({})` → `[]`
- Должна вернуть ключи для объекта с одним свойством: `keys({ x: 10 })` → `['x']`
- Унаследованные свойства не должны попадать в результат (добавь свойство в `Object.prototype` перед вызовом и удали после — для чистоты теста).
- Должна выбросить `TypeError` если `obj` равен `null`
- Должна выбросить `TypeError` если `obj` не объект (число, строка, булево значение)
