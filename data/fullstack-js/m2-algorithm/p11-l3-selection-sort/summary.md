# selectionSort — краткая выжимка

- Сортировка выбором: на каждом проходе ищем минимум в неотсортированной части и ставим в начало
- Внешний цикл — позиция для минимума, внутренний — поиск `minIndex`
- Обмен только если `minIndex !== i` — максимум n обменов
- **Иммутабельная** — копия через `slice(arr, 0, len(arr))`
- ~n²/2 сравнений, но меньше обменов, чем у пузырька
