# Сортировка выбором (selection sort)

**Краткое содержание:**
Третий алгоритм сортировки. Сортировка выбором на каждом шаге находит минимальный элемент в неотсортированной части и ставит его в начало.

### 1. Идея: ищем минимум и ставим в начало

Сортировка выбором мыслит так: найдём самый маленький элемент во всём массиве и поставим его на первое место. Потом найдём самый маленький среди оставшихся и поставим на второе. И так далее, пока весь массив не будет отсортирован.

### 2. Алгоритм по шагам

1. Проверить тип и скопировать массив.
2. Внешний цикл `i` от 0 до `len - 2` — позиция, куда ставим минимум.
3. Внутренний цикл: найти индекс минимального элемента в диапазоне от `i` до `len - 1`.
4. Если минимум не на месте `i` — поменять местами.
5. Вернуть `result`.

### 3. Реализация

```javascript
function selectionSort(arr) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');

  const result = slice(arr, 0, len(arr));
  const n = len(result);

  for (let i = 0; i < n - 1; i++) {
    let minIndex = i;
    for (let j = i + 1; j < n; j++) {
      if (result[j] < result[minIndex]) minIndex = j;
    }
    if (minIndex !== i) {
      const temp = result[i];
      result[i] = result[minIndex];
      result[minIndex] = temp;
    }
  }

  return result;
}
```

### 4. Отличие от пузырька

Оба алгоритма делают ~n²/2 сравнений, но пузырёк меняет местами соседей **много раз** (обмен на каждое нарушение порядка), а выбор — **максимум n раз** (один обмен за проход). Если обмен «дорогой», выбор выгоднее.

Для чисел это незаметно, но идея важна: при одинаковом порядке роста алгоритмы могут отличаться в несколько раз из-за разных «констант». В уроке 5 увидим это на замерах времени.

### 5. Граничные случаи

- `selectionSort([])` → `[]`
- `selectionSort([7])` → `[7]`
- `selectionSort([1, 2, 3])` → `[1, 2, 3]`
- `selectionSort([3, 2, 1])` → `[1, 2, 3]`
- `selectionSort([4, 2, 4, 1])` → `[1, 2, 4, 4]`
- `selectionSort('abc')` → `TypeError`
