# push(arr, item) — краткая выжимка

- Добавляет элемент в **конец** массива
- Возвращает **новую длину** (`len + 1`)
- **Мутабельная** — исходный массив меняется
- Реализация: `arr[len(arr)] = item`
- В тесте проверяй и возвращаемое значение, и изменённый массив
- **Test API:** примитив → `toBe`, массив целиком → `toEqual` (массивы сравниваются по ссылке, `toBe` упадёт)
- JSDoc обязателен, отметь мутабельность
