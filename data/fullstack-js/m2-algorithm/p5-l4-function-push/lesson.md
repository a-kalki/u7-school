# Функция push(arr, item) — добавление в конец

**Краткое содержание:**
`push(arr, item)` — первая мутабельная функция проекта. Добавляет элемент в конец массива, изменяя исходный, и возвращает новую длину.

### Алгоритм

1. Проверить типы: `arr` — массив. Иначе `throw new TypeError`
2. `const length = len(arr)`
3. `arr[length] = item` — JS сам поставит элемент в конец
4. Вернуть `length + 1`

```javascript
function push(arr, item) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');
  const length = len(arr);
  arr[length] = item;
  return length + 1;
}
```

### Почему возвращает длину

Стандартный `Array.prototype.push` тоже возвращает новую длину. Это удобно для цепочек проверок и логирования. В наших функциях мы повторяем поведение стандартного API.

### Мутабельность

`push` **меняет** исходный массив. В JSDoc отметь это явно: «мутирует `arr`». В тестах обязательно проверяй состояние массива после вызова.


### Test API: toBe vs toEqual

Для проверки примитивов (чисел, строк) используй `toBe` — строгое равенство. Для проверки массива целиком — `toEqual`: два массива с одинаковым содержимым всё равно разные объекты, поэтому `[1,2,3] === [1,2,3]` даёт `false` и `toBe` упадёт. `toEqual` сравнивает содержимое.

```javascript
expect(result).toBe(3);            // число — toBe
expect(arr).toEqual([1, 2, 3]);    // массив — toEqual
```
