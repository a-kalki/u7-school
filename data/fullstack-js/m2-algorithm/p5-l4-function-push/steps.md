# Шаги урока: Функция push(arr, item) — добавление в конец

---

### Подсказка: test API для проверки массивов

**kind:** `text`

До сих пор ты проверял примитивы (числа, строки, булевы) через `toBe`. Для мутабельных функций этого мало — нужно проверять ещё и **содержимое массива** после вызова. Вот короткая шпаргалка по `bun:test`:

```javascript
import { describe, test, expect } from 'bun:test';
```

- `describe(имя, () => { ... })` — группирует тесты одной функции.
- `test(имя, () => { ... })` — отдельный тест.
- `expect(value).toBe(expected)` — **строгое** равенство (`===`). Годится для примитивов: чисел, строк, булевых.
- `expect(value).toEqual(expected)` — **глубокое** равенство: сравнивает содержимое массивов и объектов. Используй именно его, когда проверяешь массив целиком.
- `expect(value).toBeUndefined()` — значение равно `undefined`.
- `expect(() => fn(...)).toThrow(TypeError)` — функция выбрасывает исключение нужного типа.

**Почему для массивов нужен `toEqual`, а не `toBe`.** Два массива с одинаковым содержимым — это **два разных объекта** в памяти. Сравнение по ссылке `[1, 2, 3] === [1, 2, 3]` даёт `false`, поэтому `toBe` для массивов всегда упадёт. `toEqual` же сравнивает элементы:

```javascript
const arr = [1, 2, 3];
expect(arr).toBe([1, 2, 3]);    // ❌ упадёт: разные ссылки
expect(arr).toEqual([1, 2, 3]); // ✅ пройдёт: содержимое совпадает
```

**Как это упрощает тесты мутабельных функций.** Вместо того чтобы проверять каждый элемент отдельно (`expect(arr[0]).toBe(1); expect(arr[1]).toBe(2); ...`), сравни весь массив разом:

```javascript
test('push добавляет элемент в конец', () => {
  const arr = [1, 2];
  const result = push(arr, 3);

  expect(result).toBe(3);              // возвращённое значение — число, toBe
  expect(arr).toEqual([1, 2, 3]);      // массив целиком — toEqual
});
```

Запомни: **примитив → `toBe`, массив/объект → `toEqual`.**

### Реализация push()

**kind:** `text`

Реализуй функцию `push(arr, item)` — добавление элемента в конец массива. Создай файлы `arrays/push.js` и `arrays/push.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)
- `item`: `any` — элемент для добавления

**Функция возвращает:** `number` — новая длина массива.

**Важно:** функция **мутабельная**. В JSDoc отметь это. В тестах проверяй и возвращаемое значение, и что элемент действительно появился в конце массива.

Тестовые случаи:
- Должна добавить элемент в конец и вернуть новую длину: `push([1, 2], 3)` → `3`, массив `[1, 2, 3]`
- Должна работать с пустым массивом: `push([], 'a')` → `1`, массив `['a']`
- Должна добавить несколько элементов по очереди (два push подряд в один массив)
- Должна добавить элемент в массив из одного элемента: `push([10], 20)` → `2`, массив `[10, 20]`
- Должна добавить `0`, `false`, `null` как полноценные элементы (проверь, что `len` их учитывает)
- Должна добавить объект как элемент: `push([], {a: 1})` → `1`
- Исходный массив изменился — проверь `arr[len-1]` после вызова
- Должна выбросить `TypeError` если `arr` не массив (`push('hello', 1)`)
