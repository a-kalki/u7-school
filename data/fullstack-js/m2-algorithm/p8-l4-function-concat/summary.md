# Функция concat(arr1, arr2) — краткая выжимка

- concat(arr1, arr2) — новый массив из элементов обоих; ИММУТАБЕЛЬНАЯ
- Оба исходных массива остаются нетронутыми — обязательная проверка в тестах
- Spread `return [...arr1, ...arr2]` запрещён: реализуем циклами
- Краевые случаи: один из массивов пустой, оба пустые
- В тестах для результата — toEqual (глубокое равенство)
