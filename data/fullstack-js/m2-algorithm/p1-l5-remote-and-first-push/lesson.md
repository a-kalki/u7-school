# Удалённый репозиторий и первый push

**Краткое содержание:**
Теория remote и push, создание репозитория на GitHub, связывание с локальным (`git remote add`), контрольная точка main и первый push.

**Время:** ~15 мин

**Основные темы:**
1. `git remote add` — связь локального и удалённого репозиториев
2. Создание репозитория на GitHub
3. Контрольная точка: пушим именно `main`
4. `git push -u origin main` и сверка истории

**Термины:**
remote — удалённый репозиторий (твоя копия проекта на GitHub);
`origin` — стандартное имя главного remote, которое предлагает Git;
push — отправить свои коммиты на удалённый репозиторий;
pull — забрать чужие коммиты с удалённого репозитория;
флаг `-u` — запомнить связь локальной ветки с удалённой (нужен только при первом push)
