### Реализация forEach()

**kind:** `text`

Реализуй функцию `forEach(arr, callback)` — перебор массива с вызовом callback для каждого элемента. Создай файлы `array-utils/for-each.js` и `array-utils/for-each.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для перебора
- `callback`: `function` — функция, которая вызывается для каждого элемента

**Функция возвращает:** `undefined`.

**Важно:** функция **иммутабельная** — не меняет исходный массив. Callback получает три аргумента: `(элемент, индекс, массив)`.

**Термины:**
итеративная функция, которая проходит по массиву и применяет callback к его элементам

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вызвать callback для каждого элемента: для `[1, 2, 3]` проверить, что callback вызван 3 раза с правильными значениями
- Должна не вызывать callback для пустого массива: `forEach([], fn)` — `fn` не вызывается ни разу (можно положить в нее `throw Error('not be called'))`.
- Должна вернуть `undefined`: `forEach([1], () => {})` → `undefined`
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция

**Подсказка по тестированию callback-вызовов:**
```js
test('должна вызвать callback для каждого элемента', () => {
  const calls = [];
  forEach([1, 2, 3], (item, i, _arr) => {
    calls.push({ el, i, arr });
  });
  expect(calls).toEqual([
    { item: 1, i: 0, arr: [1, 2, 3] },
    { item: 2, i: 1, arr: [1, 2, 3] },
    { item: 3, i: 2, arr: [1, 2, 3] },
  ]);
});
```
