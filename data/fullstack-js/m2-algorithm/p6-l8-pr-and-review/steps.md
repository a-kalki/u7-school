### Создание PR

**kind:** `text`

Создай Pull Request:

1. На GitHub нажми **Compare & pull request**
2. Выбери base: `main`, compare: `feat/array-transform`

Заполни заголовок и описание:

**Заголовок:** `Проект 6: Массивы — трансформация`

**Описание:** перечисли все 7 функций с пометками «мутабельная» / «иммутабельная»:

- `fill` — заполнение значением (мутабельная)
- `reverse` — переворот на месте (мутабельная)
- `concat` — объединение в новый массив (иммутабельная)
- `slice` — копирование подмассива (иммутабельная)
- `join` — склеивание в строку (иммутабельная)
- `splice` — удаление и вставка (мутабельная, самая сложная)
- `flat` — разглаживание через рекурсию (иммутабельная, первое применение рекурсии)

Укажи как запустить тесты (`bun test`), отметь особенности: `flat` использует рекурсию, `splice` объединяет удаление и вставку.
