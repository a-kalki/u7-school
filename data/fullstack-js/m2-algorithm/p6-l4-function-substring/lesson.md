# Функция substring(str, start, end)

**Краткое содержание:**
Извлечение подстроки с нормализацией индексов — как у стандартного `String.prototype.substring`. TDD + JSDoc после заглушки, 17 тестовых случаев.

**Время:** ~25 мин

**Основные темы:**
1. Реализация substring() через TDD
2. Нормализация индексов

**Термины:**
нормализация индексов — приведение start/end к допустимым значениям до извлечения: отрицательные и NaN → 0, больше длины → длина строки;
граница «не включая» — end указывает на символ, который НЕ попадает в результат
