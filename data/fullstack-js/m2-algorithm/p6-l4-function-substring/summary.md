# Функция substring(str, start, end) — краткая выжимка

- substring(str, start, end) — подстрока от start (включая) до end (не включая)
- Нормализация: отрицательные и NaN → 0; больше длины → длина строки; start > end → обмен местами
- JSDoc — сразу после заглушки, до реализации
- Граница end «не включая»: символ на позиции end в результат не попадает
- 17 тестов: границы, нормализация, кириллица, TypeError на каждый неверный аргумент
