# ДЗ: статья «Git для новичков» (часть 2)

**Краткое содержание:**
Обязательное чтение: вторая часть статьи «Git для новичков» (командная работа, ветки, merge). Конспект — в `homework.md`, сдаётся прямым коммитом в `main` и пушем на GitHub, без PR (образовательное исключение: мелкие некодовые правки; весь код — только через PR и ревью).

**Время:** ~40 мин (чтение + конспект + мини-PR)

**Основные темы:**
1. Командная работа в Git: ветки, merge, clone, pull
2. Конспект в `homework.md`
3. Прямой пуш в `main` — когда такое обновление допустимо

**Термины:**
clone — по англ. «клонировать»: скачать полную копию чужого репозитория локально;
pull — забрать и влить обновления с GitHub (= fetch + merge);
merge — слияние веток (ты это уже делал руками)
