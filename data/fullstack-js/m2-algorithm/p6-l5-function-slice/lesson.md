# Функция slice(str, start, end)

**Краткое содержание:**
Извлечение подстроки с поддержкой отрицательных индексов — как у стандартного `String.prototype.slice`. Сравнение с substring: главное отличие в правилах нормализации.

**Время:** ~20 мин

**Основные темы:**
1. Реализация slice() через TDD
2. Отрицательные индексы

**Термины:**
отрицательный индекс — отсчёт с конца: `-1` — последний символ, `-2` — предпоследний, `-len` — первый
