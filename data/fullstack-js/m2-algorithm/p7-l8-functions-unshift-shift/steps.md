# Шаги урока: Функции unshift(arr, item) и shift(arr)

---

### Реализация unshift() через TDD

**kind:** `text`

> Убедись, что ты в ветке `feat/array-basics`.

Реализуй функцию `unshift(arr, item)` — добавление элемента в начало со сдвигом. Создай файлы `array-utils/unshift.js` и `array-utils/unshift.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)
- `item`: `any` — элемент для добавления

**Функция возвращает:** `number` — новая длина массива.

**Важно:** функция **мутабельная** — сдвигает все существующие элементы на одну позицию вправо. JSDoc с явной отметкой, в тестах — возврат + состояние массива.

**Термины:**
сдвиг — перемещение всех элементов массива на одну позицию (вправо при вставке, влево при удалении)

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна добавить элемент в начало и вернуть новую длину: `unshift([2, 3], 1)` → `3`, массив `[1, 2, 3]`
- Должна работать с пустым массивом: `unshift([], 'a')` → `1`, массив `['a']`
- Должна добавить в массив из одного элемента: `unshift([20], 10)` → `2`, массив `[10, 20]`
- Должна сохранить порядок остальных элементов (ничего не затёрлось): `unshift(['b', 'c', 'd'], 'a')` → массив `['a', 'b', 'c', 'd']`
- Два `unshift` подряд: первый элемент становится вторым
- Должна выбросить `TypeError` если `arr` не массив

Сохрани изменения:

```
git add array-utils/unshift.js array-utils/unshift.test.js
git commit -m "Реализована unshift — добавление в начало со сдвигом"
```

### Реализация shift() через TDD

**kind:** `text`

> Убедись, что ты в ветке `feat/array-basics`.

Реализуй функцию `shift(arr)` — удаление первого элемента со сдвигом. Создай файлы `array-utils/shift.js` и `array-utils/shift.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)

**Функция возвращает:** удалённый первый элемент, либо `undefined` для пустого массива.

**Важно:** функция **мутабельная** — сдвигает все остальные элементы на одну позицию влево. Вспомни `pop`: для уборки индекса здесь тоже понадобится `delete`.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна удалить первый элемент и вернуть его: `shift([1, 2, 3])` → `1`, массив `[2, 3]`
- Должна вернуть `undefined` для пустого массива: `shift([])` → `undefined`
- Должна удалить единственный элемент: `shift([42])` → `42`, массив стал пустым
- Должна сохранить порядок остальных элементов: `shift(['a', 'b', 'c'])` → `'a'`, массив `['b', 'c']`
- Должна корректно удалить `falsy` значение (не спутать с `undefined`): `shift([0, 1])` → `0`
- Два `shift` подряд уменьшают длину на 2
- Должна выбросить `TypeError` если `arr` не массив
