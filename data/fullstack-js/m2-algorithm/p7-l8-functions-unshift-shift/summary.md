# Функции unshift(arr, item) и shift(arr) — краткая выжимка

- unshift(arr, item) — добавляет в начало со сдвигом вправо, возвращает новую длину; МУТАБЕЛЬНАЯ
- shift(arr) — удаляет первый элемент со сдвигом влево, возвращает его; МУТАБЕЛЬНАЯ
- Пустой массив: unshift возвращает 1, shift возвращает undefined
- Порядок остальных элементов обязан сохраниться — проверяем в тестах
- shift для уборки индекса использует delete (как pop)
- falsy-значения (0, false) — полноценные элементы, не спутать с undefined
