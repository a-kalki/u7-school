# Функции unshift(arr, item) и shift(arr)

**Краткое содержание:**
Зеркальная пара мутабельных операций для начала массива: добавление и удаление первого элемента — обе со сдвигом всех остальных.

**Время:** ~15 мин

**Основные темы:**
1. Реализация unshift() через TDD
2. Реализация shift() через TDD

**Термины:**
сдвиг — перемещение всех элементов массива на одну позицию (вправо при вставке, влево при удалении)
