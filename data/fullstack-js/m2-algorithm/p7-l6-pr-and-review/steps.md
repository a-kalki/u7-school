### Создание PR

**kind:** `text`

Создай Pull Request:

1. На GitHub нажми **Compare & pull request**
2. Выбери base: `main`, compare: `feat/iterative-methods`

Заполни заголовок и описание:

**Заголовок:** `Проект 7: Массивы — итеративные методы`

**Описание:** перечисли все 5 функций с краткими пояснениями:

- `forEach` — перебор, вызывает callback для каждого элемента (возвращает `undefined`)
- `map` — трансформация, новый массив из результатов callback
- `filter` — фильтрация, новый массив из элементов, прошедших проверку
- `some` — проверка «хотя бы один» с ранним выходом при `true`
- `every` — проверка «все» с ранним выходом при `false`

Все функции используют callback-паттерн (пройден в модуле 1). Все иммутабельные — не меняют исходный массив. `some` и `every` демонстрируют ранний выход.

Укажи как запустить тесты (`bun test`).
