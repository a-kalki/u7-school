# Шаги урока: Пуш ветки, PR, сообщение в чат

---

### Финальный прогон и пуш ветки

**kind:** `text`

Перед отправкой — свой чек-лист из проекта 4:

- `bun test` — все 6 функций зелёные
- `git status` — working tree clean, ты в ветке `feat/substring-search`
- `git log --oneline` — осмысленная история коммитов

Если всё в порядке — пуш:

```
git push -u origin feat/substring-search
```

---

### Создание PR по шаблону

**kind:** `text`

Создай PR: base `main` ← compare `feat/substring-search`.

**Заголовок:**
```
Проект 5: функции поиска подстрок и утилиты для строк
```

**Описание — заполни по шаблону:**

```markdown
## Что сделано

Реализованы 6 функций для работы со строками:

- indexOf(str, search) — наивный поиск подстроки
- includes(str, search) — проверка наличия подстроки
- startsWith(str, search) — проверка начала строки
- endsWith(str, search) — проверка конца строки
- reverse(str) — переворот строки
- repeat(str, count) — повторение строки

Все функции реализованы через TDD, includes/startsWith/endsWith
построены на базе indexOf.

## Как запустить тесты

bun test
```
