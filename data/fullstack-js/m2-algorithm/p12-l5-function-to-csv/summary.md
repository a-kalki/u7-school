# toCSV(data) — краткая выжимка

- **CSV** — таблица текстом: строки, колонки через `,`, заголовки. Хранит только текст → типы теряются
- **JSON** — у каждого типа своя запись; строка в `"..."`, число/boolean/`null` — без кавычек
- **Наш формат** («велосипед»): структура как у CSV, значения как в JSON
- `'25'` → `"25"` (строка), `25` → `25` (число), `true` → `true`, `null` → `null`
- `undefined` → пустая ячейка; `NaN`/`Infinity` → `null`
- **Экранирование** (упрощённое): `"` → `\"`, `\` → `\\`, `\n`, `\r`, `\t`. Запятую экранировать не нужно — она внутри кавычек
- **Код vs значение:** `'a\nb'` в коде → в памяти 3 символа (перенос — один); `\\` в коде → один `\` в значении
- **Ключи** — непустые строки без `,`, `"`, `\`, переносов; иначе `TypeError`
- **Ограничения:** плоские объекты с одинаковыми ключами (по первому объекту), значения только примитивы
- Порядок: заголовки → строки; значение через `serializeValue`
- `serializeValue`: `undefined` → `''`, `null` → `'null'`, boolean, число (`NaN`/`Infinity` → `'null'`), строка → `'"' + escapeString(value) + '"'`
- **`escapeString(value)`** — отдельный исполнитель экранирования; кавычки-обёртки сам не добавляет
- **Иммутабельная**; `JSON.stringify` не используем — пишем сериализацию сами
- JSDoc обязателен, отметь формат и экранирование
