# Функция toCSV(data)

**Краткое содержание:**
Четвёртая бизнес-утилита — сериализация массива плоских объектов в текст без потери типов. **Термины:**
* **CSV (Comma-Separated Values)** — таблица в виде текста: строки разделяются переносом, колонки — запятой, первая строка — заголовки.
* **JSON (JavaScript Object Notation)** — текстовый формат данных, где у каждого типа своя однозначная запись: строка в кавычках, число/boolean/`null` — без кавычек.
* **Сериализация** — превращение значения или структуры данных в текст для хранения или передачи.
* **Экранирование** — замена спецсимволов (`"`, `\`, перенос и др.) на безопасные последовательности (`\"`, `\\`, `\n`), чтобы они не ломали формат.
* **`escapeString(value)`** — исполнитель, который экранирует спецсимволы внутри одной строки; кавычки-обёртки не добавляет.
* **Наш формат («велосипед»)** — собственный формат: структура как у CSV, значения как в JSON.
* **Ключ (заголовок)** — имя колонки, берётся из ключей первого объекта.
* **Значение** — содержимое ячейки: строка, число, boolean, `null` или `undefined`.
* **Примитив** — простое значение (строка, число, boolean, `null`, `undefined`), в отличие от объекта или массива.
* **Иммутабельность** — свойство функции не менять входные данные, а возвращать новый результат.

### Что такое CSV и JSON

**CSV** — таблица в виде текста: строки разделяются переносом, колонки — запятой, первая строка — заголовки. Удобно и компактно, но **хранит только текст**: `'25'` и `25` выглядят одинаково, типы теряются.

**JSON** — текстовый формат данных, где у каждого типа своя однозначная запись:

| Значение | Запись |
|---|---|
| строка `'Анна'` | `"Анна"` |
| строка `'25'` | `"25"` |
| число `25` | `25` |
| `true` / `false` | `true` / `false` |
| `null` | `null` |
| `undefined` | — (нет записи) |
| `NaN`, `Infinity` | `null` |

Ключевое правило: **строка всегда в кавычках, остальные типы — без**. Именно кавычки отличают `'25'` от `25`.

### Наш формат

Не CSV и не JSON, а свой формат («велосипед»): **структура как у CSV, значения как в JSON.**

- Первая строка — ключи (заголовки), разделённые запятой.
- Далее каждая строка — один объект, значения в порядке ключей.
- Значение записывается ровно так, как его пишет JSON.
- `undefined` → пустая ячейка; пустая ячейка при чтении → `undefined`.

**Экранирование строк** (упрощённое подмножество JSON):

| Символ | В записи |
|---|---|
| `"` | `\"` |
| `\` | `\\` |
| перенос | `\n` |
| возврат каретки | `\r` |
| табуляция | `\t` |

Запятую экранировать не нужно: она внутри кавычек не разделяет колонки.

**Правила ключей:** ключ — непустая строка без `,`, `"`, `\` и переносов. Иначе — `TypeError`.

**Ограничения:** массив **плоских** объектов с одинаковыми ключами; ключи берутся по первому объекту; значения — только примитивы (объекты и массивы не поддерживаются).

### Алгоритм

1. `data` не массив → `TypeError`. Пустой массив → `''`.
2. `headers = keys(data[0])`. Каждый ключ проверить на допустимость.
3. Строка заголовков: ключи через `,`.
4. Для каждого объекта: значение → `serializeValue`, ячейки через `,`, строка закрывается `\n`.
5. `serializeValue`: `undefined` → `''`, `null` → `'null'`, boolean → `'true'`/`'false'`, число → `String(value)` (`NaN`/`Infinity` → `'null'`), строка → `'"'` + `escapeString(value)` + `'"'`.
6. `escapeString(value)` — специалист по экранированию: заменяет спецсимволы строки на пары.

```javascript
function isValidKey(key) {
  if (typeof key !== 'string' || key === '') return false;
  for (let i = 0; i < len(key); i++) {
    const ch = key[i];
    if (ch === ',' || ch === '"' || ch === '\\' || ch === '\n' || ch === '\r') return false;
  }
  return true;
}

function escapeString(value) {
  let result = '';
  for (let i = 0; i < len(value); i++) {
    const ch = value[i];
    if (ch === '"') result += '\\"';
    else if (ch === '\\') result += '\\\\';
    else if (ch === '\n') result += '\\n';
    else if (ch === '\r') result += '\\r';
    else if (ch === '\t') result += '\\t';
    else result += ch;
  }
  return result;
}

function serializeValue(value) {
  if (value === undefined) return '';
  if (value === null) return 'null';
  if (typeof value === 'boolean') return value ? 'true' : 'false';
  if (typeof value === 'number') return Number.isFinite(value) ? String(value) : 'null';
  if (typeof value !== 'string') throw new TypeError('Значение должно быть примитивом');
  return '"' + escapeString(value) + '"';
}

function toCSV(data) {
  if (!Array.isArray(data)) throw new TypeError('Ожидается массив');
  if (len(data) === 0) return '';

  const headers = keys(data[0]);

  let result = '';
  for (let i = 0; i < len(headers); i++) {
    if (!isValidKey(headers[i])) throw new TypeError('Недопустимый ключ: ' + headers[i]);
    if (i > 0) result += ',';
    result += headers[i];
  }
  result += '\n';

  for (let i = 0; i < len(data); i++) {
    for (let j = 0; j < len(headers); j++) {
      if (j > 0) result += ',';
      result += serializeValue(data[i][headers[j]]);
    }
    result += '\n';
  }

  return result;
}
```

Пример `[{ name: 'Anna', age: 25, home: '25', pet: null, isWorked: true, note: undefined }]`:

```
name,age,home,pet,isWorked,note
"Anna",25,"25",null,true,
```

`"Anna"` и `"25"` — строки (в кавычках), `25` — число, `null` — null, `true` — boolean, пустая ячейка — `undefined`.
