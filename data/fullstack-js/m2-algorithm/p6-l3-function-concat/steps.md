# Шаги урока: Функция concat(arr1, arr2) — объединение массивов

---

### Реализация concat()

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

Реализуй функцию `concat(arr1, arr2)` — объединение двух массивов в новый. Создай файлы `arrays/concat.js` и `arrays/concat.test.js`, следуй TDD.

**Функция принимает:**
- `arr1`: `array` — первый массив
- `arr2`: `array` — второй массив

**Функция возвращает:** `array` — новый массив из элементов `arr1` и `arr2`.

**Важно:** функция **иммутабельная** — исходные массивы не меняются, возвращается новый. В JSDoc отметь это. В тестах обязательно проверяй, что исходные массивы остались без изменений.

**Примечание:** не используй spread подход  `return [...arr1, ...arr2]`, реализуй через js логику.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна объединить два непустых массива: `concat([1, 2], [3, 4])` → `[1, 2, 3, 4]`
- Должна вернуть копию первого если второй пуст: `concat([1, 2], [])` → `[1, 2]`
- Должна вернуть копию второго если первый пуст: `concat([], [3, 4])` → `[3, 4]`
- Должна вернуть пустой массив для двух пустых: `concat([], [])` → `[]`
- Исходный `arr1` не должен измениться после вызова
- Исходный `arr2` не должен измениться после вызова
- Должна работать с массивами строк: `concat(['a'], ['b', 'c'])` → `['a', 'b', 'c']`
- Должна работать с массивами смешанных типов
- Должна выбросить `TypeError` если `arr1` не массив
- Должна выбросить `TypeError` если `arr2` не массив
