# cloneDeep(obj) — краткая выжимка

- Поверхностное копирование — только первый уровень, вложенные объекты/массивы остаются общими
- Глубокое копирование — рекурсивно создаёт независимые копии всех уровней
- `cloneDeep` использует рекурсию: для массивов — клонирует каждый элемент, для объектов — каждое значение
- **Порядок проверок важен:** `null` → примитивы → массив → объект
- `typeof null === 'object'` — без отдельной проверки уйдём в ветку объекта и сломаемся на `keys(null)`
- `Array.isArray` до проверки на объект — массив это тоже объект
- Примитивы возвращаются «как есть» — они не нуждаются в копировании
- **Иммутабельная** по отношению к исходному значению
- Тест: меняем копию на всех уровнях → оригинал не изменился
- JSDoc обязателен, отметь рекурсивность и иммутабельность
