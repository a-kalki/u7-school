# Шаги урока: Функция flat(arr, depth) — разглаживание вложенных массивов

---

### Реализация flat()

**kind:** `text`

> Убедись, что ты в ветке `feat/iterative-methods-2`.

Реализуй функцию `flat(arr, depth)` — разглаживание вложенных массивов. Создай файлы `arrays/flat.js` и `arrays/flat.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для разглаживания
- `depth`: `number` (необязательный, по умолчанию `1`) — глубина разглаживания. `Infinity` — разгладить полностью.

**Функция возвращает:** `array` — новый плоский массив.

**Важно:** функция **иммутабельная** — не меняет исходный массив.

Реализовать `flat` можно двумя способами:
1. **Через рекурсию (прямой цикл):** пройти по массиву, для каждого элемента — если это массив и `depth > 0`, вызвать `flat` рекурсивно.
2. **Через `reduce`:** использовать `reduce` как аккумулятор результата.

Выбери тот, который понятнее. Оба корректны — главное пройти тесты.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна разгладить один уровень: `flat([1, [2, 3], 4])` → `[1, 2, 3, 4]`
- Должна разгладить два уровня: `flat([1, [2, [3, 4]]], 2)` → `[1, 2, 3, 4]`
- Должна разгладить полностью с Infinity: `flat([1, [2, [3, [4]]]], Infinity)` → `[1, 2, 3, 4]`
- Должна вернуть копию для уже плоского массива: `flat([1, 2, 3])` → `[1, 2, 3]`, и `исходный !== результат`
- Должна вернуть пустой массив для пустого: `flat([])` → `[]`
- Должна не разглаживать при depth = 0: `flat([1, [2, 3]], 0)` → `[1, [2, 3]]`
- Должна обрабатывать смешанную вложенность с глубиной по умолчанию: `flat([1, [2], [3, [4]]])` → `[1, 2, 3, [4]]`
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `depth` передан и не число
