# Шаги урока: Функция slice(arr, start, end) — копирование подмассива

---

### Реализация slice(arr)

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

Реализуй функцию `slice(arr, start, end)` — копирование части массива в новый. Создай файлы `arrays/slice.js` и `arrays/slice.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — исходный массив (не меняется)
- `start`: `number` — начальный индекс (включая). Если отрицательный — отсчёт с конца
- `end`: `number` (необязательный) — конечный индекс (не включая). Если не передан — до конца массива. Если отрицательный — отсчёт с конца

**Функция возвращает:** `array` — новый массив из скопированных элементов.

**Важно:** функция **иммутабельная** — исходный массив не меняется. В JSDoc отметь это. В тестах проверяй, что исходный массив не изменился.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна скопировать весь массив: `slice([1, 2, 3], 0, 3)` → `[1, 2, 3]`
- Должна скопировать часть с середины: `slice([1, 2, 3, 4], 1, 3)` → `[2, 3]`
- Должна скопировать от start до конца без end: `slice([1, 2, 3, 4], 2)` → `[3, 4]`
- Должна поддерживать отрицательный start: `slice([1, 2, 3, 4], -2)` → `[3, 4]`
- Должна поддерживать отрицательный end: `slice([1, 2, 3, 4], 0, -1)` → `[1, 2, 3]`
- Должна работать с обоими отрицательными: `slice([1, 2, 3, 4], -3, -1)` → `[2, 3]`
- Должна вернуть пустой массив если start >= end: `slice([1, 2, 3], 2, 2)` → `[]`
- Должна вернуть пустой массив для пустого исходного: `slice([], 0, 1)` → `[]`
- Исходный массив не должен измениться после вызова
- Должна нормализовать выходящий за границы start: `slice([1, 2, 3], 5, 7)` → `[]`
- Должна нормализовать уходящий за границы отрицательный start: `slice([1, 2, 3], -10, 2)` → `[1, 2]`
- Должна работать с массивом строк
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `start` не число
- Должна выбросить `TypeError` если `end` передан и не число
