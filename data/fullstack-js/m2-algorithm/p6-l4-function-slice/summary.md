# slice(arr, start, end) — краткая выжимка

- Копирует часть массива в **новый** массив (иммутабельная)
- `start` — включая, `end` — не включая
- Поддержка отрицательных индексов (отсчёт с конца)
- `end` можно не передавать — копирует до конца
- `start >= end` → пустой массив
- Исходный массив не меняется
- JSDoc обязателен, отметь иммутабельность
