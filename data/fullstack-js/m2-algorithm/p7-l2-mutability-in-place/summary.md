# Мутабельность: изменение массива «на месте» — краткая выжимка

- Массив передаётся в функцию по ссылке: функция работает с тем же массивом в памяти
- Мутабельная операция — меняет исходный массив «на месте» (push, pop, unshift, shift)
- Иммутабельная — возвращает новый массив, исходный не трогает (concat, slice, все «читающие»)
- Опасность: одна часть программы мутирует массив — другая получает испорченные данные
- Дисциплина: в JSDoc явно отмечаем мутирующие функции
- Строки в JS иммутабельны, массивы — мутабельны
