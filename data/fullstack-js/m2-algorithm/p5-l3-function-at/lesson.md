# Функция at(arr, index) — доступ по индексу

**Краткое содержание:**
`at(arr, index)` возвращает элемент массива по индексу. Поддерживает отрицательные индексы: `-1` — последний элемент, `-2` — предпоследний. При выходе за границы возвращает `undefined`.

### Алгоритм

1. Проверить типы: `arr` — массив, `index` — число. Иначе `throw new TypeError`
2. Если `index < 0` — привести к положительному: `index = len(arr) + index`
3. Если после нормализации `index < 0` или `index >= len(arr)` — вернуть `undefined`
4. Вернуть `arr[index]`

### Зачем отрицательные индексы

Без `at` взять последний элемент можно только зная длину: `arr[len(arr) - 1]`. С `at` — лаконично: `at(arr, -1)`. Это удобно, когда длина неизвестна заранее.

### Связь с len

`at` — первая функция, которая **использует** `len` как строительный блок. Так весь проект строится снизу вверх: `len` → `at` → `push`/`pop` → `indexOf` → ...
