# Шаги урока: Функция at(arr, index) — доступ по индексу

---

### Реализация at()

**kind:** `text`

> Убедись, что ты в ветке `feat/array-basics`.

Реализуй функцию `at(arr, index)` — доступ к элементу с поддержкой отрицательных индексов. Создай файлы `arrays/at.js` и `arrays/at.test.js`.

**Функция принимает:**
- `arr`: `array` — массив
- `index`: `number` — индекс (положительный или отрицательный)

**Функция возвращает:** элемент массива по индексу, либо `undefined` если индекс за границами.

Тестовые случаи:
- Должна вернуть элемент по положительному индексу: `at([10, 20, 30], 1)` → `20`
- Должна вернуть первый элемент: `at([10, 20, 30], 0)` → `10`
- Должна вернуть последний элемент по отрицательному индексу: `at([10, 20, 30], -1)` → `30`
- Должна вернуть предпоследний элемент: `at([10, 20, 30], -2)` → `20`
- Должна вернуть первый через `-len`: `at([10, 20, 30], -3)` → `10`
- Должна вернуть `undefined` при выходе за правую границу: `at([10, 20, 30], 5)` → `undefined`
- Должна вернуть `undefined` при выходе за левую границу: `at([10, 20, 30], -5)` → `undefined`
- Должна вернуть `undefined` для пустого массива: `at([], 0)` → `undefined`
- Должна вернуть `undefined` для пустого массива и отрицательного: `at([], -1)` → `undefined`
- Должна работать с массивом строк: `at(['a', 'b', 'c'], 2)` → `'c'`
- Должна не мутировать исходный массив
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `index` не число (`at([1], 'a')`)
