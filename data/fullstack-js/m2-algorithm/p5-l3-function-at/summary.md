# at(arr, index) — краткая выжимка

- Возвращает элемент по индексу
- Положительный индекс — с начала, отрицательный — с конца (`-1` → последний)
- Выход за границы → `undefined`
- Использует собственную `len(arr)` для нормализации отрицательного индекса: `len(arr) + index`
- Не мутирует массив
- JSDoc обязателен
