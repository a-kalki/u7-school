# Проблема: массивы

**Краткое содержание:**
Новая структура данных: массив как упорядоченная коллекция. Состав API проекта — 9 функций, отдельная папка `array-utils/`. Ветка `feat/array-basics`.

**Время:** ~15 мин

**Основные темы:**
1. Зачем нужен массив
2. Состав API проекта
3. Ветка проекта

**Термины:**
массив — упорядоченная коллекция элементов с доступом по индексу;
структура данных — способ организации данных для удобной и эффективной работы с ними;
коллекция — обобщённое название для наборов элементов (список, массив, множество)
