# Проблема: массивы — краткая выжимка

- Массив — упорядоченная коллекция с доступом по индексу; первая настоящая структура данных модуля
- Ключевое отличие от строк: массивы мутабельны — их можно менять «на месте»
- API проекта — 9 функций: len, at, push, pop, unshift, shift, indexOf, lastIndexOf, includes
- Отдельная папка `array-utils/`: имена функций совпадают со строковыми (len, indexOf, includes) — конфликтов быть не должно
- Запрещены встроенные методы массивов и `.length`; TDD + JSDoc, коммит после каждой функции
- Ветка: `feat/array-basics` от свежего main
