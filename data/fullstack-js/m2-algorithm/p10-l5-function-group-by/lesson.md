# Функция groupBy(array, key)

**Краткое содержание:**
Пятая бизнес-утилита — группировка массива объектов по значению указанного ключа. Студент применяет `keys`, `push`, `len` и `hasOwnProperty` для создания объекта, где каждому уникальному значению ключа соответствует массив объектов с этим значением.

### 1. Задача группировки

На входе — массив объектов. Нужно сгруппировать их по значению определённого поля:

```javascript
const users = [
  { name: 'Анна', city: 'Москва' },
  { name: 'Борис', city: 'Питер' },
  { name: 'Вера', city: 'Москва' },
  { name: 'Глеб', city: 'Питер' },
];

groupBy(users, 'city');
// {
//   'Москва': [
//     { name: 'Анна', city: 'Москва' },
//     { name: 'Вера', city: 'Москва' },
//   ],
//   'Питер': [
//     { name: 'Борис', city: 'Питер' },
//     { name: 'Глеб', city: 'Питер' },
//   ],
// }
```

### 2. Алгоритм groupBy

```javascript
function groupBy(array, key) {
  if (!Array.isArray(array)) throw new TypeError('Ожидается массив');
  if (typeof key !== 'string') throw new TypeError('Ожидается строка');

  const result = {};

  for (let i = 0; i < len(array); i++) {
    const item = array[i];
    const groupValue = item[key];

    // Если группы с таким значением ещё нет — создаём пустой массив
    if (!result.hasOwnProperty(groupValue)) {
      result[groupValue] = [];
    }

    // Добавляем объект в группу
    push(result[groupValue], item);
  }

  return result;
}
```

### 3. Ключевые моменты

**hasOwnProperty для проверки группы:** используем `result.hasOwnProperty(groupValue)`, а не `result[groupValue] === undefined`, потому что группа может существовать, но быть пустым массивом (на практике — редко, но проверка через `hasOwnProperty` надёжнее).

**Значение ключа как имя свойства:** `groupValue` может быть строкой или числом. При использовании как ключ объекта оно автоматически преобразуется в строку. Поэтому `groupBy(data, 'age')` где возраст `25` создаст ключ `'25'`, а не число.

**Иммутабельность:** функция не меняет исходный массив. Объекты внутри групп — те же самые (не клонируются). Это важно отметить в JSDoc.

### 4. Граничные случаи

- `groupBy([], 'key')` → `{}` (пустой массив)
- `groupBy([{ a: 1 }, { a: 2 }, { a: 1 }], 'a')` → `{ '1': [{ a: 1 }, { a: 1 }], '2': [{ a: 2 }] }`
- `groupBy([{ x: 'a' }, { x: 'b' }, { x: 'a' }], 'x')` → `{ 'a': [{ x: 'a' }, { x: 'a' }], 'b': [{ x: 'b' }] }`
- Значение ключа может быть `undefined`: все объекты без этого ключа попадут в группу `'undefined'`
- `groupBy('не массив', 'key')` → `TypeError`
- `groupBy([], 123)` → `TypeError` (ключ должен быть строкой)

### 5. Какие свои функции используем

- `len` — длина массива
- `push` — добавление элемента в группу
- `hasOwnProperty` — проверка существования группы
