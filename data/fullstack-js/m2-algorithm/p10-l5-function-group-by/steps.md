# Шаги урока: Функция groupBy(array, key)

---

### Реализация groupBy()

**kind:** `text**

> Убедись, что ты в ветке `feat/business-utils`.

Реализуй функцию `groupBy(array, key)` — группировка массива объектов по значению указанного ключа. Создай файлы `utils/group-by.js` и `utils/group-by.test.js`, следуй TDD.

**Функция принимает:**
- `array`: `array` — массив объектов
- `key`: `string` — имя свойства, по которому группировать

**Функция возвращает:** `object` — объект, где ключи — уникальные значения группировки, значения — массивы объектов с этим значением.

**Важно:** функция **иммутабельная** — не меняет исходный массив. Объекты внутри групп — те же самые ссылки (не копируются). Отметь это в JSDoc.

Алгоритм:
1. Проверить типы: `array` — массив, `key` — строка.
2. Создать пустой объект `result`.
3. Для каждого элемента массива:
   - Взять `groupValue = item[key]`
   - Если `result` ещё не имеет свойства `groupValue` (проверить через `hasOwnProperty`) — создать пустой массив
   - Добавить `item` в массив `result[groupValue]` через `push`

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть пустой объект для пустого массива: `groupBy([], 'city')` → `{}`
- Должна сгруппировать по строковому ключу: `groupBy([{ city: 'Москва' }, { city: 'Питер' }, { city: 'Москва' }], 'city')` → `{ 'Москва': [{ city: 'Москва' }, { city: 'Москва' }], 'Питер': [{ city: 'Питер' }] }`
- Должна сгруппировать по числовому ключу: `groupBy([{ age: 25 }, { age: 30 }, { age: 25 }], 'age')` → ключи `'25'` и `'30'` (строковые, т.к. ключи объекта — всегда строки)
- Должна работать с одним элементом: `groupBy([{ x: 1 }], 'x')` → `{ '1': [{ x: 1 }] }`
- Все элементы в одной группе если ключ одинаковый: `groupBy([{ a: 1 }, { a: 1 }], 'a')` → `{ '1': [{ a: 1 }, { a: 1 }] }`
- Должна обработать отсутствующий ключ: `groupBy([{ a: 1 }, {}], 'a')` → `{ '1': [{ a: 1 }], 'undefined': [{}] }`
- Должна вернуть те же объекты (не копии): элементы в группах должны быть теми же ссылками
- Должна выбросить `TypeError` если `array` не массив
- Должна выбросить `TypeError` если `key` не строка

### Вопросы на понимание

**kind:** `text**

Ответь на вопросы. Если не знаешь — проверь гипотезу кодом через `bun`.

**1.** Почему в результате ключи всегда строки, даже если группируешь по числовому полю? Как это связано с устройством объектов в JS?

**2.** Функция не клонирует объекты — группы содержат ссылки на исходные объекты. Что будет, если изменить объект в группе? Отразится ли это на исходном массиве?

**3.** Можно ли сгруппировать массив по нескольким ключам сразу (например, по городу и возрасту)? Как бы выглядел результат и алгоритм?

**4.** Посмотри на свои реализации `keys`, `values`, `entries`, `groupBy`. Все они создают объекты/массивы на основе других объектов/массивов. Какая между ними общая закономерность?
