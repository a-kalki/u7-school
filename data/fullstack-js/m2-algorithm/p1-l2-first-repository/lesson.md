# Первый репозиторий

**Краткое содержание:**
Превращаем папку проекта в git-репозиторий: `git init`, проверка имени основной ветки (main), настройка `.gitignore`.

**Время:** ~15 мин

**Основные темы:**
1. `git init` — создание репозитория
2. Проверка имени текущей ветки: нужна `main`
3. `.gitignore` — что не должно попадать в историю

**Термины:**
`git init` — команда, превращающая обычную папку в git-репозиторий;
`.gitignore` — текстовый файл со списком того, что Git должен игнорировать;
Untracked files — «неотслеживаемые» файлы: Git их видит, но в историю они пока не попадают
