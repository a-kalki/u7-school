# Как читать чужой код — краткая выжимка

- Порядок чтения: сигнатура (что должна делать) → тесты (что обещано) → реализация (что на самом деле)
- Пять вопросов ревьюера: корректность, граничные случаи, правила модуля, читаемость, тесты
- Формула комментария та же: «Предлагаю/Нужно X, потому что Y»
- Отличия от ревью текста: код можно выполнить; критерий однозначен (тесты); цена пропуска выше; нужна конкретика («isLess('a', 'ab') вернёт true, а должна false»)
- Практика: мысленный прогон теста по шагам — где трудно себе, там внимательно ревьюеру
