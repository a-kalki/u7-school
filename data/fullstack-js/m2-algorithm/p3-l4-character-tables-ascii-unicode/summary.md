# Таблица символов: ASCII и Unicode — краткая выжимка

- Символ = число в таблице; ASCII — 128 символов (коды 0–127), Unicode — 149 000+ (включая кириллицу и эмодзи)
- Ключевые коды: пробел 32, цифры 48–57, `'A'`–`'Z'` 65–90, `'a'`–`'z'` 97–122
- Закономерность: строчная = заглавная + 32
- Разрешённые методы: `.charCodeAt(0)` (код символа) и `String.fromCodePoint(код)` (обратно)
- Лексикографическое сравнение: посимвольно слева направо по кодам; кончилась строка — она меньше
- Особенности: `'Z' < 'a'` (все заглавные меньше строчных), `'10' < '2'` (строки, не числа)
- Таблицы: asciitable.com, unicode-table.com
