# Таблица символов: ASCII и Unicode

**Краткое содержание:**
Компьютер хранит символы как числа; таблицы ASCII и Unicode; разрешённые методы `charCodeAt()` и `fromCodePoint()`; лексикографическое сравнение; практика предсказания результатов.

**Время:** ~25 мин

**Основные темы:**
1. ASCII и Unicode
2. charCodeAt() / fromCodePoint()
3. Лексикографическое сравнение
4. Практика и контрольные вопросы

**Термины:**
ASCII — таблица из 128 символов, коды 0–127 (латиница, цифры, базовые знаки);
Unicode — расширенная таблица символов: кириллица, эмодзи, иероглифы;
код символа — число символа в таблице (`'a'` → 97);
лексикографическое сравнение — посимвольное слева направо по кодам, как слова в словаре
