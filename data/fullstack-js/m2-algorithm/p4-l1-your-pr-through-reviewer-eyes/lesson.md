# Твой PR глазами ревьюера

**Краткое содержание:**
До того как ревьюеры откроют твой кодовый PR — посмотри на него сам их глазами: diff, описание, коммиты. Чек-лист самопроверки и самостоятельные правки.

**Время:** ~15 мин

**Основные темы:**
1. Взгляд со стороны: что видит ревьюер
2. Чек-лист самопроверки

**Термины:**
самопроверка — по англ. `self-review`: ревью своего PR до отправки другим;
мёртвый код — код, который никогда не выполнится;
отладочный вывод — забытые `console.log` из процесса отладки
