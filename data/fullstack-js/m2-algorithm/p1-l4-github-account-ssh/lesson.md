# GitHub: аккаунт и SSH

**Краткое содержание:**
Знакомство с GitHub, регистрация аккаунта, генерация SSH-ключа, добавление публичного ключа, проверка соединения.

**Время:** ~15 мин

**Основные темы:**
1. GitHub и зачем он нужен, если есть локальный Git
2. SSH-ключи: приватный и публичный
3. Проверка соединения с GitHub

**Термины:**
GitHub — платформа-хостинг для git-репозиториев: бэкап, портфолио, ревью;
remote — по англ. «удалённый»: репозиторий, который лежит не у тебя, а на сервере (на GitHub);
SSH — протокол безопасного подключения к серверам;
SSH-ключ — пара файлов вместо пароля: приватный (только у тебя) и публичный (его можно показывать)
