# Функция isEqual() — краткая выжимка

- `isEqual(a, b)` → `boolean`: посимвольное равенство строк
- TDD-цикл полностью самостоятельно: заглушка → тест → RED → GREEN → тесты по одному
- Ключевые случаи: равные строки, обе пустые, разная длина, пробелы (`'hi'` vs `'hi '`, `' a'` vs `'a'`), кириллица
- Исключения: `TypeError` если любой аргумент не строка
- Коммит: «Реализована isEqual — посимвольное сравнение строк»
