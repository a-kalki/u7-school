# Функция fromCSV(csvString)

**Краткое содержание:**
Четвёртая бизнес-утилита — парсинг CSV-строки обратно в массив объектов. Это самая сложная функция модуля: нужно корректно обрабатывать экранированные запятые, кавычки и переносы строк. Реализуется через посимвольный обход с отслеживанием состояния (внутри кавычек или снаружи).

### 1. Задача парсинга CSV

Вход: CSV-строка с заголовками и данными.
Выход: массив объектов.

```
name,age,city
Анна,25,Москва
Борис,30,"Санкт-Петербург"
```

→

```javascript
[
  { name: 'Анна', age: '25', city: 'Москва' },
  { name: 'Борис', age: '30', city: 'Санкт-Петербург' },
]
```

Сложность в том, что запятая может быть как разделителем полей, так и частью значения в кавычках.

### 2. Алгоритм: конечный автомат

В отличие от `parseUrl` или `getQueryParams`, здесь нельзя просто найти разделитель через `indexOf` и отрезать через `slice`. Запятая может быть как разделителем полей, так и частью значения в кавычках. Один и тот же символ играет две разные роли в зависимости от контекста.

Решение — **конечный автомат** (finite state machine): посимвольный обход строки с флагом `inQuotes`, который отслеживает, находимся ли мы внутри экранированного значения. Если не знаком с концепцией — рекомендую статью [Конечные автоматы в программировании для начинающих](https://tproger.ru/translations/finite-state-machines-for-beginners/) (простые примеры на JS).

#### Состояния и переходы

У автомата два состояния:

| Состояние | Что значит | Какие символы ждём |
|-----------|------------|-------------------|
| `inQuotes = false` | Мы **снаружи** кавычек. Сейчас ожидаем разделители полей/строк | `"` — войти внутрь, `,` — конец поля, `\n` — конец строки, остальное — символ значения |
| `inQuotes = true` | Мы **внутри** кавычек. Всё что угодно (включая запятые и `\n`) — часть значения | `"` — возможно выход (если следующая не `"`), `""` — экранированная кавычка, остальное — символ значения |

Графически:
```
           ┌──────────────────────────────────┐
           │         inQuotes = false         │
           │                                  │
           │  '"' → inQuotes = true          │
           │  ',' → завершить поле            │
           │  '\n' → завершить строку         │
           │  иначе → добавить в поле         │
           └───────────┬──────────────────────┘
                       │ '"'
                       ▼
           ┌──────────────────────────────────┐
           │         inQuotes = true          │
           │                                  │
           │  '"' и дальше '"' → добавить '"' │
           │  '"' и дальше НЕ '"' → выход    │
           │  иначе → добавить в поле         │
           └──────────────────────────────────┘
```

#### Пошаговый разбор на примере

Возьмём строку: `name,city\n"Анна, Борис",Москва`

```
i  ch    inQuotes  currentField    действие
───────────────────────────────────────────────
0  'n'   false     'n'             символ значения
1  'a'   false     'na'            символ значения
2  'm'   false     'nam'           символ значения
3  'e'   false     'name'          символ значения
4  ','   false     → завершить     push 'name', сброс currentField
5  'c'   false     'c'             символ значения
6  'i'   false     'ci'            символ значения
7  't'   false     'cit'           символ значения
8  'y'   false     'city'          символ значения
9  '\n'  false     → завершить     push 'city', push всей строки, сброс
10 '"'   false     → войти         inQuotes = true
11 'А'   true      'А'             символ значения (мы внутри!)
12 'н'   true      'Ан'            символ значения
...
17 ','   true      'Анна, '        символ значения (НЕ разделитель!)
...
22 '"'   true      → выход         следующая не '"' → inQuotes = false
23 ','   false     → завершить     push 'Анна, Борис', сброс
24 'М'   false     'М'             символ значения
...
29 'а'   false     'Москва'        конец строки (нет '\n' в конце)
→ финал: завершить последнее поле и строку
```

Результат: `rows = [['name', 'city'], ['Анна, Борис', 'Москва']]`, затем преобразуем в `[{ name: 'Анна, Борис', city: 'Москва' }]`.

Ключевое: на позиции 17 запятая внутри `'Анна, Борис'` НЕ стала разделителем — потому что `inQuotes = true`.

```javascript
function fromCSV(csvString) {
  if (typeof csvString !== 'string') throw new TypeError('Ожидается строка');
  if (csvString === '') return [];

  const rows = [];
  let currentRow = [];
  let currentField = '';
  let inQuotes = false;

  for (let i = 0; i < len(csvString); i++) {
    const ch = csvString[i];

    if (inQuotes) {
      if (ch === '"') {
        // Кавычка внутри экранированного поля
        if (i + 1 < len(csvString) && csvString[i + 1] === '"') {
          // Удвоенная кавычка → одна кавычка в значении
          currentField += '"';
          i++; // пропускаем вторую кавычку
        } else {
          // Закрывающая кавычка
          inQuotes = false;
        }
      } else {
        currentField += ch;
      }
    } else {
      if (ch === '"') {
        // Начало экранированного поля
        inQuotes = true;
      } else if (ch === ',') {
        // Разделитель полей
        push(currentRow, currentField);
        currentField = '';
      } else if (ch === '\n') {
        // Разделитель строк
        push(currentRow, currentField);
        push(rows, currentRow);
        currentRow = [];
        currentField = '';
      } else {
        currentField += ch;
      }
    }
  }

  // Последнее поле и последняя строка
  push(currentRow, currentField);
  if (len(currentRow) > 0) {
    push(rows, currentRow);
  }

  // Преобразуем в объекты
  if (len(rows) === 0) return [];

  const headers = rows[0];
  const result = [];

  for (let i = 1; i < len(rows); i++) {
    const obj = {};
    for (let j = 0; j < len(headers); j++) {
      obj[headers[j]] = j < len(rows[i]) ? rows[i][j] : '';
    }
    push(result, obj);
  }

  return result;
}
```

### 3. Ключевые моменты

**Удвоенные кавычки внутри поля:** когда мы внутри кавычек и видим `"`, нужно проверить следующий символ. Если там тоже `"` — это экранированная кавычка (добавляем одну `"` в значение). Если нет — это закрывающая кавычка.

**Запятая внутри кавычек:** когда `inQuotes === true`, запятая — просто символ значения, не разделитель.

**Перенос строки внутри кавычек:** когда `inQuotes === true`, `\n` — часть значения (хотя на практике это редкость, но стандарт CSV разрешает).

### 4. Граничные случаи

- `fromCSV('')` → `[]`
- `fromCSV('a\n1')` → `[{ a: '1' }]`
- `fromCSV('name\n"Анна, Борис"')` → `[{ name: 'Анна, Борис' }]`
- `fromCSV('name\n"say ""hi"""')` → `[{ name: 'say "hi"' }]`
- `fromCSV(123)` → `TypeError`

**Round-trip тесты** — проверка, что `fromCSV(toCSV(data))` восстанавливает исходные данные:

Простой случай:
```
data:    [{ a: '1', b: '2' }, { a: '3', b: '4' }]
toCSV:   "a,b\n1,2\n3,4\n"
fromCSV: [{ a: '1', b: '2' }, { a: '3', b: '4' }]  ✓
```

С запятыми в данных:
```
data:    [{ name: 'Анна, Борис', city: 'Москва' }, { name: 'Вера', city: 'Питер' }]
toCSV:   "name,city\n\"Анна, Борис\",Москва\nВера,Питер\n"
fromCSV: [{ name: 'Анна, Борис', city: 'Москва' }, { name: 'Вера', city: 'Питер' }]  ✓
```

С кавычками в данных:
```
data:    [{ text: 'say "hi"' }, { text: 'say "bye"' }]
toCSV:   "text\n\"say ""hi""\"\n\"say ""bye""\"\n"
fromCSV: [{ text: 'say "hi"' }, { text: 'say "bye"' }]  ✓
```

Все спецсимволы сразу (запятая И кавычки в одном значении):
```
data:    [{ msg: 'Привет, мир!', author: 'Я сказал: "Пока!"' }]
toCSV:   "msg,author\n\"Привет, мир!\",\"Я сказал: ""Пока!""\"\n"
fromCSV: [{ msg: 'Привет, мир!', author: 'Я сказал: "Пока!"' }]  ✓
```

Этот последний случай — главный стресс-тест: нужно убедиться, что запятая внутри кавычек не разбивает поле, а удвоенные кавычки корректно восстанавливаются в одиночные.

### 5. Какие свои функции используем

- `len` — длина строки и массивов
- `push` — накопление полей и строк
