# Шаги урока: Функция fromCSV(csvString)

---

### Почему здесь не работают indexOf и slice

**kind:** `text`

В `parseUrl` и `getQueryParams` ты искал разделители через `indexOf` и отрезал подстроки через `slice`. С CSV такой подход не работает. Подумай почему:

```
name,city
"Анна, Борис",Москва
```

Здесь запятая после `Анна` — это НЕ разделитель полей, а часть значения. Но запятая после `Борис"` — разделитель. Один и тот же символ `,` играет две разные роли. Какая именно — зависит от того, находимся ли мы внутри кавычек.

Вывод: нужно читать строку **посимвольно** и отслеживать контекст — внутри мы кавычек или снаружи.

---

### Конечный автомат: два состояния

**kind:** `text`

Алгоритм `fromCSV` — это **конечный автомат** (finite state machine). Конечный автомат — это модель, у которой есть набор состояний и правила перехода между ними. В каждый момент времени автомат находится ровно в ОДНОМ состоянии. Входной символ определяет: остаться в текущем состоянии или перейти в другое, и какое действие выполнить.

Это общая концепция, которая встречается в программировании повсюду: парсинг форматов (CSV, JSON, URL), обработка сетевых протоколов (TCP), проверка ввода (валидация форм), регулярные выражения, искусственный интеллект (поведение NPC в играх). Рекомендую прочитать введение в тему: **[Понятие о конечных автоматах](https://habr.com/ru/companies/piter/articles/1039106/)**.

Наш автомат для CSV имеет два состояния. Представь, что ты читаешь строку символ за символом и держишь в уме ответ на вопрос «я внутри кавычек?».

**Состояние 1: СНАРУЖИ кавычек (`inQuotes = false`)**

Мы ожидаем обычные символы значений и разделители:

| Символ | Действие |
|--------|----------|
| `"` | Войти ВНУТРЬ кавычек: `inQuotes = true` |
| `,` | Завершить текущее поле, начать новое |
| `\n` | Завершить поле, завершить строку, начать новую строку |
| любой другой | Добавить символ к текущему полю |

**Состояние 2: ВНУТРИ кавычек (`inQuotes = true`)**

Всё что угодно — часть значения. Даже запятые и переносы строк:

| Символ | Действие |
|--------|----------|
| `"` и следующий тоже `"` | Это экранированная кавычка: добавить ОДНУ `"` в поле, пропустить второй символ |
| `"` и следующий НЕ `"` | Это закрывающая кавычка: выйти НАРУЖУ (`inQuotes = false`) |
| любой другой | Добавить символ к текущему полю |

Графически переходы между состояниями:

```
           ┌──────────────────────────────────┐
           │         СНАРУЖИ (false)          │
           │                                  │
           │  '"' → войти внутрь             │
           │  ',' → завершить поле            │
           │  '\n' → завершить строку         │
           │  иначе → добавить в поле         │
           └───────────┬──────────────────────┘
                       │ '"'
                       ▼
           ┌──────────────────────────────────┐
           │         ВНУТРИ (true)            │
           │                                  │
           │  '"' и дальше '"' → добавить '"' │
           │  '"' и дальше НЕ '"' → выйти    │
           │  иначе → добавить в поле         │
           └──────────────────────────────────┘
```

### Трассировка на примере

**kind:** `text`

Возьми строку `name,city\n"Анна, Борис",Москва` и пройди по ней мысленно. Для каждого символа отслеживай `inQuotes`, `currentField` и действие:

```
i  ch    inQuotes  currentField    действие
───────────────────────────────────────────────
0  'n'   false     'n'             символ значения
1  'a'   false     'na'            символ значения
2  'm'   false     'nam'           символ значения
3  'e'   false     'name'          символ значения
4  ','   false     → завершить     push 'name', сброс currentField
5  'c'   false     'c'             символ значения
6  'i'   false     'ci'            символ значения
7  't'   false     'cit'           символ значения
8  'y'   false     'city'          символ значения
9  '\n'  false     → завершить     push 'city', push всей строки, сброс
10 '"'   false     → войти         inQuotes = true
11 'А'   true      'А'             символ значения (мы внутри!)
12 'н'   true      'Ан'            символ значения
...
17 ','   true      'Анна, '        символ значения (НЕ разделитель!)
...
22 '"'   true      → выход         следующая не '"' → inQuotes = false
23 ','   false     → завершить     push 'Анна, Борис', сброс
24 'М'   false     'М'             символ значения
...
29 'а'   false     'Москва'        конец строки
→ финал: завершить последнее поле и строку
```

Обрати внимание на позицию **17**: запятая внутри `'Анна, Борис'` НЕ стала разделителем — потому что `inQuotes = true`. В этом вся суть конечного автомата.

После обхода получим `rows = [['name', 'city'], ['Анна, Борис', 'Москва']]`. Затем первая строка становится заголовками, остальные — данными: `[{ name: 'Анна, Борис', city: 'Москва' }]`.

### Реализация fromCSV()

**kind:** `text`

> Убедись, что ты в ветке `feat/business-utils`.

Реализуй функцию `fromCSV(csvString)` — парсинг CSV-строки обратно в массив объектов. Создай файлы `utils/from-csv.js` и `utils/from-csv.test.js`, следуй TDD.

Это самая сложная функция модуля. Она должна быть обратной к `toCSV`: `fromCSV(toCSV(data))` должно возвращать данные, эквивалентные исходным.

**Функция принимает:**
- `csvString`: `string` — CSV-строка (первая строка — заголовки)

**Функция возвращает:** `array` — массив объектов

**Важно:** функция **иммутабельная**. Используй посимвольный обход с отслеживанием состояния (флаг `inQuotes`).

Краткий алгоритм (конечный автомат):
1. Инициализировать: `rows = []`, `currentRow = []`, `currentField = ''`, `inQuotes = false`.
2. Обойти строку посимвольно:
   - Если `inQuotes`:
     - `"` и следующий символ тоже `"` → добавить `"` в поле, пропустить второй
     - `"` и следующий не `"` → `inQuotes = false` (закрытие)
     - Остальное → добавить в поле
   - Если не `inQuotes`:
     - `"` → `inQuotes = true`
     - `,` → завершить поле, начать новое
     - `\n` → завершить поле, завершить строку, начать новую
     - Остальное → добавить в поле
3. После цикла: завершить последнее поле и строку.
4. Первая строка `rows[0]` — заголовки, остальные — данные.
5. Собрать массив объектов: для каждой строки данных создать объект с ключами-заголовками.

**Важно:** функция **иммутабельная**. Используй посимвольный обход с отслеживанием состояния (флаг `inQuotes`).

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть пустой массив для пустой строки: `fromCSV('')` → `[]`
- Должна разобрать простой CSV: `fromCSV('a,b\n1,2')` → `[{ a: '1', b: '2' }]`
- Должна разобрать несколько строк: `fromCSV('name,age\nАнна,25\nБорис,30')` → `[{ name: 'Анна', age: 25 }, { name: 'Борис', age: 30 }]`
- Должна обработать экранированную запятую: `fromCSV('name\n"Анна, Борис"')` → `[{ name: 'Анна, Борис' }]`
- Должна обработать экранированные кавычки: `fromCSV('name\n"say ""hi"""')` → `[{ name: 'say "hi"' }]`
- Должна быть обратной к `toCSV` (простой случай): `fromCSV(toCSV([{ a: '1', b: '2' }, { a: '3', b: '4' }]))` → `[{ a: '1', b: '2' }, { a: '3', b: '4' }]`
- Должна выполнить round-trip с запятыми в данных:
  ```
  const data = [{ name: 'Анна, Борис', city: 'Москва' }, { name: 'Вера', city: 'Питер' }];
  fromCSV(toCSV(data)) → [{ name: 'Анна, Борис', city: 'Москва' }, { name: 'Вера', city: 'Питер' }]
  ```
  (проверь, что запятая внутри `'Анна, Борис'` не разбила значение на два поля)
- Должна выполнить round-trip с кавычками в данных:
  ```
  const data = [{ text: 'say "hi"' }, { text: 'say "bye"' }];
  fromCSV(toCSV(data)) → [{ text: 'say "hi"' }, { text: 'say "bye"' }]
  ```
  (проверь, что удвоение кавычек в CSV корректно обратилось обратно в одиночные)
- Должна выполнить round-trip со всеми спецсимволами сразу:
  ```
  const data = [{ msg: 'Привет, мир!', author: 'Я сказал: "Пока!"' }];
  fromCSV(toCSV(data)) → [{ msg: 'Привет, мир!', author: 'Я сказал: "Пока!"' }]
  ```
  (запятая И кавычки в ОДНОМ значении — главный стресс-тест)
- Должна выбросить `TypeError` если аргумент не строка
