# fromCSV(csvString) — краткая выжимка

- Парсит CSV-строку обратно в массив объектов (обратна к `toCSV`)
- Посимвольный обход с флагом `inQuotes` (конечный автомат)
- Внутри кавычек: `""` → `"`, запятая — не разделитель
- Снаружи кавычек: `,` → новое поле, `\n` → новая строка
- Первая строка — заголовки, остальные — данные
- Пустая строка → `[]`
- Round-trip: `fromCSV(toCSV(data))` должен восстановить исходные данные
- Использует свои: `len`, `push`
- **Иммутабельная** — не меняет исходную строку
- JSDoc обязателен, отметь round-trip совместимость с `toCSV`
