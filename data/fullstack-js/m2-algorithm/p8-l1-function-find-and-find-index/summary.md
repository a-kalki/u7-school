# find(arr, callback) и findIndex(arr, callback) — краткая выжимка

- `find` — ищет первый элемент, удовлетворяющий callback; не найден → `undefined`
- `findIndex` — ищет индекс первого подходящего элемента; не найден → `-1`
- Обе с **ранним выходом** — обход останавливается при первом `true`
- Callback получает `(элемент, индекс, массив)`
- **Иммутабельные** — исходный массив не меняется
- Пустой массив: `find` → `undefined`, `findIndex` → `-1`
- Проверка типов: `arr` — массив, `callback` — функция
- JSDoc обязателен, отметь иммутабельность и ранний выход
