# getQueryParams(url) — краткая выжимка

- Разбирает query-строку URL в объект параметров
- Находит `?` через `indexOf`, берёт подстроку после через `slice`
- Разбивает по `&` → пары, по `=` → ключ и значение
- Использует `decodeURIComponent` для декодирования URL-кодирования (разрешённая глобальная функция)
- Использует свои: `indexOf`, `slice`, `len`
- Нет `?` → `{}`
- Параметр без значения → пустая строка
- **Иммутабельная** — не меняет исходную строку
- JSDoc обязателен, отметь использование `decodeURIComponent`
