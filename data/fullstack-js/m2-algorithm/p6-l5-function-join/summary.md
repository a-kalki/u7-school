# join(arr, separator) — краткая выжимка

- Склеивает элементы массива в строку через разделитель
- Разделитель по умолчанию — запятая `','`
- Пустой массив → `''`
- Один элемент → строка элемента без разделителя
- **Иммутабельная** — массив не меняется
- JSDoc обязателен, отметь иммутабельность
