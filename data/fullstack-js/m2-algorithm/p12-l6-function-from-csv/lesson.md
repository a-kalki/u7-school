# Функция fromCSV(csvString)

**Краткое содержание:**
Пятая бизнес-утилита — десериализация нашего формата обратно в массив объектов с восстановлением типов. Студент читает текст конечным автоматом (флаг `inString`), отделяет ячейки от разделителей и разбирает каждую ячейку по правилам нотации JSON: строка, число, boolean, `null` или `undefined` — без `JSON.parse`. Снимает экранирование, возвращая перенос строки из формата на диске (Мир 2) обратно в реальный символ в памяти (Мир 1).

**Время:** ~25 мин

**Основные темы:**
- Почему не подходят split и indexOf
- Конечный автомат: паттерн и два состояния
- Трассировка на примере
- Как читать значение
- Архитектура решения
- Реализация fromCSV()
- Вопросы на понимание
- Сохрани изменения
- Закрепление: round-trip с типами
- Термины урока

**Термины:**
* **Десериализация** — превращение текста обратно в значение.
* **Конечный автомат (FSM)** — модель разбора строки: набор состояний и правила перехода между ними по входным символам.
* **Состояние** — текущий режим автомата; у нас их два: «снаружи строки» и «внутри строки».
* **Флаг `inString`** — переменная, которая хранит текущее состояние автомата.
* **Переход** — смена состояния по входному символу (например, `"` снаружи → войти внутрь).
* **Снятие экранирования** — обратная операция: `\"` → `"`, `\\` → `\`, `\n` → перенос строки.
* **CRLF** — перенос строки в Windows-файлах: `\r\n`. `fromCSV` пропускает `\r` вне строки, поэтому такой файл читается наравне с LF.
* **Round-trip** — обратимость: `fromCSV(toCSV(data))` восстанавливает данные и их типы.
* **Ключ (заголовок)** — имя колонки (первая строка), читается как обычный текст без кавычек.
* **Примитив** — простое значение (строка, число, boolean, `null`, `undefined`), в отличие от объекта или массива.
* **Иммутабельность** — свойство функции не менять входные данные, а возвращать новый результат.

### Алгоритм

Два этапа, обратных `toCSV`: сначала разбить текст на ячейки, затем прочитать значение каждой ячейки.

1. Проверить, что аргумент — строка. Пустая строка → `[]`.
2. Пройти строку посимвольно с флагом `inString`: `,` и `\n` вне строки — разделители, внутри строки — обычные символы. `\r` вне строки (перевод каретки из Windows-файлов, CRLF) — пропускаем.
3. Первая строка `rows[0]` — ключи.
4. Каждую ячейку данных прочитать функцией `deserializeValue`: пусто → `undefined`, `null` → `null`, `true`/`false` → boolean, `"..."` → строка (снять экранирование), иначе число.
5. Собрать массив объектов.

```javascript
function deserializeValue(cell) {
  if (cell === '') return undefined;
  if (cell === 'null') return null;
  if (cell === 'true') return true;
  if (cell === 'false') return false;
  if (cell[0] !== '"') return Number(cell);

  let result = '';
  for (let i = 1; i < len(cell) - 1; i++) {
    const ch = cell[i];
    if (ch === '\\') {
      i++;
      const next = cell[i];
      if (next === 'n') result += '\n';
      else if (next === 'r') result += '\r';
      else if (next === 't') result += '\t';
      else result += next;
    } else {
      result += ch;
    }
  }
  return result;
}

function fromCSV(text) {
  if (typeof text !== 'string') throw new TypeError('Ожидается строка');
  if (text === '') return [];

  const rows = [];
  let row = [];
  let field = '';
  let inString = false;

  for (let i = 0; i < len(text); i++) {
    const ch = text[i];
    if (inString) {
      if (ch === '\\') {
        field += ch;
        i++;
        if (i < len(text)) field += text[i];
      } else if (ch === '"') {
        field += ch;
        inString = false;
      } else {
        field += ch;
      }
    } else if (ch === '"') {
      field += ch;
      inString = true;
    } else if (ch === ',') {
      push(row, field);
      field = '';
    } else if (ch === '\n') {
      push(row, field);
      push(rows, row);
      row = [];
      field = '';
    } else if (ch === '\r') {
      // перевод каретки (CRLF) — пропускаем, строку завершит '\n'
    } else {
      field += ch;
    }
  }

  if (field !== '' || len(row) > 0) {
    push(row, field);
    push(rows, row);
  }

  if (len(rows) === 0) return [];

  const headers = rows[0];
  const result = [];
  for (let i = 1; i < len(rows); i++) {
    const obj = {};
    for (let j = 0; j < len(headers); j++) {
      const cell = j < len(rows[i]) ? rows[i][j] : '';
      obj[headers[j]] = deserializeValue(cell);
    }
    push(result, obj);
  }
  return result;
}
```

### Что важно

- Внутри `"..."` символы `,` и `\n` — часть значения, а не разделители; поэтому `"Anna, Boris"` — одна ячейка.
- Строки разделяются **реальным** переносом `\n` (LF, код 10) — одним символом. А перенос **внутри значения** записан парой `\` + `n` (два символа) и раскрывается только в `deserializeValue`.
- Файлы из Windows используют CRLF (`\r\n`). `fromCSV` пропускает `\r` вне строки, поэтому такой файл читается так же, как LF-файл. При этом `\r` внутри значения по-прежнему хранится как `\r`.
- Экранирование снимается на этапе чтения значения: `\"` → `"`, `\\` → `\`, `\n` → перенос, `\r` → возврат каретки, `\t` → табуляция.
- Пустая ячейка → `undefined`; `""` → пустая строка. Это разные значения, и они различимы.
- Главная проверка — **round-trip**: `fromCSV(toCSV(data))` возвращает данные с теми же типами.
