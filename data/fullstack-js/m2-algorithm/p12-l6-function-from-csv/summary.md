# fromCSV(text) — краткая выжимка

- Парсит наш формат обратно в массив объектов (обратна к `toCSV`)
- **Конечный автомат** (FSM) — паттерн разбора: набор состояний + правила перехода
- Два состояния: снаружи `inString = false` / внутри строки `inString = true`
- Снаружи: `"` → войти, `,` → новая ячейка, `\n` → новая строка, иначе → в поле
- Внутри: `\` экранирует следующий символ, `"` → выйти, иначе → в поле
- Поэтому `"Anna, Boris"` — одно значение, запятая не разделяет колонки
- Чтение значения — `deserializeValue(cell)`, порядок проверок:
  - `''` → `undefined`; `'null'` → `null`; `'true'`/`'false'` → boolean; иначе `Number(cell)`; `"..."` → строка
- Снятие экранирования: `\"` → `"`, `\\` → `\`, `\n` → перенос, `\r`, `\t`
- Пустая ячейка (`undefined`) и `""` (пустая строка) — разные значения
- Первая строка — ключи, читаются как обычный текст
- Пустой текст → `[]`
- **Round-trip** `fromCSV(toCSV(data))` сохраняет типы — главная проверка
- **Иммутабельная**; `JSON.parse` не используем — пишем десериализацию сами
- JSDoc обязателен, отметь автомат и восстановление типов
