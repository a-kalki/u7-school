# Markdown за 10 минут

**Краткое содержание:**
Что такое markdown и где он встречается в работе разработчика, базовый синтаксис с практикой в VS Code, домашнее задание — официальная шпаргалка GitHub.

**Время:** ~15 мин (+ ДЗ)

**Основные темы:**
1. Что такое `.md` и где используется
2. Заголовки, жирный/курсив, списки, ссылки, чекбоксы, код
3. Предпросмотр в VS Code
4. ДЗ: шпаргалка GitHub

**Термины:**
markdown — простой язык разметки текста обычными символами;
разметка — пометки в тексте, которые описывают его оформление;
рендеринг — превращение разметки в красивую страницу (это делает GitHub или редактор);
предпросмотр — по англ. `preview`: показ результата рендеринга до публикации
