# Бинарный поиск — краткая выжимка

- **Идея:** на каждом шаге отбрасываем половину оставшегося диапазона (как поиск слова в словаре)
- **Требование:** массив должен быть отсортирован по возрастанию
- **Сложность:** ~log₂n шагов — O(log n). Для 1 000 000 элементов — ~20 шагов
- **Сравнение с перебором:** `indexOf` — O(n), `binarySearch` — O(log n)
- **Когда сортировать:** один поиск → просто перебор O(n); много поисков → один раз отсортировать O(n log n), дальше каждый поиск O(log n)
- **Результат:** индекс найденного элемента или `-1`
