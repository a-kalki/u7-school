# Ревью-цикл, финальный мерж и ретро — краткая выжимка

- Ревью-цикл по накатанной: раздели замечания → fix-коммиты → ответы + Resolve → re-request 🔄 → 2 апрува → мерж

- Мерж: GitHub Merge commit → Delete branch; локально: switch main → pull → branch -d → fetch --prune
- Ретро: пять полных циклов; мутабельность как контракт; промежуточные коммиты; reverse строки vs массива
- Веха: П8 — последний «по потоку»; дальше — формат заданий и напоминаний
