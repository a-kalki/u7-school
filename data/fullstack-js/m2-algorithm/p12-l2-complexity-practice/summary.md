# Тренировка сложности — краткая выжимка

- **sum** — O(n), **hasDuplicates** — O(n²), **allPairs** — O(n×m), **factorial** — O(n), **binarySearch** — O(log n)
- Твои сортировки: **bubbleSort** — O(n²), **quickSort** — O(n log n) в среднем (O(n²) в худшем), **insertionSort** — O(n) на отсортированном
- Вложенный цикл → перемножаем: O(n×m). Два последовательных → всё ещё O(n)
- Рекурсия с уменьшением на 1 → O(n). Рекурсия с делением пополам → O(log n). Деление + обработка всех элементов → O(n log n)
- Константы отбрасываются: O(2n) = O(n), O(n²/2) = O(n²)
- На малых N константа может перевешивать, на больших — порядок роста решает всё
- Ошибка в `indexOf`: не O(n), а O(n×m) — внутри цикла ещё цикл
