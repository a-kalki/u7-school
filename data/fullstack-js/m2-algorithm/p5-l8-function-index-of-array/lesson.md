# Функция indexOf(arr, item) — поиск элемента в массиве

**Краткое содержание:**
`indexOf(arr, item)` ищет элемент в массиве и возвращает индекс его первого вхождения. Если элемент не найден — `-1`. Не мутирует массив.

### Алгоритм

1. Проверить, что `arr` — массив. Иначе `throw new TypeError`
2. `const length = len(arr)`
3. Идти циклом `for (let i = 0; i < length; i++)`:
   - если `arr[i] === item` — вернуть `i`
4. Вернуть `-1`

### Сравнение через `===`

Для примитивов (числа, строки, булевы) `===` сравнивает по значению: `5 === 5` → `true`. Для объектов и массивов `===` сравнивает по ссылке: два разных объекта с одинаковым содержимым не равны.

```javascript
indexOf([1, 2, 3], 2);        // 1 — число нашлось
indexOf([{a: 1}], {a: 1});    // -1 — это ДРУГОЙ объект, ссылка не та
```
