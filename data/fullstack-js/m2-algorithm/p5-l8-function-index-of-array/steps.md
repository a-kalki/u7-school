# Шаги урока: Функция indexOf(arr, item) — поиск элемента

---

### Реализация indexOf()

**kind:** `text`

Реализуй функцию `indexOf(arr, item)` — поиск первого вхождения элемента. Создай файлы `arrays/index-of.js` и `arrays/index-of.test.js`.

**Функция принимает:**
- `arr`: `array` — массив для поиска
- `item`: `any` — искомый элемент

**Функция возвращает:** `number` — индекс первого вхождения, либо `-1` если не найден.

**Подсказка:** используй операторы сравнения и равенства, не надо "узнавать" тип данных и если это строка, то использовать строковые функции.

Тестовые случаи:
- Должна найти элемент в середине: `indexOf([10, 20, 30], 20)` → `1`
- Должна найти первый элемент: `indexOf([10, 20, 30], 10)` → `0`
- Должна найти последний элемент: `indexOf([10, 20, 30], 30)` → `2`
- Должна вернуть `-1` если элемента нет: `indexOf([10, 20, 30], 99)` → `-1`
- Должна вернуть индекс **первого** вхождения при дубликатах: `indexOf([1, 2, 1, 3], 1)` → `0`
- Должна вернуть `-1` для пустого массива: `indexOf([], 1)` → `-1`
- Должна найти строку по значению: `indexOf(['a', 'b', 'c'], 'b')` → `1`
- Должна корректно работать с массивом строк: `indexOf(['abc', 'def', 'xyz'], 'def')` → `1`
- Должна найти `0` (не спутать с `false`): `indexOf([0, false], 0)` → `0`, `indexOf([0, false], false)` → `1`
- Должна найти `false`: `indexOf([true, false], false)` → `1`
- Должна не мутировать исходный массив
- Должна выбросить `TypeError` если `arr` не массив
