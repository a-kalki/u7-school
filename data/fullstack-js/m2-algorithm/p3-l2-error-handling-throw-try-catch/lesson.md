# Обработка ошибок: throw и try-catch

**Краткое содержание:**
Зачем функциям сообщать о неправильном использовании; оператор `throw` и типы ошибок; перехват через `try-catch`; практика: предсказать вывод; `repeat()` с проверками.

**Время:** ~25 мин

**Основные темы:**
1. Проблема «тихо неверного» поведения
2. `throw`, TypeError / RangeError / Error
3. `try-catch` и свойства ошибки
4. Практика и мини-задание

**Термины:**
исключение — по англ. `exception`: ошибка, которую функция «выбрасывает» при неправильном использовании;
`throw` — оператор выброса исключения;
`try-catch` — конструкция перехвата и обработки исключений;
валидация — проверка аргументов на корректность до основной работы функции
