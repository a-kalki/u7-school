# Обработка ошибок: throw и try-catch — краткая выжимка

- «Тихо неверный» результат опаснее падения: ошибка всплывает через 10 шагов
- `throw` — выбросить исключение, код после него не выполняется
- Типы: `TypeError` (тип аргумента), `RangeError` (диапазон), `Error` (универсальный)
- `try-catch` — перехват: catch ловит **первую** ошибку и прекращает try
- Свойства: `error.name`, `error.message`, `error.stack`; `instanceof` различает типы
- Все функции проекта валидируют аргументы через throw — тесты будут это проверять
- Мини-задание: `repeat(text, count)` с тремя проверками
