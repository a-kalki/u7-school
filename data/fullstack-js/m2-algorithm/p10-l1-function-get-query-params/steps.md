### Query-строка — разбираемся с форматом

**kind:** `text`

Query-строка — это часть URL после знака `?`. Она содержит параметры в формате `ключ=значение`, разделённые символом `&`:

```
?q=javascript&page=2&sort=asc
```

Разбери этот формат мысленно:
- Разделитель `&` разбивает строку на пары
- Разделитель `=` разбивает каждую пару на ключ и значение
- Значения могут быть пустыми: `?key` → ключ есть, значения нет
- Некоторые символы кодируются: `%20` = пробел, `%D0%9F` = кириллица

Для декодирования URL-кодирования используй встроенную `decodeURIComponent` — это разрешено (это глобальная функция, не метод строки/массива).

### Реализация getQueryParams()

**kind:** `text**

Реализуй функцию `getQueryParams(url)` — разбор query-строки URL в объект. Создай файлы `utils/get-query-params.js` и `utils/get-query-params.test.js`, следуй TDD.

**Функция принимает:**
- `url`: `string` — полный URL или только query-строка

**Функция возвращает:** `object` — объект с параметрами: ключи — имена параметров, значения — строковые значения (декодированные)

**Важно:** функция **иммутабельная**. Используй свои `indexOf`, `slice`, `len` для разбора строки. Для декодирования используй `decodeURIComponent`.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть пустой объект если нет `?`: `getQueryParams('https://example.com/page')` → `{}`
- Должна вернуть пустой объект если `?` в конце: `getQueryParams('https://example.com?')` → `{}`
- Должна разобрать один параметр: `getQueryParams('https://example.com?a=1')` → `{ a: '1' }`
- Должна разобрать несколько параметров: `getQueryParams('https://example.com?a=1&b=2&c=3')` → `{ a: '1', b: '2', c: '3' }`
- Должна обработать параметр без значения: `getQueryParams('https://example.com?key')` → `{ key: '' }`
- Должна обработать несколько параметров, один без значения: `getQueryParams('https://example.com?a=1&b')` → `{ a: '1', b: '' }`
- Должна декодировать URL-кодирование: `getQueryParams('https://example.com?name=%D0%90%D0%BD%D0%BD%D0%B0')` → `{ name: 'Анна' }`
- Должна декодировать пробелы: `getQueryParams('https://example.com?q=hello%20world')` → `{ q: 'hello world' }`
- Должна работать с query-строкой без URL: `getQueryParams('a=1&b=2')` → `{ a: '1', b: '2' }`
- Должна выбросить `TypeError` если аргумент не строка
