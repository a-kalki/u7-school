# Функция trim(str) — краткая выжимка

- trim(str) — удаляет пробелы `' '` с начала и конца строки; пробелы внутри остаются
- Идея: найти первый непробельный символ слева и последний справа, взять срез между ними
- Краевые случаи: строка из одних пробелов → `''`, пустая строка → `''`, без пробелов → без изменений
- Только пробел `' '`: табы и переводы строк `\t`, `\n` не трогаем
- 11 тестов, включая TypeError на не-строку и null
