# Шаги урока: Финальный мерж homework-PR

---

### Финальная проверка

**kind:** `text`

Перед мержем убедись, что все условия выполнены:

- [ ] Получено 2 апрува (зелёные галочки рядом с именами ревьюеров)
- [ ] Все conversation помечены как resolved
- [ ] Нет незакрытых комментариев

Если чего-то не хватает — вернись к уроку 4 (доработка) или уроку 5 (эскалация) и доведи до конца.

**Термины:**
Merge commit — коммит слияния с двумя родителями (тип по умолчанию);
Delete branch — кнопка удаления ветки на GitHub после мержа;
`git fetch --prune` — очистка локальных записей об уже удалённых на GitHub ветках

---

### Мерж через интерфейс GitHub

**kind:** `text`

Выполни мерж PR:

1. Открой свой PR на GitHub
2. Нажми зелёную кнопку **Merge pull request**
3. Оставь тип слияния **Merge commit** (по умолчанию)
4. Нажми **Confirm merge**
5. После успешного мержа нажми **Delete branch** — удалить ветку на GitHub

Поздравляем: твой первый PR смержен. То, что было в ветке `docs/homework`, теперь часть `main`.

---

### Обновление локального main

**kind:** `text`

Подтяни изменения в локальный репозиторий:

```
git switch main
git pull origin main
```

Проверь, что коммиты из `docs/homework` теперь в `main`:

```
git log --oneline
```

---

### Очистка локальных веток

**kind:** `text`

Удали локальную рабочую ветку:

```
git branch -d docs/homework
```

Очисти информацию об удалённых ветках:

```
git fetch --prune
```

Проверь, что остались только нужные ветки:

```
git branch -a
```

---

### Осмысление итогов

**kind:** `text`

Ответь на вопросы (устно или в конспекте):

1. Ты прошёл полный цикл: ветка → файл → push → PR → сообщение в чат → ревью → апрувы → мерж. Что было самым сложным? Что оказалось проще, чем ты ожидал?
2. В чём разница между Merge commit, Squash and merge и Rebase and merge? Когда какой вариант уместен? (Непонятно — спроси ИИ-ассистента.)
3. После мержа ты удалил ветку на GitHub и локально. Можно ли её восстановить? Если да — как?
4. Приведи конкретный пример: какое предложение или замечание из ревью реально улучшило твой `homework.md`?

Если есть сложности с ответами — скопируй вопросы и задай их своему ИИ-ассистенту.
