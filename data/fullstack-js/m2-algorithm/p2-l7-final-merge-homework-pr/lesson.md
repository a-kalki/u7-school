# Финальный мерж homework-PR

**Краткое содержание:**
Проверка условий мержа, мерж homework-PR через интерфейс GitHub, обновление локального main и удаление рабочих веток.

**Время:** ~20 мин

**Основные темы:**
1. Условия мержа: 2 апрува и resolved
2. Merge pull request + удаление ветки на GitHub
3. `git pull` и чистка локальных веток

**Термины:**
Merge commit — коммит слияния с двумя родителями (тип по умолчанию);
Delete branch — кнопка удаления ветки на GitHub после мержа;
`git fetch --prune` — очистка локальных записей об уже удалённых на GitHub ветках
