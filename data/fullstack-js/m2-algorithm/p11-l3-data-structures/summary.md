# Структуры данных — краткая выжимка

- **Массив:** доступ O(1), вставка в начало O(n). Элементы в памяти подряд
- **Связанный список:** доступ O(n), вставка в начало O(1). Цепочка со ссылками
- **BST:** поиск O(log n) если сбалансировано, O(n) если вырождено. Дерево с правилом «слева меньше, справа больше»
- Нет одной лучшей структуры — есть компромиссы
- Выбор структуры зависит от того, какие операции делаешь чаще: читать, вставлять или искать
