# Шаги урока: Функция splice(arr, start, deleteCount, ...items) — удаление и вставка

---

### Реализация splice() — часть 1: удаление

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

`splice` — самая сложная функция в проекте 6. Разобьём на две части: сначала реализуй удаление, затем добавление.

**Часть 1: только удаление.** Реализуй `splice(arr, start, deleteCount)` без вставки новых элементов. Создай файлы `arrays/splice.js` и `arrays/splice.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)
- `start`: `number` — начальный индекс (поддержка отрицательных)
- `deleteCount`: `number` (необязательный) — сколько элементов удалить. Если не передан — удалить всё до конца

**Функция возвращает:** `array` — массив удалённых элементов.

Тестовые случаи для удаления (каждый — отдельный `test(...)`):
- Должна удалить элемент из середины: `splice([1, 2, 3, 4], 1, 2)` → вернуть `[2, 3]`, массив `[1, 4]`
- Должна удалить с начала: `splice([1, 2, 3], 0, 1)` → вернуть `[1]`, массив `[2, 3]`
- Должна удалить с конца: `splice([1, 2, 3], 2, 1)` → вернуть `[3]`, массив `[1, 2]`
- Должна удалить всё от start до конца если deleteCount не передан: `splice([1, 2, 3, 4], 2)` → `[3, 4]`, массив `[1, 2]`
- Должна вернуть пустой массив если deleteCount = 0: `splice([1, 2, 3], 1, 0)` → `[]`, массив не изменился
- Должна поддерживать отрицательный start: `splice([1, 2, 3, 4], -2, 1)` → `[3]`, массив `[1, 2, 4]`
- Должна обрезать deleteCount если он больше оставшихся элементов: `splice([1, 2, 3], 1, 5)` → `[2, 3]`, массив `[1]`
- Должна вернуть пустой массив если start >= len: `splice([1, 2, 3], 5, 1)` → `[]`

```javascript
function splice(arr, start, deleteCount, ...items)
```

Тестовые случаи для вставки (добавь к существующим тестам):
- Должна вставить элементы на место удалённых: `splice([1, 2, 3], 1, 1, 'a', 'b')` → вернуть `[2]`, массив `[1, 'a', 'b', 3]`
- Должна вставить элементы без удаления: `splice([1, 2, 3], 1, 0, 'x')` → вернуть `[]`, массив `[1, 'x', 2, 3]`
- Должна вставить в начало: `splice([2, 3], 0, 0, 0, 1)` → вернуть `[]`, массив `[0, 1, 2, 3]`
- Должна вставить в конец: `splice([1, 2], 2, 0, 3, 4)` → вернуть `[]`, массив `[1, 2, 3, 4]`
- Должна заменить элементы: `splice([1, 2, 3], 0, 2, 'a')` → вернуть `[1, 2]`, массив `['a', 3]`
