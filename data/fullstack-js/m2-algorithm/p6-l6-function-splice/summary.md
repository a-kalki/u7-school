# splice(arr, start, deleteCount, ...items) — краткая выжимка

- Удаляет `deleteCount` элементов начиная с `start` и вставляет `items` на их место
- **Мутабельная** — меняет массив на месте
- Возвращает массив удалённых элементов
- `start`: поддержка отрицательных индексов
- `deleteCount`: необязательный (по умолчанию до конца), отрицательный → 0
- `...items`: rest-параметр — элементы для вставки
- Самая сложная функция проекта: три случая (items больше/меньше/равно deleteCount)
- JSDoc обязателен, отметь мутабельность
