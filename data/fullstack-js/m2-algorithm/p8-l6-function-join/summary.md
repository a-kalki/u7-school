# Функция join(arr, separator) — краткая выжимка

- join(arr, separator) — строка из элементов через разделитель; ИММУТАБЕЛЬНАЯ
- separator по умолчанию ','; разделитель между элементами, а не после каждого
- Числа и булевы приводятся к строке; null и undefined дают пустую строку (особый случай)
- Пустой массив → ''; один элемент → без разделителя
- Сериализация: массив → строка
