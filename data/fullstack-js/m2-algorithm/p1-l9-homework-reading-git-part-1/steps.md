**kind:** `text`

Ты уже умеешь делать `init`, коммиты и push руками. Теперь закрепим теорию: статья разложит по полочкам то, что ты только что проделал.

**Задание:**

Открой `homework.md`, найди раздел **«Конспекты»** и добавь:

```markdown
## Git для новичков (часть 1)

- (5–7 пунктов того, что стало понятнее или удивило)
```

Пиши своими словами — конспект не для проверки, а для тебя: то, что сформулировано своими словами, запоминается.

**Сдача:**

```
git add homework.md
git commit -m "Добавить конспект статьи Git для новичков (часть 1)"
```

Это второй коммит в ветке `docs/homework`. На GitHub его пока не видно — отправим ветку целиком в уроке 11, вместе с созданием Pull Request.
