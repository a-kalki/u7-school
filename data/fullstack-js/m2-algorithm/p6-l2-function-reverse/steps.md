# Шаги урока: Функция reverse(arr) — переворот массива на месте

---

### Реализация reverse(arr)

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

Реализуй функцию `reverse(arr)` — переворот массива на месте. Создай файлы `arrays/reverse.js` и `arrays/reverse.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)

**Функция возвращает:** `array` — тот же массив `arr`, но с элементами в обратном порядке.

**Важно:** функция **мутабельная** — меняет исходный массив на месте. В JSDoc отметь это. В тестах проверяй и что элементы перевёрнуты, и что возвращается тот же самый массив.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна перевернуть массив из нечет. элементов: `reverse([1, 2, 3])` → `[3, 2, 1]`
- Должна перевернуть массив из чет. элементов: `reverse([1, 2, 3, 4])` → `[4, 3, 2, 1]`
- Должна вернуть тот же массив (проверь `===`)
- Должна перевернуть массив из одного элемента: `reverse([42])` → `[42]`
- Должна вернуть пустой массив без изменений: `reverse([])` → `[]`
- Должна работать с массивом строк: `reverse(['a', 'b', 'c'])` → `['c', 'b', 'a']`
- Должна работать с массивом смешанных типов: `reverse([1, 'two', null])` → `[null, 'two', 1]`
- Двойной reverse должен вернуть исходный порядок: `reverse(reverse([1, 2, 3]))` — но учти, что reverse мутирует и возвращает тот же массив, так что два вызова подряд на одном массиве вернут то же самое. Проверь на **копии**.
- Должна выбросить `TypeError` если `arr` не массив
