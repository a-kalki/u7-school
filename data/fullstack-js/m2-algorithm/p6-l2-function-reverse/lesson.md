# Функция reverse(arr) — переворот массива на месте

**Краткое содержание:**
`reverse(arr)` переворачивает массив на месте — первый элемент становится последним, второй предпоследним и т.д. Мутабельная операция: возвращает тот же массив.

### Алгоритм

1. Проверить, что `arr` — массив. Иначе `throw new TypeError`
2. Взять два указателя: `left = 0`, `right = len(arr) - 1`
3. Пока `left < right`:
   - Сохранить `arr[left]` во временную переменную `temp`
   - `arr[left] = arr[right]`
   - `arr[right] = temp`
   - `left++`, `right--`
4. Вернуть `arr`

```javascript
function reverse(arr) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');
  let left = 0;
  let right = len(arr) - 1;
  while (left < right) {
    const temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;
    left++;
    right--;
  }
  return arr;
}
```

### Почему через два указателя

Можно пройти циклом до середины и менять `arr[i]` с `arr[len - 1 - i]`. Подход с двумя указателями (`left`/`right`) нагляднее и проще в отладке.

### Чётная и нечётная длина

- **Нечётная:** `[1, 2, 3]` → left=0, right=2 → меняем 1↔3 → left=1, right=1 → условие `left < right` ложно, выходим. Средний элемент (2) остаётся на месте.
- **Чётная:** `[1, 2, 3, 4]` → left=0,right=3 → меняем 1↔4 → left=1,right=2 → меняем 2↔3 → left=2,right=1 → выходим.

### Мутабельность

`reverse` **меняет** массив на месте. В JSDoc отметь это явно.

### Отличие от строкового reverse

В проекте 3 мы реализовали `reverse(str)` для строк: строки иммутабельны, поэтому создавалась новая строка. Здесь `reverse(arr)` для массивов — мутабельная, меняет исходный массив. Это важное различие в поведении.
