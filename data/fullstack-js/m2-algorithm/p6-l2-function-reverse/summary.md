# reverse(arr) — краткая выжимка

- Переворачивает массив **на месте** (мутабельная операция)
- Алгоритм: два указателя (left/right), обмен элементов через временную переменную
- Возвращает тот же массив (не копию)
- Работает с чётной и нечётной длиной
- Пустой массив и массив из одного элемента — без изменений
- Отличие от строкового `reverse` (проект 3): тот создавал новую строку
- JSDoc обязателен, отметь мутабельность
