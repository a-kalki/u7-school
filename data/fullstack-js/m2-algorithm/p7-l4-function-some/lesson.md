# Функция some(arr, callback) — проверка «хотя бы один»

**Краткое содержание:**
`some(arr, callback)` — проверяет, удовлетворяет ли **хотя бы один** элемент условию. Возвращает `true` при первом совпадении и прекращает обход (ранний выход).

### Алгоритм

1. Проверить типы: `arr` — массив, `callback` — функция. Иначе `throw new TypeError`
2. Пройти циклом по массиву: `for (let i = 0; i < len(arr); i++)`
3. Если `callback(arr[i], i, arr) === true` → немедленно вернуть `true` (ранний выход)
4. После цикла (ни один не подошёл) → вернуть `false`

```javascript
function some(arr, callback) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');
  if (typeof callback !== 'function') throw new TypeError('Ожидается функция');
  for (let i = 0; i < len(arr); i++) {
    if (callback(arr[i], i, arr)) {
      return true;
    }
  }
  return false;
}
```

### Ранний выход

Ключевая особенность `some` — **ранний выход**: как только callback вернул `true`, обход останавливается. Остальные элементы не проверяются. Это даёт выигрыш в производительности для больших массивов. В тестах можно проверить, что callback не вызывается лишний раз после нахождения первого `true`.

### Пустой массив

Для пустого массива `some` возвращает `false` — нет ни одного элемента, значит ни один не может удовлетворить условию.
