# Шаги урока: Функция some(arr, callback) — проверка «хотя бы один»

---

### Реализация some()

**kind:** `text`

> Убедись, что ты в ветке `feat/iterative-methods`.

Реализуй функцию `some(arr, callback)` — проверка, удовлетворяет ли хотя бы один элемент условию. Создай файлы `arrays/some.js` и `arrays/some.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для проверки
- `callback`: `function` — функция-предикат, возвращает `true`/`false`

**Функция возвращает:** `boolean` — `true` если хотя бы один элемент удовлетворяет условию, иначе `false`.

**Важно:** функция должна делать **ранний выход** — остановить обход при первом `true`.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна вернуть `true` если хотя бы один подходит: `some([1, 2, 3], x => x > 2)` → `true`
- Должна вернуть `false` если ни один не подходит: `some([1, 2, 3], x => x > 10)` → `false`
- Должна вернуть `false` для пустого массива: `some([], fn)` → `false`
- Должна остановиться при первом `true` (ранний выход): создай callback-счётчик, убедись что после первого `true` вызовов не было
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция

**Подсказка по тестированию раннего выхода:**
```js
test('должна остановиться при первом true', () => {
  let callCount = 0;
  const result = some([5, 10, 15], (x) => {
    callCount++;
    return x % 5 === 0;
  });
  expect(result).toBe(true);
  expect(callCount).toBe(1); // только первый элемент
});
```
