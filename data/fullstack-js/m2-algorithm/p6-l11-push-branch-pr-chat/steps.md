### Создание PR по шаблону

**kind:** `text`

Создай PR: base `main` ← compare `feat/string-transform`.

**Заголовок:**
```
Проект 6: JSDoc и функции трансформации строк
```

**Описание — заполни по шаблону:**

```markdown
## Что сделано

Реализованы 8 функций трансформации строк:

- substring(str, start, end) — подстрока с нормализацией индексов
- slice(str, start, end) — подстрока с отрицательными индексами
- trim(str) — обрезка пробелов с краёв
- replace(str, search, replacement) — замена первого вхождения
- replaceAll(str, search, replacement) — замена всех вхождений
- pad(str, length, char, side) — дополнение до длины
- upperCase(str) / lowerCase(str) — регистр через коды символов (латиница + кириллица)

Все функции через TDD, JSDoc — сразу после заглушки.

## Особенности реализации

- slice и substring различаются правилами нормализации:
  substring приводит отрицательные к 0 и меняет границы местами,
  slice поддерживает отрицательные индексы и не меняет их местами
- replaceAll: заменённый текст не участвует в дальнейшем поиске
- upperCase/lowerCase: только charCodeAt/fromCodePoint

## Как запустить тесты

bun test
```

Что важно для ревьюеров, может быть не очевидно — обязательно указывай. Если считаешь, что команда «в теме», часть разделов можно сократить.
