# Функция len(arr) — подсчёт элементов массива

**Краткое содержание:**
Первая функция проекта 5. `len(arr)` — базовый примитив: без него ни одна другая функция массивов не работает. Считает элементы, идя по индексам, пока не встретит `undefined`.

### Зачем отдельный len для массивов

В проекте 1 уже есть `len(str)` для строк. Но массивы — другая структура, имена функций совпадают. Чтобы не было конфликта, функции массивов живут в папке `arrays/`. Файл `arrays/len.js` экспортирует `len` для массивов.

### Алгоритм

Массив в JS хранит элементы по индексам `0, 1, 2, ...`. После последнего элемента `arr[i]` возвращает `undefined`. Этим и пользуемся:

1. Проверить, что `arr` — массив (`Array.isArray`). Если нет — `throw new TypeError`
2. Идти циклом `for (let i = 0; arr[i] !== undefined; i++)` и считать
3. Вернуть счётчик

```javascript
function len(arr) {
  if (!Array.isArray(arr)) throw new TypeError('Ожидается массив');
  let count = 0;
  for (let i = 0; arr[i] !== undefined; i++) count++;
  return count;
}
```

### Подводный камень: «дырки» в массиве

Если в массиве есть элемент `undefined` (или «дырка»), `len` остановится на нём. В этом проекте мы работаем с плотными массивами без `undefined` внутри — это оговорённое ограничение. На практике избегай «дыр» в массивах.
