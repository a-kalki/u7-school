# len(arr) — краткая выжимка

- Считает элементы массива **до первого `undefined`**
- Цикл `for` с прямым обращением `arr[i]`
- `0` для пустого массива
- `throw new TypeError` если аргумент не массив (проверка через `Array.isArray`)
- Живёт в `arrays/len.js` (отдельно от строкового `len.js`)
- JSDoc обязателен
- Ветка: `feat/array-basics`
