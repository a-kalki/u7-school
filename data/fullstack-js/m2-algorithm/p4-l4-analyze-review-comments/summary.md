# Разбор пришедших замечаний — краткая выжимка

- Урок — отложенное действие: прочитать сейчас, выполнить когда придут комментарии
- Прочитать каждый комментарий внимательно, до конца — не отвечать на ходу
- Категории: 🐛 баги (блокируют мерж), 🎨 стиль, 📝 документация, 💡 предложения (на твоё усмотрение)
- По каждому: согласен → исправлю; не согласен → ответ с аргументами, не с эмоциями
- Следующие шаги — в уроке «Fix-коммиты в ветку»
