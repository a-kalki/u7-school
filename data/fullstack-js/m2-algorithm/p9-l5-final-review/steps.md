### Проверка JSDoc

**kind:** `text`

Проверь JSDoc на всех 5 функциях проекта 9. Для каждой должен быть:

- `@param` для каждого параметра с типом и описанием
- `@returns` с типом и описанием
- `@throws` где есть проверка типов (`TypeError`)
- Особенности реализации: иммутабельность, рекурсия, композиция, `hasOwnProperty`

Пример правильного JSDoc для `cloneDeep`:
```javascript
/**
 * Создаёт глубокую копию значения.
 * Для примитивов возвращает значение как есть.
 * Для массивов и объектов создаёт новую структуру с рекурсивным копированием элементов.
 *
 * @param {*} value — значение для копирования
 * @returns {*} — глубокая копия, изменение которой не затрагивает оригинал
 */
```

Если что-то пропущено — дополни.

### Проверка совместимости с ручным тестом

**kind:** `text`

Напиши небольшой ручной тест-сценарий в `test-manual.js` (или просто запусти через bun shell), который проверит цепочку: `keys` → `values` → `entries` → `cloneDeep` → `isEqualDeep`:

```javascript
// Скопируй в bun shell или создай test-manual.js и запусти через bun
import { keys } from './keys';
import { values } from './values';
import { cloneDeep } from './clone-deep';
import { isEqual } from './is-equal';

const obj = { name: 'Анна', scores: [5, 4, 5] };

// 1. Ключи
const k = keys(obj);
console.log('keys:', k); // ['name', 'scores']

// 2. Значения
const v = values(obj);
console.log('values:', v); // ['Анна', [5, 4, 5]]

// 3. Копия
const copy = cloneDeep(obj);
copy.name = 'Борис';
copy.scores[0] = 3;
console.log('original после изменения копии:', obj);
// { name: 'Анна', scores: [5, 4, 5] } — не изменился

// 4. Сравнение
console.log('isEqualDeep(original, copy):', isEqualDeep(obj, copy)); // false
console.log('isEqualDeep(original, cloneDeep(original)):', isEqualDeep(obj, cloneDeep(obj))); // true
```

*Примечание:* ты можешь скопировать этот код в буфер обмена и выполнить ее без создания файла. Используй синтаксис `bun -e "<paste your code>"`. Флаг `-e` тут означает `execute` (а может `eval`) и позволяет выполнить код переданную следующей строкой. Убедись что в твоем коде нет "обрамляющих" кавычек (в нашем случае `"`), иначе экранируй их в своем коде `\"`. Вполне возможно нужно перейти в папку с реализованными функциями или обновить пути в коде в полях `import` относительно текущей папки.
