# Ветки в Git

**Краткое содержание:**
Теория веток на W3Schools и безопасный эксперимент: создание ветки, переключение между ветками, «параллельность» состояний, удаление ветки и reflog.

**Время:** ~20 мин

**Основные темы:**
1. Что такое ветка и зачем она нужна
2. `git switch -c` — создание и переключение
3. Независимость состояний веток
4. `git branch -d` / `-D`, «висячие» коммиты, `git reflog`

**Термины:**
фича — от `feature`: реализация нового функционала;
баг — от `bug`: дословно - жук, смыслово - ошибка в программе;
ветка — по англ. `branch`: ветка, ветвление
