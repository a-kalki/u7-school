# Шаги урока: Проблема: трансформация массивов

---

### Состав API проекта — 6 функций

**kind:** `text`

Базовые операции освоены: добавляй, удаляй, ищи. Следующая ступень — **трансформация**: заполнить, перевернуть, объединить, скопировать часть, склеить в строку, вырезать и вставить.

**Состав API проекта — 6 функций.** Мутабельность теперь — часть контракта, размечаем её заранее:

| Функция | Что делает | Мутирует массив? |
|---------|-----------|------------------|
| `fill(arr, value, start, end)` | заполнение массива (или части) значением | **да** |
| `reverse(arr)` | переворот массива на месте | **да** |
| `concat(arr1, arr2)` | объединение двух массивов в новый | нет |
| `slice(arr, start, end)` | копирование подмассива в новый | нет |
| `join(arr, separator)` | склеивание массива в строку | нет |
| `splice(arr, start, deleteCount, ...items)` | удаление и вставка элементов | **да** |

Обрати внимание на баланс: три функции меняют исходный массив, три — возвращают новый. Перед каждой реализацией ты уже будешь знать, какой тип перед тобой, — и проверять это в тестах: мутирующая возвращает изменённый исходник (или новую длину/удалённые элементы), иммутабельная — новый массив при нетронутом исходнике.

Правила прежние: запрещены встроенные методы массивов и `.length`; TDD + JSDoc сразу после заглушки; мутируемость/иммутабельность — в JSDoc каждой функции; коммит после каждой функции.

**Термины:**
трансформация массива — получение нового содержимого из исходного массива: на месте (мутирующая) или в новом массиве (иммутабельная)
