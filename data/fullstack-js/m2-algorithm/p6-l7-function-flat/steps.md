# Шаги урока: Функция flat(arr, depth) — разглаживание массива

---

### Введение в рекурсию для массивов

**kind:** `text`

До сих пор все алгоритмы в проектах были итеративными — цикл `for` или `while`. Функция `flat` — первый случай, где естественнее использовать **рекурсию**: функцию, которая вызывает саму себя для решения подзадачи.

**Идея рекурсии в `flat`:** пройти по каждому элементу массива. Если элемент — массив, и мы ещё не достигли нужной глубины (`depth > 0`), то вызвать `flat` для этого элемента с `depth - 1` и добавить результат. Если элемент не массив или глубина исчерпана — добавить его как есть.

**База рекурсии** (когда не вызываем себя): элемент не массив ИЛИ `depth === 0`.

**Шаг рекурсии** (когда вызываем себя): элемент — массив И `depth > 0` → `flat(элемент, depth - 1)`.

### Реализация flat()

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

Реализуй функцию `flat(arr, depth)` — разглаживание вложенных массивов. Создай файлы `arrays/flat.js` и `arrays/flat.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив (может содержать вложенные массивы)
- `depth`: `number` (необязательный, по умолчанию `1`) — глубина разглаживания. `Infinity` — разгладить всё

**Функция возвращает:** `array` — новый разглаженный массив.

**Важно:** функция **иммутабельная** — исходный массив не меняется. Это первая функция с рекурсией в проектах.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна разгладить один уровень: `flat([1, [2, 3], 4])` → `[1, 2, 3, 4]`
- Должна разгладить два уровня: `flat([1, [2, [3, 4]]], 2)` → `[1, 2, 3, 4]`
- Должна разгладить всё с `Infinity`: `flat([1, [2, [3, [4]]]], Infinity)` → `[1, 2, 3, 4]`
- Должна не менять массив без вложений: `flat([1, 2, 3])` → `[1, 2, 3]`
- Должна вернуть пустой массив для пустого: `flat([])` → `[]`
- Должна не разглаживать при `depth = 0`: `flat([1, [2, 3]], 0)` → `[1, [2, 3]]`
- Должна разгладить смешанную вложенность с ограничением глубины: `flat([1, [2], [3, [4]]], 1)` → `[1, 2, 3, [4]]`
- Исходный массив не должен измениться
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `depth` передан и не число
