# flat(arr, depth) — краткая выжимка

- Разглаживает вложенные массивы до указанной глубины
- **Иммутабельная** — возвращает новый массив
- `depth = 1` (по умолчанию) — один уровень, `Infinity` — все уровни
- Первое применение **рекурсии** в проектах
- База рекурсии: элемент не массив или `depth === 0`
- Шаг рекурсии: элемент — массив и `depth > 0` → `flat(arr[i], depth - 1)`
- JSDoc обязателен, отметь иммутабельность
