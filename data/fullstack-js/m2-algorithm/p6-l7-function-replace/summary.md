# Функция replace(str, search, replacement) — краткая выжимка

- replace(str, search, replacement) — заменяет только первое вхождение search
- search не найден → исходная строка без изменений
- Алгоритм: свой indexOf находит позицию → результат = до + replacement + после
- Композиция функций: indexOf из проекта 5 переиспользуется, логика поиска не дублируется
- Замена может менять длину: длиннее, короче или пустая строка — все случаи в тестах
