# Bun — запускаем первый код — краткая выжимка

- **Bun** — runtime (исполнитель) для JavaScript: запускает `.js`-файлы на компьютере без браузера
- **Установка:** одна команда с [bun.sh](https://bun.sh/) для своей ОС
- **Проверка:** `bun --version` должен показать номер версии
- **Запуск:** в терминале из папки `dev` выполнить `bun hello.js` — увидишь вывод имени, цвета и возраста
- **Ошибки:** сначала реши сам (и с ИИ), затем спроси в чате группы или покажи ментору
- **Процесс работы:** создать файл → написать программу → выполнить через `bun`
