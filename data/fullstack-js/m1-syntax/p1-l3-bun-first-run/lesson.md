# Bun — запускаем первый код

**Краткое содержание:**
Урок знакомит студента с Bun — исполнителем (runtime) для JavaScript, который запускает код на компьютере без браузера. Студент устанавливает Bun и запускает из терминала редактора свой первый файл `hello.js`, созданный в прошлом уроке.

**Основные темы:**
*   Что такое Bun и зачем он нужен
*   Установка Bun на Windows / macOS / Linux
*   Проверка установки через `bun --version`
*   Запуск первого файла через `bun hello.js`
*   Что делать при ошибках

**Подробный конспект:**

**1. Что такое Bun**

*   В уроке 1 говорили про **интерпретатор** — программу, которая выполняет код.
*   В браузере JavaScript выполняет встроенный движок, а на компьютере и сервере нужен свой исполнитель.
*   **Bun** — такой «исполнитель» (по-английски — runtime) для JavaScript. Позволяет запускать `.js`-файлы прямо на компьютере, без браузера.
*   Аналогия: файл `.js` — это рецепт, а Bun — повар, который читает рецепт и выполняет его шаг за шагом. Без повара рецепт — просто текст.
*   Bun современный и быстрый, в нём уже есть всё нужное для курса.

**2. Установка Bun**

*   Установка — одна команда в терминале (терминал компьютера или внутри редактора: Terminal → New Terminal).
*   **Windows (PowerShell):**
    ```
    powershell -c "irm bun.sh/install.ps1 | iex"
    ```
*   **macOS / Linux:**
    ```
    curl -fsSL https://bun.sh/install | bash
    ```
*   Команду можно скопировать с [bun.sh](https://bun.sh/) — там есть кнопка «Copy to clipboard».
*   Проверка установки:
    ```
    bun --version
    ```
    Должен появиться номер версии, например `1.x.x`.
*   Если команда не найдена — закрыть и заново открыть терминал. Если всё ещё не работает — скопировать ошибку и спросить ИИ-ассистента.

**3. Запуск первой программы**

*   Открыть терминал в редакторе: Terminal → New Terminal (VS Code).
*   Проверить, что терминал находится в папке проекта `dev` (`C:\dev` или `~/dev`). Если нет — перейти: `cd C:\dev` (Windows) или `cd ~/dev` (macOS/Linux).
*   Выполнить команду:
    ```
    bun hello.js
    ```
*   В терминале появится вывод:
    ```
    Моё имя: Алекс
    Мой любимый цвет: синий
    Мне лет: 25
    ```
*   Это первая программа: код написан в редакторе и выполнен через Bun.

**4. Что делать при ошибках**

*   Проверить, что находишься в папке `dev` (команда `pwd` покажет текущую папку).
*   Проверить, что файл называется именно `hello.js`.
*   Скопировать текст ошибки и спросить ИИ-ассистента.
*   Если не заработает — попробовать решить с помощью ИИ.
*   Если и так не получится — спросить в чате группы или показать ментору на следующем уроке.
*   Работа программиста — постоянно решать проблемы. Но не застревай надолго: обращайся к студентам или ментору вовремя.

**Дальнейший процесс работы:**
*   В будущих уроках будут задания. Делать их всегда через один процесс:
    1.  создать файл;
    2.  написать в нём задание-программу;
    3.  выполнить через `bun`.
*   Так ты привыкнешь к главным инструментам разработчика: редактор, терминал, bun.

**Ключевые выводы:**
1.  Bun — runtime для JavaScript, который запускает `.js`-файлы на компьютере без браузера.
2.  Установка Bun — одна команда с официального сайта, проверка — `bun --version`.
3.  Запуск программы — `bun hello.js` из папки проекта в терминале.
4.  При ошибках сначала пробуй решить сам (и с ИИ), затем обращайся к группе или ментору.

**Термины:**
*   **Runtime (исполнитель)** — программа, которая выполняет код (Bun — для JavaScript на компьютере и сервере).
*   **Терминал** — командная строка для ввода команд, например `bun hello.js`.
*   **`bun`** — команда запуска программ через Bun.
