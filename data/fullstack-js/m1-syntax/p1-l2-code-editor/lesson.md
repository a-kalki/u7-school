# Редактор кода

**Краткое содержание:**
Урок знакомит студента с редактором кода — главным инструментом программиста. Студент выбирает один из двух бесплатных редакторов (VS Code или Zed), устанавливает его на свой компьютер, осваивает минимально необходимые операции и создаёт первый JavaScript-файл в папке проекта.

**Основные темы:**
*   Что такое редактор кода и зачем он нужен
*   Сравнение VS Code и Zed, выбор редактора для старта
*   Пошаговая установка на Windows / macOS / Linux
*   Базовые операции: открыть папку, создать файл, сохранить, терминал
*   Создание папки для проектов и первого файла `hello.js`

**Подробный конспект:**

**1. Что такое редактор кода**

*   Редактор кода — это программа, в которой программисты пишут код.
*   Аналогия: если код — это текст, то редактор кода — как текстовый редактор (Word или Блокнот), но специально «заточенный» под код.
*   Почему не Блокнот? Редактор кода:
    *   **подсвечивает код цветами** (подсветка синтаксиса) — сразу видно, где команда, где строка, где число;
    *   **подсказывает** продолжение, когда ты печатаешь (автодополнение);
    *   **показывает ошибки** ещё до запуска;
    *   имеет **встроенный терминал**, чтобы запускать код прямо из редактора.
*   Всё это помогает меньше ошибаться и быстрее писать код.

**2. Выбор редактора: VS Code или Zed**

*   Оба редактора бесплатные.
*   **VS Code** (Visual Studio Code):
    *   самый популярный редактор в мире, от Microsoft;
    *   работает на Windows, macOS и Linux;
    *   огромное количество расширений и обучающих материалов;
    *   если застрял — ответ легко найти в интернете или спросить у ИИ.
*   **Zed**:
    *   новый, очень быстрый и минималистичный редактор;
    *   меньше расширений, но всё нужное для старта есть;
    *   хорош, если любишь простоту и скорость.
*   Рекомендация для первого знакомства — **VS Code**: по нему больше всего материалов и подсказок. Если VS Code не нравится или не запускается — берём Zed, принципы работы те же.

**3. Установка редактора**

*   **VS Code:**
    1. Открыть сайт [code.visualstudio.com](https://code.visualstudio.com/).
    2. Нажать **Download** — сайт сам определит операционную систему.
    3. Запустить скачанный файл:
        *   **Windows:** отметить пункт «Add to PATH», далее Next → Install;
        *   **macOS:** перетащить Visual Studio Code в «Программы» (Applications);
        *   **Linux:** следовать инструкциям на сайте (пакет .deb или .rpm).
    4. Открыть VS Code.
*   **Zed:**
    1. Открыть сайт [zed.dev](https://zed.dev/).
    2. Скачать версию для своей ОС.
    3. Установить как обычную программу и открыть.
*   Если что-то пошло не так — описать проблему (или скопировать сообщение об ошибке) и спросить ИИ-ассистента.

**4. Базовые операции в редакторе**

*   **Открыть папку** — File → Open Folder (VS Code) или Open… (Zed). Редактор работает с целыми папками.
*   **Панель файлов** — слева список файлов и папок; клик по файлу открывает его.
*   **Создать файл** — иконка «новый файл» (или правой кнопкой по папке → New File).
*   **Сохранить** — Ctrl+S (Windows/Linux) или Cmd+S (macOS).
*   **Терминал** — Terminal → New Terminal (VS Code); командная строка прямо внутри редактора.
*   Разбирать все кнопки заранее не нужно — освоишь по ходу. Если что-то не найдёшь — спросить ИИ-ассистента.

**5. Папка для проектов**

*   Заводим отдельную папку, где будут жить все проекты курса.
*   Название `dev` или `learn`:
    *   **Windows:** `C:\dev` — в корне диска C;
    *   **macOS/Linux:** `~/dev` — в домашней папке.
*   Рекомендация: в пути не должно быть кириллических символов и пробелов (`"C:\Мои проекты"` — не лучший вариант, потенциальный источник проблем).
*   Открыть эту папку в редакторе: File → Open Folder → выбрать `dev`.

**6. Первый файл**

*   Создать файл `hello.js` — расширение `.js` говорит, что это JavaScript-файл.
*   Пример кода:
    ```js
    // Файл hello.js — моя первая программа
    console.log('Моё имя: Алекс');
    console.log('Мой любимый цвет: синий');
    console.log('Мне лет: 25');
    ```
*   Заменить имя, цвет и возраст на свои и сохранить (Ctrl+S / Cmd+S).
*   Текст в кавычках (`'...'`) — это строки, число `25` — без кавычек.
*   Запустить файл пока нельзя — для этого нужен Bun (следующий урок).

**Ключевые выводы:**
1.  Редактор кода — основной инструмент программиста: подсветка, подсказки, ошибки, встроенный терминал.
2.  Для старта достаточно VS Code или Zed; рекомендуем VS Code из-за большего количества материалов.
3.  Редактор работает с папками: открываем папку проекта, создаём и сохраняем файлы.
4.  Имя файла с расширением `.js` сообщает, что внутри JavaScript.
5.  Все вопросы по редактору можно задавать ИИ-ассистенту.

**Термины:**
*   **Редактор кода** — программа для написания кода с подсветкой синтаксиса, автодополнением и встроенным терминалом.
*   **Расширение файла** — суффикс в имени файла (`.js`), определяющий его тип.
*   **Терминал** — командная строка, встроенная в редактор для запуска программ.
