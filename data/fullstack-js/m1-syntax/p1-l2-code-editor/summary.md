# Редактор кода — краткая выжимка

- **Редактор кода** — программа для написания кода: подсветка синтаксиса, автодополнение, показ ошибок, встроенный терминал
- **Выбор:** VS Code (популярный, много материалов) или Zed (быстрый, минималистичный) — оба бесплатные
- **Установка:** скачать с официального сайта и установить как обычную программу
- **Папка проекта:** `C:\dev` (Windows) или `~/dev` (macOS/Linux), без кириллицы и пробелов в пути
- **Первый файл:** `hello.js` — выводит имя, любимый цвет и возраст через `console.log()`
- **Вопросы по редактору** — задавай ИИ-ассистенту
