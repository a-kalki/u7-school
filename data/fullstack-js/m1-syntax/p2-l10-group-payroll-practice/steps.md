# Шаги урока: Практика: групповая обработка зарплаты

---

### Проект: расчёт зарплаты по отделу — постановка задачи

**kind:** `text`

### Что нужно сделать

Ты будешь писать программу для расчёта зарплаты **всего отдела маркетинга**.

В отделе 4 сотрудника. Данные хранятся в массиве (список имён) и двух объектах (оклады и табель).

Задача разбита на **4 этапа**. Проходи их по порядку — каждый этап завершай запуском и проверкой результата.

---

### Исходные данные

```js
const employees = ['Иванов', 'Петрова', 'Сидоров', 'Козлова'];

const salaries = {
  Иванов: 500000,
  Петрова: 450000,
  Сидоров: 480000,
  Козлова: 520000,
};

const workDays = {
  Иванов: 20,
  Петрова: 18,
  Сидоров: 22,
  Козлова: 20,
};

const WORK_DAYS_IN_MONTH = 22;
const OPV_RATE = 0.10;
const IPN_RATE = 0.10;
```

---

### Формулы (для справки)

1. **Начислено** = `(оклад / WORK_DAYS_IN_MONTH) × отработанные дни`
2. **ОПВ** = 10% от начисленного
3. **ИПН** = 10% от (начисленное − ОПВ)
4. **На руки** = начисленное − ОПВ − ИПН

Все суммы округляй через `Math.round()`.

---

### Формат вывода

Программа должна вывести в консоль отформатированный результат, разделённый на три смысловых блока:

```
=== Сотрудники отдела маркетинга ===
Иванов: оклад 500000, отработано 20 дней
Петрова: оклад 450000, отработано 18 дней
Сидоров: оклад 480000, отработано 22 дней
Козлова: оклад 520000, отработано 20 дней

=== Расчёт зарплаты ===
Иванов: начислено 454545, ОПВ 45455, ИПН 40909, на руки 368181
Петрова: начислено 368182, ОПВ 36818, ИПН 33136, на руки 298228
Сидоров: начислено 480000, ОПВ 48000, ИПН 43200, на руки 388800
Козлова: начислено 472727, ОПВ 47273, ИПН 42545, на руки 382909

=== Итоги по отделу ===
Общий фонд оплаты: 1775454 тг
Всего удержано ОПВ: 177546 тг
Всего удержано ИПН: 159790 тг
Всего к выплате:   1438118 тг
Полный месяц: 1 сотрудников
```

Запусти программу и убедись, что блок вывелся без ошибок. Затем переходи к Этапу 2.

### Этап 2: расчёт для каждого сотрудника

Возьми код из этапа 1 и **допиши внутрь цикла** формулы расчёта зарплаты.

**Формулы (из первого шага):**

1. **Начислено** = `(оклад / WORK_DAYS_IN_MONTH) × отработанные дни`
2. **ОПВ** = `начисленное × OPV_RATE`
3. **ИПН** = `(начисленное − ОПВ) × IPN_RATE`
4. **На руки** = `начисленное − ОПВ − ИПН`

**Правила вычислений:**
- Все суммы обязательно округляй через `Math.round()`
- Оклад бери из `salaries[name]`, отработанные дни — из `workDays[name]`

**Ожидаемый вывод этапа 2:**

```
=== Расчёт зарплаты ===
Иванов: начислено 454545, ОПВ 45455, ИПН 40909, на руки 368181
Петрова: начислено 368182, ОПВ 36818, ИПН 33136, на руки 298228
Сидоров: начислено 480000, ОПВ 48000, ИПН 43200, на руки 388800
Козлова: начислено 472727, ОПВ 47273, ИПН 42545, на руки 382909
```

Проверь, что числа у всех 4 сотрудников совпадают с образцом, и переходи к Этапу 3.

### Этап 3: итоги по отделу

Возьми код из этапа 2 и **допиши** подсчёт общих итогов.

**Что нужно сделать:**

1. **Перед циклом** заведи переменные-сумматоры, инициализированные нулём:
   - `totalAccrued = 0` — общий фонд начислений
   - `totalOpv = 0` — всего удержано ОПВ
   - `totalIpn = 0` — всего удержано ИПН
   - `totalPay = 0` — всего к выплате
   - `fullMonthCount = 0` — сколько сотрудников отработали полный месяц

2. **Внутри цикла** прибавляй рассчитанные значения к сумматорам:
   - `totalAccrued += accrued` (начисленная сумма, **не** оклад из `salaries`)
   - `totalOpv += opv`
   - `totalIpn += ipn`
   - `totalPay += pay`

3. **Считай полный месяц:** если отработанные дни сотрудника больше или равны `WORK_DAYS_IN_MONTH`, увеличь `fullMonthCount` на 1:
   ```js

     fullMonthCount++;
   ```
