# Первая игра: Черепашка на сетке (PR) — краткая выжимка

- В первой практической задаче проекта «Аркада» оживляем виртуального исполнителя — Черепашку на клетчатом поле 10×10.
- В компьютерной экранной графике точка `(0, 0)` находится в верхнем левом углу, ось X увеличивается вправо, а ось Y — вниз.
- Стороны света (`N`, `E`, `S`, `W`) циклически сменяются при поворотах на 90°: направо `(index + 1) % 4`, налево `(index + 3) % 4`.
- Инвариант границ: координаты Черепашки не должны выходить за границы диапазона `0 <= x < width` и `0 <= y < height`. Шаг в стену игнорируется.
- Состояние Черепашки — чистый POJO-объект с полями `x`, `y`, `direction`, `penDown`, `trail`, `stepsCount`. Никакого ООП и классов.
- Логика игры в `games/turtle/turtle.js` описывается тремя функциями:
  - `createState(options)` — начальное состояние (размер поля, координаты, перо, след);
  - `update(state, event)` — обработка `FORWARD`, `BACKWARD`, `TURN_LEFT`, `TURN_RIGHT`, `TOGGLE_PEN`, `CLEAR_TRAIL`;
  - `getView(state)` — формирование символьной матрицы с Черепашкой (`▲`, `►`, `▼`, `◄`) и нарисованным следом (`.`).
- Студент получает готовый TUI модуль `tui/turtle.js` и раннер `games/turtle/run.js`, самостоятельно пишет только логику и тесты.
- Тесты пишутся через `bun test games/turtle/` и проверяют чистые функции без эмуляции терминала.
- Сдача задания по Git-flow: открываем ветку `feature/turtle` в начале урока от `main`, ведём всю разработку и тесты в ней, проверяем запуск `bun arcade/games/turtle/run.js`, коммитим в ветку и открываем Pull Request на GitHub (2 апрува от сокурсников для мержа).
