# Первая игра: Черепашка на сетке (PR 1) — краткая выжимка

- В первой практической задаче проекта «Аркада» оживляем виртуального исполнителя — Черепашку на клетчатом поле 10×10.
- В компьютерной экранной графике точка `(0, 0)` находится в верхнем левом углу, ось X увеличивается вправо, а ось Y — вниз.
- Стороны света (`N`, `E`, `S`, `W`) циклически сменяются при поворотах на 90°: направо `(index + 1) % 4`, налево `(index + 3) % 4`.
- Инвариант границ: координаты Черепашки не должны выходить за границы диапазона `0 <= x < width` и `0 <= y < height`. Шаг в стену игнорируется.
- Состояние Черепашки — чистый POJO-объект с полями `x`, `y`, `dir`, `penDown`, `trail`, `stepsCount`. Никакого ООП и классов.
- Логика игры в `games/turtle/turtle.js` описывается тремя функциями:
  - `createState(options)` — начальная расстановка по центру;
  - `update(state, action)` — обработка `MOVE_FORWARD`, `MOVE_BACKWARD`, `ROTATE_LEFT`, `ROTATE_RIGHT`, `TOGGLE_PEN`, `CLEAR`;
  - `getView(state)` — формирование символьной матрицы с Черепашкой (`^`, `>`, `v`, `<`) и нарисованным следом (`.`).
- Студент получает готовый рендерер `render/turtle.js` и раннер `games/turtle/run.js`, самостоятельно пишет только логику и тесты.
- Тесты пишутся через `bun test games/turtle/` и проверяют чистые функции без эмуляции терминала.
- Сдача задания: ветка `feature/turtle`, чистый запуск `bun games/turtle/run.js`, зеленые тесты и первый Pull Request (PR 1) ментору.
