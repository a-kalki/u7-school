### Суть игры глазами игрока: Черепашка-художник

**kind:** `text`

Прежде чем писать код, давай посмотрим на игру глазами человека, который запустил её в терминале.

**Что это за игра?**
«Черепашка на сетке» — классический интерактивный робот-исполнитель (Turtle Graphics). Впервые эту концепцию придумал математик и педагог Сеймур Пейперт в языке Logo: маленький виртуальный робот передвигается по экрану и рисует за собой узоры опущенным пером.

**Что видит игрок на экране терминала:**
1. **Клетчатый холст в рамке:** поле фиксированного размера 10×10 клеток.
2. **Сам исполнитель (Черепашка):** отображается на поле стрелочкой, указывающей, куда сейчас направлен её взгляд:
   - `▲` — смотрит на Север (вверх);
   - `►` — смотрит на Восток (вправо);
   - `▼` — смотрит на Юг (вниз);
   - `◄` — смотрит на Запад (влево).
3. **Нарисованный след:** каждая ячейка, где Черепашка побывала с опущенным пером, закрашивается точкой `·`.
4. **Панель статуса внизу:** выводит текущие координаты Черепашки `(x, y)`, направление взгляда, режим пера (ОПУЩЕНО или ПОДНЯТО), общее количество сделанных шагов и подсказки по клавишам.

**Как устроен процесс игры (геймплей):**
- **Движение:** игрок нажимает стрелки вверх/вниз (или `W`/`S`), и Черепашка делает шаг вперёд или назад вдоль своего направления.
- **Повороты:** игрок нажимает стрелки влево/вправо (или `A`/`D`), и Черепашка поворачивается на 90° на месте, меняя стрелку-иконку, но оставаясь в той же клетке.
- **Управление пером (Пробел):**
  - Когда перо **опущено**, Черепашка рисует: каждая новая клетка на её пути добавляется в рисунок.
  - Когда перо **поднято**, Черепашка свободно шагает, не оставляя меток (например, чтобы перейти в другой угол холста и начать новый рисунок).
- **Очистка холста (Клавиша C):** стирает все нарисованные точки, оставляя Черепашку на текущей позиции с чистым полем.
- **Границы мира:** поле окружено невидимым барьером. Если Черепашка упирается в край сетки, она просто не может шагнуть дальше и остаётся на месте — игра не падает с ошибкой.

**Цель игрока:** рисовать в терминале геометрические фигуры (квадраты, спирали, лесенки, буквы)
**Твоя цель:** Исследовать двумерное пространство координат.

### Экранная система координат и матрицы в JavaScript

**kind:** `text`

В математической декартовой системе координат ось `Y` направлена вверх. Но в компьютерной графике, экранах и терминалах стандарт иной:

- **Точка отсчёта `(0, 0)`** находится в **левом верхнем углу** экрана.
- **Ось X (горизонталь):** идёт слева направо. При шаге вправо координата `x` растёт (`x + 1`).
- **Ось Y (вертикаль):** идёт **сверху вниз** (в отличие от математики!). При шаге вниз координата `y` растёт (`y + 1`).

**Критически важное правило индексации матриц:**
Когда матрица представлена как массив строк:
```javascript
const grid = [
  ['.', '.', '.'], // строка y = 0: ячейки [0][0], [0][1], [0][2]
  ['.', 'T', '.'], // строка y = 1: ячейки [1][0], [1][1], [1][2]
  ['.', '.', '.'], // строка y = 2: ячейки [2][0], [2][1], [2][2]
];
```
Обращение к ячейке с координатами `x` и `y` всегда пишется как:
```javascript
grid[y][x] // СНАЧАЛА номер строки y, затем номер столбца x!
```
Это самая частая ловушка для начинающих разработчиков — запомни порядок `[y][x]`.

### Векторная модель направлений: N, E, S, W

**kind:** `text`

Черепашка ориентирована по сторонам света:
- `'N'` (Север — вверх): смещение `{ dx: 0, dy: -1 }`
- `'E'` (Восток — вправо): смещение `{ dx: 1, dy: 0 }`
- `'S'` (Юг — вниз): смещение `{ dx: 0, dy: 1 }`
- `'W'` (Запад — влево): смещение `{ dx: -1, dy: 0 }`

Порядок по часовой стрелке: `['N', 'E', 'S', 'W']`.

- **Поворот направо (по часовой стрелке):** следующий индекс в массиве по кругу;
- **Поворот налево (против часовой стрелки):** предыдущий индекс по кругу.

При шаге вперёд к текущим координатам `(x, y)` прибавляются соответствующие `{ dx, dy }`, а при шаге назад — вычитаются. Координаты обязательно ограничиваются рамками поля.

### Слой 2: Инфраструктура отображения Черепашки (arcade/tui/turtle.js)

**kind:** `text`

Инфраструктуру отображения и клавиатурный адаптер для Черепашки ментор выдаёт в готовом виде в чате потока.

Файл `arcade/tui/turtle.js` решает две задачи Слоя 2:

**1. Адаптер ввода (`inputAdapter`):**
Переводит сигналы клавиатуры в доменные действия игры:
- Стрелки вверх/вниз или `W`/`S` преобразуются в `{ type: 'FORWARD' }` и `{ type: 'BACKWARD' }`;
- Стрелки влево/вправо или `A`/`D` преобразуются в повороты `{ type: 'TURN_LEFT' }` и `{ type: 'TURN_RIGHT' }`;
- `Пробел` переключает режим рисования: `{ type: 'TOGGLE_PEN' }`;
- Клавиша `C` очищает след: `{ type: 'CLEAR_TRAIL' }`;
- Служебные клавиши выхода (`q`, `Ctrl+C`) и сброса (`r`) возвращаются как `null` и обрабатываются ядром.

**2. Рендерер кадра (`renderTurtle`):**
Принимает модель экрана `view`, сформированную функцией `getView(state)`:

```javascript
export function renderTurtle(view) {
  const {
    grid,        // двумерная матрица символов [' ', '·', '▲']
    x, y,        // текущие координаты черепашки
    direction,   // текущее направление: 'N', 'E', 'S', 'W'
    penDown,     // поднято или опущено перо
    stepsCount,  // счётчик сделанных шагов
  } = view;
  // Возвращает массив строк кадра с рамкой, статусом и подсказками
}
```

Сохрани файл `arcade/tui/turtle.js` от ментора в папку `arcade/tui/` и переходи к раннеру!

### ТЗ: Техническое задание на реализацию arcade/games/turtle/turtle.js

**kind:** `text`

Твоя задача — самостоятельно разработать модуль игровой логики `arcade/games/turtle/turtle.js`.

**Функция `createState(options = {})`**
Принимает необязательный объект с настройками и возвращает объект начального состояния:
- `width` (число, по умолчанию `10`) — ширина поля;
- `height` (число, по умолчанию `10`) — высота поля;
- `x` (число, по умолчанию `0`) — текущая координата X черепашки;
- `y` (число, по умолчанию `0`) — текущая координата Y черепашки;
- `direction` (строка, по умолчанию `'E'`) — направление взгляда (`'N'`, `'E'`, `'S'`, `'W'`);
- `penDown` (булево, по умолчанию `false`) — режим рисования (перо поднято);
- `trail` (массив строковых координат `['x,y']`) — след опущенного пера (по умолчанию пустой `[]`);
- `stepsCount` (число, по умолчанию `0`) — счётчик сделанных шагов.

**Функция `update(state, event)`**
Принимает текущее состояние и объект события, возвращает новое состояние игры (иммутабельно).
Обрабатывает следующие типы событий (`event.type`):
- `'TURN_RIGHT'` — поворот направления на 90° по часовой стрелке (`N → E → S → W → N`);
- `'TURN_LEFT'` — поворот направления на 90° против часовой стрелки (`N → W → S → E → N`);
- `'TOGGLE_PEN'` — переключение режима пера (`penDown`). Если перо опускается, текущая координата добавляется в `trail`;
- `'CLEAR_TRAIL'` — очистка нарисованного следа (пустой массив `trail`);
- `'FORWARD'` — шаг на 1 клетку вперёд по текущему направлению `direction` с учётом границ поля;
- `'BACKWARD'` — шаг на 1 клетку назад вдоль направления `direction`.

**Функция `getView(state)`**
Принимает текущее состояние и возвращает объект данных для рендерера:
- `grid` — двумерная матрица символов (массив строк размером `height` на `width`);
- `x`, `y`, `direction`, `penDown`, `stepsCount` — как в `state`.

**Правила построения `grid`:**
- Изначально матрица `height` на `width` заполнена пробелами `' '`;
- Для каждой координаты из `state.trail` в матрицу ставится символ точки `'.'`;
- В ячейку с текущими координатами черепашки `[y][x]` ставится иконка направления взгляда:
  - `'N'` ➔ `'▲'`
  - `'E'` ➔ `'►'`
  - `'S'` ➔ `'▼'`
  - `'W'` ➔ `'◄'`

### Термины урока

**kind:** `text`

Пройдись по понятиям урока. Убедись, что ты можешь объяснить каждое из них своими словами.

**Термины:**
* **Индексация матрицы (Row-Major Order `grid[y][x]`)** — стандарт адресации двумерных массивов, где первый индекс указывает на номер строки (вертикальная координата Y), а второй — на номер столбца (горизонтальная координата X).
* **Экранные координаты** — система координат в графических интерфейсах, где точка отсчёта `(0, 0)` находится в верхнем левом углу, ось X направлена вправо, а ось Y — вниз.
* **Инвариант состояния (State Invariant)** — гарантированное правило целостности данных, соблюдаемое при любых изменениях (координаты объекта всегда находятся в пределах поля `[0, width - 1]` и `[0, height - 1]`).
* **Клампинг (Clamping)** — программное ограничение числового значения заданным допустимым диапазоном `[min, max]`, предотвращающее выход за границы массивов.
* **Вектор направления (Direction Vector)** — представление движения парой числовых смещений `{ dx, dy }`, избавляющее логику от условных операторов `switch/case` при вычислении новой позиции.
* **Проекция состояния (State Projection / `getView`)** — чистая трансформация внутреннего состояния объекта в структуру, удобную для отображения рендерером, без мутации оригинального `state`.
* **Иммутабельное обновление** — создание нового объекта состояния через оператор расширения (`{ ...state, ... }`) вместо прямой мутации свойств исходного объекта.
* **Изолированное тестирование домена** — тестирование бизнес-логики без моков файловой системы, таймеров и терминала благодаря чистоте функций `createState` и `update`.
