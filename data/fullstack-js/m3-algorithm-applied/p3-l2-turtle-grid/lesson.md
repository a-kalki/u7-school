# Первая игра: Черепашка на сетке (PR 1)

**Краткое содержание:**
Переходим к первой самостоятельной практической разработке в проекте «Аркада». Наша задача — оживить классического робота-исполнителя: «Черепашку», которая перемещается по двумерной сетке, слушается команд игрока, поворачивается во все стороны света и рисует траекторию движения пером. Мы разбираем работу с координатами в 2D-матрицах, управление направлением, инварианты границ поля и чистое состояние. Вы получаете готовый рендерер и файл запуска, самостоятельно реализуете модуль логики `turtle.js`, покрываете его тестами и сдаёте первый Pull Request проекта ментору.

**Время:** ~35 мин

**Основные темы:**
- Двумерные координаты в программировании: экранная система координат (Y вниз, X вправо)
- Векторы направления: 4 стороны света (Север, Восток, Юг, Запад)
- Состояние исполнителя: координаты `x`, `y`, угол направления `dir`, флаг пера `penDown`
- Матрица следов: хранение пройденного пути без мутации исходных данных
- Ограничение границ (clamping): безопасное перемещение без падений за пределы сетки
- Разделение обязанностей: почему рендерер не решает, куда пойти черепашке
- Тестирование игровой логики: изоляция функций от экрана с помощью `bun test`
- Процесс сдачи PR 1: ветвление git, оформление описания и критерии приёмки ментором

**Термины:**
* **Экранные координаты** — система координат в компьютерной графике, где точка `(0, 0)` находится в верхнем левом углу, ось X направлена вправо, а ось Y — вниз.
* **Исполнитель (Agent / Turtle)** — управляемый объект на поле, обладающий положением в пространстве, направлением взгляда и набором допустимых команд.
* **Инвариант границ (Boundary Invariant)** — правило целостности мира, гарантирующее, что координаты объекта никогда не выходят за диапазон `[0, width - 1]` и `[0, height - 1]`.
* **След (Trail)** — история посещённых ячеек игрового поля, сохраняемая при включённом пере рисования.
* **Нормализация направления (Orientation)** — циклическое переключение сторон света (N -> E -> S -> W) при поворотах на 90 градусов.
* **Матрица поля (Grid Matrix)** — массив массивов `array[y][x]`, представляющий двумерную структуру игрового пространства.
* **Pull Request (PR)** — предложение изменений в кодовую базу, отправляемое на проверку старшему разработчику (ментору).

### Концепция игры: Черепашка на координатной сетке

«Черепашка» (Turtle Graphics) — одна из фундаментальных концепций в обучении программированию, созданная Сеймуром Пейпертом в языке Logo. Черепашка — это маленький виртуальный робот на клетчатом поле, который умеет выполнять базовые команды:
1. Шагать вперёд по текущему направлению;
2. Шагать назад;
3. Поворачивать на 90° налево или направо;
4. Опускать и поднимать перо для рисования следа;
5. Стирать нарисованное.

В нашем проекте поле представляет собой сетку 10×10 клеток. Сама Черепашка обозначается стрелкой в зависимости от направления:
- `^` — смотрит на Север (вверх, уменьшение Y);
- `>` — смотрит на Восток (вправо, увеличение X);
- `v` — смотрит на Юг (вниз, увеличение Y);
- `<` — смотрит на Запад (влево, уменьшение X).

Когда перо опущено (`penDown: true`), каждая ячейка, где побывала Черепашка, помечается точкой `.` или символом следа. Когда перо поднято, Черепашка перемещается, не оставляя меток.

### Экранная система координат и стороны света

В математике ось Y обычно направлена снизу вверх. Однако в компьютерных терминалах и графических библиотеках всё устроено иначе:
- Начало координат `(x = 0, y = 0)` — это **самый верхний левый угол**.
- Ось `x` идёт слева направо (от `0` до `width - 1`).
- Ось `y` идёт **сверху вниз** (от `0` до `height - 1`).

Поэтому смещение на один шаг при разных сторонах света выглядит так:

| Сторона света | Обозначение | Изменение X (`dx`) | Изменение Y (`dy`) | Символ |
|---|---|---|---|---|
| Север (North) | `'N'` | `0` | `-1` (вверх) | `^` |
| Восток (East) | `'E'` | `+1` (вправо) | `0` | `>` |
| Юг (South) | `'S'` | `0` | `+1` (вниз) | `v` |
| Запад (West) | `'W'` | `-1` (влево) | `0` | `<` |

#### Циклический поворот сторон света
Стороны света упорядочены по часовой стрелке: `['N', 'E', 'S', 'W']`.
- Поворот **направо** (по часовой стрелке): переходит к следующему индексу в массиве. После `'W'` (индекс 3) мы снова возвращаемся к `'N'` (индекс 0) через оператор остатка от деления: `(currentIndex + 1) % 4`.
- Поворот **налево** (против часовой стрелки): переходит к предыдущему индексу: `(currentIndex + 3) % 4`.

### Состояние игры (`State`)

В соответствии с правилом нашего трека, мы не создаём классы `class Turtle`. Состояние — это обычный легковесный объект:

```javascript
{
  width: 10,                 // ширина поля
  height: 10,                // высота поля
  x: 4,                      // текущая колонка Черепашки (0..9)
  y: 4,                      // текущая строка Черепашки (0..9)
  dir: 'N',                  // текущее направление: 'N' | 'E' | 'S' | 'W'
  penDown: true,             // опущен ли инструмент рисования
  trail: [                   // матрица 10x10 булевых флагов (или символов)
    [false, false, ...],
    ...
  ],
  stepsCount: 0              // счётчик выполненных перемещений
}
```

### Контракт функций модуля `games/turtle/turtle.js`

Ваша главная задача в этом уроке — создать файл `games/turtle/turtle.js` со следующими экспортируемыми функциями:

#### 1. `createState(options = {})`
Инициализирует и возвращает начальный объект состояния:
- По умолчанию размер поля `width = 10`, `height = 10`;
- Стартовая позиция по центру: `x = Math.floor(width / 2)`, `y = Math.floor(height / 2)`;
- Направление по умолчанию: `'N'`;
- Перо опущено: `penDown = true`;
- Матрица `trail`: пустая сетка `height × width`, заполненная `false`. В стартовой клетке, если перо опущено, сразу ставится `true`.

#### 2. `update(state, action)`
Принимает текущее состояние и объект действия, возвращает обновлённое состояние. Обрабатывает следующие типы действий:
- `{ type: 'MOVE_FORWARD' }` (нажатия клавиш `w` или `Up`):
  - Вычисляет новые координаты `nextX = state.x + dx`, `nextY = state.y + dy`.
  - Проверяет границы поля: `nextX` должен быть в пределах от `0` до `width - 1`, а `nextY` — от `0` до `height - 1`. Если шаг приводит к выходу за стену — Черепашка остаётся на месте!
  - Если перемещение произошло и `penDown === true`, отмечает новую клетку в матрице `trail`.
- `{ type: 'MOVE_BACKWARD' }` (клавиши `s` или `Down`):
  - Шаг назад без смены направления: координаты меняются в обратную сторону (`-dx`, `-dy`) с проверкой границ.
- `{ type: 'ROTATE_LEFT' }` (клавиши `a` или `Left`):
  - Поворачивает направление на 90° против часовой стрелки (`N -> W -> S -> E -> N`).
- `{ type: 'ROTATE_RIGHT' }` (клавиши `d` или `Right`):
  - Поворачивает направление на 90° по часовой стрелке (`N -> E -> S -> W -> N`).
- `{ type: 'TOGGLE_PEN' }` (клавиша Пробел):
  - Переключает режим пера: если было опущено — поднимает, если поднято — опускает.
- `{ type: 'CLEAR' }` (клавиша `c`):
  - Очищает все точки нарисованного следа в матрице `trail`.

#### 3. `getView(state)`
Формирует проекцию данных для рендерера:
```javascript
{
  title: 'ЧЕРЕПАШКА НА СЕТКЕ',
  grid: [ /* двумерный массив символов height x width */ ],
  stats: {
    coords: `(${state.x}, ${state.y})`,
    direction: state.dir,
    pen: state.penDown ? 'ОПУЩЕНО [РИСУЕТ]' : 'ПОДНЯТО',
    steps: state.stepsCount,
  },
  instructions: 'WASD / Стрелки: движение | Пробел: перо | C: очистка | Q: выход'
}
```

В двумерном массиве `grid`:
- Пустая клетка обозначается пробелом `' '`;
- След пройденного пути — символом `'.'`;
- Текущая позиция Черепашки — стрелочкой `'^'`, `'>'`, `'v'` или `'<'`.

### Тестирование логики через `bun test`

Игры тестируются очень легко, когда логика отделена от рендеринга! Поскольку функции `createState` и `update` чистые, вам не нужно эмулировать клавиатуру или терминал. Достаточно проверить, как меняется объект состояния:

```javascript
// games/turtle/turtle.test.js
import { describe, expect, it } from 'bun:test';
import { createState, update } from './turtle.js';

describe('Черепашка на сетке', () => {
  it('поворачивается направо', () => {
    let state = createState({ width: 10, height: 10 });
    expect(state.dir).toBe('N');

    state = update(state, { type: 'ROTATE_RIGHT' });
    expect(state.dir).toBe('E');

    state = update(state, { type: 'ROTATE_RIGHT' });
    expect(state.dir).toBe('S');
  });

  it('не выходит за верхнюю границу поля', () => {
    let state = createState({ width: 5, height: 5 });
    // переместим на самый верх y = 0
    state.y = 0;
    state.dir = 'N';

    const nextState = update(state, { type: 'MOVE_FORWARD' });
    expect(nextState.y).toBe(0); // осталась на месте
  });
});
```

Для запуска тестов используйте команду:
```bash
bun test games/turtle/
```
