# Проект 1: Пошаговая игра (PR 2) — краткая выжимка

- Во второй практической задаче «Аркады» реализуем классическую пошаговую игру на выбор без таймеров и тиков реального времени: состояние мира меняется только при нажатии клавиши игроком.
- Студент выбирает одну игру из четырёх:
  - **«2048»** (матрица 4×4, сдвиг и схлопывание одинаковых чисел через фильтрацию нулей, подсчёт очков);
  - **«Сокобан»** (кладовщик толкает ящики к целям, проверка препятствий и двойных коллизий «ящик-ящик» и «ящик-стена»);
  - **«Сапёр»** (курсорное управление, подсчёт мин у 8 соседей, волновой алгоритм каскадного раскрытия пустых зон через очередь BFS);
  - **«Крестики-нолики 3×3 / Четыре в ряд»** (два игрока, лучевое сканирование победных линий по 4 направлениям).
- Готовая инфраструктура: универсальный модуль `render/grid.js` предоставляет функции `renderGrid`, `renderNumberGrid` и готовые адаптеры клавиш `createDirectionAdapter`, `cursorActionAdapter`.
- Взаимодействие с ментором:
  1. Студент выбирает игру и запрашивает пакет у ментора в чате;
  2. Ментор выдаёт ТЗ с контрактами функций, раннер `run.js` и базовые тесты;
  3. Студент создаёт ветку `feature/<game>`, реализует чистую логику в `games/<game>/<game>.js`, пишет тесты и проверяет запуск через `bun games/<game>/run.js`;
  4. Студент открывает **Pull Request 2 (PR 2)** и проходит ревью у ментора.
- Внимание на ревью: чистота функций, декомпозиция сложных алгоритмов, краевые случаи в тестах, отсутствие ООП-классов.
