# Знакомство с Аркадой: терминал, движок и Виселица — краткая выжимка

- В проекте «Аркада» создаём интерактивные игры для терминала (TUI) на чистом JavaScript и среде выполнения Bun, без сторонних npm-библиотек и без ООП.
- Терминал превращается в живой графический холст с помощью ANSI Escape-последовательностей: альтернативный экран (`\x1b[?1049h`), скрытие курсора (`\x1b[?25l`) и возврат в начало кадра (`\x1b[H`) предотвращают мерцание без медленного `console.clear()`.
- Сырой режим ввода (Raw mode через `process.stdin.setRawMode(true)`) передаёт нажатия клавиш мгновенно по одному символу, не дожидаясь нажатия клавиши Enter.
- Архитектура проекта строго разделена на 3 независимых слоя:
  1. **Игровое ядро (`engine.js`)** — инфраструктура ввода-вывода: управление терминалом, обработка системных клавиш выхода (`Ctrl+C`, `q`) и рестарта (`r`), таймер тиков;
  2. **Адаптер ввода и Рендерер (`render/`)** — перевод сырых байтов клавиш в доменные события (`Action`) и отрисовка данных игры (`View`) в красивый многострочный псевдографический кадр;
  3. **Логика игры (`games/`)** — чистые функции без классов: `createState()`, `update(state, action)`, `getView(state)`.
- Точка входа в игру — компактный раннер `run.js`, который импортирует ядро, рендер и логику, связывая их воедино.
- Демо-игра «Виселица» (`games/hangman/`) служит готовым эталоном:
  - Словарь терминов курса по алгоритмам закодирован в Base64 (`words.js`), поддерживает русский и английский языки;
  - Переключение языка раунда выполняется клавишей `Tab`, подтверждение нового раунда после окончания — клавишей `Enter` или `Пробел`;
  - Логика проверяется автоматическими тестами `bun test games/hangman/`.
- Прохождение проекта строится по лестнице роста самостоятельности из трёх Pull Request:
  - Урок 1: Знакомство, настройка окружения и демо «Виселица» (коммит в `main` без PR);
  - Урок 2: Первая игра «Черепашка на сетке» (PR 1);
  - Урок 3: Пошаговая игра на выбор (PR 2);
  - Урок 4: Игра реального времени на тиках (PR 3);
  - Урок 5: Бонусный творческий уровень.
