# Бонусный уровень: Своя игра — краткая выжимка

- Бонусный уровень «Аркады» — открытая творческая мастерская для разработки собственной игры любого жанра на созданном фундаменте.
- Готовый каркас проекта предоставляет:
  - Игровое ядро `engine.js` (поддержка пошагового режима и тиков реального времени `tickRateMs`);
  - Универсальный TUI модуль сетки `tui/grid.js` с готовыми рамками и адаптерами стрелок;
  - Чистую функциональную архитектуру без ООП (`createState`, `update`, `getView`).
- Каталог вдохновляющих идей для терминала:
  - «Тетрис» (повороты тетрамино, удаление заполненных линий);
  - Консольный Roguelike (процедурные комнаты, туман войны, AI преследования);
  - «Арканоид / Понг» (векторы отражения мяча от стен и ракетки);
  - «Жизнь» Конвея (симулятор клеточного автомата с курсорным редактором).
- Инструменты расширения TUI:
  - Сохранение таблицы рекордов в файл через API среды `Bun.file` и `Bun.write`;
  - Звуковые эффекты через терминальный колокольчик `\x07` (ASCII Bell);
  - ANSI-цвета (`\x1b[32m`, `\x1b[31m` и др.) для подсветки объектов и статусов.
- Оформление в портфолио на GitHub: запись экрана через asciinema или GIF-анимация, подробный `README.md` со схемой архитектуры и команда запуска в одну строчку.
- Сдача по Git-flow: открываем рабочую ветку `feature/own-game` в начале урока от актуального `main`, разрабатываем игру, ТЗ и тесты строго в ней, коммитим и открываем финальный бонусный Pull Request в `main` на peer-review сокурсникам.
