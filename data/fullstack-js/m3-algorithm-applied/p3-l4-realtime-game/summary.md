# Проект: Игра реального времени на тиках (PR) — краткая выжимка

- В третьем практическом проекте «Аркады» переходим от пошаговой механики к играм реального времени на игровых тиках (Game Ticks).
- Параметр `tickRateMs` в `engine.js` запускает периодическую отправку события `{ type: 'TICK' }` в функцию `update(state, event)`.
- Студент выходит на новый уровень самостоятельности: **с нуля создаёт файл точки входа `run.js` как сборщик слоёв**, осознанно выбирая из каталога Слоя 2 подходящий рендерер и адаптер ввода, связывая их с ядром `engine.js` и настраивая ритм тиков `tickRateMs`.
- Игры на выбор:
  - **«Змейка» (Snake):** очередь координат тела `FIFO`, движение головы на каждом тике, наращивание длины при поедании еды, защита от мгновенного разворота на 180° через буфер намерения ввода (`nextDir`), выбор свободной клетки для генерации еды;
  - **«Космический уворачивальщик» (Space Dodger):** корабль внизу экрана, непрерывное падение массива метеоритов сверху вниз, удаление вышедших за экран объектов с начислением очков, проверка столкновений.
- Тестирование игр реального времени через `bun test` остаётся синхронным и детерминированным: события `{ type: 'TICK' }` передаются в функцию `update` напрямую без задержек `setTimeout`.
- Сдача по Git-flow: открываем ветку `feature/<game>` в начале урока от актуального `main`, собираем раннер `run.js`, пишем логику и тесты тиков/коллизий строго в ней, коммитим и открываем Pull Request в `main` для peer-review сокурсниками.
