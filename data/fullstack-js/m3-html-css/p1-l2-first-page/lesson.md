# Первая страница: структура HTML-документа

**Краткое содержание:**
Каркас, который есть у каждой страницы в мире: `<!DOCTYPE html>`, `<html>`, `<head>` с метаданными и `<body>` с видимым содержимым. Зачем нужны `meta charset` (кириллица!), `title` и `lang`. Создаём репозиторий проекта, первый файл `index.html` — и делаем первый настоящий шаг визитки: название компании в браузере.

### Подробный конспект

#### 1. Скелет страницы

Каждая HTML-страница начинается одинаково — с каркаса (boilerplate):

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Название страницы</title>
</head>
<body>
  <!-- всё видимое содержимое здесь -->
</body>
</html>
```

Этот каркас называют **boilerplate** — заготовка, которую копируют в каждый новый проект.

> ты можешь сохранить эту структуру в файл: `html-template.html` чтобы всегда иметь ее под рукой

#### 2. За что отвечает каждая часть

- `<!DOCTYPE html>` — «делай по современным стандартам». Всегда первая строка, всегда такая.
- `<html lang="ru">` — корневой элемент; `lang="ru"` сообщает: страница на русском. Это важно для экранных дикторов (доступность) и поисковиков.
- `<head>` — метаданные: информация *о* странице. На самой странице не отображается.
- `<body>` — всё видимое: текст, списки, таблицы.

**Про метаданные в head:**

- `<meta charset="UTF-8">` — кодировка. Русские буквы живут именно благодаря ей.
- `<meta name="viewport" ...>` — правила масштабирования на экранах разной ширины. Пока вставляй «как есть».
- `<title>` — заголовок вкладки браузера.

**Сделай:** (эксперимент на потом) когда создашь файл — временно удали строку с `charset` и обнови страницу. Посмотри, что стало с русскими буквами. Потом верни строку на место.

**Получишь:** вместо кириллицы — «крякозябры» вида `РўРћРћ`. Вот зачем нужна кодировка.

#### 3. Первый страничка и подключение стилей

CSS живёт в отдельном файле и подключается в `<head>`:

```html
<link rel="stylesheet" href="styles.css">
```

`href` — путь к файлу. Наши файлы лежат рядом, поэтому путь короткий.

Задание:
1. Создай временный файл в любой папке: `hello-world.html`, рядом файл `hello-world.css`;
2. Добавь в нее бойлерплейт, шаблон html;
3. Подключи `css` файл (пока он пустой);
4. Добавь в раздел `body` (между тегами `<body>` и `</body>`) код ниже:

```html
  <p>Привет, Мир!</p>
```

Сохрани и открой файл в браузере (двойной клик на файле или в браузере `ctrl+o`. Ты должен увидеть на странице свое приветствие.

Добавь в `css` файл строки:
```css
body {
  color: red;
}
```

Сохрани файл, и обнови страницу (`F5`) в браузере. Твоя страница должна стать красной. Как это работает мы будем изучать и узнавать в следующих уроках и проектах.

Можешь дальше поэксперементировать, например удалить из файла мету: `charset`.

Как закончишь можешь удалить файл или переместить в папку проекта которую мы создадим в следующем уроке.

#### 4. Рабочий цикл

Создал/изменил файл → **сохранил** (`Ctrl+S`) → обновил вкладку браузера (`F5`). И так по кругу — десятки раз за урок. Привыкай сразу: не сохранил — браузер покажет старое, и ты будешь искать несуществующую ошибку.

### Шаг визитки: скелет и название

Пора завести проект. Создай репозиторий `payroll-portal` (как в модулях 1–2: `git init`, связь с github репозиторием). Добавь файл `README.md`, `.gitignore` по необходимости. В общем настрой репозиторий. Все эти файлы закомить прямо в основной ветке `main` и сделай пуш в удаленный репозиторий.

Создай ветку для первого проекта: `p1-visit-card`.

Создай два файла:

```
payroll-portal/
  index.html   ← создаём сейчас
  styles.css   ← пока пустой, с комментарием /* стили появятся в проекте 2 */
```

**Сделай:** создай `index.html` с каркасом из начала урока. Сделай три изменения: в `title` — `ТОО «Дала Технолоджи»`; внутри `<body>` — заголовок `<h1>ТОО «Дала Технолоджи»</h1>`; не забудь `<link>` на `styles.css`. Открой `index.html` в браузере.

**Получишь:** вкладку «ТОО «Дала Технолоджи»» и крупный заголовок на странице. Страница «голая» — так и должно быть.

**Сделай:** включи «выбрать элемент» (`Ctrl+Shift+C`), кликни по заголовку прямо на странице — он откроется в дереве Elements. Поменяй его текст прямо в браузере на что-нибудь смешное, потом обнови страницу.

**Получишь:** убедился, что дерево в DevTools — это твоя страница; и что правки в DevTools не сохраняются в файл.

**Сделай:** перейди в ветку  (`git checkout -b p1-visit-card`): весь проект 1 будет жить в ней, а в конце отправится на код-ревью через pull request. Закоммить: `git add -A && git commit -m "p1: document skeleton"`.

### Термины урока

- **boilerplate** — от англ. `boiler` — «котёл» + `plate` — «пластина»: из полиграфии: пластины для многократной печати одинакового текста; каркас-заготовка, которую копируют в каждый проект
- **тег** — от англ. `tag` — «ярлык, бирка»: пометка вида `<p>`, описывающая, что это за фрагмент
- **атрибут** — от лат. `attributum` — «приписанное»: пара `имя="значение"` внутри открывающего тега
- **метаданные** — от греч. `meta` — «о чём-то»: «данные о данных»: то, что в `<head>`, а не на странице
- **`<html>`** — от `HyperText Markup Language`: корневой элемент страницы; всё живёт внутри него
- **`<head>`** — от англ. `head` — «голова»: служебная «голова» документа: метаданные, не видимые на странице
- **`<body>`** — от англ. `body` — «тело»: видимое «тело» страницы: всё содержимое
- **`<title>`** — от англ. `title` — «название»: заголовок вкладки браузера
- **`<meta>`** — от греч. `meta` — «о»: метатеги: кодировка, масштабирование и прочее «о странице»
- **charset** — от англ. `character set` — «набор символов»: `UTF-8` — кодировка, умеющая в кириллицу
- **viewport** — от англ. `view` — «вид» + `port` — «отверстие»: «окно просмотра»: как страница масштабируется на экране
- **`<link>`** — от англ. `link` — «связь»: подключение внешнего файла, например `styles.css`
