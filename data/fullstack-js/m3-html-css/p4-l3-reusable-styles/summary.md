# Переиспользуемые стили: базовый класс и модификатор — краткая выжимка

- **Компонент** — переиспользуемый набор стилей; описывается классом и ставится на похожие элементы
- **Scope** — правило компонента не «протекает» на соседей; `.btn` точнее, чем `button`
- **Базовый класс + модификатор:** `.btn` — форма и отступы, `.btn-ghost` — отличие
- **Utility-классы** «на одно свойство»: `num` (числа вправо), `total-row` (жирный итог), `company` (приглушённый текст)
- `<strong>` в строке «Итого» заменён на класс `total-row`: роль расширяема (фон, линия), а `<strong>` умеет только жирный
- Числовые колонки — по правому краю (разряды ровные); строки ИТОГО — жирные
- `colspan="2"` в строках ИТОГО: название занимает две колонки, числовые ячейки под ними пустые
- Пустые «Премия»/«Выслуга» — длинное тире `—`
- Мини-задание: карточка-компонент с бейджем и модификатором
- Шаг портала: секция «Табель» (10 строк: месяц, сотрудник, дни) + таблица «Результата» (октябрь, итоги по отделам и предприятию)
- Данные «Результата» — эталон из concept §5.3; числа голые
- Коммит `p4: timesheet and result tables`
