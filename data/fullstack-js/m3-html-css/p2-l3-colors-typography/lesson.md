# Цвета и типографика: палитра, шрифты, читаемость

**Краткое содержание:**
Как записывают цвет и почему наш формат — hex. Контраст: почему тёмный текст на светлом — не вкусовщина, а норма читаемости. Типографика: шрифтовой стек, размеры и вес заголовков, межстрочный интервал, выравнивание чисел в таблицах. Доводим визитку до оформленного вида: палитра, шрифт, иерархия заголовков, приглушённое описание.

### Подробный конспект

#### 1. Форматы цвета

Один и тот же цвет можно записать по-разному:

```css
color: royalblue;          /* ключевое слово */
color: #2b5fd9;            /* hex: # + 6 цифр (красный/зелёный/синий) */
color: rgb(43, 95, 217);   /* те же каналы числами */
color: hsl(222, 68%, 51%); /* тон, насыщенность, светлота */
```

Наш рабочий формат — **hex**: компактен и копируется из макетов и пипетки DevTools. Свойства: `color` — цвет текста, `background-color` — фон. С ними ты уже работал в предыдущих уроках.

**Сделай:** в DevTools кликни по цветному квадратику рядом с любым `color` в Styles — откроется пипетка. Помаксимуму поиграйся с ней: возьми со страницы любой цвет (например, с фотографии).

**Получишь:** чувствуешь, как hex-значение связано с цветом? Первые две цифры — красный, потом зелёный, потом синий: `#ff0000` — чисто красный, `#000000` — чёрный, `#ffffff` — белый.

#### 2. Контраст: не вкусовщина

Текст читается, когда отличается от фона **яркостью**, а не только оттенком. Ориентир стандарта WCAG — 4.5:1. Практика:

- основной текст — тёмный на светлом: наш `#222222` на белом;
- приглушённый текст (описания) — серее основного, но не бледнее `#666666` на белом;
- белый текст — только на тёмных заливках.

**Сделай:** (эксперимент) поставь `body { color: #cccccc; }` и посмотри на абзацы. Затем попробуй `#999999`, `#666666`.

**Получишь:** `#cccccc` читать больно — текст «растворяется». `#666666` — приглушённый, но читаемый. Прищурись: нечитаемый цвет «исчезает» первым — быстрый полевой тест контраста.

#### 3. Шрифтовой стек

`font-family` — список желаемых шрифтов: браузер берёт первый доступный:

```css
font-family: "Segoe UI", Roboto, sans-serif;
```

Последним в списке всегда стоит **общее семейство** (`sans-serif` — рубленый, `serif` — с засечками): если ни один именованный не нашёлся — системный из класса. Задаётся один раз на `body` и наследуется всем (p2-l1). Правило вкуса: одно семейство на интерфейс — иерархию делают размер и вес.

**Сделай:** в `styles.css` визитки дополни `body`:

```css
body {
  background: #f4f5f7;       /* цвет заднего фона */
  color: #222222;            /* цвет шрифта */
  font-family: sans-serif;   /* семейство шрифта */
  line-height: 1.5;          /* межстрочный интервал */
  padding: 24px;             /* отступ (4 стороны) */
  margin: 0;                 /* зазор (4 стороны) */
}
```

**Получишь:** весь текст стал тёмно-серым `#222222` (наследование!), строки в абзацах дышат — интервал `1.5` умножается на размер шрифта. `margin: 0` убрал стандартный зазор браузера по краям окна, `padding` вернул воздух уже от нас.

#### 4. Размер и вес: иерархия текста

- `font-size` в px — наш юнит: просто и предсказуемо (относительные `rem`/`em` существуют, вернёмся, когда понадобится масштабирование).
- `font-weight`: `400` — обычный, `700` — жирный.
- Иерархия визитки: `h1` — 24px, `h2` — 18px, основной текст — 14–16px.

**Сделай:** допиши правила:

```css
h1 {
  font-size: 24px;
  margin: 0 0 8px;
}

h2 {
  font-size: 18px;
  margin: 24px 0 8px;
}

p {
  margin: 0;
  color: #666666;
}

ul {
  margin: 0;
  padding-left: 24px;
}
```

**Получишь:** название крупнее разделов, разделы — акцентные (цвет с p2-l1) и хорошо отделены (24px сверху, 8px снизу), описание — приглушённое, список держит отступ маркеров. У абзаца и списка мы обнулили `margin: 0`: у браузера свои вертикальные отступы у них, а зазоры у нас задают margin заголовков.

**Сделай:** (эксперимент) временно поставь `h1` и `h2` одинаковый `font-size: 20px`. Обнови.

**Получишь:** иерархия развалилась — заголовки и подзаголовки неразличимы, страница выглядит плоско. Размер — главный инструмент иерархии. Верни 24 и 18.

#### 5. Выравнивание: приём для таблиц

`text-align`: `left` / `center` / `right`. Русский текст — по левому краю. Но есть приём: **числовые колонки таблиц выравнивают по правому краю** — разряды выстраиваются, суммы сравниваются мгновенно:

```
  600000
  450000
 2400000
```

Запомни приём — применим его в проекте 4, когда в портале появятся классы для числовых ячеек.

### Термины урока

- **hex** — от англ. `hexadecimal` — «шестнадцатеричный»: `#RRGGBB`: пары цифр на красный, зелёный, синий
- **RGB** — от `Red, Green, Blue` — «красный, зелёный, синий»: цвет из трёх каналов; `#ff0000` — чисто красный
- **HSL** — от `Hue, Saturation, Lightness` — «тон, насыщенность, светлота»: цвет через тон и его яркость
- **контраст** — от лат. `contrarius` — «противоположный»: различие по яркости; без него текст нечитаем
- **WCAG** — от `Web Content Accessibility Guidelines` — «руководства по доступности веб-контента»: стандарт доступности; ориентир 4.5:1 для текста
- **`font-family`** — от англ. — «семейство шрифтов»: стек желаемых шрифтов с резервами
- **serif** — от англ. `serif` — «засечка»: шрифты с засечками (у букв «ножки»)
- **sans-serif** — от франц. `sans` — «без»: «без засечек»; наш базовый вариант
- **px** — от англ. `pixel` — сокращение от `picture element` — «элемент картинки»: пиксель — наш юнит размеров
- **`line-height`** — от англ. — «высота строки»: межстрочный интервал; множитель от размера шрифта
- **`text-align`** — от англ. `align` — «выравнивать»: выравнивание текста; числа в таблицах — вправо
