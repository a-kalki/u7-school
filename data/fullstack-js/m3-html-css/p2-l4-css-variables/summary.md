# CSS-переменные: дизайн-токены — краткая выжимка

- «Магические значения» — числа без имени, размазанные по файлу; правка = найди-замени-неошибись
- Объявление: `:root { --имя: значение; }`; использование: `var(--имя)`; в `:root` — видна везде
- Имя — по роли в дизайне: `--color-accent` ✅, `--color-blue` ❌ (значение сменится — имя соврёт)
- Набор модуля: bg, surface, text, muted, accent, border + `--space-1..4` (4/8/16/24)
- Рефакторинг на токены не меняет вид страницы — только устраняет дубли
- Главный эффект: смена токена обновляет всё, где он используется; рассинхрон невозможен
- `var(--x, запасное)` — значение по умолчанию, если переменная не объявлена
- Правило модуля: в правилах — только `var()`; сырые значения живут только в `:root`
- Токены переезжают в П3 без изменений; в П4 добавится `--color-accent-soft`
