# CSS-переменные: дизайн-токены в одном месте

**Краткое содержание:**
В `styles.css` уже десятки сырых значений — почувствуем боль «магических чисел» на своей шкуре и вылечим её CSS-переменными: палитра и шкала отступов объявляются один раз в `:root` и используются через `var()`. Рефакторим визитку на токены и проверяем главный эффект: тема меняется в одном месте.

### Подробный конспект

#### 1. Боль: магические значения

**Сделай:** посчитай: сколько раз в твоём `styles.css` встречается цвет `#f4f5f7`? А значение `24px`? (поиском по файлу: `Ctrl+F`)

**Получишь:** один и тот же цвет размазан по нескольким правилам, отступы 24px — ещё чаще. Теперь представь: дизайнер сменил оттенок фона. Тебе придётся найти и заменить каждое вхождение — и не ошибиться ни в одном. Это и есть «магические значения»: числа без имени, размноженные по файлу.

#### 2. Лекарство: переменные

CSS умеет хранить значения с именами:

```css
:root {
  --color-bg: #f4f5f7;
}

body {
  background: var(--color-bg);
}
```

- Объявление: `--имя: значение;` в `:root` — корне документа, тогда переменная видна везде.
- Использование: `var(--имя)` — браузер подставит значение.

#### 3. Имена по роли, а не по значению

- ✅ `--color-accent` — «акцентный цвет»: смена акцента не сломает имя.
- ❌ `--color-blue` — если «blue» станет зелёным, имя начнёт врать.

Имя должно говорить о **роли значения в дизайне**, а не о самом значении.

#### 4. Рефакторим визитку на токены

**Сделай:** объяви в начале `styles.css` полный набор:

```css
:root {
  --color-bg: #f4f5f7;      /* фон страницы */
  --color-surface: #ffffff; /* поверхность: карточка */
  --color-text: #222222;    /* основной текст */
  --color-muted: #666666;   /* приглушённый текст */
  --color-accent: #2b5fd9;  /* акцент: заголовки */
  --color-border: #d9dce3;  /* границы */

  --space-1: 4px;
  --space-2: 8px;
  --space-3: 16px;
  --space-4: 24px;
}
```

**Сделай:** замени в правилах каждое сырые значение на `var()`: `#f4f5f7` → `var(--color-bg)`, `24px` → `var(--space-4)`, `8px` → `var(--space-2)` и так далее. Пройди поиском по файлу: не осталось ли сырых цветов вне `:root`?

**Получишь:** страница выглядит **точно так же** — это рефакторинг, поведение не меняется. Но теперь каждое значение живёт в одном месте с именем-ролью.

#### 5. Главный эффект: тема в одном месте

**Сделай:** поменяй акцент: `--color-accent: #b30000;`. Обнови страницу.

**Получишь:** оба заголовка `h2` покраснели от одной строки. Верни `#2b5fd9`.

**Сделай:** (эксперимент) поменяй `--space-3: 16px` на `20px` и найди на странице, где этот отступ живёт. Потом верни.

**Получишь:** у шкалы отступов на визитке пока одно применение, но механизм ясен: изменение токена — и всё, что его использует, обновилось разом. Рассинхрон цветов и отступов становится невозможным физически: пока значения в правилах написаны руками, они рано или поздно разъезжаются; токены этого не позволяют.

#### 6. Что дальше по токенам

Этот набор — дизайн-система всего портала: в проекте 3 переедет в каркас приложения без изменений, в проекте 4 к нему добавится ещё один цвет — мягкий акцент для активного пункта меню. И правило модуля на будущее: **в правилах — только `var()`, сырые цвета и отступы запрещены** (кроме самого `:root`).

### Термины урока

- **переменная** — от лат. `variabilis` — «переменчивый»: именованная ячейка со значением; меняется в одном месте
- **custom property** — от англ. `custom` — «свой, собственный» + `property` — «свойство»: официальное имя CSS-переменных
- **`:root`** — от англ. `root` — «корень»: корень документа; переменные здесь видны всей странице
- **`var()`** — сокращение от англ. `variable` — «переменная»: подстановка значения переменной
- **токен** — от англ. `token` — «жетон, знак»: именованное дизайн-решение: цвет или отступ с ролью вместо сырого значения
- **магические значения** — от англ. `magic values` — «волшебные числа»: сырые числа без имени, размазанные по файлу
- **fallback** — от англ. `fallback` — «запасной план»: значение по умолчанию: `var(--x, синий)`
- **рефакторинг** — от англ. `refactoring` — «перепланировка»: меняем устройство кода, не меняя поведение; страница выглядит так же
