# Шаги урока: Поток документа: block, inline, inline-block

---

### Теория урока на w3schools

**kind:** `text`

До сих пор элементы сами занимали место на странице: заголовки вставали друг под другом, слова — в строку. Пора понять **почему** так происходит. Это называется **поток документа** (normal flow) — автоматическая раскладка браузера. Без него flexbox и grid из следующих уроков покажутся магией.

Прочитай страницу курса:

- [HTML & CSS: Layout Fundamentals](https://www.w3schools.com/htmlcss/htmlcss_layout_flow.asp)

Обрати внимание на три типа поведения элементов и на свойство `display`.

---

### Поток по умолчанию: три типа поведения

**kind:** `text`

Каждый тег ведёт себя одним из трёх способов:

- **блочные (block)** — `h1`, `p`, `ul`, `table`, `div`: занимают всю ширину, начинаются с новой строки, уважают вертикальные `margin`;
- **строчные (inline)** — `strong`, `em`, `span`, `a`: живут внутри строки, ширина — по содержимому; `width` и `height` им задать нельзя, а вертикальные `margin` не работают;
- **строчно-блочные (inline-block)** — стоят в строке, как строчные, но позволяют задать ширину и высоту, как блочные.

**Сделай:** открой песочницу (файлы `sandbox.html` + `sandbox.css` из проекта 2 или онлайн-редактор) и замени содержимое на:

```html
<body>
  <div class="block">Первый div</div>
  <div class="block">Второй div</div>
  <span class="inline">Первый span</span>
  <span class="inline">Второй span</span>
</body>
```

```css
.block {
  background: #e8eefb;
  margin: 8px 0;
}

.inline {
  background: #ffe0b2;
}
```

**Получишь:** каждый `div` занял всю ширину и встал на свою строку — они блочные. Оба `span` уместились в одну строку, а фон «обнял» только текст — они строчные.

Знакомые слова из p1-l3: тогда деление на блочные и строчные объясняло переносы строк, теперь оно закладывает фундамент раскладки.

### Строчным нельзя задать размер

**kind:** `text`

**Сделай:** добавь в правило `.inline` ширину и высоту:

```css
.inline {
  background: #ffe0b2;
  width: 200px;
  height: 60px;
}
```

**Получишь:** ничего не изменилось. Строчный элемент игнорирует `width` и `height` — его размер задаёт текст. Это частая ловушка новичка: свойство будто «не работает».

---

### inline-block: размер и строка разом

**kind:** `text`

**Сделай:** добавь к `.inline` одну строку:

```css
.inline {
  display: inline-block;
  background: #ffe0b2;
  width: 200px;
  height: 60px;
}
```

**Получишь:** оба `span` стали прямоугольниками 200×60 и всё ещё стоят в одной строке. `inline-block` — компромисс: ведут себя как слова, но размерятся как блоки.

### Свойство display управляет потоком

**kind:** `text`

`display` — переключатель типа элемента:

| Значение | Поведение |
|---|---|
| `block` | блочный: вся ширина, новая строка |
| `inline` | строчный: внутри строки, без размеров |
| `inline-block` | в строке, но с размерами |
| `none` | элемента нет: убран из потока полностью |

**Сделай:** по очереди примени к `.block` `display: inline`, а к `.inline` — `display: block`.

**Получишь:** поведение меняется на противоположное. Свойство `display` переписывает то, что заложено в теге.

**Сделай:** (эксперимент) дай второму `div` `display: none`.

**Получишь:** элемент исчез, а соседи сомкнулись на его месте. `display: none` убирает элемент не только из вида, но и от скринридеров — пользуйся осознанно.

### float и z-index — легаси

**kind:** `text`

Исторически раскладку делали через `float` — «обтекание»: блок вынимался из потока и текст обтекал его. Так верстали целые сайты, и в старом коде ты это встретишь. Но у float много побочных эффектов, и современный способ — flexbox и grid.

`position` и `z-index` (наложение слоёв) — тоже отдельная тема, которую мы лишь упомянем.

Договоримся на весь модуль: раскладку делаем **flexbox и grid**, позиционированием и float не пользуемся.

### Термины урока

**kind:** `text`

- **normal flow** — от англ. `normal` — «обычный» + `flow` — «поток»: автоматическая раскладка элементов браузером
- **block** — от англ. `block` — «блок»: элемент на всю ширину, с новой строки
- **inline** — от англ. `inline` — «в строке»: элемент внутри строки, без своих размеров
- **inline-block** — от англ. `inline` — «в строке» + `block` — «блок»: гибрид: стоит в строке, но размеряется
- **`display`** — от англ. `display` — «отображение»: свойство, задающее тип поведения элемента
- **float** — от англ. `float` — «плавать»: старое свойство обтекания; не используем
- **z-index** — от англ. `z` (ось глубины) + `index` — «указатель»: порядок наложения слоёв; не наш инструмент
- **layout** — от англ. `layout` — «раскладка, макет»: то, как элементы расположены на странице
