# Формы: input, select, label, button — краткая выжимка

- Поля собираются в `<form>`: `action`/`method` — куда и как отправлять (в М3 не отправляем)
- `label for="X"` + `input id="X"` связывают подпись и поле: клик по подписи → фокус; нужно для доступности
- `type` задаёт вид поля: `text`, `email`, `number`, `date`, `password`; `required` — обязательность
- `select` + `option` — выпадающий список; `selected` — вариант по умолчанию
- Кнопка — `<button type="submit">`
- Встроенная валидация: `:valid` / `:invalid`; группировка — `fieldset` + `legend`; серверная проверка всё равно нужна
- Мини-задание: «Анкета нового сотрудника» в песочнице (вне приложения)
- Шаг портала: ветка `p4-portal` + селекты-фильтры в «Результате» (месяц: октябрь; отдел: все)
- Нормы селектов: отступы 4×8px, граница 1px; подписи приглушённые 14px
- Шаг портала: секция «Календарь» — компания + «Сентябрь 2026 — 21», «Октябрь 2026 — 22»
- Коммит `p4: filters and calendar section`
