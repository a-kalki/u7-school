# Проект 2: оформленная визитка — краткая выжимка

- Стили накоплены по ходу уроков p2-l1…p2-l4; в проектном уроке — таблица и сдача
- Таблица: границы 1px у всех ячеек, слитые в одну линию (border-collapse), ячейки 4×8, текст слева, thead на фоне страницы — готовый CSS приведён целиком в конспекте
- «Итого» уже жирный через `<strong>` — стили не нужны
- Сверка с растром `p2-visit-card-styled` по зонам: страница → карточка → h1 → h2 → описание → список → таблица
- Работы визуально сопоставимы, не идентичны — вариативность применения норм обсуждается на ревью
- Чек-лист: box-sizing → :root с токенами → ноль сырых значений вне :root (поиск `#` и `px`)
- Проверка каскада: DevTools → Styles — стили только из styles.css
- Git: ветка `p2-styling` (с первого урока проекта), коммиты по шагам, финальный `p2: table and ready for review`, PR → код-ревью студентами; 2 апрува → мердж
- Токены переезжают в П3; содержимое визитки (название, таблица) — в портал
