# Flexbox: строка, выравнивание, gap — краткая выжимка

- Flexbox раскладывает элементы в одном направлении; включается на родителе: `display: flex`
- Родитель — flex-контейнер, дети — flex-элементы; дети ужимаются по содержимому
- Две оси: **главная** (вдоль элементов) и **поперечная** (перпендикуляр); направление задаёт `flex-direction`: `row` / `column` (+ развёрнутые)
- `justify-content` — выравнивание вдоль главной оси (`space-between`, `center`, …)
- `align-items` — выравнивание по поперечной оси (`center` — вертикальное центрирование одной строкой)
- `gap` — ровный зазор между элементами; удобнее margin у каждого
- `flex` у детей: `grow shrink basis`; `flex: 1` — растянуться, `flex: 0 0 120px` — фиксированная ширина
- Приём «распорки»: пустой `flex: 1` прижимает остальных к краю — так строят шапку
- `flex-wrap: wrap` — перенос; `order` — визуальный порядок без правки разметки
- Мини-задание: панель «лого + название + кнопка»; имя компании — `<h1>`
- Шаг портала: собираем шапку — `.logo-mark` (квадрат 32×32 с буквой «Д», цвет из токенов) + `<h1>` в flex-строку (padding 8×24, разделитель снизу 1px)
