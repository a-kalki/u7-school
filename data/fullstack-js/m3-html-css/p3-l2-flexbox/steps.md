# Шаги урока: Flexbox: строка, выравнивание, gap

---

### Теория урока на w3schools

**kind:** `text`

Поток документа расставляет элементы предсказуемо, но выстроить их **в ряд** и раздать им пространство он не умеет: блочные элементы упрямо встают друг под друга. Flexbox решает это: он раскладывает элементы в одном направлении и управляет их выравниванием.

Прочитай страницу курса:

- [HTML & CSS: Flexbox Layout](https://www.w3schools.com/htmlcss/htmlcss_layout_flexbox.asp)

Обрати внимание на оси (main axis / cross axis), свойства `justify-content`, `align-items` и на короткую запись `flex`.

---

### Контейнер и элементы

**kind:** `text`

Flexbox включается **на родителе**:

```css
.row {
  display: flex;
}
```

Родитель становится **flex-контейнером**, а его дети — **flex-элементами**: они выстраиваются в ряд и сами решают, как поделить место.

**Сделай:** в песочнице собери строку из трёх блоков:

```html
<div class="row">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>
```

```css
.row {
  display: flex;
  background: #e8eefb;
}

.row div {
  background: #2b5fd9;
  color: #fff;
  padding: 8px 16px;
}
```

**Получишь:** блоки встали в один ряд, но перестали растягиваться на всю ширину: включился flex и ужал их по содержимому.

---

### Две оси

**kind:** `text`

У flex-контейнера две оси:

- **главная ось (main axis)** — вдоль неё выстраиваются элементы. По умолчанию — горизонтально;
- **поперечная ось (cross axis)** — перпендикулярно главной.

Направление главной задаёт `flex-direction`: `row` (по умолчанию), `column`, а также развёрнутые `row-reverse` и `column-reverse`.

**Сделай:** добавь в `.row` правило `flex-direction: column;` и обнови.

**Получишь:** блоки встали в столбик: главная ось повернулась и потянула элементы за собой. Запомни, что «главная» и «поперечная» — понятия относительные: они меняются вместе с направлением.

---

### Выравнивание: justify-content и align-items

**kind:** `text`

- **`justify-content`** — распределяет элементы вдоль **главной** оси: `flex-start`, `center`, `flex-end`, `space-between`, `space-around`;
- **`align-items`** — выравнивает элементы по **поперечной** оси: `flex-start`, `center`, `flex-end`, `stretch`.

**Сделай:** верни `flex-direction: row` и добавь:

```css
.row {
  display: flex;
  background: #e8eefb;
  justify-content: space-between;
  align-items: center;
  height: 120px;
}
```

**Получишь:** блоки разъехались по краям (`space-between`), а по вертикали встали по центру высокого контейнера (`align-items: center`). Вертикальное центрирование, которое раньше требовало костылей, — теперь одна строка.

---

### gap: ровные зазоры

**kind:** `text`

`gap` задаёт зазор **между** элементами, не добавляя лишнего по краям:

**Сделай:** добавь в `.row` `gap: 16px;` и убери `justify-content`.

**Получишь:** ровные промежутки между блоками. Это удобнее, чем margin у каждого элемента: не нужно гасить «лишний» отступ у крайних.

---

### flex-элементы: как делят место

**kind:** `text`

Свойство `flex` пишется у **детей** и управляет их размерами: `flex: grow shrink basis` — «расти / сжиматься / базовый размер».

- `flex: 1` — все элементы растягиваются поровну на всё свободное место;
- `flex: 0 0 300px` — элемент фиксированной ширины 300px, не растёт и не сжимается;
- `flex: 2` у одного и `flex: 1` у другого — первый получит вдвое больше места.

Приём «распорки»: добавить пустой элемент с `flex: 1` — он заберёт всё свободное место и прижмёт остальные к краю.

**Сделай:** сделай так: первый блок фиксированный, второй растягивается. Пометь блоки классами:

```html
<div class="row">
  <div class="fixed">A</div>
  <div class="grow">B</div>
  <div>C</div>
</div>
```

```css
.fixed {
  flex: 0 0 120px;
}

.grow {
  flex: 1;
}
```

**Получишь:** второй блок растянулся, забрав всё свободное место. Так строят панели: слева — лого, справа — всё остальное.

---

### Перенос и порядок

**kind:** `text`

- `flex-wrap: wrap;` — разрешает элементам переноситься на новую строку, вместо того чтобы бесконечно сжиматься;
- `order` — меняет визуальный порядок, не трогая разметку (например, `order: -1` выносит элемент вперёд).

**Сделай:** (эксперимент) добавь в контейнер много элементов и `flex-wrap: wrap;` — при сужении окна они перепрыгнут на следующую строку.

### Шаг портала: собираем шапку

**kind:** `text`

Цель проекта 3 — каркас приложения, и его верхняя зона — **шапка**: логотип слева и название компании рядом. Соберём шапку в песочнице, а в p3-l4 перенесём её в портал.

**Логотип — простой:** квадрат 32×32 акцентного цвета с белой буквой «Д» (первая буква «Дала Технолоджи»).

```html
<span class="logo-mark">Д</span>
```

```css
.logo-mark {
  width: 32px;
  height: 32px;
  background: var(--color-accent);
  color: var(--color-surface);
  font-size: 18px;
  font-weight: bold;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

**Название компании** — это главный заголовок страницы, поэтому тег `<h1>`. В шапке он меньше, чем был на визитке.

**Собираем шапку — flex-строку:**

```html
<header class="header">
  <span class="logo-mark">Д</span>
  <h1>ТОО «Дала Технолоджи»</h1>
</header>
```

```css
.header {
  display: flex;
  align-items: center;
  gap: 8px;
  padding: 8px 24px;
  background: var(--color-surface);
  border-bottom: 1px solid var(--color-border);
}

.header h1 {
  margin: 0;
  font-size: 20px;
}
```

**Сделай:** собери шапку в песочнице по этому коду. В DevTools выбери `header`, `logo-mark` и `h1` — проверь размеры и заливки.

**Получишь:** готовую шапку портала: лого 32×32 и название на белой полосе с разделителем. В p3-l4 она встанет в `header` портала.

> Если захочешь векторный логотип вместо буквы-символа: тот же квадрат с буквой можно собрать лёгким SVG (`<rect>` + `<text>`) — он не мутнеет при увеличении и весит мало. Для шапки достаточно и `span`.

### Термины урока

**kind:** `text`

- **flexbox** — сокращение от `Flexible Box Layout` — «гибкая блочная раскладка»: раскладка в одном направлении
- **flex-контейнер** — родитель с `display: flex`; задаёт правила для детей
- **flex-элемент** — любой прямой ребёнок контейнера
- **main axis** — от англ. `main` — «главный» + лат. `axis` — «ось»: главная ось, вдоль которой идут элементы
- **cross axis** — от англ. `cross` — «поперечный»: ось, перпендикулярная главной
- **`flex-direction`** — от англ. — «направление flex»: `row`, `column` и развёрнутые варианты
- **`justify-content`** — от англ. `justify` — «выравнивать»: распределение вдоль главной оси
- **`align-items`** — от англ. `align` — «выравнивать»: выравнивание по поперечной оси
- **`gap`** — от англ. `gap` — «зазор»: ровный промежуток между элементами
- **`flex`** — от англ. `flexible` — «гибкий»: короткая запись `grow shrink basis`
- **toolbar** — от англ. `tool` — «инструмент» + `bar` — «полоса»: панель с элементами управления
- **SVG** — от `Scalable Vector Graphics` — «масштабируемая векторная графика»: картинка из фигур и линий, описанных разметкой (необязательный вариант лого)
- **`viewBox`** — от англ. `view` — «вид» + `box` — «рамка»: внутренняя система координат SVG, по которой рисуются фигуры
