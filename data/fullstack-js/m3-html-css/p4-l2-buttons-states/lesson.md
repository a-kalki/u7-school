# Состояния: hover, focus, active

**Краткое содержание:**
Интерфейс отвечает на действия пользователя: пункт меню подсвечивается при наведении, поле — в фокусе, кнопка нажимается. Это **состояния** элементов, и управляют ими псевдоклассы `:hover`, `:focus`, `:focus-visible`, `:active`. Стилизация кнопок и ссылок, доступность фокуса для клавиатуры. Применяем к сайдбару и фильтрам портала и наполняем секцию «Сотрудники».

### Подробный конспект

#### 1. Псевдоклассы состояний

Псевдокласс — селектор, который выбирает элемент **в особом состоянии**:

| Псевдокласс | Когда срабатывает |
|---|---|
| `:hover` | на элемент навели курсор |
| `:focus` | элемент в фокусе (клик или `Tab`) |
| `:focus-visible` | фокус, для которого браузер считает нужным показать обводку |
| `:active` | элемент нажат прямо сейчас (курсор зажат) |

#### 2. hover: отклик на наведение

**Сделай:** в песочнице собери кнопку и ссылку с общим классом `btn`: отступы 8×16px, рамка и фон — акцентные, текст белый, у ссылки `text-decoration: none`. Добавь `:hover` — чуть темнее, и `:active` — ещё темнее.

**Получишь:** кнопка темнеет при наведении и темнеет сильнее при нажатии. Ссылка получает тот же вид — приём «кнопка-ссылка»: `display` в строке, но с размерами.

#### 3. focus: состояние для клавиатуры

Фокус `:focus` приходит, когда пользователь попал в элемент с клавиатуры (клавиша `Tab`). Это критично для доступности: человек, работающий без мыши, должен **видеть**, где находится.

**Сделай:** добавь `:focus-visible` с видимой обводкой (`outline: 2px solid ...; outline-offset: 2px;`) и пройдись по элементам клавишей `Tab`.

**Получишь:** вокруг кнопки появляется видимая обводка. Никогда не убирай её (`outline: none`) без замены.

#### 4. active: момент нажатия

`:active` срабатывает, пока кнопка нажата. Часто это лишь чуть более тёмный фон — но именно он даёт ощущение, что интерфейс «слышит» нажатие.

#### 5. Плавность (по желанию)

Переход можно сгладить свойством `transition`:

```css
.btn {
  transition: background 0.15s;
}
```

**Сделай:** (эксперимент) добавь `transition` и сравни поведение с ним и без него.

**Получишь:** цвет плавно перетекает вместо мгновенного переключения. Полноценные анимации — не наша тема, но 0.15s на цвете — приятная мелочь.

#### 6. Мини-задание

**Сделай (задача):** сверстай маленькое горизонтальное меню из трёх пунктов-ссылок. У пункта: при наведении — светлый фон, в фокусе с клавиатуры — видимая обводка, у активного (помечен классом) — акцентный фон и жирный текст.

**Получишь:** меню, которое «живёт» под курсором и клавиатурой.

### Термины урока

- **псевдокласс** — от греч. `pseudo` — «ложный» + класс: селектор состояния: `:hover`, `:focus`
- **`:hover`** — от англ. `hover` — «парить»: на элемент навели курсор
- **`:focus`** — от лат. `focus` — «очаг»: элемент выбран для ввода (клик или `Tab`)
- **`:focus-visible`** — от англ. `visible` — «видимый»: фокус, для которого нужна обводка
- **`:active`** — от лат. `activus` — «деятельный»: элемент нажат прямо сейчас
- **`outline`** — от англ. `outline` — «контур»: внешняя обводка фокуса
- **`transition`** — от лат. `transitio` — «переход»: плавное изменение свойства
- **состояние** — от лат. `status` — «положение»: режим элемента в данный момент
