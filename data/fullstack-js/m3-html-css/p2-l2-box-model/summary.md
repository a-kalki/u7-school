# Box model: content, padding, border, margin — краткая выжимка

- Слои коробки: content → padding (внутри, красится фоном) → border → margin (снаружи, прозрачный)
- Диаграмма box model в DevTools → Styles — реальные числа всех слоёв
- По умолчанию width = контент: padding/border растят коробку наружу (300 + 16×2 + 2×2 = 336)
- `* { box-sizing: border-box; }` — width = коробка целиком; первое правило в styles.css, стандарт всех проектов
- Shorthand по часовой: `padding: 8 12 16` = верх 8, лево/право 12, низ 16; `margin: 0 auto` — центр по горизонтали
- `border: 1px solid #d9dce3` — толщина + стиль + цвет
- Вертикальные margin соседей схлопываются (остаётся больший); зазор задаём одной стороной
- Шкала отступов: 4 / 8 / 16 / 24 — все зазоры только из неё (в p2-l4 станут токенами)
- Шаг визитки: обёртка `main.card` + карточка (белая, рамка, padding 24, max-width 680, по центру) + фон страницы #f4f5f7
