# Проект 1: страница-визитка — краткая выжимка

- Вёрстка сделана по ходу уроков p1-l2…p1-l4; этот урок — сверка и сдача
- Сверка с растром от ментора: блок за блоком сверху вниз (структура и содержание, не внешний вид)
- На странице должно быть: h1 (название) → p (описание компании) → h2 + ul (4 отдела) → h2 + таблица
- Таблица: thead + th scope="col" (3 колонки), tbody — 5 строк, «Итого 2400000» через colspan + strong
- Числа голые, без пробелов и валют; никаких div и script
- Проверка дерева в DevTools → Elements: h1 → p → h2 → ul → h2 → table
- Git: ветка `p1-visit-card`, история коммитов по шагам, финальный `p1: ready for review`, PR → код-ревью студентами потока; 2 апрува → мердж в `main`
- Растр похож, не идентичен: он с оформленной страницы; вид — тема проекта 2
