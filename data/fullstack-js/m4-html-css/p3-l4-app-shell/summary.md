# Каркас приложения: header, aside, main — краткая выжимка

- Семантические зоны: `header` (шапка), `main` (основное, один на страницу), `aside` (боковая колонка), `section` (раздел с заголовком)
- Каркас = **оболочка приложения** (app shell): шапка сверху, под ней сайдбар и рабочая область
- Шапка: flex-строка, лого 32×32 акцентного цвета + `h1` 20px, отступы 8×24px, разделитель снизу 1px
- Оболочка: grid `200px 1fr`; нейтральный `div` как родитель сетки
- Сайдбар: 200px, фон поверхностей, разделитель справа; пункты 8×16px, список без маркеров
- Активный пункт: фон мягкого акцента `#e8eefb` + жирный; задаётся классом (JS появится в модуле «DOM»)
- main: отступ 16px; секции — поверхность + рамка 1px + отступ 16px; зазор между секциями 16px
- Фиксация: `html`/`body` высота 100%, `body` — flex-колонка, оболочка `flex: 1`, main `overflow-y: auto` (и `min-height: 0`)
- Перенос визитки: `h1` → шапка, таблица «Штат» → секция «Штат»; описание и отделы остаются на визитке
- Четыре секции — с абзацами-заглушками; коммиты `p3: app shell`, `p3: sections with placeholders`
