### Семантические зоны

**kind:** `text`

Из p1-l3 ты помнишь: есть смысловые теги, а есть нейтральный `div`. В p1 нам не хватало тегов для крупных зон. Теперь они нужны:

| Тег | Смысл | Где у нас |
|---|---|---|
| `<header>` | вводная зона страницы | шапка с лого и названием |
| `<main>` | основное содержимое, один на страницу | рабочая область с секциями |
| `<aside>` | боковая колонка | сайдбар с разделами |
| `<section>` | смысловой раздел с заголовком | «Штат», «Календарь»… |
| `<nav>` | блок навигации | не используем: пункты сайдбара пока не ссылки |

`div` и `section` выглядят одинаково, но `section` сообщает смысл: это самостоятельный раздел. Правило модуля прежнее: есть смысловой тег — бери его.

**Сделай:** в песочнице поменяй свой нейтральный `<div>`-контейнер на `<section>` и открой DevTools → Elements.

**Получишь:** на странице ничего не изменилось, а дерево стало говорящим. Семантика — для людей и машин, не для вида.

### Разметка: собираем зоны

**kind:** `text`

Перестрой `index.html`: у нас та же визитка, но другой скелет. Ничего не переписывай с нуля — используй уже написанное.

**Сделай:** размести в `<body>` три зоны в таком порядке:

1. **шапка** — лого (квадрат с буквой) и название компании;
2. **обёртка оболочки** — контейнер `div`, внутри которого две зоны:
   - **сайдбар** — список из пяти пунктов: Штат, Календарь, Сотрудники, Табель, Результат;
   - **рабочая область** — пять секций, у каждой заголовок второго уровня: Штат, Календарь, Сотрудники, Табель, Результат.

В секцию «Штат» перенеси **всю таблицу** «Отдел — Должность — Оклад» вместе со строкой «Итого» из визитки. Название компании (`h1`) переезжает из тела страницы в шапку.

Подсказки:

- шапка — это `header`, сайдбар — `aside`, рабочая область — `main`; а обёртка вокруг сайдбара и main — нейтральный `div` с классом `shell` (он нужен только как родитель сетки, смысла не несёт);
- чтобы CSS цеплялся, повесь классами имена зон: `header` у шапки, `sidebar` у `aside`, `main` у рабочей области, `section` у секций; пунктам сайдбара — `menu-item` (списку — `menu`);
- пункты сайдбара — `ul` с `li` (без ссылок: клики добавятся в модуле 4);
- секции — `section`, внутри — `h2` с названием раздела;
- описание компании и список отделов в портал **не входят** — остаются на визитке.

**Получишь:** страницу без стилей, но с правильным смысловым скелетом: шапка, сайдбар, пять секций. Проверь себя в DevTools → Elements: дерево читается как содержание портала.

### Шапка

**kind:** `text`

Шапка — горизонтальная строка: лого прижат влево, рядом название.

**Сделай:** оформи шапку по нормам:

- шапке: `display: flex`, выравнивание по центру поперечной оси, зазор 8px, внутренние отступы 8px по вертикали и 24px по бокам, фон поверхностей, разделитель снизу 1px цветом границ;
- лого: квадрат 32×32, фон — акцентный, символ — белый, содержимое отцентрировано по обеим осям;
- заголовку `h1` в шапке: обнули внешний отступ, размер 20px.

Подсказки:

- лого с буквой внутри удобно центрировать тем же flex с `justify-content` и `align-items`;
- `h1` в шапке меньше, чем был на визитке (там было 24px) — теперь он часть интерфейса, а не главный герой страницы.

**Получишь:** аккуратную шапку: квадратный акцентный лого и название на белой полосе с тонкой линией снизу.

### Оболочка: сайдбар и рабочий стол

**kind:** `text`

Каркас «сайдбар + содержимое» — двумерная сетка, берём grid.

**Сделай:** задай обёртке `.shell` `display: grid` и две колонки: первая — ровно 200px, вторая — всё оставшееся (`1fr`).

Затем оформи сайдбар:

- фон поверхностей, разделитель справа 1px цветом границ, внутренние отступы 16px по вертикали и 8px по бокам;
- список пунктов: убери маркеры и браузерные отступы (`list-style: none; margin: 0; padding: 0`);
- пункту: внутренние отступы 8px по вертикали и 16px по бокам.

**Получишь:** слева — белая колонка шириной 200px со списком разделов, справа — рабочая область. В DevTools выбери сайдбар и убедись, что его ширина — ровно 200px, независимо от содержимого.

### Активный пункт меню

**kind:** `text`

Как пользователь понимает, какой раздел открыт? В реальном приложении — по подсветке. JS в модуле 3 нет, поэтому первый пункт сделаем активным **вручную, классом**.

**Сделай:** добавь первому пункту «Штат» класс (например, `active`) и в стилях: фон — мягкого акцента, текст — жирный.

Мягкий акцент — новый цвет дизайна: `#e8eefb`. Добавь его в свой блок токенов `:root` отдельной переменной (по смыслу — «фон активного пункта»), чтобы не разбрасывать сырое значение по файлу.

**Получишь:** пункт «Штат» подсвечен голубым и жирный — видно, какой раздел открыт. Остальные пункты — обычные.

### Рабочая область и секции

**kind:** `text`

**Сделай:** оформи рабочую область и секции по нормам:

- рабочей области (`main`): внутренний отступ 16px;

### Фиксация каркаса: шапка и сайдбар стоят, main скроллится

**kind:** `text`

Сейчас при прокрутке уезжает вся страница вместе с шапкой. Нужно: шапка и сайдбар на месте, прокручивается только `main`.

Здесь появляются сразу несколько новых приёмов, поэтому — код целиком.

**Сделай:** растяни страницу на всю высоту окна и переведи `body` в flex-колонку:

```css
html,
body {
  height: 100%;
}

body {
  margin: 0;
  display: flex;
  flex-direction: column;
}
```

- `html, body { height: 100%; }` — **цепочка высот**: окно → `html` → `body`. Проценты считаются от родителя, поэтому без `height: 100%` у `html` значение у `body` ни на что не опирается;
- `margin: 0` — снимаем браузерный отступ у `body`, иначе по краям останется белая полоса;
- `display: flex; flex-direction: column` — шапка и оболочка становятся flex-элементами и встают друг под другом.

**Сделай:** отдай оболочке всё место под шапкой, а рабочей области разреши прокручиваться:

```css
.shell {
  flex: 1;
  min-height: 0;
}

.sidebar {
  min-height: 0;
}

.main {
  min-height: 0;
  overflow-y: auto;
}
```

- `.shell { flex: 1 }` — оболочка забирает всё свободное место: от низа шапки до низа окна;
- `overflow-y: auto` у `.main` — прокрутка включается **внутри** рабочей области, а не у всей страницы. Поэтому шапка и сайдбар остаются на месте;
- `min-height: 0` — **ключевой приём**. По умолчанию flex-элемент не сжимается меньше своего содержимого, и колонка «распирает» страницу вместо того, чтобы дать `main` прокрутиться внутри. `min-height: 0` снимает этот запрет.

**Получишь:** настоящую оболочку приложения. Покрути страницу колесом — шапка и сайдбар на месте, движется только содержимое справа. Это ключевое отличие сайта от приложения: интерфейс стоит, меняется только рабочая область.

**Сделай:** закоммить каркас:

```bash
git commit -am "p3: app shell"
```

### Термины урока

**kind:** `text`

- **semantic** — от греч. `semantikos` — «обозначающий»: тег, сообщающий смысл (`header`, `main`, `section`)
- **`nav`** — сокращение от `navigation` — «навигация»: блок навигационных ссылок
- **app shell** — от англ. `app` — «приложение» + `shell` — «оболочка»: каркас приложения: шапка, сайдбар, рабочая область
- **`overflow`** — от англ. `overflow` — «переполнение»: что делать с содержимым, не влезающим в блок; `auto` включает прокрутку
