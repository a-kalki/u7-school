# Каркас приложения: header, aside, main

**Краткое содержание:**
Собираем визитку в каркас приложения. Семантические зоны `header`, `main`, `aside`, `section` вместо нейтральных обёрток. Оболочка приложения (app shell): шапка на flex, каркас «сайдбар + рабочая область» на grid. Перенос содержимого визитки: название переезжает в шапку, таблица — в секцию «Штат». Фиксация: шапка и сайдбар стоят, прокручивается только `main`. Остальные разделы — секции с заглушками.

### Подробный конспект

#### 1. Семантика зон

Из p1-l3 мы знаем: есть смысловые теги, а есть нейтральный `div`. Для крупных зон страницы нужны свои теги:

| Тег | Смысл | Где у нас |
|---|---|---|
| `<header>` | вводная зона страницы | шапка с лого и названием |
| `<main>` | основное содержимое, один на страницу | рабочая область с секциями |
| `<aside>` | боковая колонка | сайдбар с разделами |
| `<section>` | смысловой раздел с заголовком | «Штат», «Календарь»… |
| `<nav>` | блок навигации | не используем: пункты сайдбара пока не ссылки |

`div` и `section` выглядят одинаково, но `section` сообщает смысл: это самостоятельный раздел. Правило модуля прежнее: есть смысловой тег — бери его.

**Сделай:** в песочнице поменяй нейтральный `div`-контейнер на `section` и открой DevTools → Elements.

**Получишь:** на странице ничего не изменилось, а дерево стало говорящим. Семантика — для людей и машин, не для вида.

#### 2. Разбор макета портала

Вот цель проекта 3:

```
┌────────────────────────────────────────────────┐
│  [лого]   ТОО «Дала Технолоджи»                │  ← header: flex-строка
├──────────────┬─────────────────────────────────┤
│  Штат        │  ┌───────────────────────────┐  │
│  Календарь   │  │  Штат (таблица)           │  │
│  Сотрудники  │  ├───────────────────────────┤  │
│  Табель      │  │  Календарь (заглушка)     │  │
│  Результат   │  ├───────────────────────────┤  │
│              │  │  … и так далее            │  │
└──────────────┴─────────────────────────────────┘
   aside (200px)        main (всё остальное)
```

- **шапка** — на всю ширину, сверху;
- **оболочка** — под шапкой: слева узкий сайдбар, справа широкая рабочая область;
- в **main** — пять секций друг под другом, все видимы;
- шапка и сайдбар не уезжают при прокрутке, прокручивается только `main`.

#### 3. Разметка: собираем зоны

**Сделай:** перестрой `index.html` — та же визитка, но другой скелет:

1. **шапка** — лого (квадрат с буквой) и название компании;
2. **обёртка оболочки** (нейтральный `div` с классом `shell` — родитель сетки), внутри:
   - **сайдбар** — список из пяти пунктов: Штат, Календарь, Сотрудники, Табель, Результат;
   - **рабочая область** — пять секций, у каждой заголовок второго уровня с названием раздела.

В секцию «Штат» перенеси **всю таблицу** «Отдел — Должность — Оклад» со строкой «Итого» из визитки. Название компании (`h1`) переезжает в шапку. Описание компании и список отделов в портал **не входят** — остаются на визитке.

Классы для стилей — по именам зон: `header` у шапки, `sidebar` у `aside`, `main` у рабочей области, `section` у секций; пунктам сайдбара — `menu-item`, списку — `menu`.

**Получишь:** страницу без стилей, но с правильным смысловым скелетом.

#### 4. Шапка

Шапка — горизонтальная строка: лого прижат влево, рядом название. Нормы:

- шапке: flex-строка, выравнивание по центру поперечной оси, зазор 8px, внутренние отступы 8px по вертикали и 24px по бокам, фон поверхностей, разделитель снизу 1px цветом границ;
- лого: квадрат 32×32, фон — акцентный, символ — белый, содержимое отцентрировано по обеим осям;
- заголовку `h1` в шапке: обнули внешний отступ, размер 20px (на визитке было 24px — теперь он часть интерфейса).

**Получишь:** квадратный акцентный лого и название на белой полосе с тонкой линией снизу.

#### 5. Оболочка и сайдбар

Каркас «сайдбар + содержимое» — двумерная сетка, берём grid.

**Сделай:** обёртке `.shell` — `display: grid` и две колонки: ровно `200px` и `1fr`. Сайдбар: фон поверхностей, разделитель справа 1px цветом границ, внутренние отступы 16px по вертикали и 8px по бокам. Список пунктов: убери маркеры и браузерные отступы; пункту — внутренние отступы 8px по вертикали и 16px по бокам.

**Получишь:** слева белая колонка ровно 200px со списком, справа — рабочая область.

#### 6. Активный пункт меню

JS в модуле 3 нет, поэтому первый пункт делаем активным вручную, классом.

**Сделай:** первому пункту «Штат» — класс `active`; в стилях фон — мягкого акцента `#e8eefb`, текст — жирный. Мягкий акцент добавь в блок токенов `:root` отдельной переменной.

**Получишь:** пункт «Штат» подсвечен голубым и жирный.

#### 7. Рабочая область и секции

**Сделай:** `main` — внутренний отступ 16px; секция — фон поверхностей, граница 1px цветом границ, внутренний отступ 16px; зазор между секциями — 16px; `h2` внутри секции — обнули верхний отступ, снизу 8px, размер 18px, цвет акцентный.

**Получишь:** пять белых карточек с рамками и зазорами, каждая со своим акцентным заголовком.

#### 8. Фиксация каркаса

Сейчас при прокрутке уезжает вся страница. Нужно: шапка и сайдбар на месте, прокручивается только `main`. Появляются новые приёмы — цепочка высот и `min-height: 0`.

Растяни страницу на всю высоту и переведи `body` в flex-колонку:

```css
html,
body {
  height: 100%;
}

body {
  margin: 0;
  display: flex;
  flex-direction: column;
}
```

- `html, body { height: 100%; }` — **цепочка высот**: окно → `html` → `body`. Проценты считаются от родителя, поэтому без `height: 100%` у `html` значение у `body` ни на что не опирается;
- `margin: 0` — снимаем браузерный отступ `body`, иначе по краям останется белая полоса;
- `display: flex; flex-direction: column` — шапка и оболочка становятся flex-элементами и встают друг под другом.

Отдай оболочке всё место под шапкой, а рабочей области разреши прокручиваться:

```css
.shell {
  flex: 1;
  min-height: 0;
}

.sidebar {
  min-height: 0;
}

.main {
  min-height: 0;
  overflow-y: auto;
}
```

- `.shell { flex: 1 }` — оболочка забирает всё свободное место: от низа шапки до низа окна;
- `overflow-y: auto` у `.main` — прокрутка включается **внутри** рабочей области, а не у всей страницы: шапка и сайдбар остаются на месте;
- `min-height: 0` — **ключевой приём**: по умолчанию flex-элемент не сжимается меньше содержимого и «распирает» страницу; `min-height: 0` снимает этот запрет.

**Получишь:** настоящую оболочку приложения: интерфейс стоит, меняется только рабочая область. Ключевое отличие сайта от приложения.

**Сделай:** коммит `p3: app shell`.

### Термины урока

- **semantic** — от греч. `semantikos` — «обозначающий»: тег, сообщающий смысл (`header`, `main`, `section`)
- **`header`** — от англ. `header` — «заголовок, шапка»: вводная зона страницы
- **`main`** — от англ. `main` — «главный»: основное содержимое, один на страницу
- **`aside`** — от англ. `aside` — «в стороне»: боковая колонка (сайдбар)
- **`section`** — от лат. `sectio` — «разрез, часть»: смысловой раздел с заголовком
- **`nav`** — сокращение от `navigation` — «навигация»: блок навигационных ссылок
- **app shell** — от англ. `app` — «приложение» + `shell` — «оболочка»: каркас приложения: шапка, сайдбар, рабочая область
- **`overflow`** — от англ. `overflow` — «переполнение»: что делать с содержимым, не влезающим в блок; `auto` включает прокрутку
- **сайдбар** — от англ. `side` — «бок» + `bar` — «полоса»: боковая панель
