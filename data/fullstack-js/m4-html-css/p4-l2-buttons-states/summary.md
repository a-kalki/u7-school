# Состояния: hover, focus, active — краткая выжимка

- **Псевдоклассы** выбирают элемент в особом состоянии: `:hover`, `:focus`, `:focus-visible`, `:active`
- `:hover` — наведение; `:active` — момент нажатия; дают отклик интерфейса
- `:focus` — фокус с клавиатуры (`Tab`); критичен для доступности, обводку не убирать без замены
- `:focus-visible` + `outline` / `outline-offset` — видимая обводка фокуса
- Кнопку-ссылку делают из `<a>`: `text-decoration: none`, отступы, фон, рамка
- `transition` (по желанию) — плавное изменение, например `background 0.15s`
- Мини-задание: меню из трёх ссылок с hover/focus/active
- Шаг портала: пунктам меню — наведение (фон страницы); активный пункт остаётся голубым и жирным
- Порядок правил: при равном весе `:hover` и `.active` побеждает нижнее — активное правило ставь ниже
- Шаг портала: фильтрам — видимый фокус; секция «Сотрудники» (5 строк: имя, фамилия, должность, отдел, дата)
