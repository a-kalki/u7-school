### Состояния элемента

**kind:** `text`

Псевдокласс — селектор, который выбирает элемент **в особом состоянии**:

| Псевдокласс | Когда срабатывает |
|---|---|
| `:hover` | на элемент навели курсор |
| `:focus` | элемент в фокусе (клик или `Tab`) |
| `:focus-visible` | фокус, для которого браузер считает нужным показать обводку |
| `:active` | элемент нажат прямо сейчас (курсор зажат) |

**Сделай:** в песочнице в форме с предыдущего урока добавь класс кнопке:

```html
<button class="btn">Отправить</button>
```

**Сделай:** добавь стили:

```css
.btn {
  padding: 8px 16px;
  border: 1px solid #2b5fd9;
  background: #2b5fd9;
  color: #fff;
  text-decoration: none;
}

.btn:hover {
  background: #1f47a8;
}

.btn:active {
  background: #16337a;
}
```

**Получишь:** кнопка темнеет при наведении и темнеет ещё сильнее при нажатии.

### focus: состояние для клавиатуры

**kind:** `text`

Фокус `:focus` приходит, когда пользователь попал в элемент с клавиатуры (клавиша `Tab`). Это критично для доступности: человек, работающий без мыши, должен **видеть**, где находится.

**Сделай:** добавь правило и нажми в песочнице `Tab`, двигаясь по элементам:

```css
.btn:focus-visible {
  outline: 2px solid #2b5fd9;
  outline-offset: 2px;
}
```

**Получишь:** при перемещении фокуса клавишей `Tab` вокруг кнопки появляется видимая обводка. Никогда не убирай её (`outline: none`) без замены.

### Плавность (по желанию)

**kind:** `text`

Переход можно сгладить свойством `transition` — оно анимирует изменение:

```css
.btn {
  transition: background 0.15s;
}
```

**Сделай:** (эксперимент) добавь `transition` и сравни поведение с ним и без него.

**Получишь:** цвет плавно перетекает вместо мгновенного переключения. Полноценные анимации — не наша тема, но 0.15s на цвете — приятная мелочь.

### Термины урока

**kind:** `text`

- **псевдокласс** — от греч. `pseudo` — «ложный» + класс: селектор состояния: `:hover`, `:focus`
- **`:hover`** — от англ. `hover` — «парить»: на элемент навели курсор
- **`:focus`** — от лат. `focus` — «очаг»: элемент выбран для ввода (клик или `Tab`)
- **`:focus-visible`** — от англ. `visible` — «видимый»: фокус, для которого нужна обводка
- **`:active`** — от лат. `activus` — «деятельный»: элемент нажат прямо сейчас
- **`outline`** — от англ. `outline` — «контур»: внешняя обводка фокуса
- **`transition`** — от лат. `transitio` — «переход»: плавное изменение свойства
- **состояние** — от лат. `status` — «положение»: режим элемента в данный момент
