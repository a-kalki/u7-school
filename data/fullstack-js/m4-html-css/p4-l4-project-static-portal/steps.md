### Сверка с образцом

**kind:** `text`

Иди сверху вниз и сверь. **На твоей странице должно быть…**

**Шапка**
- `header` во всю ширину: квадратный логотип 32×32 акцентного цвета + название «ТОО «Дала Технолоджи»».

**Сайдбар**
- `aside` шириной 200px, белый, разделитель справа;
- пять пунктов: Штат, Календарь, Сотрудники, Табель, Результат;
- первый пункт активный — голубой фон и жирный; пункты отзываются на наведение.

**Рабочая область** — пять секций сплошным потоком:

- **Штат** — таблица «Отдел — Должность — Оклад», 5 строк + строка «Итого 2400000»; числа по правому краю;
- **Календарь** — строка с названием предприятия + таблица «Месяц — Норма рабочих дней»: Сентябрь 2026 — 21, Октябрь 2026 — 22;
- **Сотрудники** — таблица из 5 строк: имя, фамилия, должность, отдел, дата приёма (`2022-03-01` и т.д.);
- **Табель** — таблица из 10 строк: месяц, сотрудник, отработано дней (2 месяца × 5 сотрудников);
- **Результат** — два селекта-фильтра (месяц: октябрь по умолчанию; отдел: «Все отделы» по умолчанию) + вшитая таблица расчёта за октябрь: сотрудники по отделам, ИТОГО по каждому отделу и ИТОГО по предприятию, числа по правому краю.

**Сделай:** пройди по списку и растру. Расхождения ищи причину в DevTools → Elements / Styles и чини.

**Получишь:** портал, зоны которого совпадают с образцом. Работы студентов визуально сопоставимы, но не идентичны — детали вне норм обсуждаем на ревью.

### Проверка данных

**kind:** `text`

Данные портала — эталонный набор, единый для всего потока: в модуле «DOM» JavaScript прочитает их прямо из страницы, поэтому важно, чтобы числа совпадали с образцом **буквально**.

**Сделай:** сверь числа по секциям: оклады в «Штате» (600000, 450000, 500000, 400000, 450000, итог 2400000), нормы в «Календаре» (21 и 22), дни в «Табеле».

**Получишь:** полное совпадение. Помни правило модуля: числа — голые (`600000`), без пробелов-разделителей и знаков валют. Красивый формат появится только в финале модуля «DOM».

### Куда это растёт

**kind:** `text`

Модуль закрыт: портал свёрстан целиком, но он **статичен** — клики ни на что не влияют, числа вшиты руками. Так и задумано.

В модуле «DOM» мы его **оживим** на чистом JavaScript:

- научим сайдбар переключать разделы — неактивные секции будут скрываться;
- «Результат» прочитает данные из таблиц страницы и **посчитает** зарплату функциями (вспомнишь модуль «Синтаксис»);
- ввод данных переведёт разделы на редактирование с сохранением в браузере.

HTML, который ты сверстал, станет источником данных для логики. Драматургия модуля «DOM» начинается на следующем уроке.

### Термины урока

**kind:** `text`

- **статичный** — от греч. `statos` — «стоящий»: страница без поведения; данные вшиты, клики ничего не меняют
- **эталон** — от франц. `étalon` — «образец меры»: единый набор данных для всего потока
- **DOM** — от `Document Object Model` — «объектная модель документа»: дерево элементов, с которым работает JavaScript в модуле «DOM»
