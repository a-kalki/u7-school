# Проект 4: статичный портал целиком — краткая выжимка

- Итог модуля: все секции наполнены по ходу p4-l1…p4-l3; урок — сверка, чек-лист и сдача
- Сверка с растром `p4-static-portal` по зонам: шапка → сайдбар → пять секций
- «Штат»: 5 строк + «Итого 2400000»; «Календарь»: компания + Сентябрь 21 / Октябрь 22
- «Сотрудники»: 5 строк с датами; «Табель»: 10 строк; «Результат»: фильтры + таблица октября
- Данные — эталон `concept.md` §5; числа голые, без пробелов и валют
- Каркас: шапка на flex, оболочка на grid `200px 1fr`; прокручивается только `main`
- Пять секций видимы сплошным потоком; скрытия нет — это модуль «DOM»
- Числа — через `num`, итоги — через `total-row`; активный пункт подсвечен классом
- Токены в `:root`, сырых значений нет; никаких `<script>`
- Git: ветка `p4-portal`, коммиты по шагам, финальный `p4: static portal ready for review`, PR → 2 апрува
- Дальше — модуль «DOM»: оживляем портал, «Результат» считает из данных страницы
