# Поток документа: block, inline, inline-block — краткая выжимка

- **Поток документа (normal flow)** — автоматическая раскладка браузера; всё до сих пор происходило в нём
- **Блочные** (`h1`, `p`, `ul`, `div`): вся ширина, новая строка, уважают вертикальные margin
- **Строчные** (`span`, `strong`, `a`): внутри строки, ширина по содержимому, вертикальные margin не работают
- **Строчно-блочные** (`inline-block`): стоят в строке, но позволяют задать ширину и высоту
- Строчным нельзя задать `width`/`height` — свойство молча игнорируется
- `display` переключает тип: `block`, `inline`, `inline-block`, `none`
- `display: none` убирает элемент из потока и от скринридеров; соседи смыкаются
- `float` и `z-index` — легаси; договорённость модуля: раскладку делаем flexbox и grid
- Мини-задание: ряд меток на `inline-block`; блочная метка выпадает из ряда
- Шаг портала: ветка `p3-shell` + пустой коммит-маркер; перестройка — в p3-l4
