# Цвета и типографика — краткая выжимка

- Форматы: ключевые слова, **hex (наш выбор)**, `rgb()`, `hsl()`; `color` — текст, `background-color` — фон
- hex: `#RRGGBB` — красный/зелёный/синий; пипетка в DevTools показывает код любого пикселя
- Контраст по яркости, ориентир WCAG 4.5:1: основной #222 на белом, приглушённый не бледнее #666; тест прищуром
- `font-family` — стек с резервами, последний — общее семейство (`sans-serif`); задаётся на `body`, наследуется
- Одно семейство на интерфейс; иерархию делают размер и вес
- Размеры px: h1 24 / h2 18 / текст 14–16; `font-weight`: 400 и 700
- `line-height: 1.5` — безразмерный множитель; body: margin 0, padding 24
- Браузерные margin у `p` и `ul` обнуляем (`margin: 0`): зазоры задают margin заголовков
- `text-align: right` — приём для числовых колонок таблиц (разряды ровные); применю в П4
- Шаг визитки: полная палитра + типографика (h1 24, h2 18 акцент, описание приглушённое)
