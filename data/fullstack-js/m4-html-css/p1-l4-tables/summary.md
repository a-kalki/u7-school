# Таблицы: штатное расписание — краткая выжимка

- Таблица — только для данных «строки × колонки»; для расположения элементов — CSS (П3)
- Пустая `<table>` ничего не рисует — таблица наполняется строками
- `<tr>` — строка; `<th>` — заголовочная ячейка (жирная, по центру); `<td>` — данные
- `<thead>`/`<tbody>` — смысловые секции: стилизация шапки (П2), JS в модуле «DOM» ищет данные в tbody. Ставим всегда
- `scope="col"` — доступность заголовков колонок; невидимо глазу, видно дикторам
- `colspan="N"` — растянуть ячейку на N колонок; сумма colspan в строке = числу колонок, иначе таблица ломается
- Итоговая строка: `<td colspan="2"><strong>Итого</strong></td>` + сумма — важность через `<strong>`
- Данные — голые числа (`600000`): JS в модуле «DOM» читает их из страницы
- Таблица получает адрес: `<table id="staff">`; в визитке три адреса данных: `company-name`, `departments`, `staff`
- Шаг визитки: полная таблица 5 строк + «Итого 2400000»; коммит `p1: staff table`
