# Box model: content, padding, border, margin

**Краткое содержание:**
Каждый элемент — прямоугольная коробка из четырёх слоёв: контент, внутренний отступ, рамка, внешний отступ. Размеры и `box-sizing` — почему коробки «разбухают» и как это починить одним правилом. Шorthand-записи, схлопывание margin и шкала отступов 4/8/16/24. Главный шаг урока: визитка становится карточкой — белый блок с рамкой по центру страницы.

### Подробный конспект

#### 1. Четыре слоя коробки

Каждый тег (вне зависимости блочный или строчный) имеет коробчатую структуру из четырех слоев.

От центра наружу:

1. **Content** — содержимое (то что видит пользователь).
2. **Padding** — внутренний отступ: между содержимым и рамкой. Красится фоном элемента.
3. **Border** — рамка.
4. **Margin** — зазор до соседей. Снаружи, прозрачный.

Мнемоника: контент → подушка (padding) → рамка (border) → воздух до соседей (margin).

Понять слои проще всего руками. Поэкспериментируй: вставь в разметку песочницы:

```html
<div class="box">Коробка с содержимым</div>
```

и добавь правило:

```css
.box {
  background: #e8eefb;
  margin: 24px;
  padding-left: 16px;
  padding-right: 16px;
  border: 2px solid #2b5fd9;
}
```

**Получишь:** голубую плашку с рамкой, отодвинутую от краёв окна.

**Потренируйся:** Посмотри на неё в DevTools (F12): Выбери элемент (`ctrl+shift+c` → `click`) → Styles → прокрути вниз до диаграммы box model: четыре кольца с числами. Наведи на кольца — они подсветятся на странице.

Есть и готовый интерактив: на странице [CSS Box Model — w3schools](https://www.w3schools.com/css/css_boxmodel.asp) редактируемые примеры с кнопкой «Try it Yourself» — покрути значения и посмотри, как плашка реагирует.

#### 2. Размеры и box-sizing: почему коробка «толстеет»

**Сделай:** добавь в `.box` ширину: `width: 300px;` — и замерь реальную ширину плашки (DevTools: наведи на элемент, увидишь размеры).

**Получишь:** не 300! По умолчанию `width` — это только контент: 300 + 16×2 padding + 2×2 border = **336px**. Добавляешь отступы — коробка растёт наружу. Математика мучительная.

**Сделай:** добавь универсальное правило:

```css
* {
  box-sizing: border-box;
}
```

**Получишь:** плашка теперь ровно 300px — отступы съедены изнутри, а не добавлены снаружи. `border-box` меняет договор: ширина — это коробка целиком. Это стандарт всей веб-разработки: скопируй это правило первым в `styles.css` визитки — оно будет жить первым правилом в каждом нашем проекте.

#### 3. Shorthand: компактная запись

Короткая запись для отступов и зазоров (padding, margin):
- `margin: 24px;` — со всех сторон.
- `margin: 24px 16px;` — сверху/снизу 24, слева/справа 16.
- `margin: 8px 12px 16px;` — верх 8, лево/право 12, низ 16.
- `margin: 8px 12px 16px 24px;` — верх 8, право 12, низ 16, лево 24.

Короткая запись для границ:
- `border: 2px solid #2b5fd9;` — толщина + стиль + цвет разом.

**Сделай:** (эксперимент) поставь `.box` отступ `margin: 48px 8px;` и посмотри.

**Получишь:** коробка заметно отъехала по вертикали и прижалась по горизонтали. Поиграй значениями, пока не почувствуешь порядок сторон.

#### 4. Схлопывание margin

**Сделай:** (эксперимент) сделай две коробки подряд и дай верхней `margin-bottom: 24px`, нижней — `margin-top: 16px`.

**Получишь:** зазор не 40px, а 24px. Вертикальные margin соседей **схлопываются** — остаётся больший. Отсюда практика: зазор между блоками задаём одной стороной (например, только нижней), а не обеими.

#### 5. Шкала отступов

Дизайн не берёт отступы «с потолка»: шкала с шагом 4px — **4 / 8 / 16 / 24**. Мелочи — 4–8, внутри блоков — 16, крупные зоны — 24. Когда все отступы из шкалы, страница выглядит ровной автоматически. В уроке о переменных зафиксируем шкалу в токенах — пока просто придерживайся этих четырёх значений.

### Шаг визитки: карточка

Превращаем визитку из «простыни текста» в карточку. В HTML нужна обёртка — смысловой контейнер `main` вокруг всего содержимого `body`:

**Сделай:** в `index.html` после `<body>` открой `<main class="card">`, перед `</body>` закрой `</main>`. (Весь контент — внутри.) В `styles.css` допиши:

```css
.card {
  max-width: 680px;
  margin: 0 auto;
  background: #ffffff;
  border: 1px solid #d9dce3;
  padding: 24px;
}
```

и фон страницы:

```css
body {
  background: #f4f5f7;
}
```

**Получишь:** белую карточку с тонкой рамкой по центру светло-серой страницы. `margin: 0 auto` означает «сверху/снизу ноль, слева/справа — авто»: боковые отступы делят свободное место поровну, и карточка встаёт по центру. `max-width` не даёт ей растянуться на весь широкий экран.

**Сделай:** (эксперимент) сузь окно браузера до минимума.

**Получишь:** карточка сужается вместе с окном, но не шире 680px не становится. Открой DevTools → Elements, выбери `main` и погляди диаграмму box model — все знакомые числа.

**Сделай:** коммит: `git commit -am "p2: visit card"`.

### Термины урока

- **box model** — от англ. `box` — «коробка» + `model` — «модель»: каждый элемент — коробка из четырёх слоёв
- **content** — от англ. `content` — «содержимое»: сам текст/таблица внутри элемента
- **padding** — от англ. `padding` — «набивка, подбивка»: внутренний отступ: как мягкая набивка между содержимым и рамкой
- **border** — от англ. `border` — «граница, кромка»: рамка вокруг padding и content
- **margin** — от лат. `margo` — «край»: внешние поля: в типографии так называют поля страницы
- **box-sizing** — от англ. — «определение размера коробки»: что считать шириной: контент (`content-box`) или всю коробку (`border-box`)
- **border-box** — от англ. — «рамочная коробка»: ширина включает padding и border; стандарт всех проектов
- **shorthand** — от англ. `shorthand` — «стенография»: краткая запись: `margin: 24px 16px` вместо четырёх свойств
- **collapsing** — от англ. `collapse` — «схлопываться»: соседние вертикальные margin сливаются в больший
- **spacing scale** — от англ. — «шкала отступов»: фиксированные шаги 4/8/16/24, из которых берутся все зазоры
