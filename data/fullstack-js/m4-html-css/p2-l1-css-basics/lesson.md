# Как работает CSS: селекторы, каскад, специфичность

**Краткое содержание:**
Что такое CSS и из чего состоит его правило: селектор, блок объявлений, свойства и значения. Учимся выбирать элементы (по типу, классу, id) и разбираться, кто победит, когда два правила спорят об одном элементе: каскад, специфичность, наследование. Первый настоящий код в `styles.css` и первое видимое изменение визитки — заголовки разделов получают цвет.

### Подробный конспект

#### 1. Что такое CSS

CSS — от `Cascading Style Sheets`, «каскадные таблицы стилей» — язык описания внешнего вида. Помнишь разделение из первого урока модуля: HTML — *что* на странице, CSS — *как* это выглядит. Настало время второй половине.

Разберём само название — оно объясняет, как работает весь язык:

- **style sheets** — «таблицы (листы) стилей»: документ со списком описаний внешнего вида. Наш такой документ — файл `styles.css`;
- **cascading** — «каскадные»: правила «стекаются» сверху вниз, как водопад, и нижние могут перебивать верхние (разберём ниже в этом уроке).

CSS-файл не выполняется, как программа, а *описывает*: браузер читает его сверху вниз и приводит страницу в соответствие с описанием. Файл подключён к визитке через `<link>` ещё с p1-l2 — всё это время он был пуст, теперь оживём.

#### 2. Анатомия правила: какая часть что обозначает

Правило CSS — конструкция «кого найти → что применить»:

```css
h2 {
  color: #2b5fd9;
}
```

Разберём по частям:

| Часть | Что это |
|---|---|
| `h2` | **селектор** — кого ищем: все элементы `<h2>` на странице |
| `{ }` | **блок объявлений** — что с найденными сделать |
| `color` | **свойство** — что именно меняем (цвет текста) |
| `#2b5fd9` | **значение** — на что меняем |
| `color: #2b5fd9;` | **объявление** — пара «свойство: значение»; объявлений может быть сколько угодно |

Читается человеческим языком: «Всем `<h2>` на странице: цвет текста — #2b5fd9».

**Синтаксические правила простые:**

- селектор, затем фигурные скобки — они всегда парные;
- внутри — объявления: `свойство: значение;` — двоеточие посередине, **точка с запятой** в конце;
- комментарии — `/* вот так */`.

**Сделай:** (эксперимент) прочитай правило вслух своими словами — без слов «селектор» и «объявление», просто по-русски. Получилось что-то вроде «всем h2 — синий текст»? Поздравляю, ты понял CSS.

**Сделай:** (эксперимент)

1. создай копии файлов визитки: `index.html` → `sandbox.html` и `styles.css` → `sandbox.css`; в `sandbox.html` обнови путь к CSS.

2. в `sandbox.css` напиши правило с двумя объявлениями и убери точку с запятой у первого:

```css
h2 {
  color: #2b5fd9
  font-size: 40px;
}
```

**Получишь:** второе объявление не сработало: без `;` браузер склеил две строки и запутался. Точка с запятой — разделитель объявлений; ставь её всегда, даже после последнего. Исправь ошибку.

Сохрани, обнови страницу. Цвет заголовка изменился вместе с высотой шрифта.

**Задание по проекту:**

Теперь сделай тоже самое в `css` файле своего проекта.

**Получишь:** заголовки «Отделы» и «Штатное расписание» стали синими. Свойство `color` красит текст (подробно о цветах — в уроке о цветах и типографике). Поздравляю: страница впервые изменила вид по твоей воле.

#### 3. Где живут стили: три способа

Одно и то же правило можно записать тремя способами. Покрасим заголовок в синий каждым из них.

**Способ 1 — инлайн:** атрибут `style="..."` прямо на теге:

```html
<h2 style="color: #2b5fd9;">Отделы</h2>
```

Работает, но оформление смешивается с содержимым, правило нельзя переиспользовать. Используется в крайних случаях, когда хотим "перебить" то что описал css.

**Способ 2 — тег `<style>` в `<head>`:** стили прямо в HTML-файле:

```html
<head>
  <style>
    h2 { color: #2b5fd9; }
  </style>
</head>
```

Плюсы: Удобно для экспериментов и одностраничных демо. Так устроены онлайн-редакторы.

**Способ 3 — внешний файл через `<link>`:** стили живут отдельно, как в нашем проекте:

```html
<link rel="stylesheet" href="styles.css">
```

Плюсы: HTML чистый, стили можно переиспользовать на многих страницах, изменения видны в git. Наш выбор для проектов.

**Соглашение наших уроков:** онлайн-редактор — в `<style>`; файл-песочница и все проекты — внешний css-файл; инлайн не используем. Дальше по урокам пользуемся этим без напоминаний.

**Сделай:** покрась заголовок песочницы в синий всеми тремя способами по очереди: сначала инлайном, потом перенеси в `<style>`, потом — во внешний css-файл.

**Получишь:** результат одинаковый во всех трёх случаях — меняется только место, где живёт правило.

#### 4. Селекторы и комбинаторы: кого выбираем

| Селектор | Пример | Кого выбирает |
|---|---|---|
| тип | `p { }` | все `<p>` на странице |
| класс | `.lead { }` | все с `class="lead"` |
| id | `#header { }` | один с `id="header"` |
| универсальный | `* { }` | вообще всё |

Класс — рабочий селектор интерфейсов: группирует элементы «одного вида». Id — для уникальных, в стилях нам почти не встретится.

Атрибут `class` позволяет очень гибко управлять стилями различных тегов. Правила такие:
- в любой тег ты можешь добавлять множество различных классов `<p class="lead list primary">...</p>`
- одни класс ты можешь добавлять в множество различных тегов: `<p class="lead">...</p>`, `<li class="lead">...</li>`
- желательно, один класс делает только одну "вещь";
- `.lead {...}` читается так: выбери все элементы с классом lead — и примени к ним блок объявлений;

#### 5. Места экспериментов

Для опытов ты можешь выбрать одну из любых стратегий:
1. использовать файл песочницу у себя и напрямую тестить в браузере;
2. использовать онлайн редактор;

Онлайн редакторы можно открыть по ссылкам:
- [Список онлайн редакторов](https://www.w3schools.com/tryit/).
- [CSS редактор](https://www.w3schools.com/tryit/tryit.asp?filename=tryhtml_css).

**Сделай:** замени содержимое документа для экспериментов (песочница или онлайн-редактор) на заготовку:

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    /* для онлайн-редактора пишем здесь */
  </style>

  <!-- для песочницы пишем в файле -->
  <link rel="stylesheet" href="sandbox.css">
</head>
<body>

  <h2>Заголовок</h2>
  <p>Первый абзац</p>
  <p class="lead">Абзац-лидер</p>
  <p>Третий абзац</p>

</body>
</html>
```

> Далее мы будем давать инструкции, в зависимости от выбранного способа работы ты изменив код либо обновляешь страницу `F5` (для песочницы) или нажимаешь зеленую кнопку `Run` (в онлайн редакторе).

Обнови — должна появиться страница с заголовком и тремя абзацами.

**Сделай:** добавь стили:

```css
p {
  font-style: italic;
}

.lead {
  font-style: normal;
}
```

**Получишь:** все три абзаца наклонились, но «Абзац-лидер» — прямые. Селектор по классу нашёл только его.

#### 6. Соберем все вместе

Сводный пример: добавь в конец body:

```html
<div class="card">
  <p>Абзац внутри карточки</p>
  <span class="badge">новое</span>
  <span>обычный span</span>
</div>
<p>Абзац снаружи</p>
```

и правила:

```css
.lead {
  font-weight: bold;      /* селектор по классу */
}

.card {
  border: 1px solid green; /* будет действовать только на классы .card */
}

.card p {
  font-style: italic;     /* комбинатор «потомок»: любые p внутри .card */
}

.card > .badge {
  background: #e8eefb;    /* комбинатор «прямой ребёнок»: только .badge — ребёнок .card */
}

h2, p {
  margin: 8px;            /* запятая — группировка: одно правило для h2 И p */
}
```

**Получишь:** «Абзац-лидер» — жирный (класс); карточка имеет границу; абзац внутри карточки — курсив (потомок), абзац снаружи — нет; `.badge` — с подсветкой (прямой ребёнок), соседний span — без. Запятая — не комбинатор, а группировка: одно правило сразу для нескольких селекторов.

**Заметь:** строки `span` хоть и объявлены в разных тегах и в разных строках, но на страничке они "уместились" в одну строку. Это потому что `span` строчный (инлайн) тег, а не блоковый.

| Правило | Кого заденет | Почему |
|---|---|---|
| `.lead` | «Абзац-лидер» | класс есть только у него |
| `.card p` | абзац внутри карточки | любой `p` где-то внутри `.card` |
| `.card > .badge` | только `.badge` | прямой ребёнок `.card` |
| `h2, p` | все `h2` и все `p` | группировка перечисляет селекторы |

#### 7. Каскад: кто победит

Два правила претендуют на один элемент — браузер судит так:

1. `!important` — переопределяет всё. Пользуемся очень и очень осторожно: это костыль. Еще лучше, вообще не пользоваться;
2. **Специфичность**: id сильнее класса, класс сильнее типа. `.lead` весит больше, чем `p`, — поэтому «Абзац-лидер» прямые.
3. **Порядок**: при равном весе побеждает правило **ниже** в файле.

**Сделай:** продублируй правило `h2` вторым разом, но с другим цветом:

```css
h2 {
  color: #b30000;
}
```

**Получишь:** заголовок покраснел. Равный вес — выиграло нижнее правило.

#### 8. Наследование: стили текут вниз

`color`, `font-family`, `font-size`, `line-height` дети берут у родителей. `margin`, `padding`, `border` — не берут: отступы у каждого свои.

**Сделай:** замени все правила на одно:

```css
body {
  color: #8a055d;
}
```

**Получишь:** весь текст на странице — малиновый: цвет «стёк» с body на всё содержимое. Одно правило — вся страница. Так и будем красить визитку в следующем уроке.

#### 11. Термины урока

- **правило CSS** — от англ. `rule` — «правило»: селектор + объявления в фигурных скобках
- **селектор** — от англ. `selector` — «выбирающий» (от `select` — «выбирать»): то, как правило находит элементы: `p`, `.card`, `#top`
- **объявление** — от англ. `declaration` — «объявление»: пара `свойство: значение;` внутри правила
- **свойство** — от англ. `property` — «свойство»: что именно меняем: цвет, размер, отступ
- **каскад** — от франц. `cascade` — «водопад»: правила «текут» вниз: при равном весе побеждает нижнее
- **специфичность** — от англ. `specificity` — «конкретность»: вес селектора: id > класс > тип
- **наследование** — от англ. `inheritance` — «наследование»: дети берут часть стилей родителей: color, font...
- **инлайн-стиль** — от англ. `inline` — «в строке»: `style="..."` на элементе; мы не используем. Не путай с инлайн-элементами из p1-l3: там слово про тип тега, здесь — про способ записи CSS
- **комбинатор** — от лат. `combinare` — «соединять»: выбор по связи: `.card p` — потомок
- **`!important`** — от англ. `important` — «важный»: ломает каскад; костыль — не используем
