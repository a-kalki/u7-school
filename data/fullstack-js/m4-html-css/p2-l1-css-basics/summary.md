# Как работает CSS: селекторы, каскад, специфичность — краткая выжимка

- **CSS** — от `Cascading Style Sheets`, «каскадные таблицы стилей»: HTML — что на странице, CSS — как выглядит
- Правило = селектор + `{ свойство: значение; }` — читается «всем h2 — синий текст»; браузер читает `styles.css` сверху вниз
- В правиле: селектор — кого ищем, свойство — что меняем, значение — на что; объявления разделяются `;`
- Три способа задать стили: инлайн (`style="..."` — не используем), тег `<style>` в head, внешний файл через `<link>` (способ проектов)
- Селекторы и комбинаторы: тип `p`, класс `.lead` (рабочий), id `#footer` (редко), `*` — всё; `.card p` — потомок, `.card > p` — прямой ребёнок; запятая `h2, p` — группировка
- Каскад: `!important` (не используем) → специфичность: id > класс > тип → при равенстве нижнее правило
- Писать от общего к частному — частное побеждает порядком
- Наследуются: `color`, `font-family`, `font-size`, `line-height`; не наследуются: margin/padding/border
- `body { color }` красит всю страницу через наследование
- DevTools → Styles: откуда стиль, кто выиграл спор, галочка вкл/выкл
- Песочница — два варианта: файлы `sandbox.html` + `sandbox.css` или онлайн-редактор; онлайн — `<style>`, файл — внешний css; эксперименты в репозиторий не попадают
- Шаг визитки: `h2 { color: #2b5fd9 }` — акцентные заголовки; коммит `p2: accent headings`
