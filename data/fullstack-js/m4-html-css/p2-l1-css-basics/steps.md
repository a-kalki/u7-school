### Анатомия правила CSS

**kind:** `text`

CSS — от `Cascading Style Sheets`, «каскадные таблицы стилей» — язык описания внешнего вида. Помнишь разделение из первого урока: HTML — *что* на странице, CSS — *как* это выглядит. Пришло время второй половине.

Правило CSS — конструкция «кого найти → что применить»:

```css
h2 {
  color: #2b5fd9;
}
```

| Часть | Что это |
|---|---|
| `h2` | **селектор** — кого ищем: все элементы `<h2>` |
| `{ }` | **блок объявлений** — что с найденными сделать |
| `color` | **свойство** — что меняем (цвет текста) |
| `#2b5fd9` | **значение** — на что меняем |
| `color: #2b5fd9;` | **объявление** — пара «свойство: значение» |

Читается по-русски: «Всем `<h2>` на странице — цвет текста `#2b5fd9`». Браузер читает `styles.css` сверху вниз и приводит страницу в соответствие с описанием.

**Сделай:** (эксперимент) создай копии файлов визитки: `index.html` → `sandbox.html` и `styles.css` → `sandbox.css`; в `sandbox.html` обнови путь к CSS. В файле `sandbox.css` напиши правило с двумя объявлениями и убери точку с запятой у первого:

```css
h2 {
  color: #2b5fd9
  font-size: 40px;
}
```

**Получишь:** второе объявление не сработало: без `;` браузер склеил две строки и запутался. Точка с запятой — разделитель объявлений; ставь её всегда, даже после последнего. Исправь ошибку.

### Три способа задать стили

**kind:** `text`

Одно и то же правило можно записать тремя способами:

1. **инлайн** — атрибут `style="..."` прямо на теге:
   ```html
   <h2 style="color: #2b5fd9;">Отделы</h2>
   ```
   Работает, но оформление смешивается с содержимым и не переиспользуется. Костыль для крайних случаев.
2. **тег `<style>` в `<head>`** — стили прямо в HTML-файле. Удобно для экспериментов и одностраничных демо; так устроены онлайн-редакторы.
3. **внешний файл через `<link>`** — стили живут отдельно, как в нашем проекте:
   ```html
   <link rel="stylesheet" href="styles.css">
   ```
   HTML чистый, стили переиспользуются. Наш выбор для проектов.

Для экспериментов у тебя есть песочница `sandbox.html` + `sandbox.css` или онлайн-редактор [w3schools Tryit](https://www.w3schools.com/tryit/tryit.asp?filename=tryhtml_css).

**Соглашение наших уроков:** онлайн-редактор — в `<style>`; файл-песочница и все проекты — внешний CSS-файл; инлайн не используем.

**Сделай:** покрась заголовок песочницы в синий всеми тремя способами по очереди: сначала инлайном, потом перенеси в `<style>`, потом — во внешний CSS-файл.

**Получишь:** результат одинаков во всех трёх случаях — меняется только место, где живёт правило.

### Селекторы, классы и комбинаторы

**kind:** `text`

| Селектор | Пример | Кого выбирает |
|---|---|---|
| тип | `p { }` | все `<p>` на странице |
| класс | `.lead { }` | все с `class="lead"` |
| id | `#header { }` | один с `id="header"` |
| универсальный | `* { }` | вообще всё |

**Класс** — рабочий селектор интерфейсов: группирует элементы «одного вида». В один тег можно добавить несколько классов (`<p class="lead list primary">`), один класс — повесить на разные теги. Правило вкуса: один класс делает одну вещь.

**Комбинаторы** выбирают по связи:

- `.card p` — потомок: любой `p` где-то внутри `.card`;
- `.card > .badge` — прямой ребёнок: только `.badge` — непосредственный ребёнок `.card`;
- `h2, p` — запятая — не комбинатор, а **группировка**: одно правило сразу для нескольких селекторов.

**Сделай:** в песочнице собери страницу с заголовком, тремя абзацами (один — с `class="lead"`) и добавь правила:

```css
p {
  font-style: italic;
}

.lead {
  font-style: normal;
}
```

**Получишь:** все три абзаца наклонились, но «Абзац-лидер» — прямые. Селектор по классу нашёл только его.

### Каскад, специфичность и наследование

**kind:** `text`

Когда два правила претендуют на один элемент, браузер судит так:

1. `!important` — переопределяет всё. Это костыль, не используем;
2. **специфичность**: id сильнее класса, класс сильнее типа. `.lead` весит больше, чем `p`, — поэтому «Абзац-лидер» прямые;
3. **порядок**: при равном весе побеждает правило **ниже** в файле.

**Сделай:** продублируй правило `h2` вторым разом, но с другим цветом:

```css
h2 {
  color: #b30000;
}
```

**Получишь:** заголовок покраснел — равный вес, выиграло нижнее правило.

Ещё одно свойство языка — **наследование**: часть стилей дети берут у родителей (`color`, `font-family`, `font-size`, `line-height`), а `margin`, `padding`, `border` — нет.

**Сделай:** замени все правила на одно:

```css
body {
  color: #8a055d;
}
```

**Получишь:** весь текст на странице — малиновый: цвет «стёк» с `body` на всё содержимое. Одно правило — вся страница.

### Термины урока

**kind:** `text`

- **правило CSS** — от англ. `rule` — «правило»: селектор + объявления в фигурных скобках
- **селектор** — от англ. `selector` — «выбирающий» (от `select` — «выбирать»): то, как правило находит элементы: `p`, `.card`, `#top`
- **объявление** — от англ. `declaration` — «объявление»: пара `свойство: значение;` внутри правила
- **свойство** — от англ. `property` — «свойство»: что именно меняем: цвет, размер, отступ
- **каскад** — от франц. `cascade` — «водопад»: правила «текут» вниз: при равном весе побеждает нижнее
- **специфичность** — от англ. `specificity` — «конкретность»: вес селектора: id > класс > тип
- **наследование** — от англ. `inheritance` — «наследование»: дети берут часть стилей родителей: color, font...
- **инлайн-стиль** — от англ. `inline` — «в строке»: `style="..."` на элементе; мы не используем. Не путай с инлайн-элементами из p1-l3: там слово про тип тега, здесь — про способ записи CSS
- **комбинатор** — от лат. `combinare` — «соединять»: выбор по связи: `.card p` — потомок
- **`!important`** — от англ. `important` — «важный»: ломает каскад; костыль — не используем
- **костыль** — быстрое, временное и часто грубое решение проблемы в коде, которое устраняет внешние симптомы бага, но не решает его первопричину
- **баг** — от англ. `bug` — «жук»: во времена зарождения IT один жук стал причиной сбоя программы. С тех пор ошибки в программе обозначаются этим словом
