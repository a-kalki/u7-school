# Flexbox: строка, выравнивание, gap

**Краткое содержание:**
Поток не умеет выстраивать элементы в ряд и раздавать им пространство. Flexbox умеет: контейнер и его элементы, главная и поперечная оси, `flex-direction`, выравнивание через `justify-content` и `align-items`, ровные зазоры через `gap`. Свойство `flex` у элементов: как делить место, растягиваться и прижиматься к краю. В конце — собираем шапку портала.

### Подробный конспект

#### 1. Зачем flexbox

В нормальном потоке блочные элементы упрямо встают друг под друга. Выстроить их **в ряд** и раздать им пространство поток не умеет. Flexbox решает это: раскладывает элементы в одном направлении и управляет их выравниванием.

#### 2. Контейнер и элементы

Flexbox включается **на родителе**:

```css
.row {
  display: flex;
}
```

Родитель становится **flex-контейнером**, а его дети — **flex-элементами**: они выстраиваются в ряд и сами решают, как поделить место.

**Сделай:** в песочнице собери строку из трёх блоков с фонами и отступами.

**Получишь:** блоки встали в один ряд и перестали растягиваться на всю ширину — включился flex и ужал их по содержимому.

#### 3. Две оси

У flex-контейнера две оси:

- **главная ось (main axis)** — вдоль неё выстраиваются элементы; по умолчанию горизонтально;
- **поперечная ось (cross axis)** — перпендикулярно главной.

Направление главной задаёт `flex-direction`: `row` (по умолчанию), `column`, а также развёрнутые `row-reverse` и `column-reverse`.

**Сделай:** добавь контейнеру `flex-direction: column`.

**Получишь:** блоки встали в столбик: главная ось повернулась и потянула элементы за собой. «Главная» и «поперечная» — понятия относительные, они меняются вместе с направлением.

#### 4. Выравнивание

- **`justify-content`** — распределяет элементы вдоль **главной** оси: `flex-start`, `center`, `flex-end`, `space-between`, `space-around`;
- **`align-items`** — выравнивает по **поперечной** оси: `flex-start`, `center`, `flex-end`, `stretch`.

**Сделай:** верни `flex-direction: row` и добавь `justify-content: space-between` и `align-items: center` на высоком контейнере.

**Получишь:** блоки разъехались по краям, а по вертикали встали по центру. Вертикальное центрирование — теперь одна строка, без костылей.

#### 5. gap: ровные зазоры

`gap` задаёт зазор **между** элементами, не добавляя лишнего по краям.

**Сделай:** добавь `gap: 16px` и убери `justify-content`.

**Получишь:** ровные промежутки между блоками. Это удобнее, чем `margin` у каждого элемента: не нужно гасить лишний отступ у крайних.

#### 6. flex-элементы: как делят место

Свойство `flex` пишется у **детей**: `flex: grow shrink basis` — «расти / сжиматься / базовый размер».

- `flex: 1` — элементы растягиваются поровну на всё свободное место;
- `flex: 0 0 300px` — фиксированная ширина, не растёт и не сжимается;
- `flex: 2` и `flex: 1` — первый получит вдвое больше места.

Приём «распорки»: пустой элемент с `flex: 1` забирает всё свободное место и прижимает остальные к краю.

**Сделай:** сделай первый блок фиксированным (`flex: 0 0 120px`), второй — растягивающимся (`flex: 1`).

**Получишь:** второй блок растянулся. Так строят панели: слева — лого, справа — всё остальное.

#### 7. Перенос и порядок

- `flex-wrap: wrap;` — разрешает перенос на новую строку вместо бесконечного сжатия;
- `order` — меняет визуальный порядок, не трогая разметку (например, `order: -1` выносит элемент вперёд).

#### 8. Мини-задание

**Сделай (задача):** сверстай панель инструментов: слева лого, по центру название, справа кнопка. Лого и кнопка фиксированные, название занимает всё свободное место, зазор — 8px.

Подсказки:

- **лого** — простой квадрат 32×32 с буквой «Д»: `<span class="logo-mark">Д</span>`; размеры и цвета задай в CSS (цвет — из токенов);
- **имя компании** — главный заголовок страницы, поэтому `<h1>`;
- **кнопка** — тег `<button>`;
- панель — flex-контейнер, выравнивание по центру поперечной оси; название растягивается через `flex: 1`; зазор — одним `gap`.

**Получишь:** аккуратную панель, где название «дышит» между лого и кнопкой. Это заготовка будущей шапки.

### Шаг портала: собираем шапку

Цель проекта 3 — каркас приложения, и его верхняя зона — **шапка**: логотип слева и название компании рядом. Соберём шапку в песочнице, а в p3-l4 перенесём её в портал.

**Логотип — простой:** квадрат 32×32 акцентного цвета с белой буквой «Д» (первая буква «Дала Технолоджи»).

```html
<span class="logo-mark">Д</span>
```

```css
.logo-mark {
  width: 32px;
  height: 32px;
  background: var(--color-accent);
  color: var(--color-surface);
  font-size: 18px;
  font-weight: bold;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

Что здесь к чему:

- `<span>` — строчный элемент: «Д» — просто символ, отдельной смысловой зоны нет;
- `width` / `height` — размер лого 32×32 по норме;
- `display: flex` + `align-items` + `justify-content` — тот же flex из этого урока: буква встаёт ровно в центр квадрата;
- `background` / `color` — акцентный цвет и цвет поверхности из токенов: сменишь токен — лого перекрасится;
- `font-weight: bold` — буква жирная, чтобы читалась в маленьком квадрате.

**Название компании** — это главный заголовок страницы, поэтому тег `<h1>`. В шапке он меньше, чем был на визитке.

Собираем шапку — flex-строку:

```html
<header class="header">
  <span class="logo-mark">Д</span>
  <h1>ТОО «Дала Технолоджи»</h1>
</header>
```

```css
.header {
  display: flex;
  align-items: center;
  gap: 8px;
  padding: 8px 24px;
  background: var(--color-surface);
  border-bottom: 1px solid var(--color-border);
}

.header h1 {
  margin: 0;
  font-size: 20px;
}
```

Что здесь к чему:

- `<header>` — семантическая зона «шапка» (подробно о зонах — в p3-l4);
- `display: flex` + `align-items: center` + `gap: 8px` — лого и название в одну строку, по центру, с зазором 8px;
- `padding: 8px 24px` — внутренние отступы по норме: 8 сверху и снизу, 24 по бокам;
- `background` и `border-bottom` — белый фон и тонкий разделитель снизу по норме;
- `h1 { margin: 0; font-size: 20px }` — убираем браузерный отступ и уменьшаем размер: в шапке название — часть интерфейса.

**Сделай:** собери шапку в песочнице по этому коду. В DevTools выбери `header`, `logo-mark` и `h1` — проверь размеры и заливки.

**Получишь:** готовую шапку портала: лого 32×32 и название на белой полосе с разделителем. В p3-l4 она встанет в `header` портала.

> Если захочешь векторный логотип вместо буквы-символа: тот же квадрат с буквой можно собрать лёгким SVG (`<rect>` + `<text>`) — он не мутнеет при увеличении и весит мало. Для шапки достаточно и `span`.

### Термины урока

- **flexbox** — сокращение от `Flexible Box Layout` — «гибкая блочная раскладка»: раскладка в одном направлении
- **flex-контейнер** — родитель с `display: flex`; задаёт правила для детей
- **flex-элемент** — любой прямой ребёнок контейнера
- **main axis** — от англ. `main` — «главный» + лат. `axis` — «ось»: главная ось, вдоль которой идут элементы
- **cross axis** — от англ. `cross` — «поперечный»: ось, перпендикулярная главной
- **`flex-direction`** — от англ. — «направление flex»: `row`, `column` и развёрнутые варианты
- **`justify-content`** — от англ. `justify` — «выравнивать»: распределение вдоль главной оси
- **`align-items`** — от англ. `align` — «выравнивать»: выравнивание по поперечной оси
- **`gap`** — от англ. `gap` — «зазор»: ровный промежуток между элементами
- **`flex`** — от англ. `flexible` — «гибкий»: короткая запись `grow shrink basis`
- **toolbar** — от англ. `tool` — «инструмент» + `bar` — «полоса»: панель с элементами управления
- **SVG** — от `Scalable Vector Graphics` — «масштабируемая векторная графика»: картинка из фигур и линий, описанных разметкой (необязательный вариант лого)
- **`viewBox`** — от англ. `view` — «вид» + `box` — «рамка»: внутренняя система координат SVG, по которой рисуются фигуры
