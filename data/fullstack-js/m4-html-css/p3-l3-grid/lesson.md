# Grid: строки, колонки, fr

**Краткое содержание:**
Flexbox раскладывает в одну линию, а Grid — в двух измерениях: строки и колонки. Контейнер и треки, `grid-template-columns`, единица `fr`, зазоры `gap`, автосоздание строк. Гибкие сетки через `repeat()`/`minmax()`/`auto-fit` и явное размещение элементов. Когда брать grid, а когда flex. В конце — прототип каркаса «сайдбар + рабочий стол».

### Подробный конспект

#### 1. Зачем grid

Flexbox раскладывает элементы в одну линию — строку или колонку. Но у портала **двумерный** каркас: сайдбар и рабочий стол стоят рядом, а внутри — ряды. Для сетки «строки × колонки» есть CSS Grid.

#### 2. Контейнер и треки

Grid включается на родителе:

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr;
}
```

- родитель становится **grid-контейнером**, дети — **grid-элементами**;
- `grid-template-columns` объявляет **колонки**: сколько их и какие;
- **трек (track)** — одна колонка или строка. Представь, что ты расчертил лист линиями и раскладываешь элементы по клеткам.

**Сделай:** собери сетку из двух блоков с колонками `200px 1fr`.

**Получишь:** два блока встали в две колонки: ровно 200px и всё оставшееся место. Это половина каркаса портала.

#### 3. Единица fr

`fr` — от слова «fraction», «доля». Она делит **свободное** место между колонками:

- `200px 1fr` — первая фиксированная, вторая забирает остаток;
- `1fr 1fr` — две равные колонки;
- `1fr 2fr` — вторая вдвое шире первой.

**Сделай:** поставь `1fr 2fr` и обнови.

**Получишь:** правая колонка стала вдвое шире. Свободное место делится по числу «fr»: 1 + 2 = 3 части.

#### 4. gap: зазоры между клетками

**Сделай:** добавь `gap: 16px`.

**Получишь:** ровные промежутки и по вертикали, и по горизонтали. У grid `gap` работает сразу в оба направления (есть также `row-gap` и `column-gap`).

#### 5. Строки

Колонки мы задаём, а строки grid создаёт **сам** — по мере наполнения элементами. Нужны явные строки — объяви `grid-template-rows`.

**Сделай:** добавь в контейнер ещё два блока (итого четыре) при `1fr 1fr`.

**Получишь:** элементы разложились по двум колонкам и двум строкам; grid сам решил, сколько строк получилось.

#### 6. Гибкие колонки: repeat и minmax

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
```

- `repeat(...)` — повторяет трек столько раз, сколько влезет;
- `minmax(200px, 1fr)` — колонка не уже 200px и не шире одной доли;
- `auto-fit` — сам подбирает число колонок под ширину контейнера.

**Сделай:** (эксперимент) собери карточки и потихоньку сужай окно.

**Получишь:** колонки сами пересчитываются: три → две → одна. Ни одной строки на JS, только CSS.

#### 7. Размещение элементов

По умолчанию элементы раскладываются по порядку, но можно указать клетку явно:

- `grid-column: 1 / 3;` — элемент растянут с первой линии до третьей (на две колонки);
- `grid-row: 2 / span 2;` — начиная со второй строки, занять две строки.

**Сделай:** заставь один блок занять обе колонки: `grid-column: span 2;`.

**Получишь:** блок растянулся на всю ширину сетки. Приём пригодится для объединения колонок в строках таблиц.

#### 8. Grid или flex

| | Flexbox | Grid |
|---|---|---|
| Направление | одно (строка **или** колонка) | два (строки **и** колонки) |
| Похоже на | вереницу | расчерченный лист |
| Когда брать | панель, шапка, меню, выравнивание | каркас страницы, сетка карточек |

Практическое правило: сначала думай о форме. Лента в одну сторону — flex. Нужны ряды и столбцы одновременно — grid. Мы применим оба: шапку сделаем на flex, каркас «сайдбар + рабочая область» — на grid.

### Термины урока

- **grid** — от англ. `grid` — «сетка, решётка»: двумерная раскладка
- **grid-контейнер** — родитель с `display: grid`
- **grid-элемент** — прямой ребёнок grid-контейнера
- **track** — от англ. `track` — «дорожка»: одна колонка или одна строка сетки
- **`grid-template-columns`** — от англ. `template` — «шаблон» + `columns` — «колонки»: объявление колонок
- **`fr`** — от англ. `fraction` — «доля»: единица, делящая свободное место
- **`repeat()`** — от англ. `repeat` — «повторять»: повторение трека заданное число раз
- **`minmax()`** — от англ. `minimum`/`maximum` — «минимум»/«максимум»: границы размера трека
- **`auto-fit`** — от англ. `auto` — «автоматически» + `fit` — «умещать»: сам подбирает число колонок
- **`grid-column`** — от англ. `grid` — «сетка» + `column` — «колонка»: размещение по колонкам
- **`gap`** — от англ. `gap` — «зазор»: промежуток между треками
