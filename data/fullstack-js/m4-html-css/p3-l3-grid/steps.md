# Шаги урока: Grid: строки, колонки, fr

---

### Теория урока на w3schools

**kind:** `text`

Flexbox раскладывает элементы в одну линию — строку или колонку. Но у портала есть **двумерный** каркас: сайдбар и рабочий стол стоят рядом, а внутри — множество строк. Для сетки «строки × колонки» есть CSS Grid.

Прочитай страницу курса:

- [HTML & CSS: Grid Layout](https://www.w3schools.com/htmlcss/htmlcss_layout_grid.asp)

Обрати внимание на `grid-template-columns`, единицу `fr`, `gap` и функцию `minmax()`.

---

### Контейнер и треки

**kind:** `text`

Grid включается на родителе, как и flex:

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr;
}
```

- родитель становится **grid-контейнером**, дети — **grid-элементами**;
- `grid-template-columns` объявляет **колонки**: сколько их и какие они;
- **трек (track)** — одна колонка или строка. Представь, что ты расчертил лист линиями и раскладываешь элементы по клеткам.

**Сделай:** в песочнице собери сетку:

```html
<div class="grid">
  <div>Левая колонка</div>
  <div>Правая колонка</div>
</div>
```

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr;
  background: #e8eefb;
}

.grid div {
  background: #2b5fd9;
  color: #fff;
  padding: 16px;
}
```

**Получишь:** два блока встали в две колонки: ровно 200px и всё оставшееся место. Это уже половина каркаса портала (сайдбар + рабочий стол).

> Мы получили почти такой же результат как в `flex`. Может возникнуть вопрос, в чем разница. `Flex` это гибкая разметка, как правило в одну строку, но если элементы не помещаются, то могут "перетекать" на следующую. `Grid` это чисто табличная разметка. Мы можем сразу определять сколько столбов и строк должно быть и так и будет.

### Единица fr: доли свободного места

**kind:** `text`

`fr` — от слова «fraction», «доля». Она делит **свободное** место между колонками:

- `grid-template-columns: 200px 1fr;` — первая колонка фиксированная, вторая забирает остаток;
- `grid-template-columns: 1fr 1fr;` — две равные колонки;
- `grid-template-columns: 1fr 3fr 4fr;` — первая 12.5%, вторая 37.5%, третья 50%.

**Сделай:** поставь `grid-template-columns: 1fr 2fr;` и обнови.

**Получишь:** правая колонка стала вдвое шире левой. Свободное место делится по числу «fr»: 1 + 2 = 3 части, первая колонка — одна часть, вторая — две.

---

### gap: зазоры между клетками

**kind:** `text`

**Сделай:** добавь в `.grid` `gap: 16px;`.

**Получишь:** ровные промежутки и по вертикали, и по горизонтали. У grid `gap` работает сразу в оба направления (можно задать отдельно `row-gap` и `column-gap`).

### Строки

**kind:** `text`

Колонки мы задаём, а строки grid создаёт **сам** — по мере наполнения элементами. Нужны явные строки — объяви `grid-template-rows`.

**Сделай:** добавь в контейнер ещё два блока (итого четыре).

**Получишь:** элементы автоматически разложились по двум колонкам и двум строкам. Grid сам решил, сколько строк получилось.

**Сделай:** Удали один блок и посмотри как в этом случае будет выглядеть таблица.

### Гибкие колонки: repeat и minmax

**kind:** `text`

Живую сетку карточек удобно не считать вручную:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
```

- `repeat(...)` — повторяет трек столько раз, сколько влезет;
- `minmax(200px, 1fr)` — колонка не уже 200px и не шире 1 доли свободного места;
- `auto-fit` — сам подбирает число колонок под ширину контейнера.

**Сделай:** (эксперимент) собери карточки и потихоньку сужай окно браузера.

**Получишь:** колонки сами пересчитываются: влезали три — стало две, потом одна. Ни одной строки в JS, только CSS.

### Размещение элементов

**kind:** `text`

По умолчанию элементы раскладываются по порядку, но можно указать клетку явно:

- `grid-column: 1 / 3;` — элемент растянут с первой линии до третьей (то есть на две колонки);
- `grid-row: 2 / span 2;` — начиная со второй строки, занять две строки.

**Сделай:** заставь один блок занять обе колонки: `grid-column: span 2;`.

**Получишь:** блок растянулся на всю ширину сетки. Приём пригодится, когда строке в таблице нужно объединить колонки.

### Grid или flex?

**kind:** `text`

Оба инструмента раскладывают элементы, но по-разному:

| Описание | Flexbox | Grid |
|---|---|---|
| Направление | одно (строка **или** колонка) | два (строки **и** колонки) |
| Похоже на | вереницу | расчерченный лист |
| Когда брать | панель, шапка, меню, выравнивание | каркас страницы, сетка карточек |

Практическое правило: **сначала думай о форме.** Лента в одну сторону — flex. Нужны ряды и столбцы одновременно — grid. Мы применим оба: шапку сделаем на flex, а каркас «сайдбар + working area» — на grid.

**kind:** `text`

Каркас портала — это сетка из двух колонок: узкий сайдбар и широкий рабочий стол.

**Сделай:** собери в песочнице контейнер с двумя блоками: первый — ровно 200px (сайдбар), второй — всё остальное (рабочий стол). Слева поставь вертикальный разделитель — тонкую границу справа.

### Термины урока

**kind:** `text`

- **grid** — от англ. `grid` — «сетка, решётка»: двумерная раскладка
- **grid-контейнер** — родитель с `display: grid`
- **grid-элемент** — прямой ребёнок grid-контейнера
- **track** — от англ. `track` — «дорожка»: одна колонка или одна строка сетки
- **`grid-template-columns`** — от англ. `template` — «шаблон» + `columns` — «колонки»: объявление колонок
- **`fr`** — от англ. `fraction` — «доля»: единица, делящая свободное место
- **`repeat()`** — от англ. `repeat` — «повторять»: повторение трека заданное число раз
- **`minmax()`** — от англ. `minimum`/`maximum` — «минимум»/«максимум»: границы размера трека
- **`auto-fit`** — от англ. `auto` — «автоматически» + `fit` — «умещать»: сам подбирает число колонок
- **`grid-column`** — от англ. `grid` — «сетка» + `column` — «колонка»: размещение по колонкам
- **`gap`** — от англ. `gap` — «зазор»: промежуток между треками
