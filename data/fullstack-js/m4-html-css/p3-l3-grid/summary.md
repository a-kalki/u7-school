# Grid: строки, колонки, fr — краткая выжимка

- Grid — двумерная раскладка (строки × колонки); включается на родителе: `display: grid`
- `grid-template-columns` объявляет колонки; **трек** — одна колонка или строка
- `200px 1fr` — фиксированная колонка + остаток; `1fr 2fr` — вторая вдвое шире
- `gap` работает сразу по двум направлениям (есть `row-gap` / `column-gap`)
- Строки grid создаёт сам по мере наполнения; явные — через `grid-template-rows`
- Гибкие сетки: `repeat(auto-fit, minmax(200px, 1fr))` — колонки сами пересчитываются
- Размещение: `grid-column: span 2` / `1 / 3`, `grid-row: 2 / span 2`
- **Grid или flex:** одна лента — flex; ряды и столбцы одновременно — grid
- Проект: шапку делаем на flex, каркас «сайдбар + рабочая область» — на grid
- Мини-задание: дашборд «заголовок + три карточки»; разминка — прототип оболочки
- Домашнее задание: статья «Flexbox и Grid» — как одну задачу решали через `float`/`display: table`, потом через flex и grid
