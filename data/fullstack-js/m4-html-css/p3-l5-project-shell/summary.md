# Проект 3: каркас портала — краткая выжимка

- Каркас собран по ходу p3-l4; проектный урок — сверка, чек-лист и сдача
- Сверка с растром `p3-app-shell`: шапка → каркас «сайдбар + main» → пять секций
- Шапка: flex, лого 32×32 акцентный + название; отступы 8×24px, разделитель снизу 1px
- Сайдбар: 200px, белый, разделитель справа; пять пунктов 8×16px; первый — активный (мягкий акцент + жирный)
- Секции: поверхность + рамка 1px + отступ 16px, зазор 16px, заголовки `h2` 18px акцентные
- Проверка «прилипания»: прокрутка идёт внутри `main`, шапка и сайдбар стоят
- Таблица «Штат» из визитки на месте, включая «Итого 2400000»; числа голые
- Мягкий акцент — отдельным токеном в `:root`; никаких `<script>`
- Git: ветка `p3-shell`, коммиты по шагам, финальный `p3: ready for review`, PR → 2 апрува → мердж
