# Первая страница: структура HTML-документа — краткая выжимка

- Boilerplate: `<!DOCTYPE html>` → `<html lang="ru">` → `<head>` (метаданные) → `<body>` (видимое)
- Пользователь видит только `<title>` (вкладка) и содержимое `<body>`
- `lang="ru"` — язык страницы (доступность, поиск); `charset="UTF-8"` — кодировка, без неё кириллица = крякозябры
- `viewport` — масштабирование на экранах; вставляем всегда
- `<link rel="stylesheet" href="styles.css">` в `<head>` — подключение CSS
- Рабочий цикл: изменил → **сохранил** → F5. Не сохранил — браузер показывает старое
- Репозиторий `payroll-portal/`: `index.html` + пустой `styles.css`; title и h1 — «ТОО «Дала Технолоджи»»
- Шаг визитки: скелет + h1; коммит `p1: document skeleton`
