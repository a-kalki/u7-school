### Три языка веб-страницы

**kind:** `text`

Любая страница — работа трёх технологий:

- **HTML** — структура и содержимое: *что* на странице (заголовки, абзацы, списки, таблицы);
- **CSS** — оформление: *как* это выглядит (цвета, шрифты, отступы, расположение);
- **JavaScript** — поведение: *как* страница реагирует на действия.

Аналогия: HTML — каркас и комнаты дома, CSS — отделка и интерьер, JS — электрика и автоматика.

В этом модуле мы строим **каркас и отделку**. Твой продукт — портал предприятия «ТОО «Дала Технолоджи»» — будет статичным сайтом: все данные (штат, сотрудники, табель, зарплаты) ты вшиваешь в HTML буквально. В модуле «DOM» JavaScript прочитает эти данные прямо из страницы и научится считать.

**Сделай:** мысленно раздели любую знакомую страницу — почту или новостной сайт — на три слоя: что здесь структура, что оформление, а что поведение.

### Как браузер показывает страницу

**kind:** `text`

Браузер читает HTML-файл, строит из него **дерево элементов** и рисует его, применяя CSS. Нет CSS — страница «голая»: чёрный текст на белом. Именно такой будет твоя первая визитка, и это нормально: сначала структура, потом красота.

Браузер **прощает ошибки разметки**: страница откроется, даже если ты забыл закрыть тег. Но выглядеть она может не так, как задумано. Поэтому проверяем не «открылось ли», а *что именно* открылось — через DevTools.

**Рабочее место** — два инструмента, оба у тебя уже есть:

- **браузер** — Chrome, Edge или Firefox;
- **редактор кода** — VS Code или тот, в котором ты работал в предыдущих модулях.

Проект модуля будет жить в репозитории `payroll-portal/` — заведём его на следующем уроке.

### DevTools: рентген страницы

**kind:** `text`

Открой DevTools: `F12` или `Ctrl+Shift+I` (`Cmd+Option+I` на macOS). Или правый клик по элементу страницы → **Inspect** («Просмотреть код»). Слева — панель **Elements**: дерево HTML. Справа — стили выбранного элемента. Здесь же всё можно править прямо в браузере.

**Сделай:** открой любую новостную страницу, кликни правой кнопкой по заголовку новости → Inspect. В дереве Elements найдётся именно этот заголовок. Дважды кликни по его тексту в дереве и впиши что-нибудь своё — например, «Эту новость написал я».

**Получишь:** заголовок на странице мгновенно поменяется. Никакой магии: ты отредактировал копию страницы в памяти браузера.

**Сделай:** обнови страницу (`F5`).

**Получишь:** заголовок вернулся к настоящему. Правки в DevTools временные, до перезагрузки. Настоящий код живёт в файлах — DevTools только для осмотра и экспериментов.

### Инструмент «Выбрать элемент»

**kind:** `text`

Самый удобный способ знакомиться с чужой страницей — инструмент **«Выбрать элемент»**:

- **где:** иконка-курсор в левом верхнем углу панели DevTools. Быстрее — горячая клавиша `Ctrl+Shift+C` (`Cmd+Shift+C` на macOS);
- **как:** включил — водишь мышью, элементы подсвечиваются, рядом всплывает ярлык: имя тега, размеры, цвет. **Клик** — элемент раскрыт в дереве Elements. Выход — `Esc`.

**Сделай:** включи «выбрать элемент» и медленно проведи курсором по логотипу, картинке и подвалу новостной страницы.

**Получишь:** каждый элемент подсвечивается, в ярлыке — его тег и размеры: у логотипа один, у картинки другой. Так страница «рассыпается» на отдельные элементы, как под рентгеном.

**Сделай:** кликни по подвалу — он раскрылся в дереве Elements. Теперь води мышью по строкам дерева.

**Получишь:** на странице подсвечивается именно тот элемент, на строке которого курсор. Кликом выбирают элемент со страницы, наведением в дереве — находят его на странице.

**Шпаргалка клавиш:**

| Клавиши | Что делают |
|---|---|
| `F12` или `Ctrl+Shift+I` | открыть/закрыть DevTools |
| `Ctrl+Shift+C` | включить «выбрать элемент» |
| ПКМ → Inspect | открыть DevTools и сразу выбрать элемент |
| `Esc` | выйти из режима выбора |
| `F5` | обновить страницу (сброс правок из DevTools) |

Этим инструментом мы будем пользоваться весь модуль: вёрстка проверяется глазами и DevTools.

**kind:** `text`

**Цель модуля** — дать основы вёрстки: понять, из чего состоит страница и как она строится. Мы пройдём по самым верхам — специалистом по вёрстке ты не станешь, но будешь хорошо понимать, как выстраиваются сайты.

### Термины урока

**kind:** `text`

- **HTML** — от `HyperText Markup Language`, «язык разметки гипертекста»: гипертекст — текст со ссылками, разметка — пометки, описывающие структуру
- **CSS** — от `Cascading Style Sheets`, «каскадные таблицы стилей»: каскад — «водопад», правила «текут» вниз по странице (подробно в П2)
- **JavaScript** — назван «в честь» Java маркетингом 1995 года, с языком Java не связан; на сайте живёт в файлах `.js`
- **DOM** — от `Document Object Model`, «объектная модель документа»: дерево элементов, которое браузер строит из HTML
- **DevTools** — от `Developer Tools`, «инструменты разработчика»: встроенный в браузер набор для осмотра и отладки страниц
- **Inspect** — от англ. `inspect`, «осматривать»: пункт меню ПКМ, показывает элемент в дереве Elements
- **сайт** — от англ. `site`, «место, участок»: набор связанных страниц для просмотра
- **веб-приложение** — от англ. `web application`, «приложение в сети»: страница, реагирующая на действия пользователя
