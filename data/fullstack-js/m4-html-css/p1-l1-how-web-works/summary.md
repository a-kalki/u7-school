# Как устроен веб: браузер, HTML, CSS и JS — краткая выжимка

- **HTML** — структура («что на странице»), **CSS** — оформление («как выглядит»), **JS** — поведение («как реагирует»)
- Модуль 3 — только HTML+CSS: портал статичен, JS подключится в модуле 4
- Сайт — страницы для чтения; веб-приложение — реагирует на действия. Наш портал в М3 — сайт, в М4 станет приложением
- Вёрстка — будущая база данных: JS в М4 прочитает данные прямо из HTML
- Браузер строит дерево элементов и рисует с учётом CSS; без CSS страница «голая» — так и задумано в П1
- Браузер прощает ошибки разметки — проверяем структуру через DevTools, а не «открылось/не открылось»
- DevTools: `F12` / `Ctrl+Shift+I` / ПКМ → Inspect; **Elements** — дерево HTML + стили
- Правки в DevTools временные (до перезагрузки) — инструмент осмотра, код живёт в файлах
- Модуль: 4 проекта — одна растущая работа (визитка → оформление → каркас → портал с данными)
