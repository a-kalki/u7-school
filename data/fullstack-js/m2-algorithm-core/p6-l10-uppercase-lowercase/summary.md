# Функции upperCase() и lowerCase() — краткая выжимка

- upperCase/lowerCase — перевод регистра через коды символов: charCodeAt + String.fromCodePoint
- Разница между регистрами постоянна: 'a' (97) − 'A' (65) = 32; для кириллицы: 'а' (1072) − 'А' (1040) = 32
- Диапазоны: латиница a–z / A–Z, кириллица а–я / А–Я; остальные символы — без изменений
- Функции-зеркала: вторая реализуется быстро, если первая продумана структурно
- Тесты: смесь латиницы и кириллицы, цифры/знаки/пробелы не меняются, пустая строка → ''
