# Функция at(arr, index) — краткая выжимка

- at(arr, index) — элемент по индексу; отрицательный индекс — отсчёт с конца (-1 — последний)
- Индекс за границами или пустой массив → undefined (не ошибка!)
- Нормализация отрицательного индекса: позиция = len(arr) + index
- Функция не мутирует массив — отмечаем в JSDoc
- 13 тестов: границы, отрицательные, пустой массив, TypeError
