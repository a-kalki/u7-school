# Как тестировать мутабельные функции — краткая выжимка

- Тест мутабельной функции проверяет два результата: возвращённое значение + состояние массива после вызова
- Для каждого теста — новый массив: переиспользование одного массива между тестами — источник хрупкости
- Тесты независимы: каждый сам создаёт данные, порядок запуска не важен
- С мутабельными функциями это критично: первый тест «портит» общий массив — второй видит испорченные данные
- Один тест = одна проверяемая идея; «подготовка» следующего теста через побочные эффекты — плохо
