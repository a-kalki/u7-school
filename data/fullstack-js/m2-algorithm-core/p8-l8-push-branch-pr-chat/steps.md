### Создание PR по шаблону

**kind:** `text`

Создай PR: base `main` ← compare `feat/array-transform`.

**Заголовок:**
```
Проект 8: Массивы — трансформация
```

**Описание — заполни по шаблону:**

```markdown
## Что сделано

Реализованы 6 функций трансформации массивов (папка array-utils/):

- fill(arr, value, start, end) — заполнение значением (мутирует)
- reverse(arr) — переворот на месте, алгоритм двух указателей (мутирует)
- concat(arr1, arr2) — объединение в новый массив (иммутабельная)
- slice(arr, start, end) — копирование подмассива (иммутабельная)
- join(arr, separator) — склеивание в строку (иммутабельная)
- splice(arr, start, deleteCount, ...items) — удаление и вставка (мутирует)

## Особенности реализации

- Мутабельные функции возвращают тот же массив (fill, reverse) —
  проверено тестами
- splice реализован в два шага: сначала удаление, затем вставка
  через rest-параметр ...items
- join: null и undefined при склейке дают пустую строку (как
  стандартный Array.prototype.join)
- Нормализация отрицательных индексов — как в строковом slice
  проекта 6

## Как запустить тесты

bun test
```

Что важно для ревьюеров, может быть не очевидно — обязательно указывай. Если считаешь, что команда «в теме», часть разделов можно сократить.
