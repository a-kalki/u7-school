# Функция splice(arr, start, deleteCount, ...items)

**Краткое содержание:**
Самая сложная функция проекта: удаление и вставка элементов. Реализация в два захода: сначала удаление, затем вставка. Новая техника — rest-параметр.

**Время:** ~20 мин

**Основные темы:**
1. Часть 1: только удаление
2. Часть 2: вставка элементов
3. Сохрани изменения

**Термины:**
rest-параметр — сбор остальных аргументов функции в массив (`...items`) — понадобится во второй части;
вариадическая функция — функция, принимающая любое число аргументов
