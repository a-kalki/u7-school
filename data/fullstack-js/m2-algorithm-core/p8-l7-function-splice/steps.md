# Шаги урока: Функция splice(arr, start, deleteCount, ...items)

---

### Реализация splice() — часть 1: только удаление

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

`splice` — самая сложная функция проекта. Разобьём на две части: сначала реализуй удаление, затем добавление.

**Часть 1: только удаление.** Реализуй `splice(arr, start, deleteCount)` без вставки новых элементов. Создай файлы `array-utils/splice.js` и `array-utils/splice.test.js`.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)
- `start`: `number` — начальный индекс (поддержка отрицательных)
- `deleteCount`: `number` (необязательный) — сколько элементов удалить. Если не передан — удалить всё до конца

**Функция возвращает:** `array` — массив удалённых элементов.

**Важно:** функция **мутабельная** — меняет исходный массив и возвращает отдельный массив удалённых элементов. В JSDoc отметь это: мутация + возвращаемое значение — обе части контракта.

**Термины:**
rest-параметр — сбор остальных аргументов функции в массив (`...items`) — понадобится во второй части;
вариадическая функция — функция, принимающая любое число аргументов

Тестовые случаи для удаления (каждый — отдельный `test(...)`):
- Должна удалить элемент из середины: `splice([1, 2, 3, 4], 1, 2)` → вернуть `[2, 3]`, массив `[1, 4]`
- Должна удалить с начала: `splice([1, 2, 3], 0, 1)` → вернуть `[1]`, массив `[2, 3]`
- Должна удалить с конца: `splice([1, 2, 3], 2, 1)` → вернуть `[3]`, массив `[1, 2]`
- Должна удалить всё от start до конца если deleteCount не передан: `splice([1, 2, 3, 4], 2)` → вернуть `[3, 4]`, массив `[1, 2]`
- Должна вернуть пустой массив если deleteCount = 0: `splice([1, 2, 3], 1, 0)` → `[]`, массив не изменился
- Должна поддерживать отрицательный start: `splice([1, 2, 3, 4], -2, 1)` → вернуть `[3]`, массив `[1, 2, 4]`
- Должна обрезать deleteCount если он больше оставшихся элементов: `splice([1, 2, 3], 1, 5)` → вернуть `[2, 3]`, массив `[1]`
- Должна вернуть пустой массив если start >= len: `splice([1, 2, 3], 5, 1)` → `[]`
- Должна нормализовать уходящий за границы отрицательный start: `splice([1, 2, 3], -10, 1)` → вернуть `[1]`, массив `[2, 3]`
- Должна ничего не удалять при отрицательном deleteCount: `splice([1, 2, 3], 1, -1)` → вернуть `[]`, массив `[1, 2, 3]`
- Должна выбросить `TypeError` если `arr` не массив

```

git commit -m "Реализована splice, часть 1 — удаление элементов"
```

### Реализация splice() — часть 2: вставка

**kind:** `text`

Теперь добавь поддержку вставки элементов. Функция должна принимать дополнительные аргументы после `deleteCount`:

```javascript
function splice(arr, start, deleteCount, ...items)
```

`...items` — **rest-параметр**: все аргументы, переданные после `deleteCount`, собираются в массив `items`. Функция становится вариадической — принимает любое число аргументов.

Тестовые случаи для вставки (добавь к существующим тестам):
- Должна вставить элементы на место удалённых: `splice([1, 2, 3], 1, 1, 'a', 'b')` → вернуть `[2]`, массив `[1, 'a', 'b', 3]`
- Должна вставить элементы без удаления: `splice([1, 2, 3], 1, 0, 'x')` → вернуть `[]`, массив `[1, 'x', 2, 3]`
- Должна вставить в начало: `splice([2, 3], 0, 0, 0, 1)` → вернуть `[]`, массив `[0, 1, 2, 3]`
- Должна вставить в конец: `splice([1, 2], 2, 0, 3, 4)` → вернуть `[]`, массив `[1, 2, 3, 4]`
- Должна вставить по отрицательному start: `splice([1, 2, 3], -1, 0, 'x')` → вернуть `[]`, массив `[1, 2, 'x', 3]`
- Должна заменить элементы: `splice([1, 2, 3], 0, 2, 'a')` → вернуть `[1, 2]`, массив `['a', 3]`
