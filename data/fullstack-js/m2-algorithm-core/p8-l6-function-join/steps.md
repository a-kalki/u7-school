# Шаги урока: Функция join(arr, separator) — склеивание массива в строку

---

### Реализация join() через TDD

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

Реализуй функцию `join(arr, separator)` — склеивание элементов массива в строку. Создай файлы `array-utils/join.js` и `array-utils/join.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив элементов
- `separator`: `string` (необязательный, по умолчанию `','`) — разделитель между элементами

**Функция возвращает:** `string` — строка из элементов, разделённых `separator`.

**Важно:** функция **иммутабельная** — массив не меняется. Это первая функция, которая превращает массив в строку (обратная операция раньше встречалась только через конкатенацию вручную).

**Подсказки:**
- Разделитель вставляется **между** элементами, а не после каждого: `'1-2-3'`, а не `'1-2-3-'`
- Числа и булевы приводятся к строке: `42` → `'42'`, `true` → `'true'`
- Особый случай — `null` и `undefined`: при склейке они дают **пустую строку**, а не `'null'`/`'undefined'` (так ведёт себя стандартный `Array.prototype.join`). Это видно из теста `join([1, undefined, null, 3])` → `'1,,,3'` — обработай случай явно

**Термины:**
сериализация — превращение структуры данных (массива, объекта) в строку для хранения или передачи, например: `[1, 2, 3]` → `'1;2;3'` (перевод в CSV)

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна склеить с разделителем по умолчанию (запятая): `join([1, 2, 3])` → `'1,2,3'`
- Должна склеить с явным разделителем: `join([1, 2, 3], '-')` → `'1-2-3'`
- Должна склеить с пробелом: `join(['a', 'b', 'c'], ' ')` → `'a b c'`
- Должна склеить с пустым разделителем: `join(['a', 'b', 'c'], '')` → `'abc'`
- Должна вернуть `''` для пустого массива
- Должна вернуть `''` для пустого массива с явным разделителем: `join([], '-')` → `''`
- Должна работать с многосимвольным разделителем: `join(['a', 'b'], '--')` → `'a--b'`
- Должна вернуть строку из одного элемента без разделителя: `join([42], ',')` → `'42'`
- Должна работать с `null` и `undefined` как элементами: `join([1, undefined, null, 3])` → `'1,,,3'`
- Должна работать с булевыми значениями: `join([1, true, false])` → `'1,true,false'`
- Исходный массив не должен измениться
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `separator` передан и не строка
