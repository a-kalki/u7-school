# Практика: мини-ревью на образце

**Краткое содержание:**
Тренировка ревью на учебном примере: находишь предложение и критическое замечание в «воображаемом» коде, затем сверяешься с разбором.

**Время:** ~20 мин

**Основные темы:**
1. Поиск проблем в чужом коде
2. Формулировка по правилам команды
3. Разбор эталонного ревью

**Термины:**
граничный случай — ситуация на краю допустимых входных данных (пустая строка, разная длина, `undefined`)
