# Практика: мини-ревью на образце — краткая выжимка

- Тренировка на образце: код isEqual с двумя заложенными проблемами
- Найти минимум: 1 предложение («Предлагаю X, потому что Y») и 1 критическое замечание («Нужно X, потому что Y»)
- Критическое в образце: нет проверки длин строк — ошибка на `undefined.charCodeAt(0)` или ложный `true`
- Предложение в образце: переименовать `code1`/`code2` в `charCodeA`/`charCodeB`
- `.charCodeAt()` — разрешённый метод, нарушения правил модуля нет
- Найдено критическое → итог ревью: Request changes
