# Функция replaceAll(str, search, replacement) — краткая выжимка

- replaceAll(str, search, replacement) — заменяет все вхождения search
- Главная тонкость: заменённый текст не участвует в дальнейшем поиске — поиск продолжается после вставленного replacement
- `'aaa'.replaceAll('aa', 'ba')` → `'baa'`, а не `'ba'` — проверь этот случай обязательно
- Пустой search — отдельный случай: replacement вставляется между всеми символами
- Пустая исходная строка → `''`
