# Шаги урока: Доработка по ревью

---

### Процесс доработки

**kind:** `text`

Твой homework-PR лежит в чате, и ревьюеры — живые люди: они увидят его не сразу. Ждать в пустую не нужно.

**Как работает этот урок:**

1. Прочитай все шаги **сейчас** — чтобы понимать процесс
2. Когда ревьюеры оставят комментарии (возможно, через несколько часов или на следующий день) — вернись к этому уроку и выполни шаги по-настоящему
3. Если шаг понятен сейчас — смело жми «Выполнено»

**Термины:**
отложенное действие — шаг, который выполняется не сейчас, а когда случится событие (придут комментарии);
conversation — обсуждение: комментарий ревьюера и ответы под ним в PR;
resolved — пометка «вопрос закрыт» на conversation

---

Когда ревьюер оставил замечания к твоему PR, нужно их отработать. Процесс:

1. Прочитай комментарий → пойми суть замечания
2. Ответь: «Согласен, исправлю» ИЛИ «Не согласен, потому что...»
3. Внеси правки локально.
4. Как обработаешь все коменты: `git add` → `git commit` → `git push`
5. PR на GitHub обновится автоматически
6. Отметь комментарий как **resolved** (если согласен и исправил)
7. Если в ревью ставили `Request changes` запроси повторное ревью (🔄 в панели Reviewers), если написали комменты но дали `Approve`, то можешь мерджить (если уже собрал два Approve и больше нет активных замечаний)

---

### Практика: ответ на замечание

**kind:** `text`

Представь: ревьюер оставил комментарий к твоему `homework.md`:

> В разделе «Кто я» весь текст идёт сплошным абзацем — тяжело читать. Предлагаю разбить на два-три абзаца и добавить, почему ты выбрал именно этот курс.

Допустим что ты принял замечания (это шаги для одного комментария):

1. Свой ответ ревьюеру (да, так будет лучше, сделаю)
2. Внеси изменения в нужные файлы
3. После исправления — в интерфейсе PR запиши что сделано (например: сделано!)

> 💡 Если комментарии к твоему PR уже пришли — выполняй задание по-настоящему, на реальном замечании.

---

### Запрос повторного ревью

**kind:** `text`

Когда все правки внесены и на все комментарии отвечено:

1. Сделай комит и пуш
2. В правой панели PR найди ревьюеров
3. Рядом с именем каждого — иконка «повторного запроса» (две стрелки по кругу)
4. Нажми её для каждого ревьюера

Также можешь написать в чате:

```
Правки по ревью внесены, жду повторной проверки 🙏
```

Сейчас, возможно, повторное ревью тебе не понадобится (у тебя может не быть критических замечаний). Но механику запомни — в проектах с кодом она понадобится почти наверняка.
