# Доработка по ревью — краткая выжимка

- Комментарии могут прийти не сразу — процесс доработки изучи заранее и вернись к нему, когда придут
- Цикл доработки: понял замечание → ответил («согласен» / «не согласен, потому что») → правки → add/commit/push → PR обновился сам → resolved → re-request review
- Соглашаться или спорить — оба ответа нормальны, но спорить нужно с аргументами
- Запрос повторного ревью: иконка 🔄 рядом с именем ревьюера в панели Reviewers (+ сообщение в чат)
- Если комментарии уже пришли — выполняй шаги по-настоящему
