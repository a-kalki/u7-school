# Шаги урока: Мутабельность: изменение массива «на месте»

---

### Что такое мутабельность

**kind:** `text`

Массив передаётся в функцию **по ссылке**. Это значит, что функция работает с тем же самым массивом в памяти, а не с его копией. Если функция меняет массив — изменения видны снаружи.

Различают два типа операций:

- **Мутабельная** — изменяет исходный массив «на месте». Пример: `push` добавляет элемент в конец существующего массива.
- **Иммутабельная** — создаёт новый массив, исходный не трогает. Пример: `concat` возвращает новый массив из двух исходных.

В этом проекте функции `push`, `pop`, `unshift`, `shift` — **мутабельные**. А `len`, `at`, `indexOf`, `lastIndexOf`, `includes` — не мутируют массив (только читают).

Запомни: «мутировать» = «менять на месте то, что тебе дали».

**Термины:**
мутабельность — способность объекта изменяться «на месте» после создания;
иммутабельность — неизменяемость: операции возвращают новый объект, исходный не трогают;
передача по ссылке — функция получает тот же объект в памяти, а не его копию

### Практика: мутабельная или иммутабельная?

**kind:** `text`

Посмотри на гипотетические функции и определи, мутируют они исходный массив или нет. Не запускай код — сначала подумай, потом проверь.

```javascript
// Наш len из проекта 3, но для массивов
function len(arr) {
  let count = 0;
  for (let i = 0; arr[i] !== undefined; i++) count++;
  return count;
}

// Функция A
function addToEnd(arr, item) {
  const length = len(arr);
  arr[length] = item;
  return length + 1;
}

// Функция B
function copyWith(arr, item) {
  const length = len(arr);
  const result = [];
  for (let i = 0; i < length; i++) result[i] = arr[i];
  result[length] = item;
  return result;
}
```

Вопросы:
1. Какая функция мутирует `arr`, а какая — нет?
2. Что выведет этот код:
```javascript
const a = [1, 2];
const ra = addToEnd(a, 3);
console.log('A:', a[2], ra);

const b = [1, 2];
const rb = copyWith(b, 3);
console.log('B:', b[2], rb[2]);
```

### Почему мутабельность опасна

**kind:** `text`

Представь: один и тот же массив используют две части программы. Одна часть мутирует массив, не предупредив другую — и та получает «испорченные» данные.

```javascript
const users = ['Анна', 'Борис', 'Вера'];

function takeFirst(list) {
  // гипотетический shift — удаляет первый элемент из list
  const first = list[0];
  // ...сдвигаем влево...
  return first;
}

const firstUser = takeFirst(users);
console.log('Взяли:', firstUser);
console.log('Осталось:', users[0], users[1], users[2]);
```

Без мутации `users` оставался бы нетронутым. С мутацией — «Анна» исчезает из исходного массива, и любой код, который рассчитывал на три элемента, сломается.

**Вывод:** мутабельные функции мощные, но требуют дисциплины. Нужно всегда знать — меняет функция свой аргумент или нет. Поэтому в JSDoc мы будем явно отмечать мутирующие функции.
