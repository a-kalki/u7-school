# Сортировка выбором (selection sort)

**Краткое содержание:**
Поиск минимума, O(n²), минимум обменов.

**Время:** ~20 мин

**Основные темы:**
- Реализация selectionSort()
- Вопросы на понимание
- Сохрани изменения
- Термины урока

**Термины:**
* **Selection sort (сортировка выбором)** — на каждом шаге находим минимум в неотсортированной части и ставим его на текущую позицию.
* **Неотсортированная часть** — суффикс массива, который ещё не упорядочен.
* **minIndex** — индекс текущего минимума среди оставшихся элементов.
* **Обмен (swap)** — перестановка двух элементов местами.
* **Минимум обменов** — selection sort делает не более n−1 обменов.
