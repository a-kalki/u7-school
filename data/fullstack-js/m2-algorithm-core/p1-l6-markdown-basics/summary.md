# Markdown за 10 минут — краткая выжимка

- Markdown — разметка обычными символами; файлы `.md`; рендерится на GitHub и почти везде
- Где встретишь: README.md, описание PR, комментарии в issue, homework.md
- Синтаксис: `#` заголовки, `**жирный**`, `*курсив*`, `` `код` ``, списки `-` и `1.`, ссылки `[текст](url)`, чекбоксы `- [ ]`
- Предпросмотр в VS Code: Ctrl+Shift+V (Cmd+Shift+V на Mac)
- ДЗ: [шпаргалка GitHub](https://docs.github.com/ru/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) — найти 3 приёма сверх урока и опробовать
