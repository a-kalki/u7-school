### Что такое markdown и где ты его встретишь

**kind:** `text`

**Markdown** — простой язык разметки: текст форматируется обычными символами, без кнопок и панелей. Файлы markdown имеют расширение `.md`.

Где ты с ним столкнёшься уже в этом проекте:

- **homework.md** — файл, который ты создашь через пару уроков
- **Описание Pull Request** — оформляется markdown'ом
- **README.md** — визитка любого репозитория на GitHub
- **Комментарии в PR и issue** — обсуждения на GitHub тоже пишутся markdown'ом

Смысл простой: ты пишешь обычный текст с небольшими пометками (`#`, `**`, `-`), а GitHub и другие инструменты превращают его в красивую страницу с заголовками, списками и ссылками.

**Термины:**
markdown — простой язык разметки текста обычными символами;
разметка — пометки в тексте, которые описывают его оформление;
рендеринг — превращение разметки в красивую страницу (это делает GitHub или редактор);
предпросмотр — по англ. `preview`: показ результата рендеринга до публикации

### Базовый синтаксис: попробуй сам

**kind:** `text`

Открой VS Code → создай файл `notes.md` (потом удалим). Включи предпросмотр: **Ctrl+Shift+V** (Cmd+Shift+V на Mac). Набирай и смотри, что получается:

```
# Заголовок 1 уровня
## Заголовок 2 уровня
### Заголовок 3 уровня

Обычный текст. **Жирный текст**. *Курсив*. `код в строке`

Список:
- первый пункт
- второй пункт

Нумерованный список:
1. раз
2. два

Ссылка: [текст ссылки](https://github.com)

Чекбоксы:
- [x] сделано
- [ ] ещё нет

Блок кода — три обратных апострофа до и после:
```
так выглядит блок кода
```
```

**Проверь себя:** в `notes.md` сделай заголовок, выдели один пункт списка жирным и добавь ссылку на github.com. В предпросмотре всё должно выглядеть как задумано. Файл можно удалить — в репозиторий он не попадёт (а если попал — пока не страшно, коммитить его мы не будем).

> 💡 Нет VS Code под рукой — потренируйся в онлайн-редакторе markdown: [markdownlivepreview.com](https://markdownlivepreview.com/) — печатаешь слева, справа сразу видишь отрисованный результат. Регистрация не нужна.

### ДЗ: официальная шпаргалка GitHub

**kind:** `text`

Прочитай официальную шпаргалку по markdown от GitHub — она понадобится тебе в каждом Pull Request:

**[Basic writing and formatting syntax](https://docs.github.com/ru/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)**

**Задание:** найди в статье **три приёма**, которых не было в шаге выше (например: таблицы, цитаты, зачёркивание, эмодзи). Опробуй каждый в своём `notes.md` через предпросмотр.

Это домашнее задание — но не одноразовое: возвращайся к шпаргалке каждый раз, когда оформляешь описание PR.
