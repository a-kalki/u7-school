# Функция isEqual()

**Краткое содержание:**
Первая функция сравнения — `isEqual(a, b)`: полный TDD-цикл самостоятельно, с продуманным набором тестов. Коммит.

**Время:** ~30 мин

**Основные темы:**
1. TDD-цикл для isEqual
2. Тестовые случаи: равенство, длины, пробелы, кириллица, исключения

**Термины:**
сигнатура функции — имя, что принимает и что возвращает;
`boolean` — логический тип: `true` или `false`;
посимвольное сравнение — сравнение по одному символу за раз
