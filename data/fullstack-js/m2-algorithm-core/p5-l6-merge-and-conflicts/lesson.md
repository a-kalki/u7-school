# Слияние веток и конфликты

**Краткое содержание:**
Теория merge и конфликтов + практика в изолированных ветках: fast-forward, создание и разрешение конфликта, откат тупика через `reset --hard`.

**Время:** ~35 мин

**Основные темы:**
1. Теория: merge и конфликты
2. Практика: fast-forward merge
3. Практика: конфликт и его разрешение
4. Откат экспериментов: `git reset --hard`

**Термины:**
fast-forward — «перемотка»: слияние без merge-коммита, когда `main` не двигался с момента ветвления;
маркер конфликта — строки `<<<<<<<`, `=======`, `>>>>>>>` в файле с конфликтом;
`git revert` — коммит-отмена: откатывает изменения, не переписывая историю (для уже опубликованных веток)
