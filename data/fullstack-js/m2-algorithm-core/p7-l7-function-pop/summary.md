# Функция pop(arr) — краткая выжимка

- pop(arr) — удаляет последний элемент и возвращает его; МУТАБЕЛЬНАЯ
- Пустой массив → undefined (без ошибки)
- Оператор delete: убирает индекс, оставляя «дырку»; не сдвигает элементы
- delete vs a[i] = undefined: для len результат одинаковый, но delete семантически честнее
- pop через delete: len в следующий раз корректно остановится раньше
- Тесты: возврат + состояние; pop([0]) → 0, не спутать с undefined
