# Что такое Git и зачем он нужен

**Краткое содержание:**
Первый урок проекта: карта всего пути проекта 1, знакомство с ресурсом W3Schools, базовая теория Git (система контроля версий, репозиторий, коммит, stage, ветка).

**Время:** ~15 мин

**Основные темы:**
1. Карта проекта 1: от локальной папки до Pull Request
2. Ресурс W3Schools: регистрация, бесплатно vs PRO, английский язык
3. Что такое система контроля версий, репозиторий, коммит, stage
4. Установка и настройка Git

**Термины:**
система контроля версий — по англ. `Version Control System` (`VCS`): программа, которая хранит историю изменений и позволяет работать параллельно;
репозиторий — по англ. `repository`, сокращённо `repo`: папка проекта под наблюдением Git вместе со всей историей изменений;
коммит — по англ. `commit`: зафиксированное изменение, «снимок» файлов с пояснением что и зачем менялось;
stage (индекс) — «полка» подготовки: что попало в stage, то войдёт в ближайший коммит;
ветка — по англ. `branch`: независимая линия разработки
