# Что такое Git и зачем он нужен — краткая выжимка

- Проект 1 — про инструменты (Git и GitHub), без кода. Путь: папка → репозиторий → коммиты → push → ветка → Pull Request
- Градиент детализации: пока пошаговые инструкции, дальше — ведение по потоку, позже — задания и напоминания
- W3Schools — основной источник теории по Git; регистрация обязательна; бесплатной версии достаточно
- Уроки W3 на английском — это фича: запоминай термины в оригинале (repository, commit, branch, stage)
- Git — система контроля версий: история изменений, параллельная работа, откат
- Ключевые понятия: репозиторий, коммит, stage (индекс), ветка
