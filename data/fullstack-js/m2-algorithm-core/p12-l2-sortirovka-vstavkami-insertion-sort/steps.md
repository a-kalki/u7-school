### Реализация insertionSort()

**kind:** `text`

Убедись, что ты в ветке `feat/sorting` и что `bubbleSort` из урока 1 закоммичена.

**Аналогия алгоритма "Вставкой".** Ты раскладываешь карты в руке по возрастанию. Берёшь новую карту и вставляешь её между теми, что уже лежат в порядке. Ты не перебираешь всю руку заново — только ищешь место для одной карты.

Реализуй функцию `insertionSort(arr)`. Создай файлы `sorting/insertion-sort.js` и `sorting/insertion-sort.test.js`, следуй TDD.

**Функция принимает:** `arr`: `array` — массив чисел для сортировки.

**Функция возвращает:** `array` — новый отсортированный по возрастанию массив.

**Важно:** функция **иммутабельная** — исходный массив не меняется.

**Человеческий псевдокод:**
1. Скопируй массив, чтобы не испортить исходный.
2. Бери элементы по одному, начиная со второго.
3. Для каждого элемента — вставляй его в уже отсортированную левую часть: сдвигай вправо всё, что больше него, пока не найдёшь нужное место.
4. Поставь элемент на освободившееся место.
5. Верни результат.

**Технический алгоритм (подсказка):**
- в начале функции проверь тип: `if (!Array.isArray(arr)) throw new TypeError('arr must be array');`
- сделай копию: `const result = arr.slice();`
- закэшируй длину: `const n = result.length;` и используй `n` в цикле;
- внешний цикл `i` от 1 до `n - 1`;
- запомни `current = result[i]`;
- заведи `j = i - 1` — индекс соседа слева от `current`;
- внутренний цикл `while`: пока `j >= 0` и `result[j] > current`, сдвигай `result[j + 1] = result[j]` и уменьшай `j` (уводим вправо всех, кто больше `current`);
- когда цикл остановился, `j` указывает на элемент ≤ `current` (или на −1), значит свободное место — `j + 1`: поставь туда `current`.

**Тестовые случаи** (каждый — отдельный `test(...)`):
- Пустой массив: `insertionSort([])` → `[]`
- Один элемент: `insertionSort([7])` → `[7]`
- Уже отсортированный: `insertionSort([1, 2, 3])` → `[1, 2, 3]`
- Обратный порядок: `insertionSort([3, 2, 1])` → `[1, 2, 3]`
- С дубликатами: `insertionSort([4, 2, 4, 1])` → `[1, 2, 4, 4]`
- Иммутабельность: исходный массив не изменился
- `insertionSort('abc')` → `TypeError`

### Термины урока

**kind:** `text`

Пройдись по основным понятиям урока. Если что-то не можешь объяснить своими словами — вернись к соответствующему шагу.

**Термины:**
* **Insertion sort (сортировка вставками)** — берём элементы по одному и вставляем каждый в уже отсортированную левую часть.
* **Отсортированная часть** — префикс массива, который уже упорядочен.
* **Сдвиг** — перемещение элемента вправо на одну позицию, чтобы освободить место для вставки.
* **Почти отсортированный массив** — данные, где элементы почти на своих местах; вставки работают почти за один проход внешнего цикла.
