# Сортировка вставками (insertion sort)

**Краткое содержание:**
Вставка элемента в отсортированную часть, O(n²), ~O(n) на почти отсортированных.

**Время:** ~20 мин

**Основные темы:**
- Реализация insertionSort()
- Вопросы на понимание
- Сохрани изменения
- Термины урока

**Термины:**
* **Insertion sort (сортировка вставками)** — берём элементы по одному и вставляем каждый в уже отсортированную левую часть.
* **Отсортированная часть** — префикс массива, который уже упорядочен.
* **Сдвиг** — перемещение элемента вправо на одну позицию, чтобы освободить место для вставки.
* **Почти отсортированный массив** — данные, где элементы почти на своих местах; вставки работают почти за O(n).
* **O(n)** — число операций растёт линейно с размером массива.
