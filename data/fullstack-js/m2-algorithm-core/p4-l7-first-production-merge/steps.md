### Мерж через интерфейс GitHub

**kind:** `text`

Выполни мерж PR:

1. Открой свой PR на GitHub
2. Нажми зелёную кнопку **Merge pull request**
3. Оставь тип слияния **Merge commit** (по умолчанию)
4. Нажми **Confirm merge**
5. После успешного мержа нажми **Delete branch** — удалить ветку на GitHub

Это твой **первый боевой мерж кода**: 7 функций из ветки `feat/string-comparison` теперь часть `main`. Ими будут пользоваться ревьюеры и следующие проекты.

---

### Обновление локального main

**kind:** `text`

Подтяни изменения в локальный репозиторий:

```
git switch main
git pull origin main
```

Проверь, что коммиты из `feat/string-comparison` теперь в `main`:

```
git log --oneline
```

---

### Очистка локальных веток

**kind:** `text`

Удали локальную feature-ветку:

```
git branch -d feat/string-comparison
```

Очисти информацию об удалённых ветках:

```
git fetch --prune
```

Проверь, что остались только нужные ветки:

```
git branch -a
```
