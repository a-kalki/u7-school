# Структуры данных: массив, связанный список, дерево

**Краткое содержание:**
Массив, связанный список, BST — компромиссы, выбор под задачу.

**Время:** ~20 мин

**Основные темы:**
- Почему структура данных имеет значение
- Массив — знакомый, но не идеальный
- Связанный список — зеркальный компромисс
- Бинарное дерево поиска (BST)
- Три структуры — три компромисса
- Прикладные вопросы
- Сохрани понимание
- Термины урока

**Термины:**
* **Структура данных** — способ организации данных в памяти, определяющий скорость операций над ними.
* **Массив** — данные хранятся подряд: доступ по индексу O(1), вставка в начало O(n).
* **Связанный список** — узлы связаны ссылками: доступ по индексу O(n), вставка в начало O(1).
* **Узел (node)** — элемент структуры со значением и ссылкой(-ами) на соседние узлы.
* **Бинарное дерево поиска (BST)** — дерево, где слева меньшие значения, справа большие; поиск O(log n) при балансе.
* **Сбалансированное дерево** — поддеревья примерно равной высоты; при дисбалансе BST деградирует до O(n).
* **AVL-дерево / красно-чёрное дерево** — самобалансирующиеся деревья, поддерживающие высоту O(log n).
* **Компромисс (trade-off)** — нет «лучшей» структуры: быстрые одни операции означают медленные другие.
