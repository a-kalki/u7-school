### GitHub Flow своими словами

**kind:** `text`

Не подглядывая, опиши своими словами (в конспекте или вслух) весь путь, который ты прошёл в этом проекте:

```
ветка → коммиты → push → Pull Request → ревью → мерж
```

Особенно важно уметь объяснить:
- зачем изменениям нужна отдельная ветка, а не работа прямо в `main`
- что происходит между «создал PR» и «смержили» (спойлер: ревью)
- чем PR отличается от простого `git push`

Это ядро всего проекта. В следующих проектах этот цикл будет повторяться до автоматизма.
