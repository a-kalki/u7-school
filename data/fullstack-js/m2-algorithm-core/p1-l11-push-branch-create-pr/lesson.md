# Пуш ветки и создание Pull Request

**Краткое содержание:**
Финальная проверка, отправка ветки `docs/homework` на GitHub, создание первого настоящего PR из ветки в `main` и сообщение со ссылкой в общий чат.

**Время:** ~20 мин

**Основные темы:**
1. Финальная проверка перед отправкой
2. `git push -u origin docs/homework`
3. Создание PR (base: main, compare: docs/homework)
4. Описание PR как markdown-практика
5. Сообщение в общий чат

**Термины:**
флаг `-u` (upstream) — связать локальную ветку с удалённой, чтобы дальше писать просто `git push`;
base — «куда» вливаем (`main`);
compare — «что» вливаем (твоя ветка);
pin — закреплённое сообщение в чате;
аппрув — по англ. `approve`: одобрение ревьюера
