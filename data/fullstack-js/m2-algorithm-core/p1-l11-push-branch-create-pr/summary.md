# Пуш ветки и создание Pull Request — краткая выжимка

- Финальная проверка: ветка `docs/homework`, `git status` чистый, все коммиты на месте
- `git push -u origin docs/homework` — первый push ветки; `-u` запоминает связь (дальше — `git push`)
- PR: base `main` ← compare `docs/homework` — «влить мою ветку в main»
- Описание PR — по шаблону, markdown'ом: «Кто я», цели (чекбоксы), что внутри
- Проверь PR глазами ревьюера: вкладка Files changed (diff), понятность описания
- Механика ревью: сообщение в общий чат (ссылка + «нужно 2 аппрува»), закрепить (pin)
- Новый коммит в ветку → PR обновляется автоматически
