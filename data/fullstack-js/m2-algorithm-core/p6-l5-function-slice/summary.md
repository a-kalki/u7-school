# Функция slice(str, start, end) — краткая выжимка

- slice(str, start, end) — подстрока с поддержкой отрицательных индексов: `-1` — последний символ
- Отрицательный индекс = отсчёт с конца: фактическая позиция = len(str) + индекс
- В отличие от substring: start и end НЕ меняются местами; end необязателен (по умолчанию — до конца)
- Нормализация всё равно нужна: выход за границы обрезается
- 18 тестов: положительные, отрицательные, оба отрицательных, границы, кириллица, TypeError
