# Ветки в Git — краткая выжимка

- Ветка — ярлык на коммит, а не копия файлов; `main` — «источник правды»
- `git switch -c <имя>` — создать ветку и переключиться; `git branch` — список веток
- Каждая ветка — независимое состояние проекта: переключение меняет рабочую папку
- `git branch -d` — безопасное удаление (только слитых веток), `-D` — принудительное
- Неслитые коммиты после удаления ветки становятся «висячими» (dangling)
- `git reflog` — локальный журнал действий, восстановление «потерянных» коммитов (~30 дней)
- Префиксы имён веток: `feat/` — функциональность, `docs/` — документация, `fix/` — исправления
