# values(obj) и entries(obj) — краткая выжимка

- `values(obj)` — массив значений свойств объекта
- `entries(obj)` — массив пар `[ключ, значение]`
- Обе строятся через композицию с `keys(obj)` — не дублируют `for...in`
- Принцип DRY: изменение в `keys` автоматически отражается в `values` и `entries`
- `keys` → `for...in` + `hasOwnProperty` (один раз), `values`/`entries` → `keys` + обход массива ключей
- Проверка типа: `typeof obj !== 'object' || obj === null` → `TypeError`
- Обе **иммутабельные** — исходный объект не меняется
- Пустой объект → `[]` для обеих функций
- JSDoc обязателен
