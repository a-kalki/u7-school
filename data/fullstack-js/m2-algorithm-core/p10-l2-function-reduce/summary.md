# reduce(arr, callback, initialValue) — краткая выжимка

- Сворачивает массив в одно значение через аккумулятор
- Callback получает `(аккумулятор, элемент, индекс, массив)`
- **С initialValue:** аккумулятор = initialValue, обход с индекса 0
- **Без initialValue:** аккумулятор = arr[0], обход с индекса 1
- Пустой массив с initialValue → initialValue; без → `TypeError`
- **Иммутабельная** — исходный массив не меняется
- Используй `arguments.length >= 3` для проверки наличия initialValue
- JSDoc обязателен, отметь иммутабельность и два режима работы
