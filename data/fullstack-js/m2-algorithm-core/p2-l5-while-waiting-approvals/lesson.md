# Пока ждёшь апрувы

**Краткое содержание:**
Как следить за уведомлениями, пока PR ждёт ревью, и что делать, если ревьюер молчит.

**Время:** ~10 мин

**Основные темы:**
1. Уведомления GitHub и чат
2. Алгоритм эскалации

**Термины:**
notification — уведомление GitHub или почты о событии в твоём PR;
эскалация — постепенное усиление напоминаний: личка → чат → другой ревьюер → ментор
