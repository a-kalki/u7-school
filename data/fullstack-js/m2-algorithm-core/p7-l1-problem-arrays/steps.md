# Шаги урока: Проблема: массивы

---

### Зачем нужен массив

**kind:** `text`

До сих пор ты работал с отдельными значениями: строка, число, булево. Но почти любая реальная программа оперирует **наборами**: список задач, список пользователей, список товаров в корзине, список результатов поиска.

**Массив** — упорядоченная коллекция элементов с доступом по индексу. Это первая настоящая **структура данных** в модуле: способ организации данных, от которого зависит, насколько удобно и быстро с ними работать.

Строки и массивы похожи: и там, и там элементы пронумерованы индексами с нуля. Но есть фундаментальное отличие, которое определи весь этот проект: строки иммутабельны (их нельзя изменить после создания), а массивы — **мутабельны**: их можно менять «на месте». Что это значит на практике — следующий урок.

**Термины:**
массив — упорядоченная коллекция элементов с доступом по индексу;
структура данных — способ организации данных для удобной и эффективной работы с ними;
коллекция — обобщённое название для наборов элементов (список, массив, множество)

### Состав API проекта — 9 функций

**kind:** `text`

| Функция | Что делает | Мутирует массив? |
|---------|-----------|------------------|
| `len(arr)` | количество элементов | нет |
| `at(arr, index)` | элемент по индексу (с отрицательными) | нет |
| `push(arr, item)` | добавление в конец | **да** |
| `pop(arr)` | удаление с конца | **да** |
| `unshift(arr, item)` | добавление в начало | **да** |
| `shift(arr)` | удаление с начала | **да** |
| `indexOf(arr, item)` | индекс первого вхождения | нет |
| `lastIndexOf(arr, item)` | индекс последнего вхождения | нет |
| `includes(arr, item)` | есть ли элемент в массиве | нет |

Все функции живут в **отдельной папке `array-utils/`** — и это не случайность: твоя строковая `len` из `string-utils/` уже существует. Функции с одинаковыми именами для строк и для массивов не должны конфликтовать — поэтому каждая структура данных получает свою папку.

Правила реализации прежние: запрещены встроенные методы массивов (`push`, `pop`, `slice`, `map`, ...) и свойство `.length`. Для проверки «это массив?» разрешена `Array.isArray(...)` — подсказку дадим в уроке про len. TDD + JSDoc сразу после заглушки, коммит после каждой функции.
