# Первый репозиторий — краткая выжимка

- `mkdir js-algorithms && cd js-algorithms && git init` — папка становится git-репозиторием
- Основная ветка для курса — `main`. Проверка: `git branch --show-current`
- Если ветка называется иначе — не ищем готовую команду, а формулируем вопрос ИИ и добиваемся `main`
- `.gitignore` — список того, что не попадает в историю: `node_modules/`, `.env`, `.DS_Store`, `dist/`
- `git status` показывает: Untracked files (не отслеживаются) и изменения
- Удаление папки `.git` = потеря всей истории версий
