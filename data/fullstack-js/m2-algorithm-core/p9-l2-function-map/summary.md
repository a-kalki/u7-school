# map(arr, callback) — краткая выжимка

- Вызывает `callback` для каждого элемента, собирает результаты в **новый массив**
- Callback получает (элемент, индекс, массив)
- **Иммутабельная** — исходный массив не меняется
- Длина результата всегда равна длине исходного массива
- Пустой массив → пустой массив
- JSDoc обязателен, отметь иммутабельность
