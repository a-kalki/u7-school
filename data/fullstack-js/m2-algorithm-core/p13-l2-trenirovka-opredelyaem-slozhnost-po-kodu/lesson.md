# Тренировка: определяем сложность по коду

**Краткое содержание:**
Задачи A–J, поиск ошибок, когда константа перевешивает порядок роста.

**Время:** ~18 мин

**Основные темы:**
- Разминка: задачи A–E
- Сверяем ответы A–E
- Задача F: primesUpTo (посложнее)
- Задачи H–J: твои сортировки из проекта 12
- Сверяем ответы H–J
- Задача G: найди ошибку
- Когда константа имеет значение
- Сохрани понимание
- Термины урока

**Термины:**
* **Анализ сложности по коду** — определение O-класса функции без запуска кода: по циклам, рекурсии и структуре алгоритма.
* **Вложенный цикл** — цикл внутри цикла; обычно даёт O(n²) или O(n×m).
* **Последовательные циклы** — несколько циклов подряд; всё ещё O(n), множитель отбрасывается.
* **Рекурсия** — вызов функцией самой себя; уменьшение n на 1 даёт O(n) вызовов, деление пополам — O(log n).
* **Константа** — постоянный множитель; на малых данных может решать, но с ростом n им пренебрегают.
* **Правило отбрасывания** — O(2n) = O(n), O(n² + 100n) = O(n²), O(n + log n) = O(n).
