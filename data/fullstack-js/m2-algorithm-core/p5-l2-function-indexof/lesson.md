# Функция indexOf(str, search)

**Краткое содержание:**
Главная функция проекта — наивный поиск подстроки через TDD: скользящее окно, 14 тестовых случаев, включая хитрые пересекающиеся совпадения.

**Время:** ~40 мин

**Основные темы:**
1. Алгоритм скользящего окна
2. TDD-цикл для indexOf
3. Сложные тестовые случаи

**Термины:**
скользящее окно — кусок длиной с `search`, который сдвигается по строке на одну позицию за шаг;
почти-совпадение — совпало только начало окна, а не всё: главный источник ошибок в indexOf;
заглушка — реализация, когда функция возвращает всегда один вариант ответа;
