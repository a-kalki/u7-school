# Функция indexOf(str, search) — краткая выжимка

- `indexOf(str, search)` → `number`: индекс первого вхождения или `-1`
- Наивный алгоритм: окно длиной с `search` движется по `str`, посимвольное сравнение на каждой позиции
- Заглушка: `return -1` — падает на первом же тесте
- Особый случай: `'abababc'`, `'ababc'` → 2 — окно должно «отступать назад» при срыве почти-совпадения
- `search` длиннее `str` → `-1`; пустой `search` → `0`; несколько вхождений → первое
- `TypeError` для не-строк в обоих аргументах
- Коммит: «Реализована indexOf — наивный поиск подстроки»
