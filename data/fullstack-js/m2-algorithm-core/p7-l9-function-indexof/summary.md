# Функция indexOf(arr, item) — краткая выжимка

- indexOf(arr, item) — индекс первого вхождения элемента, или -1 если не найден
- Сравнение через ===: никакого «угадывания» типов и строковых функций
- Строгое равенство различает 0 и false — тесты это проверяют
- Дубликаты: возвращаем индекс первого вхождения
- Функция не мутирует массив
