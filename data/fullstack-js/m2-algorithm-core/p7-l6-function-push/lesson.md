# Функция push(arr, item) — добавление в конец

**Краткое содержание:**
Первая мутабельная функция проекта. Перед ней — шпаргалка по bun:test: чем проверять массив целиком (toEqual) и почему toBe для массивов не работает.

**Время:** ~15 мин

**Основные темы:**
1. Подсказка: test API для проверки массивов
2. Реализация push() через TDD

**Термины:**
глубокое (структурное) равенство — сравнение по содержимому (элемент за элементом), а не по ссылке (toEqual);
строгое равенство — сравнение по ссылке/значению через `===` (toBe)
