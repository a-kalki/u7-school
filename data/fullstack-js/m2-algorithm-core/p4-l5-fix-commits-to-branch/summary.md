# Fix-коммиты в ветку — краткая выжимка

- Правки — прямо в feature-ветку (`git switch feat/string-comparison`), отдельная ветка не нужна
- Одно исправление = один коммит с осмысленным сообщением: «Исправлено: ...», «Добавлен тест: ...»
- Push без `-u` — связь уже настроена; PR обновится автоматически
- На каждый комментарий — ответ по шаблону: исправил / не согласен с причиной / принял предложение
- После ответа — **Resolve conversation**
- Все критические исправлены и resolved → запрос повторного ревью
