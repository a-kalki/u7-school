# Первый коммит — краткая выжимка

- Теория: W3Schools [Git Commit](https://www.w3schools.com/git/git_commit.asp) — `git add`, `git commit`, `git log`
- `git add <файл>` (рекомендуется), `git add .`, `git add -A` — варианты добавления в stage
- Перед коммитом проверяй `git status`: зелёное — в stage, красное — не добавлено
- `git commit -m "сообщение"` — коммит; без `-m` откроется редактор
- Правила сообщения: глагол («Добавить», «Реализована»), до 72 символов, понятно что сделано
- История: `git log --oneline`, `git log -3`, `git log --graph`
