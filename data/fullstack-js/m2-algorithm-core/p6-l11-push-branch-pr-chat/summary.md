# Пуш ветки, PR, сообщение в чат — краткая выжимка

- Чек-лист перед пушем: 8 функций, JSDoc у всех, `bun test` зелёный, working tree clean, осмысленная история коммитов
- `git push -u origin feat/string-transform`
- PR-шаблон: что сделано (список функций), особенности реализации (slice vs substring, replaceAll, upperCase/lowerCase), как запустить тесты
- Для ревьюеров важна неочевидная информация — она обязательна в описании
- Сообщение в чат: ссылка на PR + «нужно 2 апрува для мержа»
