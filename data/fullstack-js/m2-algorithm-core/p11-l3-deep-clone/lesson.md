# Глубокое копирование: cloneDeep(obj)

**Краткое содержание:**
Урок вводит различие между поверхностным и глубоким копированием. Студент реализует `cloneDeep` — рекурсивную функцию, создающую полную копию объекта или массива со всеми уровнями вложенности. Это первый опыт рекурсии для структур данных в рамках модуля.

**Термины:**
глубокая (структурная) копия — копия значения, независимая на всех уровнях вложенности

### Алгоритм

1. `null` → вернуть `null`
2. Примитив (`typeof value !== 'object'`) → вернуть как есть
3. Массив (`Array.isArray`) → новый массив, рекурсивно склонировать каждый элемент
4. Объект → новый объект, рекурсивно склонировать каждое значение через `keys`

```javascript
function cloneDeep(value) {
  if (value === null) return null;
  if (typeof value !== 'object') return value;

  if (Array.isArray(value)) {
    const result = [];
    for (let i = 0; i < len(value); i++) {
      result[i] = cloneDeep(value[i]);
    }
    return result;
  }

  const result = {};
  const objKeys = keys(value);
  for (let i = 0; i < len(objKeys); i++) {
    const key = objKeys[i];
    result[key] = cloneDeep(value[key]);
  }
  return result;
}
```

### Поверхностное и глубокое копирование

Поверхностная копия копирует только первый уровень — вложенные объекты и массивы остаются общими. Глубокая копия рекурсивно создаёт независимые копии всех уровней: изменение копии нигде не затрагивает оригинал.

### Порядок проверок

`null` проверяется до `typeof`, а массив — до общей ветки объекта. Если поменять порядок, `cloneDeep(null)` уйдёт в ветку объекта и упадёт на `keys(null)`.
