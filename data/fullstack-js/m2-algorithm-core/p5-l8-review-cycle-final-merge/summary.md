# Ревью-цикл и финальный мерж — краткая выжимка

- Ревью-цикл по накатанной (методика — П4): категории комментариев → правки в ветку (1 фикс = 1 коммит) → ответы + Resolve → 🔄 re-request → 2 апрува + resolved
- Мерж: Merge pull request → Merge commit → Delete branch
- Локально: `git switch main` → `git pull origin main` → `git branch -d feat/substring-search` → `git fetch --prune`
- Итог: полный цикл пройден дважды — процесс превращается в рабочий инструмент
- Дальше — формат «задания и напоминания», без пошаговых инструкций
