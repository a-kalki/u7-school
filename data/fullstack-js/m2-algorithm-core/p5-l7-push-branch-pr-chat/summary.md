# Пуш ветки, PR, сообщение в чат — краткая выжимка

- Чек-лист перед PR: `bun test` зелёный, `git status` чистый, история осмысленная
- Пуш: `git push -u origin feat/substring-search`
- PR: base `main` ← compare `feat/substring-search`, заголовок «Проект 5: функции поиска подстрок и утилиты для строк»
- Описание: 6 функций + «includes/startsWith/endsWith построены на базе indexOf» + как запустить тесты
- Сообщение в чат: ссылка + «нужно 2 апрува»
- Ревью-цикл по накатанной (проект 4)
