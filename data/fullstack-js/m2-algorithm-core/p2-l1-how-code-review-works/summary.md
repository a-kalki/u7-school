# Как работает код-ревью — краткая выжимка

- Ревью: вторая пара глаз (автор «слеп» к своим ошибкам), знание не оседает в одной голове, обучение в обе стороны, дисциплина
- Ревью — не поиск виноватых: автор и ревьюер против проблемы, а не друг против друга
- Три исхода на GitHub: Comment (просто комментарий), Approve (принять), Request changes (нужны исправления)
- Наша механика: PR → сообщение в общий чат → ревьюят студенты и менторы → 2 апрува → автор мержит сам
- Побываешь в обеих ролях: автор (homework-PR) и ревьюер (чужие PR)
