# flat(arr, depth) — краткая выжимка

- Разглаживает вложенные массивы до указанной глубины (`depth`, по умолчанию `1`)
- **Иммутабельная** — возвращает новый массив
- `depth = 0` → без изменений; `depth = Infinity` → полностью плоский
- База рекурсии: элемент не массив или `depth === 0`
- Шаг рекурсии: элемент — массив и `depth > 0` → `flat(item, depth - 1)`
- Можно реализовать двумя способами: через рекурсию (прямой цикл) или через `reduce`
- Использует `Array.isArray()` и `push`
- JSDoc обязателен, отметь иммутабельность и рекурсию
