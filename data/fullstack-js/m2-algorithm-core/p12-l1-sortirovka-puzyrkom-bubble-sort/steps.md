# Шаги урока: Сортировка пузырьком (bubble sort)

---

### О чём этот проект

**kind:** `text`

До сих пор ты реализовывал функции, которые работают с данными: сравнение строк, поиск подстрок, методы массивов. Теперь — новый поворот.

В этом проекте ты реализуешь **четыре алгоритма сортировки** и **бинарный поиск**:
- пузырьком (bubble sort);
- вставками (insertion sort);
- выбором (selection sort);
- быструю сортировку (quick sort);
- бинарный поиск (binary search).

Все сортировки делают одно и то же — превращают неотсортированный массив в отсортированный. Но делают это по-разному. В конце проекта ты соберёшь испытательный стенд, который **замерит время** каждого алгоритма на массивах разных размеров, а также сравнит линейный и бинарный поиск — и увидишь своими глазами, что на больших данных разница может быть в сотни и тысячи раз.

Это наблюдение станет фундаментом для следующего проекта про сложность алгоритмов.

### Только нативный JS

**kind:** `text`

**⚙️ Важное правило проекта.** В начале модуля были объявлены правила запрещающие нативный функционал, например `[1, 2].length`, `[1, 2].push(3)`. Это правило для этого проекта снимается.

**Почему так.** Цель проекта — измерить **чистую скорость самих алгоритмов**. Наши функции-обёртки устроены через циклы: например, `len` каждый раз пересчитывает длину, пока не дойдёт до `undefined`. Внутри сортировок они добавили бы накладные расходы, и замер показывал бы не скорость алгоритма, а работу наших функций — сравнение потеряло бы смысл.

> Свои реализации никуда не деваются: они остаются в `array-utils/` и продолжают использоваться в других проектах.

### Реализация bubbleSort()

**kind:** `text`

**Аналогия алгоритма "Пузырьком".** Вспомни стакан газировки: пузырьки всплывают наверх. Здесь наоборот — самый большой элемент «всплывает» в конец массива. Ты проходишь по массиву, сравниваешь соседей и меняешь их местами, если левый больше правого. После одного прохода максимум оказывается в конце.

Реализуй функцию `bubbleSort(arr)`. Создай файлы `sorting/bubble-sort.js` и `sorting/bubble-sort.test.js`, следуй TDD.

**Функция принимает:** `arr`: `array` — массив чисел для сортировки.

**Функция возвращает:** `array` — новый отсортированный по возрастанию массив.

**Важно:** функция **иммутабельная** — исходный массив не меняется.

**Человеческий псевдокод:**
1. Скопируй массив, чтобы не испортить исходный.
2. Много раз пройди по массиву слева направо, сравнивая соседние пары.
3. Если левый больше правого — поменяй их местами.
4. После каждого прохода самый большой элемент гарантированно в конце, поэтому следующий проход можно не доводить до конца.
5. Повторяй, пока весь массив не встанет по порядку. Верни результат.

**Технический алгоритм (подсказка):**
- в начале функции проверь тип: `if (!Array.isArray(arr)) throw new TypeError('arr must be array');`
- сделай копию: `const result = arr.slice();`
- закэшируй длину: `const n = result.length;` и используй `n` в циклах;
- внешний цикл `i` от 0 до `n - 2`;
- внутренний цикл `j` от 0 до `n - 2 - i`;
- если `result[j] > result[j + 1]` — поменяй их местами через временную переменную `temp`.

**Тестовые случаи** (каждый — отдельный `test(...)`):
- Пустой массив: `bubbleSort([])` → `[]`
- Один элемент: `bubbleSort([7])` → `[7]`
- Уже отсортированный: `bubbleSort([1, 2, 3])` → `[1, 2, 3]`
- Обратный порядок: `bubbleSort([3, 2, 1])` → `[1, 2, 3]`
- С дубликатами: `bubbleSort([4, 2, 4, 1])` → `[1, 2, 4, 4]`
- Иммутабельность: после вызова исходный массив не изменился
- `bubbleSort('abc')` → `TypeError`

**kind:** `text`

**1.** Почему внутренний цикл идёт до `n - 2 - i`, а не до `n - 1`? Что изменится, если не уменьшать правую границу?

### Термины урока

**kind:** `text`

Пройдись по основным понятиям урока. Если что-то не можешь объяснить своими словами — вернись к соответствующему шагу.

**Термины:**
* **Сортировка** — приведение элементов в порядок (здесь — по возрастанию).
* **Bubble sort (пузырьковая сортировка)** — сравнение соседних пар и обмен, если левый больше; наибольший элемент «всплывает» в конец.
* **Обмен (swap)** — перестановка двух элементов местами через временную переменную.
* **Нативный метод** — встроенное средство JS (`arr.length`, `arr.slice()`, `arr.push()`), а не собственная функция.
