# Сортировка пузырьком (bubble sort)

**Краткое содержание:**
Попарные обмены соседей, O(n²). Старт проекта.

**Время:** ~20 мин

**Основные темы:**
- О чём этот проект
- Только нативный JS
- Ветка проекта
- Реализация bubbleSort()
- Вопросы на понимание
- Сохрани изменения
- Термины урока

**Термины:**
* **Сортировка** — приведение элементов в порядок (здесь — по возрастанию).
* **Bubble sort (пузырьковая сортировка)** — сравнение соседних пар и обмен, если левый больше; наибольший элемент «всплывает» в конец.
* **Обмен (swap)** — перестановка двух элементов местами через временную переменную.
* **Нативный метод** — встроенное средство JS (`arr.length`, `arr.slice()`, `arr.push()`), а не собственная функция.
* **Иммутабельность** — функция не меняет входной массив, а возвращает новый.
* **O(n²)** — число операций растёт как квадрат размера массива: при удвоении n время растёт примерно в 4 раза.
