# Твой PR глазами ревьюера — краткая выжимка

- Пройди по своему PR как ревьюер: описание → коммиты → diff → тесты
- Ревьюер формирует впечатление за первые две минуты
- Чек-лист: описание с «как проверить», нет коммитов-мусора, нет отладочных логов, понятные имена, граничные случаи покрыты, правила модуля соблюдены, сообщение в чате живо
- Нашёл проблему — исправь сейчас: правки в ветку → push → PR обновится сам
- Самопроверка = меньше кругов доработки
