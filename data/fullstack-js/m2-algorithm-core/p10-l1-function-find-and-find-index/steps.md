### Реализация findIndex()

**kind:** `text`

Реализуй функцию `findIndex(arr, callback)` — поиск индекса первого подходящего элемента. Создай файлы `array-utils/find-index.js` и `array-utils/find-index.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для поиска
- `callback`: `function` — условие поиска, получает `(элемент, индекс, массив)`

**Функция возвращает:** `number` — индекс первого элемента, для которого callback вернул `true`, или `-1` если не найден.

**Важно:** функция **иммутабельная**, с **ранним выходом**.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна найти индекс первого подходящего элемента: `findIndex([1, 2, 3, 4], x => x > 2)` → `2`
- Должна вернуть `-1` если элемент не найден: `findIndex([1, 2, 3], x => x > 10)` → `-1`
- Должна вернуть `-1` для пустого массива: `findIndex([], () => true)` → `-1`
- Должна остановиться на первом совпадении: `findIndex([1, 2, 3, 4], x => x > 1)` → `1` (а не `2` или `3`)
- Должна вернуть `0` если первый же элемент подходит: `findIndex([5, 7, 3], x => x > 4)` → `0`
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция

### Реализация find()

**kind:** `text`

Реализуй функцию `find(arr, callback)` — поиск первого подходящего элемента. Создай файлы `array-utils/find.js` и `array-utils/find.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив для поиска
- `callback`: `function` — условие поиска, получает `(элемент, индекс, массив)`

**Функция возвращает:** `any` — первый элемент, для которого callback вернул `true`, или `undefined` если не найден.

**Важно:** функция **иммутабельная** — не меняет исходный массив. Использует **ранний выход** — обход останавливается при первом совпадении.

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна найти первый подходящий элемент: `find([1, 2, 3, 4], x => x > 2)` → `3`
- Должна вернуть `undefined` если элемент не найден: `find([1, 2, 3], x => x > 10)` → `undefined`
- Должна вернуть `undefined` для пустого массива: `find([], () => true)` → `undefined`
- Должна остановиться на первом совпадении: `find([1, 2, 3, 4], x => x > 1)` → `2` (а не `3` или `4`)
- Должна передавать правильные аргументы в callback `(el, i, arr) => {...}`
- Должна выбросить `TypeError` если `arr` не массив
- Должна выбросить `TypeError` если `callback` не функция
