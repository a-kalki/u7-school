# ДЗ: статья «Git для новичков» (часть 2) — краткая выжимка

- Статья: [Git для новичков (часть 2)](https://habr.com/ru/articles/542616/) — командная работа, ветки, merge, clone, pull
- Термины статьи: clone (полная копия чужого репозитория), pull (забрать обновления), merge (слияние)
- Читается после первого мержа: материал ложится на живой опыт
- Конспект 5–7 пунктов в `homework.md` — файл «про тебя»; README — «про проект», конспект туда не пишем
- Сдача: прямой коммит в `main` → `git push origin main` — без ветки и PR
- Прямой пуш в `main` — образовательное исключение для мелких некодовых правок; весь код — только через PR и ревью (2 апрува)
