# homework.md в отдельной ветке — краткая выжимка

- Любая работа — в отдельной ветке; `main` меняется только через Pull Request
- Префиксы веток: `feat/` — код, `docs/` — документация, `fix/` — исправления, `refactor/` — улучшения
- `git switch -c docs/homework` — ветка под первые файлы курса
- `homework.md`: «Кто я», цели на модуль (чекбоксы), раздел «Конспекты», заметка для ревьюера — файл «про тебя»
- `README.md`: что за проект, что внутри, как запустить — визитка «про проект», рендерится на главной GitHub
- Заметка для ревьюера приглашает предложить правки по оформлению — первый PR получает живое ревью на безопасном материале
- Предпросмотр markdown: VS Code, Ctrl+Shift+V
- Коммит: `git add README.md homework.md` → «Добавить homework.md и README.md: знакомство с проектом»
