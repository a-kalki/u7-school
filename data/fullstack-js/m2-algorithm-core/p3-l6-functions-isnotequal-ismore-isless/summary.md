# Функции isNotEqual, isMore, isLess — краткая выжимка

- `isNotEqual(a, b)`: `true` если строки НЕ равны (проще всего — через уже готовую isEqual)
- `isMore(a, b)`: лексикографическое «больше» — первый различающийся символ решает; если `a` длиннее при общем префиксе — больше
- `isLess(a, b)`: лексикографическое «меньше»
- Тонкие случаи: `'A'(65) < 'a'(97)` — все заглавные меньше строчных; пробел (32) меньше буквы; `''` меньше любой непустой
- Один TDD-цикл и один коммит на каждую функцию
- Коммиты: «Реализовать isNotEqual», «Реализовать isMore — лексикографическое сравнение», «Реализовать isLess(a, b)»
