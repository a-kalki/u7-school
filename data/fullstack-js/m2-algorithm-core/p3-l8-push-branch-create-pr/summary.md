# Пуш ветки и создание Pull Request — краткая выжимка

- Финальный прогон: `bun test` — все 7 функций зелёные; `git status` чистый; история коммитов осмысленная
- Перед PR обнови `README.md`: в «Что внутри» — string-utils (7 функций) и инструкция запуска тестов
- Пуш: `git push -u origin feat/string-comparison` (по памяти, третий раз)
- PR: base `main` ← compare `feat/string-comparison`
- Заголовок: «Проект 3: TDD и 7 функций сравнения строк»
- Описание по шаблону: список функций, TDD-подход, как запустить тесты (`bun test`)
- Сообщение в чат: ссылка + «нужно 2 апрува»
- Ревью и доведение до мержа — тема проекта 4; пока ждёшь — ДЗ
