# Функция reverse(arr) — краткая выжимка

- reverse(arr) — переворачивает массив на месте; МУТАБЕЛЬНАЯ, возвращает тот же массив (===)
- Алгоритм двух указателей: левый и правый индексы движутся навстречу с обменом элементов
- Классический приём — пригодится в дальнейших алгоритмах
- Проверка двойного reverse — на копии массива (reverse мутирует исходник)
- Краевые случаи: 0 и 1 элемент — ничего не ломается
