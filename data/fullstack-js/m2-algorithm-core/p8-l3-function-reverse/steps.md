# Шаги урока: Функция reverse(arr) — переворот массива на месте

---

### Реализация reverse() через TDD

**kind:** `text`

> Убедись, что ты в ветке `feat/array-transform`.

Реализуй функцию `reverse(arr)` — переворот массива на месте. Создай файлы `array-utils/reverse.js` и `array-utils/reverse.test.js`, следуй TDD.

**Функция принимает:**
- `arr`: `array` — массив (будет изменён)

**Функция возвращает:** `array` — тот же массив `arr`, но с элементами в обратном порядке.

**Важно:** функция **мутабельная** — меняет исходный массив на месте. В JSDoc отметь это. В тестах проверяй и что элементы перевёрнуты, и что возвращается тот же самый массив.

**Идея алгоритма — два указателя.** Поставь один указатель на первый элемент, второй — на последний. Обменяй элементы под указателями, сдвинь левый вправо, правый влево. Повторяй, пока указатели не встретятся. Это классический приём — запомни его, он ещё не раз встретится в алгоритмах.

**Термины:**
алгоритм двух указателей — приём: два индекса движутся навстречу друг другу, на каждом шаге обрабатывая пару элементов

Тестовые случаи (каждый — отдельный `test(...)`):
- Должна перевернуть массив из нечётного числа элементов: `reverse([1, 2, 3])` → `[3, 2, 1]`
- Должна перевернуть массив из чётного числа элементов: `reverse([1, 2, 3, 4])` → `[4, 3, 2, 1]`
- Должна перевернуть массив из двух элементов: `reverse([1, 2])` → `[2, 1]`
- Должна вернуть тот же массив (проверь `===`)
- Должна перевернуть массив из одного элемента: `reverse([42])` → `[42]`
- Должна вернуть пустой массив без изменений: `reverse([])` → `[]`
- Должна работать с массивом строк: `reverse(['a', 'b', 'c'])` → `['c', 'b', 'a']`
- Должна работать с массивом смешанных типов: `reverse([1, 'two', null])` → `[null, 'two', 1]`
- Двойной reverse должен восстановить исходный порядок: `const a = [1, 2, 3]; reverse(reverse(a));` → `a` снова `[1, 2, 3]`
- Должна выбросить `TypeError` если `arr` не массив
