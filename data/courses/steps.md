# Шаги урока: Редактор кода

---

### Что такое редактор кода

**kind:** `text`

Редактор кода — это программа, в которой программисты пишут код. Если код — это текст, то редактор кода — это как текстовый редактор (Word или Блокнот), но специально «заточенный» под код.

Почему нельзя просто писать в Блокноте? Редактор кода:
- **подсвечивает код цветами** (подсветка синтаксиса) — сразу видно, где команда, где строка, где число
- **подсказывает** продолжение, когда ты печатаешь (автодополнение)
- **показывает ошибки** ещё до запуска
- имеет **встроенный терминал**, чтобы запускать код прямо из редактора

Всё это помогает меньше ошибаться и быстрее писать код.

---

### Выбери редактор: VS Code или Zed

**kind:** `text`

Редакторов много, но для старта мы советуем выбрать один из двух — оба бесплатные.

**VS Code** (Visual Studio Code)
- Самый популярный редактор в мире, от Microsoft
- Работает на Windows, macOS и Linux
- Огромное количество расширений и обучающих материалов
- Если застрял — ответ на любой вопрос легко найти в интернете или спросить у ИИ

**Zed**
- Новый, очень быстрый и минималистичный редактор
- Меньше расширений, но всё нужное для старта есть
- Хорош, если любишь простоту и скорость

Выбери один и переходи к установке.

### Установи редактор

**kind:** `text`

**Если выбрал VS Code:**

1. Открой сайт [code.visualstudio.com](https://code.visualstudio.com/)

**Если выбрал Zed:**

1. Открой сайт [zed.dev](https://zed.dev/)

### Как работать в редакторе: самое нужное

**kind:** `text`

Сейчас тебе понадобятся всего несколько вещей:

- **Открыть папку** — меню File → Open Folder (в VS Code) или Open… (в Zed). Редактор работает с целыми папками, а не с отдельными файлами
- **Панель файлов** — слева список файлов и папок; кликай по файлу, чтобы открыть его
- **Создать файл** — в панели файлов нажми на иконку «новый файл» (или правой кнопкой по папке → New File) и введи имя
- **Сохранить** — Ctrl+S (Windows/Linux) или Cmd+S (macOS). Несохранённые изменения обычно отмечены точкой рядом с именем файла
- **Терминал** — меню Terminal → New Terminal (в VS Code); откроется командная строка прямо внутри редактора

Разбирать все кнопки заранее не нужно — освоишь по ходу. Если что-то не найдёшь, спроси ИИ-ассистента: «Где в VS Code находится терминал?», «Как создать файл в Zed?» и так далее.

### Создай папку для проектов

**kind:** `text`

Заведём отдельную папку, где будут жить все проекты курса. Так файлы не потеряются и всегда будут под рукой.

1. Создай папку с названием `dev` или `learn`:

Вот так лучше не делать: `"C:\Мои проекты"`. Скорее всего это будет работать, но это также источник будущих потенциальных проблем.

Теперь редактор «смотрит» на эту папку, и всё, что мы создадим, будет лежать в ней.

### Создай первый файл

**kind:** `text`

В открытой папке создай файл `hello.js`:

1. В панели файлов нажми «New File» (новый файл)
2. Назови его `hello.js` — расширение `.js` говорит, что это JavaScript-файл
3. Вставь в файл такой код:

```js
// Файл hello.js — моя первая программа
console.log('Моё имя: Алекс');
console.log('Мой любимый цвет: синий');
console.log('Мне лет: 25');
```

4. Замени имя, цвет и возраст на свои
5. Сохрани файл (Ctrl+S / Cmd+S)

Обрати внимание: текст в кавычках (`'...'`) — это строки, а число `25` пишется без кавычек. Подробно об этом поговорим позже.

Запустить этот файл мы пока не можем — для этого нужен Bun. О нём — в следующем уроке.

# Шаги урока: Bun — запускаем первый код

---

### Что такое Bun

**kind:** `text`

В уроке 1 мы говорили про **интерпретатор** — программу, которая выполняет код. В браузере JavaScript выполняет встроенный движок, а на компьютере и сервере нужен свой исполнитель.

**Bun** — это как раз такой «исполнитель» (по-английски — runtime) для JavaScript. Он позволяет запускать `.js`-файлы прямо на твоём компьютере, без браузера.

Простая аналогия: файл `.js` — это рецепт, а Bun — повар, который читает рецепт и выполняет его шаг за шагом. Без повара рецепт — просто текст в файле.

Bun современный и быстрый, а ещё в нём уже есть всё нужное для нашего курса. Именно через него мы будем запускать все программы.

---

### Установи Bun

**kind:** `text`

Установка Bun — это одна команда в терминале. Открой терминал компьютера (или терминал внутри редактора: Terminal → New Terminal) и выполни команду для своей системы.

**Windows (PowerShell):**

```
powershell -c "irm bun.sh/install.ps1 | iex"
```

**macOS / Linux:**

```
curl -fsSL https://bun.sh/install | bash
```

Команду можно скопировать с официального сайта [bun.sh](https://bun.sh/) — там есть кнопка «Copy to clipboard».

После установки проверь, что всё получилось:

```
bun --version
```

Ты должен увидеть номер версии, например `1.x.x`.

Если команда не найдена — закрой и заново открой терминал (иногда нужно, чтобы система «увидела» новую программу). Если всё ещё не работает — скопируй текст ошибки и спроси ИИ-ассистента.

---

### Запусти свою первую программу

**kind:** `text`

Теперь всё готово, чтобы запустить файл, созданный в прошлом уроке.

1. Открой терминал **в редакторе**: Terminal → New Terminal (в VS Code). Обычно он открывается сразу в папке проекта. Проверь, что в терминале указан путь к твоей папке `dev` (`C:\dev` или `~/dev`). Если нет — перейди командой:
   - Windows: `cd C:\dev`
   - macOS/Linux: `cd ~/dev`
2. Выполни команду:

```
bun hello.js
```

3. В терминале должен появиться вывод твоего кода — примерно так:

```
Моё имя: Алекс
Мой любимый цвет: синий
Мне лет: 25
```

🎉 Поздравляем! Ты только что запустил свою первую программу на JavaScript: написал код в редакторе и выполнил его через Bun.

Если вывода нет или появилась ошибка:
- проверь, что ты находишься в папке `dev` (команда `pwd` покажет текущую папку)
- проверь, что файл называется именно `hello.js`
- скопируй текст ошибки и спроси ИИ-ассистента

Когда всё заработает — нажми «Выполнено».

Если не заработает, то попробуй решить его с помощью ИИ.

Если и так не получится, спроси совета в чате группы или на следующем уроке покажи ментору.
