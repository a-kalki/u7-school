# Спецификация экранов Streams (UI Spec)

Документ описывает экраны Telegram-бота модуля Streams: каталог, карточки, программа, детали, создание потока, запись.
Служит **отправной точкой для разработки** — что уже реализовано, что запланировано.

Условные обозначения:
- ✅ реализовано
- ❌ не реализовано
- 📋 в бэклоге / запланировано в треке

---

## S01 — Каталог потоков

**Как попасть:** кнопка `📚 Потоки курсов` в главном меню.
**Кому:** всем ролям.

**Содержание:**
- Заголовок `📚 Потоки курсов`
- Легенда: `🟡 — идёт набор   🔵 — идёт обучение   🟢 — завершён   ⚫ — в архиве`
- Кнопки-потоки: `{эмодзи} {StreamTitle}` — `enrollment` и `active` по умолчанию, `completed`/`archived` — через переключатели

**Кнопки:**

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `{эмодзи} {StreamTitle}` | видимый поток | ✅ |
| `🟢 Вкл. завершённые` | есть завершённые | ✅ |
| `⚫ Вкл. архивированные` | есть архивные | ✅ |
| `🔵 Только активные` | показаны все | ✅ |
| `↩️ Главное меню` | всегда | ✅ |

**Доменная логика:**
- `list-streams` → фильтр по статусу в зависимости от переключателей
- Иконки статусов едины для catalog и mentor-tools (🟡/🔵/🟢/⚫)

## S02 — Карточка потока (curious-режим)

**Как попасть:** клик на поток в S01 (ветка «Потоки курсов»).
**Кому:** всем ролям. **Только curious-функциональность, без менторских инструментов.**

**Содержание:**
```
📋 *{StreamTitle}*
_{StreamDescription}_
👤 Ментор: {MentorName}
📅 Старт: {StartDate}
🕐 Время: {HH:MM}
👥 Студентов: {N}
📌 Статус: {StatusLabel}
📚 Курс: Fullstack JS   ← ⚠️ техдолг: захардкожено
```

**Кнопки — публичные (всем ролям, включая ментора как зрителя):**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `📖 Программа курса` | → S03 | ✅ |
| `👥 Студенты` | список студентов (прозрачность, формат S07) | ✅ |
| `📋 Детали` | → S04 | ✅ |

**Кнопки — гостевые (только НЕ владелец потока, `canEnroll`):**

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `📝 Записаться` | поток в наборе → S10 | ✅ |

> Кнопка «🔔 Уведомить о наборе» удалена (трек bot-ui-dialog-nav): обработчика
> не было, тычки вели в «Неизвестная команда»; фича отменена владельцем.

**Кнопка — всегда:**

| Кнопка | Статус |
|--------|--------|
| `⬅️ Назад к списку` | ✅ |

> ⚠️ В этом режиме **нет** lifecycle-кнопок ментора (`🚀 Запустить` / `✅ Завершить` / `📁 В архив`). Управление — через S02m (ветка «Инструменты ментора»).

**Доменная логика:**
- `get-stream` → карточка
- `list-stream-students` → подсчёт студентов
- `get-user` (ментор) → имя ментора

## S02m — Карточка потока (mentor-режим) (✅ реализовано)

**Как попасть:** «🛠️ Инструменты ментора» → «📋 Мои потоки» → поток (где я ментор).
**Кому:** только владелец потока / ADMIN (`StreamPolicy.canEdit`). Тот же поток, что в S02, но в режиме управления.

**Содержание** как в S02 + `📊 Сводка потока` (счёт по статусам: active/not_advanced/abandoned/enrolled; медиана/отстающие/сортировка).

**Кнопки — панель управления (внизу карточки):**

| Кнопка | Статус потока | Статус |
|--------|---------------|--------|
| `🚀 Запустить` | набор | ✅ |
| `✅ Завершить` | идёт обучение | ✅ |
| `📁 В архив` | завершён | ✅ |
| `👥 Студенты` | любой → S07/S08 **с действиями** | ✅ |

> **Подтверждения:** `🚀 Запустить` — без подтверждения.
> `✅ Завершить` → «⚠️ Завершить поток?» → `Да, завершить` / `Отмена`.
> `📁 В архив` → «⚠️ Отправить в архив?» → `Да, в архив` / `Отмена`. **Только для завершённых потоков** (доменное правило: `StreamAr.archive()` требует `COMPLETED`).

**Кнопки — всегда (вверху):** `⬅️ Назад к моим потокам` → `mentor:my-streams`.

## S03 — Программа курса

**Как попасть:** `📖 Программа курса` в S02.
**Кому:** все.
**Формат:** дерево проектов и уроков через `renderTree` (проекты жирным, уроки с отступом
и метой `— N шагов`). Обрезка при >4000 символов.

**⚠️ Требование экранирования:** реальные названия уроков содержат `-`, `(`, `)`, `.`
(например, «Обработка ошибок: throw и try-catch») — без экранирования спецсимволов
отправка сообщения падает. Заголовки обязаны экранироваться до рендера дерева.

**Содержание:**
```
📖 *Программа курса*
📁 *Git, TDD и посимвольное сравнение строк*
    📝 Обработка ошибок: throw и try-catch — 2 шага
    📝 Математические операторы (+, -, *, /) — 1 шаг
📁 *Продвинутый*
    📝 Асинхронность — 1 шаг
```
Проекты — жирным (`📁 *Заголовок*`), уроки — обычным текстом с отступом
и метой `— N шагов`. Формат задаёт `renderTree` (`apps/u7-bot/src/shared/tree-renderer.ts`).

**Кнопки:**

| Кнопка | Статус |
|--------|--------|
| `⬅️ Назад к потоку` | ✅ |

## S09 — Wizard создания потока

**Как попасть:** «🛠️ Инструменты ментора» → «➕ Создать поток».
**Кому:** `MENTOR`, `ADMIN`.

**Шаги wizard'а:**

| # | Поле | Источник по умолчанию | Кнопки |
|---|------|----------------------|--------|
| 0 | Выбор модуля | список опубликованных | — |
| 1 | Название | `module.title` | — |
| 2 | Описание | `module.description` | — |
| 3 | Дата старта (YYYY-MM-DD) | — | — |
| 4 | Цель | `module.goal` | ✅ Принять / ⏭️ Пропустить |
| 5 | Результат | `module.result` | ✅ Принять / ⏭️ Пропустить |
| 6 | Правила | `module.rules` | ✅ Принять / ⏭️ Пропустить |
| 7 | Целевая аудитория | `module.targetAudience` | ✅ Принять / ⏭️ Пропустить |
| 8 | Дополнительно | `module.additional` | ✅ Принять / ⏭️ Пропустить |
| 9 | Telegram-группа | — | ⏭️ Пропустить |
| 10 | Кодовое слово | — | ⏭️ Пропустить |

**Подтверждение:** превью всех полей → `✅ Создать` / `⬅️ Изменить`.

**Логика:**
- программа потока берётся из выбранного опубликованного модуля; созданный поток сразу открыт для набора
- кодовое слово, если задано, сохраняется и требуется при записи

## S10 — Запись на поток (проверка кодового слова)

**Как попасть:** `📝 Записаться` в S02.
**Кому:** Guest / Candidate (`canEnroll`).

**Сценарий:**
1. Поток **без** кодового слова → сразу зачисление → поздравление-уведомление
   (🎉 + поток/дата/ссылка на группу) → возврат в главное меню.
2. Поток **с** кодовым словом → экран «🔑 Введите кодовое слово для записи
   на поток:» + кнопка `❌ Отмена`; слово вводится обычным сообщением,
   экран с подсказкой не меняется.
3. Слово верное → зачисление (как в п. 1).
4. Слово неверное → короткий переспрос «❌ Неверное слово. Осталось
   попыток: {N}» (всего 3) — поверх экрана.
5. 3 неудачи → возврат на карточку потока (S02).

**Кнопки:**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `❌ Отмена` | возврат на карточку потока (S02) | ✅ |

**Надёжность:**
- слово проверяется и на экране (подсчёт попыток), и в домене (безопасность)
- прочие ошибки (уже записан и т.п.) — короткое предупреждение поверх экрана

## S11 — Приглашение желающим (проактивное)

Отдельного экрана нет: приглашение — уведомление без кнопок. При открытии
набора модуль желаний сам собирает текст (поток/дата/ментор) и отправляет
через общий механизм уведомлений.

Содержание (plain, до экранирования):

```
📣 Открылся набор на «{title}», который ты хотел пройти! Старт: {дд.мм.гггг}. Ментор: {имя}. Подробности: /start → 📚 Потоки курсов. Для записи нужен ключ — его выдаёт ментор. Не актуально — отмени желание: 📖 Программы курсов → карточка курса → 🗑️.
```

- Кнопок нет: запись — через карточку потока (S02) → «Записаться».
- Профиль ментора недоступен — строка «Ментор: …» опускается; поток не
  находится — приглашение молчаливо пропускается.

## SIN — Уведомления о бездействии и уходе из учёбы (✅ реализовано — трек student-inactivity)

Проактивные экраны (без точки входа из меню) — сторя `inactivity.story.ts`
в streams-контроллере. Терминология трека: **«Снять с учёбы»** (не «отчислить»).

### SIN-W — Предупреждение студенту (5+ дней бездействия)

Подписка на `student.inactivity-warning` (job `inactivity-sweep`, 19:00 UTC).

```
⏳ Учёба стоит

Ты не занимаешься уже N дней.

Если бездействие продлится больше недели, ментор может снять тебя с учёбы за бездействие.

Меню бота: /start
```

Кнопок нет: уведомление не влияет на открытые экраны; подсказка `/start` —
для тех, кто давно не открывал бота. Самовыход «Покинуть учёбу» — через
меню бота.

### SIN-M — Кандидат на снятие (ментору, 7+ дней)

Подписка на `student.inactivity-remove-candidate`.

```
🛑 Кандидат на снятие с учёбы

Студент *{Имя}* из группы «{Поток}» не занимался N дней.

ℹ️ Уведомления были ранее отправлены студенту.

Действия по студенту — в меню: /start
```

(ℹ️-строка — только если студенту слались предупреждения, `wasWarned`)

Кнопок нет: «Снять с учёбы» ментор выполняет через меню мониторинга
(карточка студента → «Снять с учёбы»).

### SIN-A — Реакции на уход (student.abandoned)

Тексты уведомлений задаёт домен (при самовыходе / снятии):
- ментору (самовыход студента): «🚪 Студент {Имя} покинул учёбу с потока
  «{Поток}» по собственному желанию.»
- студенту (снятие ментором): «Ты снят с учёбы с потока «{Поток}» за
  бездействие и исключён из его группы. Прогресс сохранён — если захочешь
  вернуться, напиши ментору потока.»

Доставка — общий механизм уведомлений. Реакция экранов — только мягкий
кик из Telegram-группы (ниже).

**Сопутствующее (не UI-экраны):**
- снятый студент мягко исключается из Telegram-группы потока
  (исключение + разбан — пользователь может вернуться по ссылке);
  нет группы/прав у бота — запись в лог.
- активный студент сам покинул группу → ментору уведомление «🚪 Студент
  {Имя} покинул группу «{Поток}».»; статус студента не меняется.
