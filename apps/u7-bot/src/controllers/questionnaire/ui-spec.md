# Спецификация экранов Questionnaire (UI Spec)

Документ описывает экраны Telegram-бота модуля Questionnaire с точки зрения
пользователя: содержание, кнопки, переходы и видимое поведение.
Служит **отправной точкой для разработки**.

Условные обозначения:
- ✅ реализовано
- ❌ не реализовано
- 📋 в бэклоге / запланировано в треке

---

## Путь пользователя

Два варианта входа в анкету:

- **По приглашению (likert-анкеты):** система присылает приглашение (S01) →
  «▶️ Начать заполнение» → вопросы (S02/S03) → завершение (S04).
- **При записи на курс:** кнопка «🎓 Хочу пройти курс» в каталоге курсов
  → желание создаётся в статусе «ждёт анкету» → приходит приглашение (S01b)
  → «▶️ Заполнить анкету» → вопросы (S02/S03) → завершение (S04).
  Анкета открывается только по нажатию кнопки — сама по себе не всплывает.

---

## S01 — Приглашение (📋 invite) ✅

**Как попасть:** приходит от системы.
**Содержание:**
```
📋 *Анкета*

{inviteText или дефолт «Заполните, пожалуйста, анкету.»}

Для отмены в любой момент нажмите /cancel.

Если кнопки не открываются — наберите /start.
```

**Кнопки:**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `▶️ Начать заполнение` | первый вопрос анкеты (S02/S03) | ✅ |
| `❔ Зачем это нужно?` | пояснение (см. ниже) | ✅ |
| `⏭️ Пропустить` | подтверждение отказа (S06a) | ✅ |

- «❔ Зачем это нужно?» показывается только если у анкеты задан поясняющий
  текст. Пояснение: `{whyText или «Нет дополнительной информации.»}` +
  кнопка `✅ Хорошо` → снова S01.
- Строка «Если кнопки не открываются…» — для пользователей, у которых
  приглашение могло устареть: /start открывает свежее меню.

---

## S01b — Приглашение при записи на курс ✅

**Как попасть:** кнопка «🎓 Хочу пройти курс» в каталоге курсов — у курса
задан пул анкеты.

**Содержание:**
```
📋 *Анкета*

Для вас подготовлена анкета — заполните, пожалуйста.

Если кнопки не открываются — наберите /start.
```

**Кнопки:**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `▶️ Заполнить анкету` | первый вопрос анкеты этого курса (S02/S03) | ✅ |

- Запись на курс только зовёт: анкета открывается по нажатию кнопки,
  сама по себе не всплывает; желание в это время уже «ждёт анкету»
  (pending, см. courses/ui-spec.md W02).
- Повторное открытие карточки курса при незавершённой анкете — не это
  приглашение, а W04 «▶️ Продолжить анкету» (courses/ui-spec.md).

## S02a — Одиночный выбор (🔘 single choice) ✅

**Содержание:**
```
*Вопрос N из M*

*{текст вопроса}*

1. ( ) {вариант 1}
2. ( ) {вариант 2}
3. ( ) {вариант 3}
```

**Кнопки:** `1`, `2`, `3`… — по одной на вариант.

**Поведение:**
- клик по варианту → у выбранного появляется маркер `(x)`, кнопки исчезают,
  следующим сообщением приходит следующий вопрос — в чате остаётся история
  «вопрос → выбранный ответ»;
- клик по кнопке старого (уже отвеченного) вопроса → предупреждение S10,
  ничего не ломается;
- шапка «Вопрос N из M» — прогресс по **активной ветке** анкеты (с учётом
  ветвления по уже данным ответам), а не по всему пулу вопросов;
- под **первым** вопросом анкеты — подсказка «В любой момент можно нажать
  /cancel — вернёшься в главное меню.»

---

## S02b — Множественный выбор (☑️ multiple choice) ✅

**Содержание:**
```
*Вопрос N из M*

*{текст вопроса}*

1. [ ] {вариант 1}
2. [x] {вариант 2}
3. [ ] {вариант 3}
```

**Кнопки:** `1`, `2`, `3`… (тогглы) + `Далее -->`.

**Поведение:**
- клик по варианту — переключение: маркер обновляется на том же экране
  (`[x]` ↔ `[ ]`), кнопки остаются живыми;
- «Далее -->» появляется только когда выбран хотя бы один вариант
  (при пустом выборе кнопки «Далее» нет);
- «Далее» → у выбранных остаются финальные маркеры `[x]`, кнопки исчезают,
  следующим сообщением — следующий вопрос или завершение (S04);
- «Далее» без выбора (если всё же нажата) → предупреждение S10, ничего не
  ломается.

---

## S03 — Текстовый вопрос (✏️ text) ✅

**Содержание:**
```
*Вопрос N из M*

*{текст вопроса}*

Введите ваш ответ текстом...
```

**Кнопки:** отсутствуют.

**Поведение:** ответ вводится обычным сообщением → предыдущий вопрос
фиксируется (как в S02a), следующим сообщением приходит следующий вопрос
или завершение. Ввод текста на вопросе с кнопками → короткое предупреждение
«Ожидался ответ с выбором (нажатием кнопки)», экран не меняется, можно
ответить кнопкой.

---

## S04 — Завершение (✅ completed) ✅

**Как попасть:** после последнего ответа.

**Содержание:**
```
✅ *Анкета завершена*

{completionText или дефолт «Спасибо! Твоя анкета принята.»}
```

**Кнопки:** `↩️ Главное меню` ✅

---

## S05 — Прерывание анкеты (🚫 cancelled) ✅

Прерывание — только через подтверждение (и командой, и кнопкой).

### S05a — Подтверждение прерывания

**Как попасть:** команда `/cancel` во время анкеты **или** кнопка
«⏭️ Прервать» в напоминаниях (S07/S09).

**Содержание:**
```
Вы уверены, что хотите прервать анкету?

{cancelWarning — если у анкеты задан}
```

**Кнопки:**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `✅ Да, прервать` | анкета прерывается → S05b | ✅ |
| `❌ Нет, продолжить` | возврат к текущему вопросу | ✅ |

### S05b — Прервано

**Содержание:** «Анкета прервана.»
**Кнопки:** `↩️ Главное меню` ✅

---

## S06 — Отказ от приглашения (⏭️ declined) ✅

### S06a — Подтверждение отказа

**Как попасть:** «⏭️ Пропустить» на S01.

**Содержание:**
```
Вы уверены, что хотите пропустить анкету?

{cancelWarning — если задан}
```

**Кнопки:**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `✅ Да, пропустить` | отказ подтверждается → S06b | ✅ |
| `❌ Нет, вернуться` | возврат к приглашению (S01) | ✅ |

### S06b — Отказ подтверждён

**Содержание:** «Анкета пропущена.»
**Кнопки:** `↩️ Главное меню` ✅

---

## S07 — Напоминание о закрытии (⏳ warning) ✅

**Когда:** анкета не трогалась 6 часов.

**Содержание:**
```
⏳ *Анкета приостановлена*

Мы заметили, что ты давно не заполнял анкету. Скоро она будет закрыта.

Продолжить?

Если кнопки не открываются — наберите /start.
```

**Кнопки:**

| Кнопка | Действие | Условие | Статус |
|--------|----------|---------|--------|
| `▶️ Продолжить` | вернуться к анкете этого курса | анкета привязана к курсу | ✅ |
| `⏭️ Прервать` | подтверждение прерывания (S05a) | всегда | ✅ |

Кнопки работают даже у тех, кто давно не открывал бота.

---

## S09 — Приглашение продолжить (📋 continue-invite) ✅

**Когда:** анкета не трогалась 3 часа.

**Содержание:**
```
📋 *Анкета*

Вы начали заполнять анкету — продолжим?

Если кнопки не открываются — наберите /start.
```

**Кнопки:** как в S07 (`▶️ Продолжить анкету` / `⏭️ Прервать`).

---

## S08 — Закрыто по таймауту (⏱ timeout-abandon) ✅

**Когда:** анкета не трогалась 9 часов — закрывается автоматически.

**Содержание:** «⏱ Анкета была закрыта из-за длительной неактивности.»
**Кнопок нет.** При ручном прерывании дубля нет (пользователь уже видел
«Анкета прервана.»).

---

## Жизненный цикл брошенной анкеты ✅

Цепочка напоминаний: **3 часа → S09**, **6 часов → S07**, **9 часов →
закрытие + S08**.

- каждое напоминание отправляется **один раз**;
- любая активность (ответ на вопрос) сбрасывает цепочку с начала;
- «Продолжить» возвращает к месту, где пользователь остановился.

---

## S10 — Предупреждения (⚠️ stale) ✅

Короткие предупреждения поверх экрана — анкета не меняется, ввод остаётся,
можно продолжать:

| Ситуация | Текст |
|----------|-------|
| нажата кнопка старого вопроса | «⚠️ Эта кнопка относится к предыдущему вопросу.» |
| «Далее» без единого выбранного варианта | «⚠️ Сначала выбери хотя бы один вариант.» |

---

## Качество отображения ✅

Любые тексты — варианты ответов, названия курсов, inviteText/whyText,
completionText с точками, скобками, дефисами и прочими спецсимволами —
отображаются корректно, без сбоев отправки.
