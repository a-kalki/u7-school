# Спецификация экранов Peer Review — Отзывы (UI Spec)

Документ описывает экраны Telegram-бота модуля отзывов: сбор текстовых отзывов
участниками завершённого потока и их просмотр. Отзывы всегда видны всем.

Служит **отправной точкой для разработки** — что уже реализовано, что запланировано.

Условные обозначения:
- ✅ реализовано
- ❌ не реализовано
- 📋 в бэклоге / запланировано в треке

---

## Путь пользователя

Текущие входы:

- **По приглашению:** поток завершён → каждому участнику персонализированное
  приглашение (S01) → кнопка ведёт **сразу в кампанию** (S03, список адресатов).
- **Из главного меню (хаб «Отзывы»):** кнопка `💬 Отзывы` в главном меню
  (видна при наличии живых кампаний) → S02 «Мои отзывы» → кампания → S03.
- **Чтение:** «💬 Отзывы» в карточке потока (streams S02) → постраничный
  просмотр (S07).

Будущие входы (бэклог): задача в `/tasks` «Заполни отзывы по завершённому
потоку {name}» с кнопкой «Выполнено» (task-модуль); кнопка «Анкета»
(likert-метрики — отдельная от отзыва точка входа).

---

## Доменные основы (для контекста спека)

- `ReviewCampaign` — кампания сбора по скоупу (сейчас — поток), окно 7 дней
  (константа), снапшот участников с исходами на момент закрытия потока.
- Исход участника — собственная проекция модуля (не копия статусов студента);
  вычисляется при создании кампании через API статусов и признаков студента,
  сырые статусы (`advanced`, `abandoned`, …) в кампанию и UI не попадают:
  `completed` «завершил», `dropped` «забросил», `never_started` «не начал».
- Разрешённые адресаты: «завершил» → одногруппники + ментор; «забросил»/«не
  начал» → только ментор; ментор → все студенты. Никогда — отзыв о себе.
- `Review`: автор, адресат, роли, исход автора (снапшот из кампании),
  context, scopeId, text. Один отзыв на пару (автор, адресат) в кампании,
  перезапись разрешена в пределах окна.
- Лейблы исходов модуля: «завершил», «забросил», «не начал» (роль «ментор» —
  отдельная роль, не исход). Студенческий словарь меток («окончил»,
  «окончил, не прошёл», …) остаётся в зонах stream и сюда не переносится.
- Окно проверяет домен — UC не считает даты сам: живость конкретной кампании
  подтверждает агрегат (доменная ошибка «возможность закрыта»), списки живых
  кампаний отдаёт репозиторий (метод «дай активные»). Истекло → сторя рендерит
  экран-заглушку.

## S01 — Приглашение (invite) 📋

**Когда:** событие `stream.completed` (публикует UC complete-stream).
**Кому:** всем участникам потока. Приглашение персонализировано — кнопка
ведёт сразу в кампанию (S03), минуя список кампаний.

Студенту (исход «завершил»):
```
🏁 Поток «{StreamTitle}» завершён!

Поделитесь впечатлениями об одногруппниках и менторе — это часть
цифрового профиля каждого. Пишите только правду.
```

Студенту (исходы «забросил» / «не начал»):
```
🏁 Поток «{StreamTitle}» завершён!

Поделитесь впечатлениями о менторе и учёбе — это поможет школе
и тем, кто только выбирает, учиться ли. Пишите только правду.
```

Ментору:
```
🏁 Поток «{StreamTitle}» завершён!

Поделитесь впечатлениями о студентах потока — это часть их
цифрового профиля. Пишите только правду.
```

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `💬 Отзывы` | → S03 (кампания этого потока) | 📋 |

> Механика invite (ФР-6): кнопка работает, даже если получатель давно не
> открывал бота; при устаревании — `/start`. Одно приглашение на участника,
> напоминаний нет (до task-модуля).

---

## S02 — «Мои отзывы» (хаб отзывов, список кампаний) 📋

**Как попасть:** кнопка `💬 Отзывы` в главном меню (декларативная
`menuButtons` стори) — видна при наличии живых кампаний; нет кампаний —
нет кнопки.

```
💬 Отзывы
```

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `🏁 Поток «{title}» · {мой прогресс M/K} · {N} дн.` | живая кампания | 📋 |
| `↩️ Главное меню` | всегда | 📋 |

> M/K — мои отзывы / доступные адресаты.
> Из приглашения (S01) — сразу в кампанию (S03), минуя этот экран.

---

## S03 — Список адресатов кампании 📋

**Как попасть:** кнопка `💬 Отзывы` из приглашения (S01) или выбор кампании
в S02.

```
✍️ Поток «{title}». О ком хотите рассказать? Пишите кому хотите
и сколько хотите.
⏳ Возможность открыта ещё {N} дн.
```

*Легенда:*
✅ — если мой отзыв об адресате уже есть:

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `✅ Студент: {Имя}` | адресат-студент, отзыв уже есть | 📋 |
| `Студент: {Имя}` | адресат-студент, отзыва нет | 📋 |
| `Ментор: {Имя}` | адресат-ментор (только для автора-студента), без ✅ если отзыв есть — `✅ Ментор: {Имя}` | 📋 |
| `↩️ Главное меню` | всегда | 📋 |

> Автору с исходом «забросил»/«не начал» доступен только ментор (правила
> адресации кампании).
> ✅ — только мои отзывы. Чужие — в просмотре (S07).
> Отдельной кнопки «Закончить» нет: выход — главное меню или `/cancel`;
> кампания живёт до конца окна независимо от выхода.

---

## S04 — Перезапись (ввод с заменой) 📋

**Как попасть:** клик по ✅-адресату в S03. Отдельной кнопки «Перезаписать»
нет — экран сразу принимает текст.

```
✏️ Вы уже писали о {Имя}:

«{текущий текст отзыва}»

Отправьте новый текст — он заменит текущий.
Или нажмите «Назад».
```

**Ввод:** тот же контракт, что в S05 (10–3500 символов, переспросы без
потери контекста).

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `❌ Назад` | → S03 без изменений | 📋 |

---

## S05 — Ввод отзыва 📋

**Как попасть:** клик по адресату без ✅ в S03.

Текст-подсказка зависит от направления и статуса автора:

- студент → о студенте:
  «Расскажите о {Имя}. Как бы вы описали его профессиональные, командные
  и личностные качества? Не обязательно перечислять всё — пишите только то,
  что хотите написать, и пишите правду. Если считаете, что что-то стоит
  подтянуть, — напишите и об этом.»
- ментор → о студенте:
  «Расскажите о студенте {Имя}: сильные стороны, чего удалось достичь
  за поток, что стоит подтянуть.»
- исход «завершил» → о менторе:
  «Поделитесь впечатлением о работе с ментором {Имя}: что помогало учиться,
  что мешало, чего не хватило. Пишите правду — это поможет и ментору,
  и школе.»
- исход «не начал» → о менторе:
  «Почему так и не начали учёбу? Что не совпало с ожиданиями? Ваши
  впечатления о менторе и школе помогут тем, кто только выбирает.»
- исход «забросил» → о менторе:
  «Почему забросили учёбу? Какие пожелания оставите школе и ментору?
  Что стоит ожидать людям, которые рассматривают возможность здесь учиться.»

**Ввод:** 10–3500 символов; короче — переспрос, длиннее — «пожалуйста,
сократите» (контекст не теряется). `/cancel` — выход из диалога отзывов.

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `⏭️ Пропустить` | → S03 без сохранения | 📋 |

---

## S06 — Сохранение → возврат в список 📋

После сохранения — **новый экран** с обновлённым списком адресатов:

```
✅ Отзыв о {Имя} сохранён. О ком ещё рассказать?
⏳ Возможность открыта ещё {N} дн.
```

Кнопки — как в S03 (у {Имя} появился ✅).

---

## S07 — Просмотр отзывов (чтение, пагинация) 📋

**Как попасть:** «💬 Отзывы» в карточке потока (streams S02). Только чтение —
кнопки перехода в живую кампанию отсюда нет.

Кнопка в карточке потока видна, если есть хотя бы один отзыв по потоку.

**Формат** — группировка по адресатам, статус адресата/автора — снапшот
кампании (контекст отзыва):

```
💬 Отзывы — поток «{StreamTitle}» · стр. 1/3
———
👤 {Имя} (студент · завершил):
«{текст}» — {автор} (студент)
👤 {Имя} (студент · забросил):
«{текст}» — {автор} (студент)
👤 {Имя} (ментор):
«{текст}» — {автор} (студент · не начал)
```

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `‹ Пред` | не первая страница | 📋 |
| `След ›` | не последняя страница | 📋 |
| `⬅️ Назад к потоку` | всегда | 📋 |

> Разбиение постраничное: страница наполняется целыми отзывами до лимита
> символов (запас на шапку и клавиатуру, суммарно < 4096); отзыв не рвётся
> посередине.

### Абстракция пагинации 📋

> Вопрос абстракции пагинации (хелпер в bot-ui-story, переиспользование
> в дереве учебной программы) вынесен в тактический файл

## Бэклог

- 📋 **Задача `/tasks`** — при появлении кампании создаётся (или может
  создаваться) задача «Заполни отзывы по завершённому потоку {name}»
  с кнопкой «Выполнено» → кампания (S03). Требует task-модуль.
- 📋 **Метрики-анкеты (likert)** — раздельная от отзыва кнопка «Анкета».
  Паттерн интеграции: кампания запускает анкету через фасад questionnaire
  с `ownerInfo` (context/scopeId/targetId); ER peer-review на
  `questionnaire.completed` раскладывает ответы по своим местам.
- 📋 **Exit-кампания** — после завершения текущего потока триггеры
  перепривязываются с `stream.completed` на личные события студентов
  (`student.abandoned` / `student.completed`): уход — приглашение сразу.
  Свои тексты (причины, пожелания школе и ментору). Детали — `tactics-draft.md`.
- 📋 **Кампании по сессиям** (код-ревью, парное программирование —
  в парном возможно несколько смотрящих) — `session_completed`.
  Детали — `tactics-draft.md`.
- 📋 **Напоминания об окне** — с task-модулем.
- 📋 **Отзывы о курсе** — отдельный контекст.

## Снятые решения

- Видимость отзывов: всем и всегда в карточке потока; ✅-маркеры — только свои отзывы.
- Окно: 7 дней (константа); истекло — возможности нет, домен отклоняет запись.
- Длина текста: 10–3500; переполнение — просить сократить.
- Перезапись: разрешена в окне, без confirm-кнопки — ввод сразу заменяет,
  «Назад» отменяет.
- исходы «забросил»/«не начал»: пишут только ментору, со своими текстами-подсказками.
- Приглашение персонализировано: кнопка ведёт сразу в кампанию (S03).
- Хаб «Отзывы»: кнопка главного меню (видна при живых кампаниях) → S02.
- Роли в кнопках: `Студент: {Имя}` / `Ментор: {Имя}`, ✅ при наличии отзыва.
- S07 — только чтение, с пагинацией.
- Анкета и отзыв — раздельные точки входа.
