# UI-спецификация: Контроллер «Программы курсов»

> **Контроллер:** `CoursesController` (`name = 'course'`)
> **Префикс callback'ов:** `course:course-catalog:*`

## Экраны

### S00: Курсы школы

**Триггер:** Кнопка «📖 Программы курсов» в главном меню, callback `course:course-catalog:list`

**Содержание:**
- Заголовок: «📖 *Курсы*»
- Для каждого курса: эмодзи направления + `*Курс: <название>*` (жирный)
- Под каждым курсом inline: этапы с эмодзи трека и числом модулей
- Кнопки: по одной на курс (ведёт на S00b), «↩️ Главное меню»

**Особые случаи:**
- Нет курсов: «Пока нет доступных курсов.» + кнопка «↩️ Главное меню»

### S00b: Этапы курса

**Триггер:** Клик на курс, callback `course:course-catalog:phases:<courseId>`

**Содержание:**
- Заголовок: «📖 *Курс: <название>*»
- Для каждого этапа: эмодзи + `*Этап: <название>*` + число модулей
- Под каждым этапом inline: модули с числом проектов и уроков
- Кнопки: по одной на этап (ведёт на S00c), «⬅️ Назад к курсам школы»

### S00c: Модули этапа

**Триггер:** Клик на этап, callback `course:course-catalog:modules:<courseId>:<phaseIdx>`

**Содержание:**
- Заголовок: «📖 *Этап: <название>*»
- Для каждого модуля: `*Модуль: <название>*` + число проектов и уроков
- Под каждым модулем inline: проекты с числом уроков
- Кнопки: по одной на модуль (ведёт на S00d), «⬅️ Назад к курсу»

### S00d: Проекты модуля (tree-renderer)

**Триггер:** Клик на модуль, callback `course:course-catalog:projects:<courseId>:<phaseIdx>:<moduleId>`

**Содержание:**
- Заголовок: «📖 *Модуль: <название>*»
- Дерево проектов: рендеринг через `renderTree()` из `shared/tree-renderer.ts`
- Кнопки: по одной на проект (ведёт на S00e), «⬅️ Назад к этапу»

### S00e: Уроки проекта

**Триггер:** Клик на проект, callback `course:course-catalog:lessons:<courseId>:<phaseIdx>:<moduleId>:<projectIdx>`

**Содержание:**
- Заголовок: «📖 *Проект: <название>*»
- Для каждого урока: `*Урок: <название>*` + число шагов
- Под каждым уроком inline: до 3 первых шагов (описания)
- Кнопки: только «⬅️ Назад к модулю»

## Кросс-ссылки

- Кнопка «↩️ Главное меню» — через `this.uiApp.getAction<CommunityActions>('mainMenu')()`

## tree-renderer

Файл: `apps/u7-bot/src/shared/tree-renderer.ts`

Чистая функция `renderTree(nodes: TreeNode[]): string` — рендерит дерево в MarkdownV2.
Не зависит от доменов, готова к переиспользованию в streams/learning/mentor.
