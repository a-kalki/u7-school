# Спецификация экранов Learning (UI Spec)

Документ описывает экраны Telegram-бота модуля Learning: хаб, дерево уроков, просмотр шагов, прогресс.
Служит **отправной точкой для разработки** — что уже реализовано, что запланировано.

Условные обозначения:
- ✅ реализовано
- ❌ не реализовано
- 📋 в бэклоге / запланировано в треке

---

## S05 — Хаб «Моя учёба»

**Как попасть:** `🎓 Моя учёба` в главном меню.
**Кому:** только `STUDENT`.

**Содержание:**
```
📖 *Моя учёба*

Выберите действие:
```

**Кнопки — активный студент (enrolled/active):**

| Текст | Код | Статус |
|-------|-----|--------|
| `▶️ Продолжить учёбу` / `▶️ Начать учёбу` | `learning:my-study:continue` → S05a (текущий шаг) | ✅ |
| `📂 Уроки` | `learning:my-study:lessons` → S05b (дерево) | ✅ |
| `📊 Мой прогресс` | `progress:progress:{streamId}` → S06 | ✅ |
| `🚪 Покинуть учёбу` | `learning:my-study:leave-confirm` → confirm | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

**Кнопки — завершивший студент (not_advanced/abandoned):**

| Текст | Код | Статус |
|-------|-----|--------|
| `📊 Мой прогресс` | `progress:progress:{streamId}` → S06 | ✅ |
| `🚪 Покинуть учёбу` | `learning:my-study:leave-confirm` → confirm | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> Текст кнопки зависит от прогресса: `▶️ Продолжить учёбу` если есть завершённые шаги, иначе `▶️ Начать учёбу`.
> «▶️ Продолжить учёбу» / «▶️ Начать учёбу» и «📂 Уроки» скрыты для завершивших — обучение окончено.

**Confirm-диалог выхода (самовыход, FR-4):**
```
🚪 *Покинуть учёбу?*

Прогресс сохранится, но ментор больше не будет тебя сопровождать.
```

| Текст | Код | Статус |
|-------|-----|--------|
| `🚪 Да, покинуть` | `learning:my-study:leave` → UC drop-student | ✅ |
| `❌ Остаться` | `learning:my-study` → хаб | ✅ |

**Результат выхода:** `Ты покинул учёбу. Жаль, что не сложилось — возвращайся, когда будешь готов!` + кнопка `⬅️ В меню`.

> Самовыход: студент → `abandoned` + мягкий кик из TG-группы потока (FR-6, событие `student.abandoned`). Восстановлен треком bot-ui-dialog-learning.

## S05a — Просмотр шага (активный / read-only)

**Как попасть:** `▶️ Продолжить учёбу` / `▶️ Начать учёбу` в S05, или клик на шаг в S05b.
**Кому:** `STUDENT`.

**Содержание:**
```
📖 *Поток:* {StreamTitle}
📁 *Проект:* {ProjectTitle}
📚 *Урок:* «{LessonTitle}»
🔢 p{projectIndex}-l{lessonIndex}

――――――――

📊 [████░░] {completed}/{Total}
📝 *Шаг {position} из {Total}:* {StepDescription}

{StepContent}

――――――――

_Шаги урока:_
✅ _Уже пройденный шаг_
▶️ _Текущий шаг_
🔒 _Будущий шаг_
```

**Кнопки — активный шаг (режим «Продолжить»):**

| Текст | Код | Статус |
|-------|-----|--------|
| `✅ Выполнено` | `learning:complete:{streamId}:{stepId}` | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> «📊 Мой прогресс» доступен только из хаба (S05). На шаге кнопка убрана — фокус на задании.

**Кнопки — просмотр пройденного шага (read-only, из S05b):**

| Текст | Код | Условие | Статус |
|-------|-----|---------|--------|
| `◀️ Назад` | `learning:my-study:view:{streamId}:{prevStepId}` | скрыта на первом completed | ✅ |
| `▶️ Вперёд` | `learning:my-study:view:{streamId}:{nextStepId}` | скрыта на последнем completed | ✅ |
| `⬅️ Назад к уроку` | `learning:my-study:lesson:{lessonId}` → S05b (шаги урока) | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> Прогресс-бар показывает **завершённые** шаги урока (`completed`), а не порядковый номер шага.
> ◀️/▶️ листают **только completed шаги** — владение экраном сохраняется, транспорт рендерит edit'ом на месте. Текущий шаг через листание недоступен.
> Список шагов урока всегда виден внизу — студент понимает, где находится.

## S05b — Дерево навигации «📂 Уроки» ✅

**Как попасть:** `📂 Уроки` в S05.
**Кому:** `STUDENT`.

**UX-контракт «Диалог и Экран» (трек bot-ui-dialog-learning):** стори возвращает экран (`screen`); edit или send решает транспорт по владению экраном — drill-down внутри дерева рендерится edit'ом на месте (seq не растёт), переходы между стори (хаб ↔ дерево ↔ шаг) — по стандартной политике рендера (`bot-ui-session-architecture.md` §5).

### Уровень 1: Проекты

**Тело сообщения** — полная иерархия модуля с иконками статусов (глубина — до уроков, без шагов):
```
📂 *Уроки*

📁 *Проект 1: Название* (2/5) ✅
    📝 Урок 1: Название (3/3) ✅
    📝 Урок 2: Название (1/4) ▶️

📁 *Проект 2: Название* (0/3) 🔒
    📝 Урок 1: Название (0/2) 🔒
```

> Иконки статусов: ✅ completed, ▶️ current, 🔒 locked. Проекты — жирным.

| Текст | Код | Статус |
|-------|-----|--------|
| `📁 {ProjectTitle} ({N}/{M})` | `learning:my-study:project:{projectIndex}` | ✅ |
| `⬅️ Назад к учёбе` | `learning:my-study` → S05 | ✅ |

> В скобках — прогресс: пройдено/всего уроков. Показываются **все** проекты модуля.

### Уровень 2: Уроки проекта

**Тело сообщения** — уроки проекта с шагами и иконками статусов:
```
📂 *Уроки* › {ProjectTitle}

📝 *Урок 1: Название* (3/3) ✅
    📄 Шаг 1: Описание ✅
    📄 Шаг 2: Описание ✅
    📄 Шаг 3: Описание ✅
📝 *Урок 2: Название* (1/4) ▶️
    📄 Шаг 1: Описание ✅
    📄 Шаг 2: Описание ▶️
    📄 Шаг 3: Описание 🔒
    📄 Шаг 4: Описание 🔒
```

> Иконки: ✅ completed, ▶️ current, 🔒 locked. Уроки — жирным.

| Текст | Код | Статус |
|-------|-----|--------|
| `📝 {LessonTitle} ({N}/{M})` | `learning:my-study:lesson:{lessonId}` | ✅ |
| `⬅️ Назад к проектам` | `learning:my-study:lessons` → уровень 1 | ✅ |

### Уровень 3: Шаги урока

**Тело сообщения** — список шагов с маркерами и описаниями:
```
📂 *Уроки* › {ProjectTitle} › {LessonTitle}

✅ _Описание пройденного шага_
▶️ _Описание текущего шага_
🔒 _Описание будущего шага_

Выберите шаг:
```

| Текст | Код | Условие | Статус |
|-------|-----|---------|--------|
| `✅ {StepDescription}` | `learning:my-study:view:{streamId}:{stepId}` | completed | ✅ |
| `▶️ {StepDescription}` | `learning:my-study:continue` → S05a | current | ✅ |
| `⬅️ Назад к урокам` | `learning:my-study:project:{projectIndex}` → уровень 2 | ✅ |

> 🔒-шаги — только в тексте, не кнопками. Telegram не поддерживает disabled-кнопки.
> В кнопках используется `StepDescription` (заголовок шага).

## S06 — Прогресс студента

**Как попасть:** `📊 Мой прогресс` в S05.
**Кому:** только `STUDENT`.

**Содержание:**
```
📊 *Мой прогресс* — {StreamTitle}

📊 Общий: [████░░] {completed}/{total}

✅ *Проект 1: {ProjectTitle}* — [████░░] {completed}/{total}
    ✅ {LessonTitle} — [████░░] {completed}/{total}
    ▶️ {LessonTitle} — [██░░░░] {completed}/{total}
    🔒 {LessonTitle} — [░░░░░░] 0/{total}
▶️ *Проект 2: {ProjectTitle}* — ...
🔒 *Проект 3: {ProjectTitle}* — ...

📝 Всего шагов завершено: {completed} из {total}
```

> Иконки статуса: ✅ completed, ▶️ current, 🔒 locked — по проектам и урокам.

**Ошибки:** чужой streamId → `⚠️ Этот прогресс не соответствует вашему текущему потоку.`; снапшот не найден → `⚠️ Программа потока не найдена.`

**Кнопки:**

| Текст | Код | Статус |
|-------|-----|--------|
| `⬅️ Назад к учёбе` | `learning:my-study` → S05 (хаб) | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

## S05n — Проактивные сообщения хаба ✅

**Источник:** подписка `HubStory` на `student.completed` (`getEventSubscriptions`).

Доставка (контракт «Диалог и Экран»):

- **Кнопочные проактивы (7a/7b) — канал `invite`** (ФР-6, временное
  исключение И3 до модуля tasks-system): кнопки штампуются легальной
  эпохой диалога получателя, нажатие → switch в стори каталога,
  `/start` → reopen. Прежний UX сохранён.
- Чистые уведомления (без кнопок) доставляет механизм `userFacade.notify`
  — контроллер `user`, сторя `notify` (трек user-notify; тексты — в UC
  `complete-student`).

### Зачисление (student.enrolled) — подписка удалена (трек user-notify)

Дубль убран: студент уже получает флоу-ответ view-stream
«🎉 Вы успешно записаны на поток!», дополненный инструкцией:
«Теперь вы можете получить функционал по учёбе, набрав /start и перейдя
по кнопке «Моя учёба»». Событие `student.enrolled` остаётся — его слушает
ER `fulfill-wish` (модуль wish).

### Сообщение о завершении модуля (событие `student.completed`)

Хаб рендерит кнопочные ветки (invite):

| Условие | Текст | Кнопка |
|---------|-------|--------|
| `advanced` + есть следующий | `🏁 Модуль завершён! Хочешь записаться на следующий?` | `➡️ Следующий модуль` → `course:course-catalog:wish:{nextModuleId}` |
| `not_advanced` | `🔁 Модуль не пройден до конца. Хочешь записаться на него снова?` | `🔁 Пройти модуль снова` → `course:course-catalog:wish:{moduleId}` |

Безкнопочные ветки доставляет UC `complete-student` через `userFacade.notify`:

| Условие | Текст |
|---------|-------|
| `advanced` + `isLast` | `🎉 Курс завершён! Поздравляем — ты прошёл всю программу.` |
| `advanced` + место неизвестно | `🏁 Модуль завершён!` |

- Место модуля — через `appApi.execute('get-module-place')` (домен курсов).
- Обработка кнопки — в `CourseCatalogStory` (`wish` → UC `create-module-wish`).
