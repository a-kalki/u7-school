# Спецификация экранов Learning (UI Spec)

Документ описывает экраны Telegram-бота модуля Learning: хаб, дерево уроков, просмотр шагов, прогресс.
Служит **отправной точкой для разработки** — что уже реализовано, что запланировано.

Условные обозначения:
- ✅ реализовано
- ❌ не реализовано
- 📋 в бэклоге / запланировано в треке

---

## S05 — Хаб «Моя учёба»

**Как попасть:** `🎓 Моя учёба` в главном меню.
**Кому:** только `STUDENT`.

**Содержание:**
```
🎓 *Моя учёба*

Выберите действие:
```

**Кнопки — активный студент (enrolled/active):**

| Текст | Код | Статус |
|-------|-----|--------|
| `▶️ Продолжить учёбу` / `▶️ Начать учёбу` | `learning:my-study:continue` → S05a (текущий шаг) | ✅ |
| `📂 Уроки` | `learning:my-study:lessons` → S05b (дерево) | ✅ |
| `📊 Мой прогресс` | `progress:progress:{streamId}` → S06 | ✅ |
| `🚪 Покинуть поток` | `learning:my-study:leave-confirm` → confirm | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

**Кнопки — завершивший студент (not_advanced/abandoned):**

| Текст | Код | Статус |
|-------|-----|--------|
| `📊 Мой прогресс` | `progress:progress:{streamId}` → S06 | ✅ |
| `🚪 Покинуть поток` | `learning:my-study:leave-confirm` → confirm | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> Текст кнопки зависит от прогресса: `▶️ Продолжить учёбу` если есть завершённые шаги, иначе `▶️ Начать учёбу`.
> «▶️ Продолжить учёбу» / «▶️ Начать учёбу» и «📂 Уроки» скрыты для завершивших — обучение окончено.

**Confirm-диалог выхода:**
```
🚪 *Покинуть поток?*

Вы уверены, что хотите покинуть поток? Это действие нельзя отменить.
```

| Текст | Код | Статус |
|-------|-----|--------|
| `🚪 Да, покинуть` | `learning:my-study:leave` → drop-student | ✅ |
| `❌ Отмена` | `learning:my-study` → хаб | ✅ |

**Результат выхода:** `👋 Вы покинули поток. Если захотите вернуться — обратитесь к ментору.`

## S05a — Просмотр шага (активный / read-only)

**Как попасть:** `▶️ Продолжить учёбу` / `▶️ Начать учёбу` в S05, или клик на шаг в S05b.
**Кому:** `STUDENT`.

**Содержание:**
```
📖 *Поток:* {StreamTitle}
📁 *Проект:* {ProjectTitle}
📚 *Урок:* «{LessonTitle}»
🔢 p{projectIndex}-l{lessonIndex}

――――――――

📝 *Шаг {position} из {Total}:* {StepDescription}
📊 [████░░] {completed}/{Total}

{StepContent}

――――――――

_Шаги урока:_
✅ _Уже пройденный шаг_
▶️ _Текущий шаг_
🔒 _Будущий шаг_
```

**Кнопки — активный шаг (режим «Продолжить»):**

| Текст | Код | Статус |
|-------|-----|--------|
| `✅ Выполнено` | `learning:complete:{streamId}:{stepId}` | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> «📊 Мой прогресс» доступен только из хаба (S05). На шаге кнопка убрана — фокус на задании.

**Кнопки — просмотр пройденного шага (read-only, из S05b):**

| Текст | Код | Условие | Статус |
|-------|-----|---------|--------|
| `◀️ Назад` | `learning:my-study:view:{streamId}:{prevStepId}` | скрыта на первом completed | ✅ |
| `▶️ Вперёд` | `learning:my-study:view:{streamId}:{nextStepId}` | скрыта на последнем completed | ✅ |
| `⬅️ Назад к уроку` | `learning:my-study:lesson:{lessonId}` → S05b (шаги урока) | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> Прогресс-бар показывает **завершённые** шаги урока (`completed`), а не порядковый номер шага.
> ◀️/▶️ листают **только completed шаги** в одном сообщении (editMessage). Текущий шаг через листание недоступен.
> Список шагов урока всегда виден внизу — студент понимает, где находится.

## S05b — Дерево навигации «📂 Уроки» ✅

**Как попасть:** `📂 Уроки` в S05.
**Кому:** `STUDENT`.

**UX-конвенция:** все переходы внутри дерева — **editMessage** (одно сообщение на весь сеанс). Вход из хаба и выход в хаб — sendMessage.

### Уровень 1: Проекты

**Тело сообщения** — полная иерархия модуля с иконками статусов (глубина — до уроков, без шагов):
```
📂 *Уроки*

📁 *Проект 1: Название* (2/5) ✅
    📝 Урок 1: Название (3/3) ✅
    📝 Урок 2: Название (1/4) ▶️

📁 *Проект 2: Название* (0/3) 🔒
    📝 Урок 1: Название (0/2) 🔒
```

> Иконки статусов: ✅ completed, ▶️ current, 🔒 locked. Проекты — жирным.

| Текст | Код | Статус |
|-------|-----|--------|
| `📁 {ProjectTitle} ({N}/{M})` | `learning:my-study:project:{projectIndex}` | ✅ |
| `⬅️ Назад к учёбе` | `learning:my-study` → S05 (sendMessage) | ✅ |

> В скобках — прогресс: пройдено/всего уроков. Показываются **все** проекты модуля.

### Уровень 2: Уроки проекта

**Тело сообщения** — уроки проекта с шагами и иконками статусов:
```
📂 *Уроки* › {ProjectTitle}

📝 *Урок 1: Название* (3/3) ✅
    📄 Шаг 1: Описание ✅
    📄 Шаг 2: Описание ✅
    📄 Шаг 3: Описание ✅
📝 *Урок 2: Название* (1/4) ▶️
    📄 Шаг 1: Описание ✅
    📄 Шаг 2: Описание ▶️
    📄 Шаг 3: Описание 🔒
    📄 Шаг 4: Описание 🔒
```

> Иконки: ✅ completed, ▶️ current, 🔒 locked. Уроки — жирным.

| Текст | Код | Статус |
|-------|-----|--------|
| `📝 {LessonTitle} ({N}/{M})` | `learning:my-study:lesson:{lessonId}` | ✅ |
| `⬅️ Назад к проектам` | `learning:my-study:lessons` → уровень 1 (editMessage) | ✅ |

### Уровень 3: Шаги урока

**Тело сообщения** — список шагов с маркерами и описаниями:
```
📂 *Уроки* › {ProjectTitle} › {LessonTitle}

✅ _Описание пройденного шага_
▶️ _Описание текущего шага_
🔒 _Описание будущего шага_

Выберите шаг:
```

| Текст | Код | Условие | Статус |
|-------|-----|---------|--------|
| `✅ {StepDescription}` | `learning:my-study:view:{streamId}:{stepId}` | completed | ✅ |
| `▶️ {StepDescription}` | `learning:my-study:continue` → S05a | current | ✅ |
| `⬅️ Назад к урокам` | `learning:my-study:project:{projectIndex}` → уровень 2 (editMessage) | ✅ |

> 🔒-шаги — только в тексте, не кнопками. Telegram не поддерживает disabled-кнопки.
> В кнопках используется `StepDescription` (заголовок шага).

## S05n — Проактивные сообщения хаба ✅

**Источник:** подписки `HubStory` на доменные события (`getEventSubscriptions`).

Два типа доставки (см. `bot-architecture.md` §3.5):

- **`send()` — сообщение с кнопками.** Ломает текущий флоу: клавиатура
  предыдущего экрана снимается, новое сообщение становится последним.
  Используется, когда пользователю предлагается действие-кнопка.
- **`notify()` — уведомление, строго без кнопок.** Помечается заголовком
  `🔔 *Уведомление:*`, не вмешивается в поток (клавиатура предыдущего экрана
  сохраняется, `lastBotMessage` не трогается, ввод не захватывается).

### Сообщение о зачислении (событие `student.enrolled`)

```
🎓 Ты зачислен в поток «{StreamTitle}»!

Начинай учёбу — кнопка ниже.
```

| Текст | Код | Действие |
|-------|-----|----------|
| `🎓 Моя учёба` | `learning:hub:my-study` | → S05 |

- Доставка — `send()` (есть кнопка → новый экран, флоу ломается).
- `telegramId` резолвится через `appApi.execute('user', 'get-user')`.
- Название потока необязательно: сбой `get-stream` не мешает сообщению (текст без названия).
- Нет `telegramId` — сообщение не отправляется.

### Сообщение о завершении модуля (событие `student.completed`)

Текст определяется парой `(outcome, getModulePlace(moduleId))`:

| Условие | Текст | Кнопка |
|---------|-------|--------|
| `advanced` + есть следующий | `🏁 Модуль завершён! Хочешь записаться на следующий?` | `➡️ Следующий модуль` → `course:course-catalog:wish:{nextModuleId}` |
| `not_advanced` | `🔁 Модуль не пройден до конца. Хочешь записаться на него снова?` | `🔁 Пройти модуль снова` → `course:course-catalog:wish:{moduleId}` |
| `advanced` + `isLast` | `🎉 Курс завершён!` | без кнопки |
| `advanced` + место неизвестно | `🏁 Модуль завершён!` | без кнопки |

- Строки с кнопкой — доставка `send()` (новый экран, флоу ломается).
- Строки без кнопки — доставка `notify()` (заголовок `🔔 Уведомление:`,
  поток пользователя не трогается).
- `abandoned` событием не публикуется — тишина.
- Место модуля — через `appApi.execute('get-module-place')` (домен курсов).
- Обработка кнопки — в `CourseCatalogStory` (`wish` → UC `create-module-wish`).
