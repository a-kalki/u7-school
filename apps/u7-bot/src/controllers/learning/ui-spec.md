# Спецификация экранов Learning (UI Spec)

Документ описывает экраны Telegram-бота модуля Learning: хаб, дерево уроков, просмотр шагов, прогресс.
Служит **отправной точкой для разработки** — что уже реализовано, что запланировано.

Условные обозначения:
- ✅ реализовано
- ❌ не реализовано
- 📋 в бэклоге / запланировано в треке

---

## S05 — Хаб «Моя учёба»

**Как попасть:** `🎓 Моя учёба` в главном меню.
**Кому:** только `STUDENT`.

**Содержание:**
```
📖 *Моя учёба*

Выберите действие:
```

**Кнопки — активный студент (enrolled/active):**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `▶️ Продолжить учёбу` / `▶️ Начать учёбу` | → S05a (текущий шаг) | ✅ |
| `📂 Уроки` | → S05b (дерево) | ✅ |
| `📊 Мой прогресс` | → S06 | ✅ |
| `🚪 Покинуть учёбу` | → подтверждение выхода | ✅ |
| `↩️ Главное меню` | главное меню | ✅ |

**Кнопки — завершивший студент (not_advanced/abandoned):**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `📊 Мой прогресс` | → S06 | ✅ |
| `🚪 Покинуть учёбу` | → подтверждение выхода | ✅ |
| `↩️ Главное меню` | главное меню | ✅ |

> Текст кнопки зависит от прогресса: `▶️ Продолжить учёбу` если есть завершённые шаги, иначе `▶️ Начать учёбу`.
> «▶️ Продолжить учёбу» / «▶️ Начать учёбу» и «📂 Уроки» скрыты для завершивших — обучение окончено.

**Confirm-диалог выхода (самовыход, FR-4):**
```
🚪 *Покинуть учёбу?*

Прогресс сохранится, но ментор больше не будет тебя сопровождать.
```

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `🚪 Да, покинуть` | выход из учёбы | ✅ |
| `❌ Остаться` | возврат в хаб | ✅ |

**Результат выхода:** `Ты покинул учёбу. Жаль, что не сложилось — возвращайся, когда будешь готов!` + кнопка `⬅️ В меню`.

> Самовыход: студент → `abandoned` + мягкий кик из TG-группы потока (FR-6, событие `student.abandoned`). Восстановлен треком bot-ui-dialog-learning.

## S05a — Прохождение шага (активный)

**Как попасть:** `▶️ Продолжить учёбу` / `▶️ Начать учёбу` в S05.
**Кому:** `STUDENT`.

> Просмотр пройденных/текущего шага (read-only) и листание живут в карточке шага drill-down
> (`S05b`). Отметка `✅ Выполнено` — только здесь, в разделе прохождения.

**Содержание:**
```
📖 *Поток:* {StreamTitle}
📁 *Проект:* {ProjectTitle}
📚 *Урок:* «{LessonTitle}»
🔢 p{projectIndex}-l{lessonIndex}

――――――――

📊 [████░░] {completed}/{Total}
📝 *Шаг {position} из {Total}:* {StepDescription}

{StepContent}

――――――――

_Шаги урока:_
✅ _Уже пройденный шаг_
▶️ _Текущий шаг_
🔒 _Будущий шаг_
```

**Кнопки — активный шаг (режим «Продолжить»):**

| Кнопка | Статус |
|--------|--------|
| `✅ Выполнено` | ✅ |
| `↩️ Главное меню` | ✅ |

> «📊 Мой прогресс» доступен только из хаба (S05). На шаге кнопка убрана — фокус на задании.
> Если все шаги программы уже завершены (итоговый статус ещё ставит ментор), «Продолжить учёбу» ведёт на экран «Завершение потока» (S05c), а не на повтор завершённого шага — иначе повторный клик «Выполнено» даёт same-content edit и ошибку Telegram «message is not modified».

> Прогресс-бар показывает **завершённые** шаги урока (`completed`), а не порядковый номер шага.
> Список шагов урока всегда виден внизу — студент понимает, где находится.

## S05b — Drill-down «📂 Уроки» 📋 (трек `module-program-nav_20260928`)

**Как попасть:** `📂 Уроки` в S05.
**Кому:** `STUDENT`.

**Формат:** карточная drill-down навигация `модуль → проект → урок → шаг`. Каждый уровень —
карточка с шапкой-крошками, пояснением «состоит из N …», списком детей (жирным, нумерованным)
с подуровнями, кнопками-детьми и листанием соседей. Переходы внутри drill-down обновляют
сообщение на месте.

**Общие правила:**
- Шапка — «хлебные крошки»: `📂 *Уроки* › {Проект} › {Урок} › Шаг N`.
- Пояснение уровня: «Модуль состоит из N проектов», «Проект состоит из N уроков», «Урок состоит из N шагов».
- Дети первого уровня — жирным и нумерованными кнопками (`1.`, `2.`, …); подуровень — обычным списком с отступом.
- Статусы: `✅` пройдено / `▶️` текущий / `🔒` закрыто; в скобках — прогресс `(N/M)`.
- Листание `◀️ Пред. …` / `След. … ▶️` — в пределах родителя; на границе кнопки нет.
- `⬅️ Назад к {родителю}` — на уровень выше; на верхнем уровне — `⬅️ Назад к учёбе`.
- В непройденный шаг попасть нельзя — он только строкой со статусом `🔒`.

### Карточка модуля (верхний уровень)

```
📂 *Уроки*
Модуль состоит из 2 проектов

1. **Проект: Введение в web** (2/5) ✅
    📝 Урок 1: Как устроен web (3/3) ✅
    📝 Урок 2: Что такое фронтенд и бэкенд (0/2) ▶️
2. **Проект: Готовим инфраструктуру** (0/3) 🔒
    📝 Урок 1: Выбор, установка и настройка редактора (0/2) 🔒
```

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `1. 📁 {Проект} ({N}/{M})` | все проекты модуля | 📋 |
| `⬅️ Назад к учёбе` | всегда → S05 | 📋 |

### Карточка проекта

```
📂 *Уроки* › Введение в web
Проект состоит из 2 уроков

1. **Урок: Как устроен web** (3/3) ✅
    📄 Шаг 1: … ✅
    📄 Шаг 2: … ✅
2. **Урок: Что такое фронтенд и бэкенд** (0/2) ▶️
    📄 Шаг 1: … ▶️
    📄 Шаг 2: … 🔒
```

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `1. 📝 {Урок} ({N}/{M})` | все уроки проекта | 📋 |
| `◀️ Пред. проект` / `След. проект ▶️` | сосед по порядку в модуле | 📋 |
| `⬅️ Назад к модулю` | всегда | 📋 |

### Карточка урока

```
📂 *Уроки* › Введение в web › Как устроен web
Урок состоит из 3 шагов

1. ✅ Описание шага
2. ▶️ Описание шага
3. 🔒 Описание шага
```

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `1. ✅/▶️ {Описание}` | доступный шаг (пройденный / текущий) | 📋 |
| `◀️ Пред. урок` / `След. урок ▶️` | сосед по порядку в проекте | 📋 |
| `⬅️ Назад к проекту` | всегда | 📋 |

> `🔒`-шаги — только строки со статусом, без кнопок входа (Telegram не поддерживает disabled-кнопки).

### Карточка шага (только просмотр)

```
📂 *Уроки* › Введение в web › Как устроен web › Шаг 2
▶️ В процессе

{тело шага}
```

| Кнопка | Условие | Статус |
|--------|---------|--------|
| `◀️ Пред. шаг` / `След. шаг ▶️` | только доступные (пройденные + текущий) | 📋 |
| `⬅️ Назад к уроку` | всегда | 📋 |

> На карточке шага **нет** кнопки «Выполнено» — отметка о выполнении только в разделе
> прохождения (`S05a`). На текущем шаге «следующий» исчезает (дальше только `🔒`).
> Менторская и публичная версии той же навигации — `S02m` / `S02` / `S03`
> (`streams/ui-spec.md`): у ментора без статусов и с телами всех шагов, у любопытного — без статусов и без тел.

## S05c — Transition-экраны (завершение урока / проекта) ✅

**Как попасть:** автоматически после нажатия `✅ Выполнено` на последнем шаге урока или проекта.
**Кому:** `STUDENT`.

### Завершение урока

```
🎉 Урок «{LessonTitle}» завершён!
📊 Прогресс по модулю: [████░░] {completed}/{total}
📊 Прогресс по проекту: [████░░] {completed}/{total}
```

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `▶️ Начать следующий урок` | → S05a | ✅ |
| `↩️ Главное меню` | главное меню | ✅ |

### Завершение проекта

```
🚀 Проект «{ProjectTitle}» завершён!
📊 Прогресс по модулю: [████░░] {completed}/{total}
```

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `▶️ Начать следующий проект` | → S05a | ✅ |
| `↩️ Главное меню` | главное меню | ✅ |

### Завершение потока

**Как попасть:** нажатие «✅ Выполнено» на последнем шаге программы, либо повторный вход через «Продолжить учёбу» / повторный клик «Выполнено», когда все шаги уже завершены (итоговый статус ещё ставит ментор — идемпотентно).

```
🏆 *Поток полностью завершён!* Поздравляем с успешным окончанием обучения!
```

| Кнопка | Статус |
|--------|--------|
| `↩️ Главное меню` | ✅ |

## S06 — Прогресс студента

**Как попасть:** `📊 Мой прогресс` в S05.
**Кому:** только `STUDENT`.

**Содержание:**
```
📊 *Мой прогресс* — {StreamTitle}

📊 Общий: [████░░] {completed}/{total}

✅ *Проект 1: {ProjectTitle}* — [████░░] {completed}/{total}
    ✅ {LessonTitle} — [████░░] {completed}/{total}
    ▶️ {LessonTitle} — [██░░░░] {completed}/{total}
    🔒 {LessonTitle} — [░░░░░░] 0/{total}
▶️ *Проект 2: {ProjectTitle}* — ...
🔒 *Проект 3: {ProjectTitle}* — ...

📝 Всего шагов завершено: {completed} из {total}
```

> Иконки статуса: ✅ completed, ▶️ current, 🔒 locked — по проектам и урокам.

**Ошибки:** чужой streamId → `⚠️ Этот прогресс не соответствует вашему текущему потоку.`; снапшот не найден → `⚠️ Программа потока не найдена.`

**Кнопки:**

| Кнопка | Действие | Статус |
|--------|----------|--------|
| `⬅️ Назад к учёбе` | → S05 (хаб) | ✅ |
| `↩️ Главное меню` | главное меню | ✅ |

## S05n — Проактивные сообщения хаба ✅

**Источник:** подписка `HubStory` на `student.completed` (`getEventSubscriptions`).

Доставка:

- **Сообщения с кнопками** (7a/7b) работают даже у тех, кто давно не
  открывал бота; нажатие кнопки ведёт в каталог курсов. Прежний UX сохранён.
- Уведомления без кнопок доставляет общий механизм уведомлений
  (не экраны хаба); тексты задаёт домен.

### Зачисление

Отдельного сообщения нет — дубль убран: студент уже получает экран записи
на поток «🎉 Вы успешно записаны на поток!» с инструкцией, как открыть
функционал учёбы (/start → «Моя учёба»).

### Сообщение о завершении модуля (событие `student.completed`)

Хаб рендерит кнопочные ветки (invite):

| Условие | Текст | Кнопка |
|---------|-------|--------|
| `advanced` + есть следующий | `🏁 Модуль завершён! Хочешь записаться на следующий?` | `➡️ Следующий модуль` → `course:course-catalog:wish:{nextModuleId}` |
| `not_advanced` | `🔁 Модуль не пройден до конца. Хочешь записаться на него снова?` | `🔁 Пройти модуль снова` → `course:course-catalog:wish:{moduleId}` |

Безкнопочные ветки доставляет домен через общий механизм уведомлений:

| Условие | Текст |
|---------|-------|
| `advanced` + `isLast` | `🎉 Курс завершён! Поздравляем — ты прошёл всю программу.` |
| `advanced` + место неизвестно | `🏁 Модуль завершён!` |

- Место модуля в программе определяет домен курсов.
- Нажатие кнопки обрабатывает каталог курсов (запись желания на модуль).
