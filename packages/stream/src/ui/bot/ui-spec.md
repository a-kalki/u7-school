# Спецификация экранов Stream (UI Spec)

Документ описывает все экраны Telegram-бота модуля Stream: их содержимое, кнопки, условия видимости и доменную логику.
Служит **отправной точкой для разработки** — что уже реализовано, что запланировано.

Условные обозначения:
- ✅ реализовано
- ❌ не реализовано
- 📋 в бэклоге / запланировано в треке

---

## Карта экранов

```
Главное меню
├─ 📖 Программы курсов → Каталог курсов (S00)                ← ✅
│   └─ курс → Этапы → Модули → Проекты → Уроки (S00, drill-down)
├─ 📚 Потоки курсов → Каталог потоков (S01) (curious-режим)
│   └─ поток → Карточка потока, curious-режим (S02)
│       ├─ 📖 Программа → Программа модуля (S03)
│       ├─ 📋 Детали → Детали потока (S04)
│       ├─ 📊 Студенты → Мониторинг (S07) → Карточка студента (S08)
│       └─ 📊 Студенты → Мониторинг (S07) → Карточка студента (S08)
├─ 🎓 Моя учёба → Хаб (S05) → Прогресс (S06) / Дерево уроков (S05b) / Transition (S05c)    ← ✅
├─ 🛠️ Инструменты ментора → Мои потоки (S02m) / Создать поток (S09) / Мониторинг (S07)   ← ✅
├─ ✍️ Инструменты автора → (отложено, см. раздел ниже)      ← 📋 техдолг
├─ 📝 Заполнить анкету (onboarding)
├─ 💬 Сообщество школы
└─ ❓ Помощь
```

**Принцип веток (см. `architecture-evolution.md` §2.10, §2.11):**
- «Потоки курсов» — только curious-функциональность, **без менторских инструментов**.
- Управление потоком — только в «Инструментах ментора» (трек `mentor_tools_20260713`) → «Мои потоки» → S02m (mentor-режим).
- S07/S08 (студенты) открыты всем ролям — прозрачность; кнопки действий — только ментору/админу.

## S00 — Каталог курсов: 5-уровневый drill-down (✅ реализовано)

**Как попасть:** «📖 Программы курсов» в главном меню.
**Кому:** всем ролям.
**Формат:** как в «Моя учёба → Уроки» — каждый уровень показывает текущие объекты жирным + кнопками, подуровень — inline текстом.

### Уровни:

| Уровень | Заголовок | Жирный+кнопка | Inline (текст) | Кнопка «Назад» |
|---------|-----------|---------------|----------------|----------------|
| 0 | `📖 *Курсы*` | Курсы | Этапы (с числом модулей) | `↩️ Главное меню` |
| 1 | `📖 *Курс: {title}*` | Этапы | Модули (с проектами/уроками) | `⬅️ Назад к курсам` |
| 2 | `📖 *Этап: {title}*` | Модули | Проекты (с числом уроков) | `⬅️ Назад к курсу` |
| 3 | `📖 *Модуль: {title}*` | Проекты | Уроки (с числом шагов) | `⬅️ Назад к этапу` |
| 4 | `📖 *Проект: {title}*` | Уроки | Шаги (заголовки, без тел, макс. 3) | `⬅️ Назад к модулю` |

### Пример S00 (уровень 0):
```
📖 *Курсы*
💻 *Курс: Основы программирования*
    🗂️ Этап: Синтаксис — 1 модуль
    🗂️ Этап: Алгоритмика — 1 модуль

💼 *Курс: Бизнес-аналитика*
    🗂️ Этап: Анализ — 1 модуль
```

### Примечания:
- Карточки курса S00a нет — клик на курс сразу ведёт на уровень этапов.
- Кнопка «📚 Найти поток» убрана (кросс-контроллерная навигация — техдолг, см. §архитектуры).

## S01 — Каталог потоков

**Как попасть:** кнопка `📚 Потоки курсов` в главном меню.
**Кому:** всем ролям.

**Содержание:**
- Заголовок `📚 Потоки курсов`
- Легенда: `🟡 — идёт набор   🔵 — идёт обучение   🟢 — завершён   ⚫ — в архиве`
- Кнопки-потоки: `{эмодзи} {StreamTitle}` — `enrollment` и `active` по умолчанию, `completed`/`archived` — через переключатели

**Кнопки:**

| Текст | Код | Условие | Статус |
|-------|-----|---------|--------|
| `{эмодзи} {StreamTitle}` | `view-stream:view:{id}` | видимый поток | ✅ |
| `🟢 Вкл. завершённые` | `catalog:list-with-completed` | есть completed | ✅ |
| `⚫ Вкл. архивированные` | `catalog:list-with-all` | есть archived | ✅ |
| `🔵 Только активные` | `catalog:list` | показаны все | ✅ |
| `↩️ Главное меню` | `app:main-menu` | всегда | ✅ |

**Доменная логика:**
- `list-streams` → фильтр по статусу в зависимости от переключателей
- Иконки статусов едины для catalog и mentor-tools (🟡/🔵/🟢/⚫)

## S02 — Карточка потока (curious-режим)

**Как попасть:** клик на поток в S01 (ветка «Потоки курсов»).
**Кому:** всем ролям. **Только curious-функциональность, без менторских инструментов.**

**Содержание:**
```
📋 *{StreamTitle}*
_{StreamDescription}_
👤 Ментор: {MentorName}
📅 Старт: {StartDate}
🕐 Время: {HH:MM}
👥 Студентов: {N}
📌 Статус: {StatusLabel}
📚 Курс: Fullstack JS   ← ⚠️ техдолг: захардкожено (см. F3 в spec.md трека)
```

**Кнопки — публичные (всем ролям, включая ментора как зрителя):**

| Текст | Код | Статус потока | Статус |
|-------|-----|---------------|--------|
| `📖 Программа курса` | `view-stream:program:{id}` | любой → S03 | ✅ |
| `📋 Детали` | `view-stream:details:{id}` | любой → S04 | ✅ |
| `📊 Студенты` | `monitor:students:{id}` | любой → S07 (прозрачность) | ✅ |

**Кнопки — гостевые (только НЕ владелец потока, `canEnroll`):**

| Текст | Код | Статус потока | Статус |
|-------|-----|---------------|--------|
| `📝 Записаться` | `enroll:enroll:{id}` | `enrollment` → S10 | ✅ |
| `🔔 Уведомить о наборе` | `view-stream:notify:{id}` | `active` (гость) → заглушка | ✅ |

**Кнопка — всегда:**

| Текст | Код | Статус |
|-------|-----|--------|
| `⬅️ Назад к списку` | `catalog:list` | ✅ |

> ⚠️ В этом режиме **нет** lifecycle-кнопок ментора (`🚀 Запустить` / `✅ Завершить` / `📁 В архив`). Управление — через S02m (ветка «Инструменты ментора», трек `mentor_tools_20260713`).

**Доменная логика:**
- `get-stream` → карточка
- `list-stream-students` → подсчёт студентов
- `get-user` (ментор) → имя ментора

## S02m — Карточка потока (mentor-режим) (✅ реализовано)

**Как попасть:** «🛠️ Инструменты ментора» (трек `mentor_tools_20260713`) → «📋 Мои потоки» → поток (где я ментор).
**Кому:** только владелец потока / ADMIN (`StreamPolicy.canEdit`). Тот же поток, что в S02, но в режиме управления.

**Содержание:** как в S02 + `📊 Сводка потока` (счёт по статусам: active/advanced/not_advanced/abandoned/enrolled; медиана/отстающие/сортировка — трек 6).

**Кнопки — панель управления (внизу карточки):**

| Текст | Код | Статус потока | Статус |
|-------|-----|---------------|--------|
| `🚀 Запустить` | `activate-stream:activate:{id}` | `enrollment` | ✅ (перенос из S02) |
| `✅ Завершить` | `view-stream:complete:{id}` | `active` | ✅ (перенос из S02) |
| `📁 В архив` | `view-stream:archive:{id}` | `completed` | ✅ (перенос из S02) |
| `👥 Студенты` | `monitor:students:{id}` | любой → S07/S08 **с действиями** | ✅ |

> **Подтверждения:** `🚀 Запустить` — без подтверждения.
> `✅ Завершить` → «⚠️ Завершить поток?» → `Да, завершить` / `Отмена`.
> `📁 В архив` → «⚠️ Отправить в архив?» → `Да, в архив` / `Отмена`. **Только для завершённых потоков** (доменное правило: `StreamAr.archive()` требует `COMPLETED`).

**Кнопки — всегда (вверху):** `⬅️ Назад к моим потокам` → `mentor:my-streams`.

## S03 — Программа курса

**Как попасть:** `📖 Программа курса` в S02.
**Кому:** все.
**Формат:** как последний уровень S00 — проекты+уроки жирным, шаги inline (макс. 3). Обрезка при >4000 символов.

**Содержание:**
```
📖 *Программа курса*
📁 *Проект: Введение*
    📝 *Урок: Переменные и типы* — 2 шага
        1. Что такое переменные
        2. Типы данных
    📝 *Урок: Условные операторы* — 2 шага
        1. If-else
        2. Switch
📁 *Проект: Циклы и функции*
    📝 *Урок: Циклы* — 2 шага
        1. For
        2. While
```

**Кнопки:**

| Текст | Код | Статус |
|-------|-----|--------|
| `⬅️ Назад к потоку` | `view-stream:view:{id}` | ✅ |

## S05 — Хаб «Моя учёба»

**Как попасть:** `🎓 Моя учёба` в главном меню.
**Кому:** только `STUDENT`.

**Содержание:**
```
🎓 *Моя учёба*

Выберите действие:
```

**Кнопки — активный студент (enrolled/active):**

| Текст | Код | Статус |
|-------|-----|--------|
| `▶️ Продолжить учёбу` / `▶️ Начать учёбу` | `learning:my-study:continue` → S05a (текущий шаг) | ✅ |
| `📂 Уроки` | `learning:my-study:lessons` → S05b (дерево) | ✅ |
| `📊 Мой прогресс` | `progress:progress:{streamId}` → S06 | ✅ |
| `🚪 Покинуть поток` | `learning:my-study:leave-confirm` → confirm | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

**Кнопки — завершивший студент (advanced/not_advanced/abandoned):**

| Текст | Код | Статус |
|-------|-----|--------|
| `📊 Мой прогресс` | `progress:progress:{streamId}` → S06 | ✅ |
| `🚪 Покинуть поток` | `learning:my-study:leave-confirm` → confirm | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> Текст кнопки зависит от прогресса: `▶️ Продолжить учёбу` если есть завершённые шаги, иначе `▶️ Начать учёбу`.
> «▶️ Продолжить учёбу» / «▶️ Начать учёбу» и «📂 Уроки» скрыты для завершивших — обучение окончено.

**Confirm-диалог выхода:**
```
🚪 *Покинуть поток?*

Вы уверены, что хотите покинуть поток? Это действие нельзя отменить.
```

| Текст | Код | Статус |
|-------|-----|--------|
| `🚪 Да, покинуть` | `learning:my-study:leave` → drop-student | ✅ |
| `❌ Отмена` | `learning:my-study` → хаб | ✅ |

**Результат выхода:** `👋 Вы покинули поток. Если захотите вернуться — обратитесь к ментору.`

## S05a — Просмотр шага (активный / read-only)

**Как попасть:** `▶️ Продолжить учёбу` / `▶️ Начать учёбу` в S05, или клик на шаг в S05b.
**Кому:** `STUDENT`.

**Содержание:**
```
📖 *Поток:* {StreamTitle}
📁 *Проект:* {ProjectTitle}
📚 *Урок:* «{LessonTitle}»
🔢 p{projectIndex}-l{lessonIndex}

――――――――――――――

📝 *Шаг {position} из {Total}:* {StepDescription}
📊 [████░░] {completed}/{Total}

{StepContent}

――――――――――――――

_Шаги урока:_
✅ _Уже пройденный шаг_
▶️ _Текущий шаг_
🔒 _Будущий шаг_
```

**Кнопки — активный шаг (режим «Продолжить»):**

| Текст | Код | Статус |
|-------|-----|--------|
| `✅ Выполнено` | `learning:complete:{streamId}:{stepId}` | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> «📊 Мой прогресс» доступен только из хаба (S05). На шаге кнопка убрана — фокус на задании.

**Кнопки — просмотр пройденного шага (read-only, из S05b):**

| Текст | Код | Условие | Статус |
|-------|-----|---------|--------|
| `◀️ Назад` | `learning:my-study:view:{streamId}:{prevStepId}` | скрыта на первом completed | ✅ |
| `▶️ Вперёд` | `learning:my-study:view:{streamId}:{nextStepId}` | скрыта на последнем completed | ✅ |
| `⬅️ Назад к уроку` | `learning:my-study:lesson:{lessonId}` → S05b (шаги урока) | ✅ |
| `↩️ Главное меню` | `app:main-menu` | ✅ |

> Прогресс-бар показывает **завершённые** шаги урока (`completed`), а не порядковый номер шага.
> ◀️/▶️ листают **только completed шаги** в одном сообщении (editMessage). Текущий шаг через листание недоступен.
> Список шагов урока всегда виден внизу — студент понимает, где находится.

## S05b — Дерево навигации «📂 Уроки» ✅

**Как попасть:** `📂 Уроки` в S05.
**Кому:** `STUDENT`.

**UX-конвенция:** все переходы внутри дерева — **editMessage** (одно сообщение на весь сеанс). Вход из хаба и выход в хаб — sendMessage.

### Уровень 1: Проекты

**Тело сообщения** — полная иерархия модуля с иконками статусов (глубина — до уроков, без шагов):
```
📂 *Уроки*

📁 *Проект 1: Название* (2/5) ✅
    📝 Урок 1: Название (3/3) ✅
    📝 Урок 2: Название (1/4) ▶️

📁 *Проект 2: Название* (0/3) 🔒
    📝 Урок 1: Название (0/2) 🔒
```

> Иконки статусов: ✅ completed, ▶️ current, 🔒 locked. Проекты — жирным.

| Текст | Код | Статус |
|-------|-----|--------|
| `📁 {ProjectTitle} ({N}/{M})` | `learning:my-study:project:{projectIndex}` | ✅ |
| `⬅️ Назад к учёбе` | `learning:my-study` → S05 (sendMessage) | ✅ |

> В скобках — прогресс: пройдено/всего уроков. Показываются **все** проекты модуля.

### Уровень 2: Уроки проекта

**Тело сообщения** — уроки проекта с шагами и иконками статусов:
```
📂 *Уроки* › {ProjectTitle}

📝 *Урок 1: Название* (3/3) ✅
    📄 Шаг 1: Описание ✅
    📄 Шаг 2: Описание ✅
    📄 Шаг 3: Описание ✅
📝 *Урок 2: Название* (1/4) ▶️
    📄 Шаг 1: Описание ✅
    📄 Шаг 2: Описание ▶️
    📄 Шаг 3: Описание 🔒
    📄 Шаг 4: Описание 🔒
```

> Иконки: ✅ completed, ▶️ current, 🔒 locked. Уроки — жирным.

| Текст | Код | Статус |
|-------|-----|--------|
| `📝 {LessonTitle} ({N}/{M})` | `learning:my-study:lesson:{lessonId}` | ✅ |
| `⬅️ Назад к проектам` | `learning:my-study:lessons` → уровень 1 (editMessage) | ✅ |

### Уровень 3: Шаги урока

**Тело сообщения** — список шагов с маркерами и описаниями:
```
📂 *Уроки* › {ProjectTitle} › {LessonTitle}

✅ _Описание пройденного шага_
▶️ _Описание текущего шага_
🔒 _Описание будущего шага_

Выберите шаг:
```

| Текст | Код | Условие | Статус |
|-------|-----|---------|--------|
| `✅ {StepDescription}` | `learning:my-study:view:{streamId}:{stepId}` | completed | ✅ |
| `▶️ {StepDescription}` | `learning:my-study:continue` → S05a | current | ✅ |
| `⬅️ Назад к урокам` | `learning:my-study:project:{projectIndex}` → уровень 2 (editMessage) | ✅ |

> 🔒-шаги — только в тексте, не кнопками. Telegram не поддерживает disabled-кнопки.
> В кнопках используется `StepDescription` (заголовок шага).

## S10 — Проверка кодового слова

**Как попасть:** `📝 Записаться` на потоке с `enrollmentKey` (S02/S00b).
**Кому:** Guest / Candidate.

**Сценарий:**
1. Бот: «Введите кодовое слово для записи на поток»

**Кнопки:**

| Текст | Код | Статус |
|-------|-----|--------|

**Архитектура:**
- Story (UI) проверяет слово для UX и подсчёта попыток
- Use-case `enroll-student` **тоже** проверяет слово — безопасность на уровне домена

## ✍️ Инструменты автора (📋 ОТЛОЖЕНО — техдолг)

> Не реализуется в Релизе 2. Функциональность зафиксирована здесь, чтобы система документации явно содержала эту потребность. UC создания уже реализованы (трек `author_role_20260708`), UI-входа нет. См. `architecture-evolution.md` §2.8, §2.9.

**Ответственность (когда встанет потребность):**
- Создание/редактирование **модулей** (title, description, goal, result, rules, targetAudience, additional).
- Создание/редактирование **курсов**: phases, направления (tech/business), порядок модулей (`add-module-to-course`, `add-phase`).
- Создание/редактирование **проектов, уроков, шагов** внутри модуля (типы шагов: текст/код/файл).
- Роль `AUTHOR`. Создание — прерогатива роли; редактирование — ADMIN или автор (по `authorId`).

**Вход:** «✍️ Инструменты автора» в главном меню (role-gated `AUTHOR`). Подменю: модули / курсы / уроки и шаги.
