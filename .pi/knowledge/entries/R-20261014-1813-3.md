# Одноразовые скрипты укладки/генерации контента не коммитим

- **Тип:** practice
- **Контекст:** скрипты разовой укладки/генерации контента (`scripts/deliver-*.ts`, `generate-m2-*.ts`, ARCADE-*)
- **Решение:** временные скрипты не попадают в коммиты и удаляются после использования.
- **Почему:** они не идемпотентны — например `generate-m2-sources.ts` создавал дубли папок с транслитерированными слагами — и не должны жить в истории.
- **Как применить:** держать такие скрипты рядом с рабочей копией контента, явно помечать, удалять по завершении; не добавлять в git.
