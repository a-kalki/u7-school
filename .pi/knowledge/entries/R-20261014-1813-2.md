# Ссылки на учебные модули — по имени, без номера

- **Тип:** decision
- **Контекст:** генерация уроков и перекрёстные ссылки между модулями
- **Решение:** в учебном контенте ссылаться на модуль по имени, не по порядковому номеру.
- **Почему:** модули переносят и перенумеровывают — так m2 («Алгоритмика») разделили на «Алгоритмика: ядро» и «Алгоритмика: прикладное», и номера модулей 3+ сдвинулись. Номера в текстах ломаются.
- **Как применить:** при генерации уроков указывать только имя модуля; где возможно — обойтись без упоминания модуля вовсе.
